# インタビュー版「100の質問」

調査日: 2026-11-28

## アイデア

一般の人に向けた「100の質問」系の Web は流行った。そのインタビュー版を作る。

| | 100の質問 | インタビュー版 |
|---|---|---|
| 質問 | 固定のリスト | 前の答えを受けて深掘りする（「それはなぜ？」「具体的には？」） |
| 回答 | テキスト | 声や動画 |
| 出来上がるもの | 回答の一覧ページ | 記事、音声、短い動画 |

面白さの核は聞き返し。LLM がこれをやるので、以前は作れなかった種類のサービスになる。

## 既存のサービス

既存は2方向に偏っている。軽いノリで一般の人が遊んで共有するものは、軽く探した範囲では見当たらない（日本の個人向けは深く調べ直す余地あり）。

### 自分史・回想録系（海外。家族・高齢者向けが中心）

- [Biography Studio AI](https://www.producthunt.com/posts/biography-studio-ai): 声でインタビューされ、本・オーディオブック・ポッドキャストに出力。声の複製対応
- [Iloomi](https://apps.apple.com/app/id6467228839): 聞き返しつきで一人称の物語を書く
- [Times of My Life](https://apps.apple.com/in/app/id6745264350): 「仮想の伝記作家」。PDF・音声・動画で出力
- [Memorias](https://www.producthunt.com/posts/memorias-3): 話した人生を本にする。細部をでっち上げないのが売り
- [HereAfter AI](https://apps.apple.com/app/id1626176069): 本人の録音した声で答える音声の記録庫
- [ToldByMe](https://apps.apple.com/app/id6760141562): AI ガイド付きインタビュー + 音声入力
- StoryWorth: 毎週メールで質問が届き1年で本になる（記憶からの補足）

### 法人・編集部向け（日本にもある。AI は聞き手ではなく制作の効率化）

- [note「AI執筆サポート」](https://www.help-note.com/hc/ja/articles/36010453947033-AI%E5%9F%B7%E7%AD%86%E3%82%B5%E3%83%9D%E3%83%BC%E3%83%88%E3%81%A7%E5%8E%9F%E7%A8%BF%E3%82%92%E4%BD%9C%E6%88%90%E3%81%99%E3%82%8B%E6%96%B9%E6%B3%95)（note pro）
- [StoryHub インタビュー](https://ascii.jp/elem/000/004/371/4371713/)
- [sonata](https://www.gamebusiness.jp/article/2026/03/23/26475.html)（2026年3月に正式版）
- ユーザー調査で AI が聞き手になるもの: Listen Labs、Outset など

### 空いていそうなところ

| | 既存 | インタビュー版「100の質問」 |
|---|---|---|
| 対象 | 家族、高齢者、企業 | 一般の若い人、SNS 利用者 |
| 雰囲気 | 真面目、残すため | 軽い、遊び |
| 出力 | 本、PDF | 共有したくなるページ、画像、短い音声・動画 |
| 広がり方 | 個人で完結 | 友達が見て自分もやる |

差別化の軸: 聞き手のキャラ、テーマの軽さ、SNS で映える出力。

## つくるには

### 難易度（段階で変わる）

1. **テキストで聞き返すだけ（簡単。数日で動く）**
   - テーマを選ぶ → AI が1問ずつ聞いて深掘り → 最後に記事風の Q&A ページを生成して共有 URL を出す
   - 必要なもの: LLM の API、データベース、共有ページ、OGP 画像
2. **声で答える（中くらい）**
   - 録音 → 文字起こし（Whisper 等）→ 次の質問、を交互に。押して話す方式なら素直に作れる
   - 本人の声を残せるので音声インタビューとして公開できる
3. **音声のまま会話する（中〜やや難しい）**
   - OpenAI Realtime、Gemini Live などのリアルタイム音声 API
   - 相づち、割り込み、沈黙の扱いが体験の質を左右し、調整に時間がかかる。費用も分単位で効く
4. **動画で撮って編集して公開する（難しい）**
   - 録画 → 間を詰める → 字幕 → ハイライト切り出し。[動画を上げると複数の形に仕上げるツール](video-to-multi-output.md) の流れがそのまま要る
   - サーバー側の処理が重く、保存容量の費用もかかる

### 技術より手間がかかるところ

- 費用: 音声の会話・動画処理は1人あたりの原価がテキストより大きい。無料公開なら回数の上限が要る
- 個人情報: 聞き返されると思わぬことまで話す。公開前に本人が確認・編集できる画面は必須
- 荒らし・不適切な内容: 共有ページを持つ以上、内容の判定と通報の仕組みが要る
- インタビュアーの人格設計: 質問の質と聞き返しの上手さで面白さが決まる。一番作り込みがいのあるところ

### 始め方の案

まず段階 2（押して話す音声 + 聞き返し + 記事ページ生成）で試作し、聞き返しが面白いかを確かめる。面白ければ段階 3・4 に広げる。

先に決めること:

- テーマ（自分史、仕事、推し語りなど）
- 出来上がったものをどこで共有させるか（SNS 向けの画像、記事ページ、音声）
