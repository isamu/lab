# 動画を上げると複数の形に仕上げるツール

調査日: 2026-11-28（知識ベースが中心。料金・機能は変わりうるので使う前に確認）

## アイデア

動画を1本上げると、次の4つが出てくる。

- 適当に編集していい感じにする → 動画
- 音声だけにして、間合いや効果音を入れる → ポッドキャスト
- サムネを作る
- テキストに書き起こす → ブログ

## 既存のサービス

4つを1本でそれなりにこなせるのは Descript くらい。

| サービス | 動画を自動で整える | 音声だけにする | サムネ | 書き起こしからブログ |
|---|---|---|---|---|
| Descript | ◎ 文字起こしを消すと映像も切れる。えー・あー・無音の削除、AI エージェント（Underlord） | ◎ 音声で書き出し。Studio Sound で音質補正。効果音も置ける | △ | ○ ショーノート・ブログの下書き |
| Riverside | ○ Magic Clips で短尺を切り出す | ○ | △ | ○ ショーノート・要約 |
| Podcastle | ○ | ◎ | △ | ○ |
| Vrew | ○ 無音カット・字幕 | △ | × | ○ 文字起こしの書き出し |

一つの工程に強いもの:

- 短尺の切り出し: Opus Clip, Vizard, CapCut
- 音声の仕上げ: Auphonic（音量の均し・ノイズ除去・無音カット。API あり）、Adobe Podcast Enhance
- 書き起こしからの記事化: Castmagic
- サムネ: Canva の AI 機能、サムネ専用の画像生成サービス

## つくるには

1本で全部やる CLI は見当たらない。OSS の部品を組み合わせる。

```
入力動画
 ├─ whisper / faster-whisper / WhisperX   … タイムスタンプ付きで書き起こし（WhisperX は話者分離つき）
 ├─ auto-editor                           … 無音・間延びを自動カット
 ├─ ffmpeg                                … 音声の抜き出し、効果音・BGM の合成（amix / adelay）、loudnorm で音量をそろえる
 ├─ LLM                                   … 書き起こしからブログ記事、チャプター、効果音を入れる位置の指示
 └─ 画像生成 API + ffmpeg でフレーム抽出    … サムネ
```

- 間合いや効果音は、LLM に書き起こしを読ませて「ここに間、ここで効果音」という JSON を出させ、ffmpeg で合成する形が組みやすい
- 音声の仕上げだけ Auphonic の API に出す手もある

手元にある部品:

- `mulmoterminal-video-edit` スキル: ffmpeg でカット、字幕、テロップ
- mulmocast: 台本から音声・動画を生成。LLM が作った台本をポッドキャストにする部分に使える
