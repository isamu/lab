# Glossary

<!-- stet: bold-density — a glossary, so the bold is on purpose -->
**Build**: one run of the steps that make an image. **Cache**: output kept from an earlier build. **Image**: a snapshot of the files a container starts from. **Layer**: the change one step makes to an image. **Tag**: a name given to one image. **Registry**: a server that stores images. **Volume**: storage kept outside a container.
