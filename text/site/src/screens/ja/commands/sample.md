# CI でテスト用のデータを使い回す

結合テストは、毎回同じテスト用のデータを作り直していて、時間の大半をそこに使っていました。

## 何を変えたか

データを作るのに要るもの（スキーマ・生成スクリプト・初期値・設定・環境変数・依存の一覧・Node の版）を一つのハッシュにまとめ、キャッシュの鍵にしました。

鍵が変わらない限りデータを作り直さずにキャッシュから戻すようにしたので、ふつうの pull request でデータを作る段がほとんどの場合で数秒のうちに終わるようになり、テストを待つ時間がずいぶん短くなったとチームの皆が感じていて、週に何度も聞いた待ち時間への不満も、この仕組みを入れてからの一か月のあいだには一度も聞かなくなりました。

## 結果

ふつうの pull request で、18 分かかっていたテストが 7 分で終わるようになりました。
