# 用語集

<!-- stet: bold-density — 用語集なので太字が多いのは意図的 -->
**ビルド**は、イメージを作る手順を一通り動かすことです。**キャッシュ**は、前のビルドで作ったものを取っておいたものです。**イメージ**は、コンテナを起動するときのもとになるファイルのまとまりです。**レイヤー**は、手順の一つがイメージに加えた変更です。**タグ**は、イメージに付けた名前です。**レジストリ**は、イメージを置いておくサーバーです。**ボリューム**は、コンテナの外に残しておく保存場所です。**ネットワーク**は、コンテナどうしをつなぐ道筋です。**ポート**は、外からコンテナに届く入り口の番号です。
