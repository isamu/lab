# ウェブサイト保守業務委託契約書

株式会社みなと商事（以下「甲」という。）と、合同会社ささき制作（以下「乙」という。）は、次のとおり契約を結ぶ。

## 第1条（目的）

甲は、甲のウェブサイトの保守業務（以下「本業務」という。）を乙に委託し、乙はこれを受託する。

## 第2条（契約期間）

契約期間は、2026年11月1日から2026年10月31日までとする。

## 第3条（委託料）

本業務の委託料は、次のとおりとする。

| 項目 | 金額 |
| --- | --- |
| 月次の更新作業 | 50,000円 |
| サーバーの監視 | 20,000円 |
| 合計 | 80,000円 |

甲は、毎月の委託料を翌月末日までに乙に支払う。支払の方法は、第9条に定める。

## 第5条（報告）

乙は、毎月の作業の内容を、翌月5日までに甲に報告する。初回の報告日は、2026年12月5日（月）とする。

## 第6条（定義）

この契約において「本業務」とは、甲のウェブサイトの更新、監視及び障害の対応をいう。

## 第7条（協議）

この契約に定めのない事項は、甲乙が誠実に協議して決める。
