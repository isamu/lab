# リファレンス：chaff が見つけられること

chaff が見つけられることを、ルールごとに一覧にしました。
どのルールにも、指摘される文の例と、その例に chaff をかけたときの実際の出力を載せています。
ルールの名前を押すと、そのルールの詳しいページに進みます。
チームの決まりに合うルールが無いときは、[ルールを足す](./adding-rules) を読みます。
ルールが何を根拠にしているかは、[参考文献](./bibliography) にまとめました。

## 一覧の見かた

| 印 | 意味 |
| --- | --- |
| 既定で動く | 何も設定しなくても動きます |
| 試験中 | 既定では動きません。下の「試験中のルールを動かす」の方法で動かします |
| chaff.yaml に書いたとき | チームが `chaff.yaml` に書いた語や見出しだけを見ます。書かなければ何も言いません |
| chaff test | 意味を読まないと決まらない検査です。`npx chaffjs test` で AI が読みます |
| 日本語 / 英語 | そのルールが見る文書の言語です |

例の出力は、サイトを作るたびに chaff をかけ直して作っています。
かけるときのジャンルは `business/report` で、試験中のルールも動かしています。
ほかの設定で試した例には、その `chaff.yaml` を添えました。
出力の頭の `1:7` は、例の文の 1 行目 7 字目という意味です。

## 試験中のルールを動かす

試験中のルールは、誤った指摘を減らしている途中なので、既定では止めています。
全部を動かして見るときは、`--experimental` を付けます。

```bash
npx chaffjs --experimental 報告書.md   試験中のルールも動かして見る
```

一つだけ動かすときは、`chaff.yaml` の `rules` に強さを書きます。

```yaml
rules:
  doubled-word: normal
```

Markdown の記法を見るルール（見出しの深さ、画像の代替テキスト、リンクの行き先など）は Markdown の文書でだけ動きます。
`.txt` では「Markdown の文書ではないため」と出して止まります。

ジャンルによっては、試験中のルールを既定で動かします。
どのジャンルで何が動くかは、[ジャンルのページ](../../genres/)にあります。

## 意味を読む検査は chaff test で

結びに中身があるか、数字に根拠があるか、リスクを書いたかは、どれも意味を読まないと決まりません。
chaff は機械で箇所を絞り込み、`npx chaffjs test` でその箇所だけを AI に送って読ませます。
`npx chaffjs test --dry-run 報告書.md` なら、何を送るかを、送る前に画面で確かめられます。
AI を使わなくても、ほかの検査はすべて動きます。
