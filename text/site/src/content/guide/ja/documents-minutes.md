# 議事録でできること

議事録は、会議で何が決まり、誰がいつまでに何をするのかを残す文書です。
chaff は、日付と曜日の食い違い、議題の番号の抜け、予告した数と項目の数の食い違いを機械で見つけます。
ジャンルは `business/meeting-notes` です。議事要旨も同じジャンルで見ます。

## 議事録でよく起きること

議事録は、会議の途中や直後に急いで書きます。前回の議事録を写して作ることも多くあります。

| 崩れ | 例 |
| --- | --- |
| 曜日が合わない | 前回の日時を写し、日付だけを直した |
| 議題の番号が飛ぶ | 議題 3 を飛ばしたまま、番号を振り直していない |
| 数が合わない | 「決定事項は次の 3 点です」の下に、2 つしか書いていない |
| 文末が混ざる | 「〜した。」と「〜しました。」が、一つの議事録に混ざる |
| 誰が決めたか書いていない | 「B 案で進めることが決定された」 |

最後の 2 つは、後から読む人が「誰が決めたのか」を確かめられなくなります。

## chaff が見ること、見ないこと

このジャンルで見る主なルールは、次のとおりです。どれも試験中で、`--experimental` を付けたときに動きます。

| ルール | 見つけるもの |
| --- | --- |
| `date-weekday-mismatch` | 日付に添えた曜日が、暦と合っていない所 |
| `numbering-gap` | 議題の番号の抜けや重なり |
| `announced-count-mismatch` | 予告した数と、すぐ下の箇条書きの数の食い違い |
| `no-mixed-desumasu` | です・ます と だ・である の混ざり |
| `latin-spacing` | 日本語と英数字の間の空白の、付け方の揺れ |

見ないことも決めてあります。

- 発言の中身が正しいかは見ません。会議で本当にそう決まったかは、出席した人が確かめます。
- 宿題に担当者が書いてあるかは見ません。表の空いた欄は、人が見て埋めます。
- 年を書いていない日付の曜日は確かめません。宿題の期限の「10月14日」は、暦と照らしません。
- 誰がしたのかが無い受け身（「決定された」）は見ません。議事録は会議がしたことを書くので、主は形の上では会議です。指摘すると、ほとんどの議事録に出てしまいます。

## かけてみる

準備がまだなら、先に[準備する](./documents#準備する)を済ませます。
次の議事録を `gijiroku.md` という名前で保存しました。

```markdown
# 第12回 サイト改修定例 議事録

- 日時：2026年10月7日（火）10:00〜11:00
- 場所：本社 3階 会議室B
- 出席：山田（営業部）、鈴木（情報システム部）、佐々木（ささき制作）
- 記録：鈴木

## 1. 前回の宿題の確認

前回の宿題は、すべて終わっていました。問い合わせフォームの不具合は、9月30日に直しました。

## 2. トップページの案

佐々木から、トップページの案を 2 つ説明した。A 案は写真を大きく使い、B 案は新着情報を上に置く。

意見交換の結果、B 案で進めることが決定された。

## 4. 公開の日程

公開日は11月20日とする。ただし、KPI の見直しの結果によっては、公開日を後ろにずらすことも検討されることとなった。

## 決定事項

決定事項は次の 3 点です。

- トップページは B 案で進める
- 公開日は 11 月 20 日とする

## 次回までの宿題

| 担当 | 内容 | 期限 |
| --- | --- | --- |
| 佐々木 | B 案のデザインを仕上げる | 10月14日 |
| 鈴木 | サーバーの移行の手順を確認する | 10月14日 |
| | 写真の使用許可を取る | 10月10日 |

次回は 2026年10月14日（水）10:00 から、同じ会議室で行う。
```

`--genre` を付けなくても、chaff は「決定事項」の見出しを見て、議事録だと見分けます。
画面の 1 行目の「ジャンルは内容から」が、その印です。
何も付けずにかけると、指摘は出ません。議事録で役に立つルールは、どれも試験中だからです。

```
$ npx chaffjs gijiroku.md --compact

gijiroku.md   business/meeting-notes · 日本語   ジャンルは内容から


指摘 0 件、動いていない rule 95 件
```

`--experimental` を付けて、試験中のルールも動かします。
`--compact` は、1 件を 2 行にまとめて出す印です。

```
$ npx chaffjs gijiroku.md --experimental --compact

gijiroku.md   business/meeting-notes · 日本語   ジャンルは内容から

  3:6     error   「2026-10-07」は水曜日です（火曜日と書いてあります）
                  date-weekday-mismatch
  4:10    warning 日本語と前の数字のあいだを詰めています（この文書はふつう空ける。4 箇所のうち 1 箇所が違う）
                  latin-spacing
  4:15    warning 日本語と英字のあいだを詰めています（この文書はふつう空ける。7 箇所のうち 1 箇所が違う）
                  latin-spacing
  10:1    warning この文だけ他と文末の調子が違います（本文の中で 3 文）
                  no-mixed-desumasu
  10:20   warning この文だけ他と文末の調子が違います（本文の中で 3 文）
                  no-mixed-desumasu
  18:1    error   「2」の次が「4」です（3 番目のはず）
                  numbering-gap
  24:1    warning この文だけ他と文末の調子が違います（本文の中で 3 文）
                  no-mixed-desumasu
  24:9    warning 「3 点」と予告していますが、すぐ下の箇条書きは2項目です
                  announced-count-mismatch

指摘 8 件、動いていない rule 23 件
```

## 指摘の意味と直しかた

| 行 | 指摘 | 意味 | 直しかた |
| --- | --- | --- | --- |
| 3 | `date-weekday-mismatch` | 2026年10月7日は水曜日です | 曜日を「（水）」に直します。会議が火曜日だったなら、日付を直します |
| 4 | `latin-spacing` | ほかは「B 案」と空けているのに、「3階」「会議室B」だけ詰めています | 「3 階」「会議室 B」と空けて揃えます |
| 10、24 | `no-mixed-desumasu` | 議事録の多くは「〜した。」なのに、この 3 文だけ「〜ました。」「〜です。」です | 「〜した。」「〜である。」に揃えます |
| 18 | `numbering-gap` | 議題 2 の次が 4 です | 3 に振り直すか、抜けた議題 3 を足します |
| 24 | `announced-count-mismatch` | 「3 点」と書いたのに、2 つしかありません | 抜けた決定事項を足すか、「2 点」に直します |

議事録が「〜した。」と「〜しました。」のどちらで書くべきかを、chaff は決めません。
一つの議事録の中で少ないほうを指摘し、多いほうに揃えるよう勧めます。

16 行目の「決定された」と 20 行目の「検討されることとなった」は、誰が決め、誰が検討するのかが無い受け身です。
このジャンルでは受け身を指摘しないので、人が読んで確かめます。
宿題の表の 3 行目には、担当者がいません。これも chaff は見ないので、人が見て埋めます。

## 意味を読む検査は AI に頼む

`npx chaffjs test` を使うと、気をつけることを書いていないかを AI に読ませます。
`npx chaffjs test gijiroku.md --dry-run` で確かめると、1 箇所を送ると出ます。
議事録で何を残すべきかは、会議ごとに違います。AI の答えを読んで、人が決めます。

## chaff.yaml の始め方

議事録を置くフォルダに、次の `chaff.yaml` を置きます。

```yaml
genre: business/meeting-notes
language: ja

rules:
  date-weekday-mismatch: normal
  numbering-gap: normal
  announced-count-mismatch: normal
  no-mixed-desumasu: normal
  required-sections: normal

required_sections:
  - 決定事項
  - 宿題
```

この `chaff.yaml` を置くと、`npx chaffjs gijiroku.md --compact` だけで、`latin-spacing` 以外の指摘が出ます。
`required_sections` には、議事録に必ず要る見出しを書きます。
「決定事項」や「宿題」の見出しが無い議事録は、`required-sections` が指摘します。
書き方は [設定](./configuration) の「社内用語と必須の見出しを決める」にあります。
