# AI エージェントを並列で動かした一か月

コーディング用のエージェントを4つ、それぞれ別の git worktree で同時に動かしています。最初の一か月でわかったことを書きます。

## 得たもの

- 4枚のチケットが一度に進みます。
- エージェントの終わりを待たずに、次の作業を始められます。
- 直し方が決まらないときは、2つのエージェントに別々のやり方を試させ、よいほうの差分を残します。

## 払ったもの

エージェントごとに作業コピーとテストとレビューが要ります。8コアのノート PC では、5つ目を足すと、どのテストもそれまでより遅くなりました。

いまはエージェントを4つまでにし、1つに1ファイルだけを任せています。2つのエージェントが同じ関数を書き換えることはありません。

## 始めるなら

関係のないチケット2枚に、エージェント2つから始めます。差分を読む時間が自分で書く時間より短くなってから、3つ目を足します。
