# @chaff-lang/en

Official English adapter for [chaff](https://www.npmjs.com/package/chaff). Bundled with `chaff`; you do not need to install it yourself.

It provides:

- Sentence splitting (handles `Dr.`, `e.g.`, `U.S.`, `$3.50` without breaking the sentence)
- L2 lexicons (empty intensifiers, padded openings, cliched closings)

To add a language: official adapters are `@chaff-lang/<lang>`, third-party ones are `chaff-lang-<lang>` — the same split as `@typescript-eslint/*` and `eslint-plugin-*`.
