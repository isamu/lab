# 結びで励ます・請け合う文が重なる（`closing-exhortation`）

**こんな文書に:** ブログ、社内報のコラム、体験記。とくに AI に下書きを頼んだ文章の結びに出やすい型です。

## 元の文章

```markdown chaff-before
# 家計簿を三か月つけてみた

家計簿をつけ始めたのは、春に通帳を見て、思ったより残っていなかったからです。
レシートを貼るのは続かないと分かっていたので、夜に一回だけ、その日に使った額を手帳に書くことにしました。

三か月たって分かったのは、外食よりも、コンビニで買う飲み物のほうが多かったことです。
一回は百数十円でも、月に四十回近く買っていました。

家計簿は、思ったほど手間がかかりません。ぜひ今日から始めてみてください。きっと、毎月のお金の流れが見えてくるはずです。
```

## 直した文章

```markdown chaff-after
# 家計簿を三か月つけてみた

家計簿をつけ始めたのは、春に通帳を見て、思ったより残っていなかったからです。
レシートを貼るのは続かないと分かっていたので、夜に一回だけ、その日に使った額を手帳に書くことにしました。

三か月たって分かったのは、外食よりも、コンビニで買う飲み物のほうが多かったことです。
一回は百数十円でも、月に四十回近く買っていました。

いまは水筒を持って出るようにしています。手帳に書くのは一日一行で、かかるのは一分ほどです。
```

## 直し方

元の結びは「ぜひ今日から始めてみてください」「きっと〜見えてくるはずです」と、読み手を励ます文が二つ続きます。
一つなら人もよく書きますが、二つ重なると、どの記事にも付けられる結びになり、生成された文章によくある型に見えます。
何より、読み手が持ち帰れる中身がありません。

直した文章では、励ましを消して、本文で分かったことの続き（水筒を持って出るようにした）と、手間が実際にどれくらいか（一日一行、一分ほど）を書きました。
「手間がかからない」と言う代わりに、どれくらいかかるかを書くと、読み手は自分で試すかどうかを決められます。

## 設定

結びに励ます文が2つあると指摘します。

```yaml chaff-settings
rules:
  closing-exhortation: strict
```

`strict` にすると、1つでも指摘します。`relaxed` は3つからです。
「ぜひご検討ください」のような、ビジネスの文書の普通の結びは指摘しません。
法令・契約（`legal`）、手順書（`docs`）、講演（`speech`）、文学（`literature`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain
$ npx chaffjs explain closing-exhortation --genre blog/essay

  結びで励ます・請け合う文が重なる   (closing-exhortation)

  「ぜひ〜してみてください」「きっと〜はずです」「You've got this」で結ぶ記事は、中身の代わりに読み手を励まして終わります。1 つなら人も書きますが、結びに重なると、生成文によくある型に見えます。

  直しかた: 励ましを消して、本文で分かったことのうち一番持ち帰ってほしい 1 つを書いてください。

  設定できる値:
    strict   結びの励ます・請け合う文が 1 個あれば指摘
  → normal   結びの励ます・請け合う文が 2 個あれば指摘
    relaxed  結びの励ます・請け合う文が 3 個あれば指摘

  いまは normal です。

  変える:  npx chaffjs relax closing-exhortation --why "理由"
```
