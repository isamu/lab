# ファイルによって書き方が違う語（`cross-doc-term-variant`）

**こんな文書に:** 何ページにも分かれた説明書、社内の手引きの束、ヘルプのサイト。ページごとに書いた人や書いた時期が違うと、一つのページの中ではそろっていても、ページどうしで書き方が分かれます。

## 元の文章

```markdown chaff-before
# 控えを取る

毎週金曜日の夕方に、共有フォルダの控えを取ります。

1. 管理画面を開き、「控え」を選びます。
2. 控えを置くサーバを選びます。
3. 「今すぐ取る」を押します。

終わると、サーバの一覧に今日の日付が出ます。
```

```markdown chaff-file setup.md
# 初めての設定

最初に、共有フォルダを置くサーバーを決めます。

1. 管理画面を開き、「設定」を選びます。
2. 使うサーバーの名前を入れます。
3. 「保存」を押します。

サーバーの名前は、情報システム課に聞いてください。
```

```markdown chaff-file restore.md
# 控えから戻す

まちがえて消したファイルは、過去30日分の控えから、5分ほどで戻せます。

1. 管理画面を開き、「戻す」を選びます。
2. 控えを置いたサーバーと日付を選びます。
3. 戻したいファイルに印を付けて、「戻す」を押します。
```

## 直し方

この説明書は三つのページに分かれています。「初めての設定」と「控えから戻す」は「サーバー」と書き、「控えを取る」のページだけが「サーバ」と書いています。
一つのページの中ではそろっているので、ページを一枚ずつ読み直しても気づきません。けれども読み手は、ページをまたぐと別のものかと迷います。サイトの中を「サーバー」で検索すると、このページだけ出てきません。

少ないほうのページを、ほかの二つと同じ「サーバー」に直しました。
chaff は、一度に渡したファイルどうしを比べます。説明書の束をまとめて `npx chaffjs docs/` のように渡すと、この揺れが見つかります。

## 設定

```yaml chaff-settings
prefer:
  サーバ: サーバー
rules:
  cross-doc-term-variant: strict
```

チームで寄せる書き方を決めているなら、`prefer` に「使わない書き方: 使う書き方」の組を書いておきます。ファイルの数の多い少ないに関係なく、`preferred-term` がどのファイルでも「サーバ」を指します。
ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
文芸のジャンルでは、はじめから動きません。比べる書き方は、カタカナ語の語末の「ー」、イギリスとアメリカの綴り、英字の語のハイフンの有無の三つです。
