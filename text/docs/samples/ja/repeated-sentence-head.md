# 同じ書き出しの文が続く（`repeated-sentence-head`）

**こんな文書に:** お店や施設の紹介、製品の案内、ブログの記事。紹介したいものを主語にして、文ごとに同じ書き出しを繰り返しがちな文章です。

## 元の文章

```markdown chaff-before
# 町の図書館が新しくなりました

駅の北口にある市立図書館が、半年の工事を終えて、今月から開館しています。

新しい図書館は、建物の一階に子ども向けの本のコーナーを広く取っています。
新しい図書館は、二階に静かに勉強できる席を四十席用意しています。
新しい図書館は、平日の夜八時まで開くことになりました。
新しい図書館は、借りた本を駅の返却ポストにも返せるようになりました。

利用のカードは、これまでのものがそのまま使えます。
```

## 直した文章

```markdown chaff-after
# 町の図書館が新しくなりました

駅の北口にある市立図書館が、半年の工事を終えて、今月から開館しています。

一階には子ども向けの本のコーナーを広く取り、二階には静かに勉強できる席を四十席用意しました。
平日は夜八時まで開いています。
借りた本は、駅の返却ポストにも返せるようになりました。

利用のカードは、これまでのものがそのまま使えます。
```

## 直し方

元の段落は、四つの文がどれも「新しい図書館は、」で始まっています。
読み手は、同じ書き出しが続くうちに文の切れ目を見失い、後ろのほうの文を読み飛ばします。
何が新しくなったのかは、それぞれの文の後半にしか書かれていません。

直した文章では、主語を前の段落に任せ、場所や時間から書き始めました。
一階と二階の話は一つの文にまとめ、「平日は」「借りた本は」と、文ごとに知らせたい中身が頭に来ます。

箇条書きの項目どうしや、見出しをまたいだ文は数えません。

## 設定

同じ書き出しの文が三つ続くまでなら指摘しません。`strict` にすると二つ、`relaxed` にすると四つまでです。
法務・文学のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  repeated-sentence-head: relaxed
```

見ないことにするなら `repeated-sentence-head: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax repeated-sentence-head --why "同じ主語で特徴を並べる製品の紹介のため"
```

```text chaff-explain
$ npx chaffjs explain repeated-sentence-head --genre blog/owned-media

  変える:  npx chaffjs relax repeated-sentence-head --why "理由"
```
