# 内の段の無い「並びに」「若しくは」（`connective-hierarchy`）

**こんな文書に:** 社内規程、規則、要綱、契約書。法令の書き方をまねて、改まった語を選んだつもりの所で起きやすいまちがいです。

## 元の文章

```markdown chaff-before
# 出張旅費規程

## 第1条（目的）

この規程は、従業員が業務のために出張するときの旅費について定める。

## 第2条（申請）

出張する者は、出発の5日前までに、出張申請書並びに日程表を所属長に提出する。

## 第3条（精算）

出張から戻った者は、7日以内に、領収書若しくは利用明細を添えて旅費を精算する。
```

## 直した文章

```markdown chaff-after
# 出張旅費規程

## 第1条（目的）

この規程は、従業員が業務のために出張するときの旅費について定める。

## 第2条（申請）

出張する者は、出発の5日前までに、出張申請書及び日程表を所属長に提出する。

## 第3条（精算）

出張から戻った者は、7日以内に、領収書又は利用明細を添えて旅費を精算する。
```

## 直し方

法令の書き方では、並べる語を段で使い分けます。
二つを並べるだけなら「及び」「又は」です。「並びに」「若しくは」は、並べたものをもう一段重ねるときだけ使います（A及びB並びにC、A若しくはB又はC）。

第2条は「出張申請書並びに日程表」と、二つを並べるだけなのに「並びに」を使っています。
規程を読み慣れた人は、「並びに」を見ると内の段の「及び」を探し、見つからずに止まります。
第3条の「領収書若しくは利用明細」も同じです。

直した文章では、一段の並べ方なので「及び」と「又は」にしました。
二段に重ねるつもりだったのなら、語を替えるのではなく、内の段を書き足してください。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  connective-hierarchy: strict
```

仮名の「ならびに」「もしくは」は、普通の文で一段の並べ方にも使われるので見ません。
同じ節に「及び」「又は」があれば、段の組を作ったと読んで指摘しません。鉤括弧の中の語句も見ません。
文学（`literature`）と話し言葉（`speech`）のジャンルでは動きません。
