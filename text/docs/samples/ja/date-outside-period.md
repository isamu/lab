# 書いた期間の外の日付（`date-outside-period`）

**こんな文書に:** 出張や旅行の日程、展示会や研修の案内、工事の工程表。日程を一日ずらしたときに、期間の行か日程の行の片方だけを直す、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：大阪の展示会への出張の日程

営業部のみなさま

お疲れさまです。総務課の山本です。
来月の大阪の展示会について、出張の日程が決まりましたのでお知らせします。

出張期間：2026年12月8日〜2026年12月11日

- 12月8日 新大阪に移動し、ブースの設営
- 12月9日 展示会の1日目
- 12月10日 展示会の2日目
- 12月12日 ブースの撤収と東京への移動

宿は、会場の近くのホテルを4泊で取ってあります。

どうぞよろしくお願いいたします。
```

## 直した文章

```markdown chaff-after
件名：大阪の展示会への出張の日程

営業部のみなさま

お疲れさまです。総務課の山本です。
来月の大阪の展示会について、出張の日程が決まりましたのでお知らせします。

出張期間：2026年12月8日〜2026年12月11日

- 12月8日 新大阪に移動し、ブースの設営
- 12月9日 展示会の1日目
- 12月10日 展示会の2日目
- 12月11日 ブースの撤収と東京への移動

宿は、会場の近くのホテルを3泊で取ってあります。

どうぞよろしくお願いいたします。
```

## 直し方

出張期間は12月8日から12月11日までと書いてあるのに、日程の最後の行は12月12日です。宿も4泊と書いてあるので、12月12日に戻る前の日程の名残でしょう。
出張に行く人は、期間の行で上司の承認を取り、日程の行で切符を取ります。二つが食い違ったままだと、承認された日より一日長く出張するか、切符を取り直すことになります。

直した文章では、日程の最後の行を12月11日にし、宿を3泊に直しました。期間のほうが誤りなら、出張期間を12月12日までに直します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  date-outside-period: strict
```

期間は「出張期間」「旅行期間」「会期」のような期間の語で始まる一行から読み、その後ろの同じ節の箇条書き、表の行、見出しの日付を比べます。前泊や事後の予定、申込締切や予約の日のように、期間の外に置く語がある日付は比べません。「9月18日までに」のように締め切りの語の付いた日付も比べません。期間の前後に予定を置くなら、「前泊」「事後」のようにそう分かる書き方にすると指摘されません。
文学のジャンルでは止めています。期間そのものの始まりと終わりは `date-range-reversed` が見ます。
