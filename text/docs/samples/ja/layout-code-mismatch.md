# 部屋の内訳と合わない間取り（`layout-code-mismatch`）

**こんな文書に:** 物件の案内、賃貸や売買の募集の図面の文字、不動産の広告の原稿。同じ建物の別の部屋の情報を写すと、間取りの記号と部屋の内訳が合わなくなります。

## 元の文章

```markdown chaff-before
# グランメゾン港北 502号室

駅から歩いて7分の、南向きの部屋です。

| 項目 | 内容 |
| --- | --- |
| 間取り | 3LDK |
| 間取り詳細 | LDK 14.2帖、洋室 6帖、洋室 5.5帖 |
| 専有面積 | 68.4平方メートル |
| 所在階 | 5階（10階建て） |

内見は、土曜日と日曜日の10時から17時まで受け付けています。
```

  ⚠  部屋の内訳と合わない間取り

     間取り「3LDK」の居室は3室ですが、内訳に挙げた居室は2室です
     物件の「間取り 3LDK」の頭の数は、L・D・K と納戸（S）を除いた居室の数です。同じ物件の間取り詳細が「LDK 11.5帖、洋室 6帖、洋室 5帖」なら居室は二つで、3LDK か内訳のどちらかが間違っています。別の部屋の情報を写したときや、間取りの記号だけを書き換えたときに起きます。内訳に LDK を挙げたのに間取りが 2DK のように、記号に無い L・D・K を内訳が挙げるときも言います。

## 直した文章

```markdown chaff-after
# グランメゾン港北 502号室

駅から歩いて7分の、南向きの部屋です。

| 項目 | 内容 |
| --- | --- |
| 間取り | 3LDK |
| 間取り詳細 | LDK 14.2帖、洋室 6帖、洋室 5.5帖、洋室 4.5帖 |
| 専有面積 | 68.4平方メートル |
| 所在階 | 5階（10階建て） |

内見は、土曜日と日曜日の10時から17時まで受け付けています。
```

## 直し方

「3LDK」の頭の3は、LDK のほかに居室が三つあるという意味です。けれども間取り詳細には、洋室が二つしか書いてありません。
この案内は、同じ建物の2LDK の部屋の案内を写して作りました。間取りの記号は直したのに、詳細の部屋を一つ足し忘れていました。
部屋を探す人は、家族の人数と部屋の数で物件を絞ります。三つめの部屋の広さが分からないと、子ども部屋にできるかを決められず、問い合わせか見送りになります。

直した文章では、間取り詳細に抜けていた洋室 4.5帖を足しました。
反対に、部屋が二つなら、間取りの記号を「2LDK」に直します。
chaff は、「間取り」の項目の記号と、「間取り詳細」の項目や記号の後ろの括弧に書いた部屋の内訳だけを読みます。納戸・S・サービスルームは居室に数えません。書斎のように物件で数え方の違う部屋が内訳にあれば、数を比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  layout-code-mismatch: strict
```

広告の原稿を出す前に必ず止めたいなら `strict` にします。
部屋の内訳を書いていない物件は比べません。文芸のジャンルでは、はじめから動きません。

```text chaff-explain

  直しかた: 間取りの記号と部屋の内訳を物件の図面と見比べて、間違っているほうを直してください。

  設定できる値（数える上限は無く、指摘の重さが変わります）:

  変える:  npx chaffjs relax layout-code-mismatch --why "理由"
```
