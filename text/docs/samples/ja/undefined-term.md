# 定義した語の形で書いたのに、どこにも定義が無い（`undefined-term`）

**こんな文書に:** 業務委託契約書、利用規約、覚書。条を足したり、ほかの契約から条を写したりすると、定義していない「本〇〇」が紛れ込みます。

## 元の文章

```markdown chaff-before
# ロゴ制作業務委託契約書

株式会社やまびこ書房（以下「甲」という。）と、デザイン事務所あかり（以下「乙」という。）は、次のとおり契約を結ぶ。

## 第1条（委託）

甲は、甲の新しいロゴを作る業務（以下「本業務」という。）を乙に委託する。

## 第2条（納品）

乙は、2026年12月18日までに、本業務の結果を甲に納める。

## 第3条（権利）

本デザインの著作権は、甲が委託料を払った時に、乙から甲に移る。
```

## 直した文章

```markdown chaff-after
# ロゴ制作業務委託契約書

株式会社やまびこ書房（以下「甲」という。）と、デザイン事務所あかり（以下「乙」という。）は、次のとおり契約を結ぶ。

## 第1条（委託）

甲は、甲の新しいロゴを作る業務（以下「本業務」という。）を乙に委託する。

## 第2条（納品）

乙は、2026年12月18日までに、本業務で作ったロゴ（以下「本デザイン」という。）を甲に納める。

## 第3条（権利）

本デザインの著作権は、甲が委託料を払った時に、乙から甲に移る。
```

## 直し方

この契約は、第1条で「本業務」を定義しています。第3条では「本デザイン」と、同じ「本」の付いた形で書いていますが、どこにも定義がありません。
読み手は、本デザインが納めたロゴそのものなのか、途中の案まで含むのかが分かりません。著作権が移るものの範囲が決まらないのは、契約として困ります。

納品を決める第2条で、納めるロゴを「（以下「本デザイン」という。）」と定義しました。これで第3条の本デザインが、納めたロゴを指すとはっきりします。
定義した語の書き違いなら、定義した語に直します（本成果物 → 本業務）。
chaff は、文書が「本」を付けた語を一つ以上定義しているときだけ、定義の無い「本〇〇」を最初の一か所だけ指します。

## 設定

```yaml chaff-settings
rules:
  undefined-term: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
契約（`legal/contract`）で動きます。法令や判決、特許、説明書、論文、文芸、講演のジャンルでは、はじめから動きません。
