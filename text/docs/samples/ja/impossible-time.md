# 時計に無い時刻（`impossible-time`）

**こんな文書に:** 会議や説明会の案内、集合の時刻を知らせるメール。24時間の書き方と午前・午後の書き方を一つの時刻に重ねる、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：新しい勤怠システムの説明会について

各部署のみなさま

お疲れさまです。人事課の原田です。

来月から使う勤怠システムの説明会を開きます。
説明会は12月3日（木）の午後13時から、本社の会議室Bで行います。
一時間ほどで終わる予定です。
ノートパソコンをお持ちの方は、当日に持ってきてください。

よろしくお願いします。
```

## 直した文章

件名：新しい勤怠システムの説明会について

## 直し方

「午後13時」は時計にありません。午後1時のつもりで、24時間の書き方の「13時」に「午後」を重ねたのでしょう。
多くの人は察して午後1時に来ますが、「午後3時」の打ち間違いかもしれないと迷う人も出ます。集まる時刻は、迷う余地の無い書き方にします。

直した文章では、「午後1時」にしました。「13時」と書いてもかまいません。二つの書き方を一つの時刻に混ぜないことが大事です。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  impossible-time: relaxed
```

午前・午後を付けた時は12まで、分と秒は59までなので、どのジャンルでも動きます。午前・午後を付けない「25:00」「26時」は、深夜の番組表のように24を超えて数える書き方があるので言いません。「1:75」のような縮尺や比も時刻と読みません。
