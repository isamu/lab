# 起点を言う「より」（`yori-as-from`）

**こんな文書に:** 社内の案内、お知らせ、役所や学校の文書。改まった調子で書くと、「12月8日より受付を始めます」「担当者よりご連絡します」と、起点を「より」で書きます。

## 元の文章

```markdown chaff-before
件名：経理の窓口の場所が変わります

社員のみなさま

お疲れさまです。経理課の上田です。

経理の窓口は、2階から4階の402号室に移ります。
新しい窓口では、12月8日（月）より受付を始めます。
受付の時間は、これまでと同じ午前10時から午後4時までです。
移る前の週は、引っ越しの作業があるため、窓口を閉めます。
その週に急ぎの精算がある方には、担当者よりご連絡します。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：経理の窓口の場所が変わります

社員のみなさま

お疲れさまです。経理課の上田です。

経理の窓口は、2階から4階の402号室に移ります。

受付の時間は、これまでと同じ午前10時から午後4時までです。
```

## 直し方

「12月8日（月）より受付を始めます」「担当者よりご連絡します」の「より」は、時と人の起点を言っています。公用文の書き方では、「より」は比べるときだけに使い、起点は「から」で書きます。
同じメールに「2階から4階の402号室に移ります」と「から」もあるので、読み手は「より」と「から」を書き分けた理由があるのかと考えます。

直した文章では、二つの「より」を「から」にしました。「昨年より増えた」のような比べる「より」は、chaff は指しません。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  yori-as-from: strict
```

「より」の後に、始まり・送り・来ることを言う語（開始、連絡、参る）が続くときだけ指します。「により」「より一層」と、鉤括弧で引いた中は見ません。
プレスリリース（`business/press-release`）では、「12月1日より提供を開始いたします」が決まった書き方なので止めています。文学と話し言葉のジャンルでも止めています。
