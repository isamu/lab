# 予約番号などの文字の入れ違い（`reference-number-variant`）

**こんな文書に:** 予約の確認メール、受付の控え、注文の確認書。同じ番号を何度も書き写すうちに、隣り合う二つの文字が入れ違います。

## 元の文章

```markdown chaff-before
件名：ご宿泊の予約を承りました

山田 太郎 様

このたびは、ホテルみなと坂をご予約いただき、ありがとうございます。
次のとおり、ご予約を承りました。

予約番号：MN-48215

- ご宿泊日：2026年12月18日から1泊
- お部屋：禁煙のツインルーム
- ご人数：大人2名

ご予約を変えたいとき、取り消したいときは、予約番号 MN-48251 をフロントにお伝えください。

どうぞよろしくお願いいたします。

ホテルみなと坂 フロント
電話 045-000-0000
```

## 直し方

上の予約番号は「MN-48215」、取り消しの案内の予約番号は「MN-48251」です。最後の二つの数字が入れ違っています。
お客さまがどちらを伝えればよいか分からず、違う番号を伝えると予約が見つかりません。隣り合う二つの文字の入れ違いは、打ち間違いでいちばん多い形です。

予約の記録を確かめて、案内のほうの番号を「MN-48215」に直しました。
chaff は、「予約番号」「受付番号」のような同じ種類の語のすぐ後ろに書いた番号どうしを比べ、隣り合う二つの文字だけが入れ違った番号を指します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」になります。`relaxed` にしても「注意」のままです。

```yaml chaff-settings
rules:
  reference-number-variant: strict
```

数字を4つ以上含む英数字の並びだけを番号と見ます。予約番号と受付番号のように種類の違う番号、一文字だけ違う番号、離れた文字の入れ違いは指しません。
「原契約番号」「旧契約番号」のように別のものの番号を引く語の番号は、文書自身の「契約番号」とは比べません。
文芸と話し言葉のジャンルでは、はじめから動きません。
