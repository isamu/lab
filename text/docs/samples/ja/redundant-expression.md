# 重言（`redundant-expression`）

**こんな文書に:** 報告書、議事録、メール。急いで書いた文や、話すときの癖のまま書いた文に、「一番最初」「返事を返す」が入ります。

## 元の文章

```markdown chaff-before
# 新人研修の振り返り

## 研修の流れ

今年の新人研修は、4月7日から三週間、本社で行いました。
一番最初の週は、会社の仕組みと、社内の道具の使い方を学びました。
二週目からは、部署ごとに分かれて、先輩の仕事に付きました。

## 新人の声

研修の後に、新人の十二人に聞き取りをしました。
「メールの書き方を、もっと早く教わりたかった」という声が多く出ました。
配属されてから、お客様への返事を返すのに時間がかかったそうです。

## 来年に向けて

来年は、メールの書き方を最初の週に入れます。
先輩に付く期間は、いまの二週間のままにします。
```

## 直し方

「一番最初の週」の「一番」と「最初」、「返事を返す」の「返事」と「返す」は、同じことを二度言っています。読み手は二つ目の語に何か意味があるのかと探して、つまずきます。

直した文章では、「最初の週」「返事をする」と、重ねた一方を外しました。文のほかの所は変えていません。外しても意味は変わりません。
「排気ガス」のように辞書が一語として載せる言い方や、「あらかじめ予約」のように強める書き方として定着したものは、chaff は指しません。

## 設定

ふだんは重言を含む文が 1 文あれば指摘し、`relaxed` にすると 2 文からになります。

```yaml chaff-settings
rules:
  redundant-expression: relaxed
```

言い回しの一覧と、重ねを外した形は、言語ごとの語彙表にあります。
文学のジャンルでは止めています。
