# 期限も担当も無い依頼（`request-without-deadline`）

**こんな文書に:** 社内外のメール、依頼の文書。調べたことを丁寧に書いたのに、最後の依頼が「ご確認ください」だけで終わる、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：忘年会の会場の候補について

総務課のみなさま

お疲れさまです。営業部の大野です。

12月の忘年会の会場について、候補を二つに絞りました。
一つは駅前にある和食店で、四十人まで入れます。
もう一つは本社のそばにある洋食店で、三十五人まで入れます。
どちらも、12月19日（金）の夜は空いていると聞いています。

候補の店の資料を添付しますので、ご確認ください。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：忘年会の会場の候補について

総務課のみなさま

お疲れさまです。営業部の大野です。

12月の忘年会の会場について、候補を二つに絞りました。
一つは駅前にある和食店で、四十人まで入れます。
もう一つは本社のそばにある洋食店で、三十五人まで入れます。
どちらも、12月19日（金）の夜は空いていると聞いています。

候補の店の資料を添付しますので、12月3日（水）までに、どちらがよいかをお知らせください。

よろしくお願いします。
```

## 直し方

会場の候補を丁寧に二つまで絞ったのに、最後が「ご確認ください」で終わっています。いつまでに、何を返せばよいのかが書かれていないので、受け取った総務課は急ぐ理由が分かりません。
忘年会の日は決まっていて、店の予約には締め切りがあります。返事が遅れると、どちらの店も埋まるかもしれません。

直した文章では、「12月3日（水）までに、どちらがよいかをお知らせください」と、期限と、返してほしいことを書きました。受け取った人は、自分が何をいつまでにすればよいのかがすぐに分かります。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  request-without-deadline: strict
```

確認・返信・提出のように、済んだかどうかが後で分かる動作を頼む文だけを見ます。期限か担当が、その文か次の文にあれば指しません。
「ご不明な点があれば、ご連絡ください」のような条件付きの申し出や、「ご了承ください」は見ません。
ビジネスの文書で動き、法務、説明書、学術、文学、話し言葉のジャンルでは止めています。
