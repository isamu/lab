# 慣用句の誤用（`idiom-misuse`）

**こんな文書に:** 研修の振り返り、社内報、ブログ、あいさつ文。気持ちを込めて書く文ほど、慣用句を使いたくなる所です。

## 元の文章

```markdown chaff-before
# 新人研修を終えて

製造部の新人、川口です。4月から3か月の研修を終えたので、振り返りを書きます。

最初の配属先の検品で、私は部品の数え間違いを二度しました。
そのとき指導役の先輩に「数える前に、箱の中を区切って並べるといい」と言われました。先輩の助言は的を得ていて、それから数え間違いは一度もありません。

研修の最後の発表では、汚名挽回のつもりで、検品の手順を一枚の図にまとめて見せました。
図は、いまも検品の棚に貼ってあります。
```

## 直した文章

```markdown chaff-after
# 新人研修を終えて

製造部の新人、川口です。4月から3か月の研修を終えたので、振り返りを書きます。

最初の配属先の検品で、私は部品の数え間違いを二度しました。
そのとき指導役の先輩に「数える前に、箱の中を区切って並べるといい」と言われました。先輩の助言は的を射ていて、それから数え間違いは一度もありません。

研修の最後の発表では、名誉挽回のつもりで、検品の手順を一枚の図にまとめて見せました。
図は、いまも検品の棚に貼ってあります。
```

## 直し方

「的を得る」は、「的を射る」と「当を得る」が混ざった形です。「汚名挽回」も、「汚名返上」と「名誉挽回」が混ざっています。
意味は通じますが、読み手には言葉を取り違えたように見え、せっかくの振り返りの中身よりも、そちらが気になってしまいます。

直した文章では、「的を射ていて」と「名誉挽回」にしました。
「汚名返上」でもかまいません。chaff は、二つの言い方を示します。

## 設定

一覧にある形が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  idiom-misuse: relaxed
```

見るのは一覧にある形だけです。辞書によって認め方が分かれる形（押しも押されもしない）は載せていません。
小説の台詞にはわざと崩した言い方があるので、文学（`literature`）のジャンルでは動きません。
