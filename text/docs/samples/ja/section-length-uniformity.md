# 節の長さが揃いすぎている（`section-length-uniformity`）

**こんな文書に:** ブログ、旅行記、README。AI に見出しを立てて書かせると、どの節も三文ずつ、同じ長さで埋まります。

## 元の文章

```markdown chaff-before

## 出かける前に

宿は二か月前に取りました。
子どもが二人いるので、駅から歩いて十分ほどの旅館で、和室に布団を敷ける部屋にしました。
新幹線は、三人掛けの席を前後二列です。

## 一日目

昼過ぎに着きました。
荷物を宿に預けて市場まで歩きましたが、海鮮丼はどの店も一時間待ちと聞いて、焼き魚の定食にしました。
夕方は川沿いを散歩しました。

## 二日目

朝いちばんに庭園へ行きました。
人の少ないうちに池のまわりを一周し、午後は美術館に入りましたが、下の子が飽きて一時間で出ました。
夜は、宿で教わったおでんの店です。

## 三日目

最後の日は雨でした。
駅の中のお土産売り場で過ごし、和菓子を職場と学校の友だちのぶんまで買うと、袋が三つになりました。
帰りの新幹線では、子どもたちはすぐ眠りました。

## かかったお金

全部で十八万円ほどです。
宿と新幹線が四人で十四万円、残りが食事とお土産と入場料で、思っていたより食事にお金がかかりました。
次は連休を外して行くつもりです。
```

## 直し方

元の文章は、五つの節がどれも三文で、長さもほとんど同じです。
けれども、書くことの量は節ごとに違うはずです。
雨でお土産売り場にいただけの三日目と、庭園と美術館とおでんの店を回った二日目が同じ長さだと、見出しごとに機械的に埋めたように見えます。

直した文章では、書くことの少ない節を短いままにしました。
三日目とかかったお金は、一文か二文です。
そのぶん、旅でいちばんよかった二日目に、人の少ない朝の庭園や、カウンターだけのおでんの店のことを書き足しています。
読み手は、節の長さから、どこが旅の中心だったのかを受け取れます。

## 設定

節の長さのばらつきが35%より小さいと指摘します。中身のある節が5より少ない文書は測りません。

```yaml chaff-settings
rules:
  section-length-uniformity: relaxed
```

`relaxed` にすると25%より小さいときだけ、`strict` なら45%より小さいときに指摘します。
測る節の数の下限は、`options` の `min_sections` で変えられます。

```yaml chaff-settings
options:
  section-length-uniformity:
    min_sections: 7
```

見出しの節の半分以上が聞き手の問いで始まるインタビューは見ません。
ビジネス文書（`business`）と仕様書（`technical/spec`）では見ません。法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでも、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain
$ npx chaffjs explain section-length-uniformity --genre blog/essay

  節の長さが揃いすぎている   (section-length-uniformity)

  見出しごとに機械的に埋めると、節の長さが揃います。書くことの量は節ごとに違うはずです。

  直しかた: 書くことの少ない節は短いままにしてください。

  設定できる値:
    strict   節の長さのばらつきが 45% 未満なら指摘
  → normal   節の長さのばらつきが 35% 未満なら指摘
    relaxed  節の長さのばらつきが 25% 未満なら指摘
    off      見ない

  オプション（chaff.yaml の options で決めます）:
    min_sections: 5   （既定）
      測る節の数の下限。節が少ないと長さのばらつきは偶然で小さく出て、人の書いた文書でも揃って見えます

  決める:  chaff.yaml に options: { section-length-uniformity: { <名前>: <値> } } を書く

  いまは normal です。

  変える:  npx chaffjs relax section-length-uniformity --why "理由"
```
