# 割引率が定価と単価から出る率と合わない（`discount-rate-mismatch`）

**こんな文書に:** 数量で値引きする価格表、まとめ買いの料金表。段を一つ足したときに、上の段の割引率を写したままにする、という形がよくあります。

## 元の文章

```markdown chaff-before
# チラシの印刷の料金

A4判で片面に刷るチラシの料金です。定価は1部12.0円です。

まとめてご注文いただくと、部数に応じて1部の単価を下げます。

| ご注文の部数 | 1部の単価 | 割引率 |
| --- | --- | --- |
| 1,000部から | 10.8円 | 10% |
| 3,000部から | 9.6円 | 20% |
| 5,000部から | 9.0円 | 20% |

送料は、どの部数でも無料です。
```

## 直した文章

```markdown chaff-after
# チラシの印刷の料金

A4判で片面に刷るチラシの料金です。定価は1部12.0円です。

まとめてご注文いただくと、部数に応じて1部の単価を下げます。

| ご注文の部数 | 1部の単価 | 割引率 |
| --- | --- | --- |
| 1,000部から | 10.8円 | 10% |
| 3,000部から | 9.6円 | 20% |
| 5,000部から | 9.0円 | 25% |

送料は、どの部数でも無料です。
```

## 直し方

定価が1部12.0円で、5,000部からの単価が9.0円なら、3.0円の値引きで割引率は25%です。表には20%と書いてあります。5,000部の段を足すときに、上の段の割引率を写したのでしょう。
単価で比べる人には問題ありませんが、割引率で比べる人には、3,000部と5,000部で値引きが変わらないように見えます。多く頼むほうが得だという、この表でいちばん伝えたいことが伝わりません。

直した文章では、割引率を25%にしました。単価のほうが誤りなら、20%に合わせて単価を9.6円に直します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  discount-rate-mismatch: strict
```

見出しが割引率と単価を言う列の、同じ行の二つの升を、定価と比べます。定価は、表の定価の列、表の外の文（定価は1部12.0円です）、「| 定価 | 12.0円 |」の行のどれかから読み、文書に一つだけのときに使います。書いた率の桁で丸めて合うものは合っていると読みます。違う定価が二つ以上あるもの、定価と単価の単位が違うものは比べません。
