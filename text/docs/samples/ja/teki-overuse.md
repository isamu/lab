# 「〜的」の多用（`teki-overuse`）

**こんな文書に:** 提案書、企画書、事業計画。言いたいことがまだ固まっていないときや、AI に下書きさせたときに、「効果的」「効率的」「積極的」が一文に重なります。

## 元の文章

```markdown chaff-before
# 店頭の在庫の数え方を見直す案

## いまの問題

各店では、閉店後に店長が在庫を紙に数えて書き、翌朝に本部へ送っています。
数え終わるまでに、毎晩一時間ほどかかります。
本部は紙の数字を打ち直すので、月に二、三回は打ち間違いが出ます。

## 案

在庫の管理を、効果的かつ効率的な仕組みに変え、店長の負担を積極的に減らします。
具体的には、各店に読み取りの端末を一台ずつ置き、棚の札を読ませて数えます。
数えた数は、そのまま本部の在庫表に入ります。

## 費用と日程

端末は一台三万円で、二十店で六十万円です。
一月に三店で試し、四月から全店で使います。
```

## 直した文章

```markdown chaff-after
# 店頭の在庫の数え方を見直す案

## いまの問題

各店では、閉店後に店長が在庫を紙に数えて書き、翌朝に本部へ送っています。

## 案

在庫を数える仕事を端末に任せ、店長が毎晩かけている一時間を十分ほどに減らします。

数えた数は、そのまま本部の在庫表に入ります。

## 費用と日程

端末は一台三万円で、二十店で六十万円です。
一月に三店で試し、四月から全店で使います。
```

## 直し方

「在庫の管理を、効果的かつ効率的な仕組みに変え、店長の負担を積極的に減らします。」には「〜的」が三つあります。どれも良さそうな性質を指すだけで、何をどう変えるのかを言っていません。読み手は、この文を読み終えても、案の中身が分かりません。
次の文が「具体的には」で始まるのは、前の文が中身を言っていない合図です。

直した文章では、「在庫を数える仕事を端末に任せ、店長が毎晩かけている一時間を十分ほどに減らします。」と、何を・どれだけ変えるのかを書きました。「具体的には」は要らなくなったので消しました。

## 設定

一文の中の「〜的」の数で見ます。ふだんは 2 個まで、`relaxed` にすると 3 個まで、`strict` にすると 1 個までです。

```yaml chaff-settings
rules:
  teki-overuse: relaxed
```

「目的」「的確」のように一語になったものや、法令が定めた語（電磁的方法）は数えません。
文学の随筆（`literature/essay`）では止めています。
