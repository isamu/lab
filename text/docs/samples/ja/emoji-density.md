# 絵文字が多い（`emoji-density`）

**こんな文書に:** お店や団体のブログ、お知らせ、メールの案内。親しみを出そうとして、文のたびに絵文字を添えがちな文章です。

## 直し方

元の案内は、ほとんどの文の終わりに絵文字が付いていて、1000字あたり26個になります。
一つ二つなら親しみが出ますが、並ぶと、時刻や参加費のような読み落としてほしくない文が、飾りの間に埋もれます。
画面を読み上げて使う人には、絵文字の名前が一つずつ読まれ、案内の中身が途切れます。

直した文章では、店の名前に添えたパンの絵文字だけを残し、ほかは外しました。
楽しさは「季節のかぼちゃパン」「店のパンとコーヒーで一休み」という中身のほうで伝わります。

chaff は文書全体の、1000字あたりの絵文字の数で見ます。日本語で500字より短い文書は測りません。
「設定→プリンター」のような語と語の間の矢印は、道筋を示す区切りなので数えません。

## 設定

ふだんは1000字あたり8個までです。`strict` にすると3個、`relaxed` にすると20個までになります。
文学のジャンルでは既定で止めています。

```yaml chaff-settings
rules:
  emoji-density: relaxed
```

見ないことにするなら `emoji-density: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax emoji-density --why "子ども向けの案内で絵文字を目印に使うため"
```
