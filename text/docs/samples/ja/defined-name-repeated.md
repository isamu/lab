# 短い呼び名を定めた名前を、あとで正式の名前のまま書いている（`defined-name-repeated`）

**こんな文書に:** 契約書、覚書、利用規約。ひな形の条文をよその契約から写すと、写した条文にだけ会社の正式な名前が残ることがあります。

## 元の文章

```markdown chaff-before
# 清掃業務委託契約書

株式会社あおば不動産（以下「甲」という。）と有限会社ひかりクリーン（以下「乙」という。）は、甲が管理する建物の清掃について、次のとおり契約を結ぶ。

## 第1条（業務の内容）

乙は、甲が指定する建物の共用部分を、毎週月曜日と木曜日に清掃する。

## 第2条（用具の保管）

乙は、清掃の用具を、株式会社あおば不動産が指定する倉庫に保管する。

## 第3条（報告）

乙は、清掃を終えた日ごとに、作業の結果を書面で甲に報告する。
```

## 直した文章

```markdown chaff-after
# 清掃業務委託契約書

株式会社あおば不動産（以下「甲」という。）と有限会社ひかりクリーン（以下「乙」という。）は、甲が管理する建物の清掃について、次のとおり契約を結ぶ。

## 第1条（業務の内容）

乙は、甲が指定する建物の共用部分を、毎週月曜日と木曜日に清掃する。

## 第2条（用具の保管）

乙は、清掃の用具を、甲が指定する倉庫に保管する。

## 第3条（報告）

乙は、清掃を終えた日ごとに、作業の結果を書面で甲に報告する。
```

## 直し方

この契約は、前文で「株式会社あおば不動産」を「甲」と呼ぶと定めています。ところが第2条だけ、正式の名前に戻っています。
契約を読む人は、ここに書かれた会社が甲と同じなのか、甲とは別の立場で出てきたのかを確かめなければなりません。争いになったとき、こうした違いは読み方の分かれ目になります。

第2条の名前を、定めた呼び名の「甲」に直しました。
署名欄のように正式の名前が要る所や、ほかの会社と並べて書く所では、正式の名前のままでかまいません。chaff は名前だけの行や、呼び名と並べて書いた行は指しません。

## 設定

```yaml chaff-settings
rules:
  defined-name-repeated: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
法務のジャンル（`legal/*`）でだけ動きます。説明書や論文、文芸、講演のジャンルでは、はじめから動きません。
