# 番号の抜け・重なり（`numbering-gap`）

**こんな文書に:** 社内規程、契約書、手順書。条を一つ削ったり、別の版から条を移したりしたあとに、番号を振り直し忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 在宅勤務規程

## 第1条（目的）

この規程は、従業員が自宅で勤務するときの手続と守るべき事項を定める。

## 第2条（対象者）

在宅勤務ができる者は、入社から6か月を経過した従業員とする。

## 第3条（申請）

在宅勤務を希望する者は、勤務する週の前週の金曜日までに、所属長に申請する。

## 第5条（勤務時間）

在宅勤務の日の勤務時間は、通常の勤務日と同じとする。

## 第6条（情報の管理）

在宅勤務をする者は、会社の資料を家族の目に触れない場所で扱う。
```

```markdown chaff-after
# 在宅勤務規程

## 第4条（勤務時間）
```

## 直し方

この規程は、第3条の次がいきなり第5条です。
検討の途中で「第4条（通信費の負担）」を削り、残りの番号をそのままにした、という形です。
読む従業員には、第4条が消えたのか、別の資料に書いてあるのか、ただの書き損じなのかが分かりません。
あとで「第5条に定める勤務時間」と引いたとき、版によって指す条がずれるおそれもあります。

直した文章では、第4条から番号を振り直しました。
削った条をわざと欠番として残すなら、「第4条（削除）」と番号だけを書いておくと、読み手にもそれが伝わります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「エラー」として出し、`relaxed` にすると「注意」になります。

```yaml chaff-settings
rules:
  numbering-gap: relaxed
```

同じ親の下で隣り合う番号だけを比べます。別の章の番号どうしや、枝番号（第3条の2）は比べません。
括弧で囲んだ番号（（1））と囲まない番号は別の並びとして比べ、手順の「1.」「2.」「4.」のような番号付きの箇条書きも、書いた番号で比べます。
見出しが「抜粋」「主な」のように一部だけを引くと言っているものは見ません。
どのジャンルでも動きます。
