# 1回の量と回数を掛けると、書いた上限を超える（`product-exceeds-maximum`）

**こんな文書に:** 薬や健康食品の説明書、肥料や洗剤の使い方、機械の運転の手引き。1回の量を改めたのに、同じ段落の「1日の最大量」を前のまま残すと、書いたとおりに使った人が上限を超えます。

## 元の文章

```markdown chaff-before
# 使い方

## 飲み方

15歳以上の方は、1回2錠を、1日3回まで水かぬるま湯で飲んでください。1日の最大量は4錠です。

次に飲むまでに、4時間以上あけてください。

## 気をつけること

ほかの痛み止めと一緒に飲まないでください。
飲んでも痛みが続くときは、医師か薬剤師に相談してください。
```

## 直した文章

```markdown chaff-after
# 使い方

## 飲み方

15歳以上の方は、1回2錠を、1日3回まで水かぬるま湯で飲んでください。1日の最大量は6錠です。

次に飲むまでに、4時間以上あけてください。

## 気をつけること

ほかの痛み止めと一緒に飲まないでください。
飲んでも痛みが続くときは、医師か薬剤師に相談してください。
```

## 直し方

「1回2錠を、1日3回まで」のとおりに飲むと、1日に6錠になります。ところが同じ段落の「1日の最大量」は4錠です。
読む人は、どちらに従えばよいか分かりません。3回目を飲んでよいのか迷う人も、上限を超えて飲んでしまう人も出ます。

この見本では、添付文書を確かめて、上限のほうが古い数のまま残っていたとして6錠に直しました。
1回の量か回数のほうが間違っているなら、そちらを直します。どれが正しいかは、chaff には決められません。書いた人が確かめます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  product-exceeds-maximum: strict
```

一つの段落に、印の付いた1回の量（1回2錠）、期間あたりの回数（1日3回）、同じ期間の上限（1日の最大量は4錠）がちょうど一つずつあり、量と上限の単位が同じときだけ比べます。
「1回1〜2錠」のような幅、錠とmgのように単位の違う量、表の中は読みません。料金の「1日の上限」は、合計より低く決めるのがふつうなので比べません。
文芸のジャンルでは、はじめから動きません。
