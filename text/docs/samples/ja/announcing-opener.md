# 予告で始まる文が多い（`announcing-opener`）

**こんな文書に:** 報告書、ふりかえり、ブログ。アンケートや結果をまとめる文章で、AI に下書きさせると「ポイントは」「注目すべきは」で始まる文が続きます。

## 元の文章

```markdown chaff-before
# 新人研修のふりかえり

今年の新人研修は、4月の三週間、十二人で行いました。
終わったあとに、新人と講師の両方にアンケートを取り、全員から答えをもらいました。

## よかったこと

ポイントは、現場の社員が講師に入った日の満足度が高かったことです。
とくに、営業の同行を一日入れた週は、五段階で平均4.6でした。
注目すべきは、同行の前日に質問を書き出す時間を取った班ほど、点が高かったことです。
質問を持って行った班は、帰ってからの報告も具体的でした。

## 直したいこと

重要なのは、座学の日が続いた二週目に、集中が切れたという声が多かったことです。
ビジネスマナーと社内の制度の説明が、三日続けて午前も午後も座学でした。
講師からも、後ろの席ほど反応が薄かったという声がありました。

来年は、座学を一日おきにして、あいだに現場の見学か演習を入れます。
同行の前日に質問を書き出す時間は、全部の班で取ることにしました。
日程の案は、5月末までに人事課でまとめて、各部の部長に回します。
```

## 直し方

元の文章は、「ポイントは、」「注目すべきは、」「重要なのは、」と、三つの段落の頭で大事なことを言うと予告しています。
予告が一つなら目印になりますが、三つ続くと、どの文も同じ重さに見えます。
読み手は予告を読み飛ばして、その後ろの中身を探すことになります。

直した文章では、予告を消して、中身から書き始めました。
「現場の社員が講師に入った日は、満足度が高く出ました」のように、文の主語が結果そのものになります。
いちばん伝えたいことが一つだけなら、その一つに予告を残してもかまいません。

## 設定

予告で始まる文が3個あると指摘します。数は文書の長さによらず、数で見ます。

```yaml chaff-settings
rules:
  announcing-opener: strict
```

`strict` にすると2個から、`relaxed` なら5個からです。
文の途中の「このポイントは」は数えません。
「大事なのは」「結論から言うと」は、生成 AI が広まる前の人の記事にも同じくらいあるので数えません。
法令・契約（`legal`）、手順書（`docs`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score report.md` で見られます。
