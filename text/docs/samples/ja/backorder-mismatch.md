# 残数が発注数量から納品数量を引いた数と合わない（`backorder-mismatch`）

**こんな文書に:** 分けて届ける品の納品書、発注残の一覧、仕入れの進み具合の報告。納品数量だけを直したときや、別の行の残数を写したときに、残数が合わなくなります。

## 元の文章

```markdown chaff-before
# 納品書（分納の1回目）

さくら文具株式会社 御中

ご注文の品のうち、在庫のある分を先にお届けします。残りの品は、11月28日にお届けする予定です。

| 品名 | 発注数量 | 納品数量 | 残数 |
| --- | --- | --- | --- |
| A4のコピー用紙 | 100箱 | 60箱 | 40箱 |
| ボールペン（黒） | 500本 | 500本 | 0本 |
| クリアファイル | 300枚 | 120枚 | 280枚 |
```

## 直した文章

```markdown chaff-after
# 納品書（分納の1回目）

さくら文具株式会社 御中

ご注文の品のうち、在庫のある分を先にお届けします。残りの品は、11月28日にお届けする予定です。

| 品名 | 発注数量 | 納品数量 | 残数 |
| --- | --- | --- | --- |
| A4のコピー用紙 | 100箱 | 60箱 | 40箱 |
| ボールペン（黒） | 500本 | 500本 | 0本 |
| クリアファイル | 300枚 | 120枚 | 180枚 |
```

## 直し方

残数は、同じ行の発注数量から納品数量を引いた数です。クリアファイルは300枚の注文に120枚を届けたので、残りは180枚です。
元の文章の「280枚」は、打ち間違えです。受け取った側は、この残数を見て次の便を待ちます。届いた品を数えた人が、次の便でさらに100枚届くと思い込むと、倉庫の場所を空けて待つことになります。

直した文章では、残数を180枚に直しました。
chaff は、列の見出しの語（発注数量、納品数量、残数、未納数、発注残）だけで、どの列が何かを決めます。列の並びは見ません。
三つの升がどれも同じ単位の整数である行だけを比べます。「未定」や空の升がある行は比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  backorder-mismatch: strict
```

納品書を送る前に必ず止めたいなら `strict` にします。
前回と今回の納品数量の列が両方ある表は、片方だけでは残りが決まらないので比べません。文芸のジャンルでは、はじめから動きません。
