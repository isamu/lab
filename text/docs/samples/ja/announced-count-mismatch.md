# 予告した数と箇条書きの数が合わない（`announced-count-mismatch`）

**こんな文書に:** 持ち物や手続きを知らせるメール、確認の項目を並べた案内。あとから項目を一つ足したのに、「次の3点」を直し忘れる、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：入社の日の持ち物について

杉本 様

お世話になっております。人事課の小野です。12月1日の入社の日について、ご案内します。

当日は、朝9時に本社の1階の受付へお越しください。
次の3点を忘れずにお持ちください。

- 年金手帳か、基礎年金番号の分かる書類
- 給与の振込先の口座が分かるもの
- 前の勤め先の源泉徴収票
- 印鑑

分からないことがあれば、このメールに返信してください。

よろしくお願いいたします。
```

## 直した文章

```markdown chaff-after
件名：入社の日の持ち物について

杉本 様

お世話になっております。人事課の小野です。12月1日の入社の日について、ご案内します。

当日は、朝9時に本社の1階の受付へお越しください。
次の4点を忘れずにお持ちください。

- 年金手帳か、基礎年金番号の分かる書類
- 給与の振込先の口座が分かるもの
- 前の勤め先の源泉徴収票
- 印鑑

分からないことがあれば、このメールに返信してください。

よろしくお願いいたします。
```

## 直し方

「次の3点」と書いたのに、すぐ下の持ち物は4つあります。印鑑をあとから足して、予告の数を直し忘れたのでしょう。
読む人は、4つのうちどれかが要らないのか、3点という数が誤りなのかを決められません。前の晩に「3点そろった」と数えた人は、印鑑を忘れて来ます。

直した文章では、予告を「次の4点」にしました。印鑑が要らないなら、項目を消して3点のままにします。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  announced-count-mismatch: strict
```

箇条書きのすぐ前の文が、「次の」「以下の」のような先を指す語か、終わりのコロンと一緒に数（3点、2つ）を書いているときだけ、いちばん外側の項目の数と比べます。「約3点」「3つ以上」のような目安の数、「次のいずれか一つ」のように選ぶ数、「第3条」のような番号は比べません。「出席者（6名）：田中、鈴木、…」のように、一行に名前を並べた所も数を比べます。
文学のジャンルでは止めています。
