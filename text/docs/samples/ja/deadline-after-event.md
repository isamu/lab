# 申込締切が催しの日より後（`deadline-after-event`）

**こんな文書に:** 講座や説明会や催しの案内、出欠を尋ねる案内状。前の回の案内を使い回して、開く日だけを新しくする、という形がよくあります。

```markdown chaff-before

地震や大雨のときに、家族でどう動けばよいかを、消防署の方から教わる教室です。小学生とその保護者の方が対象です。

日時：2026年12月12日（土）13:30〜15:30

場所：みどり台公民館 2階の大会議室

定員：20組（先着順）

申込締切：2026年12月18日（金）

申し込みは、公民館の受付か電話で受け付けます。当日は、動きやすい服装でお越しください。
```

## 直した文章

```markdown chaff-after
# 親子で学ぶ防災教室のご案内

地震や大雨のときに、家族でどう動けばよいかを、消防署の方から教わる教室です。小学生とその保護者の方が対象です。

日時：2026年12月12日（土）13:30〜15:30

場所：みどり台公民館 2階の大会議室

定員：20組（先着順）

申込締切：2026年12月4日（金）

申し込みは、公民館の受付か電話で受け付けます。当日は、動きやすい服装でお越しください。
```

## 直し方

教室は12月12日に開くのに、申込の締め切りは12月18日です。締め切りに間に合わせて17日に申し込んだ人は、そのときには教室が終わっています。前の回の案内を写して、日時の行だけを新しくしたのでしょう。
読む人の多くは締め切りの日だけを手帳に書くので、ぎりぎりまで申し込まない人が出ます。案内を出したあとに気づいても、配ったチラシは直せません。

直した文章では、締め切りを教室の一週間前の12月4日（金）にしました。何日前にするかは書いた人が決めることです。chaff は、締め切りが催しの日より後であることだけを示します。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  deadline-after-event: relaxed
```

「日時」「開催日」で始まり時刻のある行の日付を催しの日と読み、申込の語（申込、出欠、予約）と締め切りの語（まで、締切、期限）の両方がある文の日付と比べます。時刻の無い日時の行、年の無い日付、日付が二つある文は比べません。アンケートの回答期限のように、申込でない締め切りも比べません。
法令・規約、手引き、論文、文学、スピーチのジャンルでは止めています。これらの文書に書く日付は、その文書が決める催しと締め切りではなく、ほかで起きたことを伝える日付だからです。
