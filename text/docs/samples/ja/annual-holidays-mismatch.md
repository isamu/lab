# 毎週の休みから決まる日数より少ない年間休日（`annual-holidays-mismatch`）

**こんな文書に:** 求人票、募集要項、会社案内の働き方のページ。前の年の求人や別の職種の求人から行を写すと、休日の制度と年間休日の日数が合わなくなります。

## 元の文章

```markdown chaff-before
# 経理スタッフの募集

株式会社みなと商事では、本社の経理課で働く人を募集します。

| 項目 | 内容 |
| --- | --- |
| 仕事の内容 | 請求書の発行、支払いの手続き、月ごとの締め |
| 勤務地 | 本社（横浜市中区） |
| 勤務時間 | 9時から17時30分（休憩60分） |
| 休日 | 完全週休2日制（土曜日・日曜日）、祝日、年末年始 |
| 年間休日 | 95日 |

応募は、履歴書と職務経歴書を採用担当あてにメールで送ってください。
```

株式会社みなと商事では、本社の経理課で働く人を募集します。

| 項目 | 内容 |
| --- | --- |
| 仕事の内容 | 請求書の発行、支払いの手続き、月ごとの締め |
| 勤務地 | 本社（横浜市中区） |

## 直し方

「完全週休2日制」は、毎週かならず2日休めるという意味です。一年は52週なので、それだけで休みは104日になります。祝日と年末年始を足せば、もっと多くなります。
それなのに年間休日が「95日」では、どちらかが間違っています。応募する人は、土曜日に出る週があるのではと不安になり、面接で聞くか、応募をやめてしまいます。

この求人では、休日の制度が正しく、年間休日は工場の求人の行を写したままでした。カレンダーで数え直した「122日」に直しました。
反対に、土曜日に出る週があるのなら、「完全」を外して「週休2日制」と書きます。chaff は「完全」の付かない週休2日制を、毎週2日休むとは読まないので、比べません。
年間休日が最低の日数より多いのは普通なので、多いほうは指摘しません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  annual-holidays-mismatch: strict
```

求人を出す前に必ず止めたいなら `strict` にします。
「約120日」「120日以上」のように幅のある日数や、職種ごとに休日の制度が違う求人は比べません。文芸のジャンルでは、はじめから動きません。
