# 主題から述語までが遠い（`topic-predicate-distance`）

**こんな文書に:** 報告書、議事録、お知らせ。「〜は」と書き出してから、理由や経緯を挟み込んで、何がどうなったのかが文の最後まで出てこない文書です。

## 元の文章

```markdown chaff-before
# 秋の社内運動会について

総務課からの報告です。

10月に予定していた社内運動会は、会場となる体育館で床の張り替えが予定より長引いていることと、当日に別の部署の研修が重なる人が多いことがわかったため、各部の代表と話し合った結果、来年の春に延期することになりました。

新しい日程は、決まりしだいお知らせします。
```

## 直した文章

```markdown chaff-after
# 秋の社内運動会について

総務課からの報告です。

10月に予定していた社内運動会を、来年の春に延期します。
会場となる体育館で床の張り替えが予定より長引いていて、当日に別の部署の研修が重なる人も多いことがわかりました。
各部の代表と話し合って決めました。

新しい日程は、決まりしだいお知らせします。
```

## 直し方

元の文は「社内運動会は、」と主題を出してから、述語の「延期することになりました」まで89字あります。
その間に、床の張り替えの話、研修が重なる話、話し合った話が挟まっていて、読み手は運動会がどうなったのかを最後まで待つことになります。
報告を受ける人がまず知りたいのは、運動会があるのかないのかです。

直した文章では、主題と述語をつなげて「社内運動会を、来年の春に延期します」と先に言い、理由と決め方を次の文に出しました。
一文目で結論が分かり、二文目からは知りたい人だけが理由を読めます。

chaff は、文の最初の「名詞＋は」から文の終わりの述語までの字数を数えます。鉤括弧で引いたものの中は数えません。

## 設定

報告書（`business/report`）では、主題から述語まで80字までなら指摘しません。`strict` にすると60字、`relaxed` にすると100字までです。
法務のジャンルでは別の数字を持ち、文学のジャンルでは既定で止めています。

```yaml chaff-settings
rules:
  topic-predicate-distance: relaxed
```

見ないことにするなら `topic-predicate-distance: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax topic-predicate-distance --why "条件を先に並べる規程の文体に合わせるため"
```
