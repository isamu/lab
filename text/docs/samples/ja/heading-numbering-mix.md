# 見出しの番号の付け方が揃っていない（`heading-numbering-mix`）

**こんな文書に:** 報告書、企画書、手順書。あとから節を一つ差し込んだときに、その見出しだけ番号を付け忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 来店客アンケート 集計報告

## 1. 調査の目的

新しい会員カードを始めてから、来店する客の満足度が変わったかを調べました。

## 2. 調査の方法

10月の土日に、レジで会計を済ませた客に用紙を渡し、312人から回答を得ました。

## 回答者の内訳

回答者の6割が、週に一度以上来店する会員でした。

## 3. 結果

満足と答えた客は、前の年の調査より8ポイント増えて、71パーセントでした。
```

## chaff の指摘

```text chaff-output

  ·  見出しの番号の付け方が揃っていない

     見出し「回答者の内訳」だけ番号がありません（兄弟の見出しは「1. 調査の目的」など 3 個が番号付き）
     「1. 概要」「3. 費用」と番号を付けた見出しのあいだに番号の無い「手順」があったり、「1.」「2.」の隣に「3）」や「第4章」があったりすると、読み手は番号の無い見出しが別の扱いなのか、番号が抜けたのか迷います。目次や参照（「3 章で述べた」）とも合わなくなります。どちらの付け方が正しいかは決めず、同じ親の下の同じ深さの見出し（兄弟）のうち少ないほうを指します。番号を持つ語（第1章、Chapter 1）と、番号を付けないのがふつうの前後の見出し（目次、参考文献）は言語ごとの語彙表にあります。
```

## 直した文章

```markdown chaff-after
# 来店客アンケート 集計報告

## 1. 調査の目的

新しい会員カードを始めてから、来店する客の満足度が変わったかを調べました。

## 2. 調査の方法

10月の土日に、レジで会計を済ませた客に用紙を渡し、312人から回答を得ました。

## 3. 回答者の内訳

回答者の6割が、週に一度以上来店する会員でした。

## 4. 結果

満足と答えた客は、前の年の調査より8ポイント増えて、71パーセントでした。
```

## 直し方

この報告書の見出しは「1.」「2.」「3.」と番号が付いているのに、あいだに差し込んだ「回答者の内訳」だけ番号がありません。
読む人は、この節だけ本文とは別の扱いなのか、番号を付け忘れたのか迷います。
会議で「3 の結果を見てください」と言われても、上から三つ目の節を開いた人は内訳を読むことになります。

直した文章では、「回答者の内訳」に「3.」を付け、後ろの「結果」を「4.」に振り直して、兄弟の見出しの番号を揃えました。
番号の無い見出しを本文の外に置くつもりなら（「参考資料」のように）、親を分けます。
どちらの付け方が正しいかは chaff は決めず、兄弟の見出しのうち少ないほうを指します。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  heading-numbering-mix: strict
```

兄弟の見出しが三つ未満の所と、番号のあるものと無いものが同じ数の所は比べません。
目次、参考文献、付録、「お問い合わせ先」のような前後の見出しと、番号の並びの前と後ろに置いた「はじめに」「まとめ」は、兄弟に数えません。
「第1週」「第3回」のように期間や催しを名指す番号は、番号と読みません。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain heading-numbering-mix --genre business/report

  見出しの番号の付け方が揃っていない   (heading-numbering-mix)

  「1. 概要」「3. 費用」と番号を付けた見出しのあいだに番号の無い「手順」があったり、「1.」「2.」の隣に「3）」や「第4章」があったりすると、読み手は番号の無い見出しが別の扱いなのか、番号が抜けたのか迷います。目次や参照（「3 章で述べた」）とも合わなくなります。どちらの付け方が正しいかは決めず、同じ親の下の同じ深さの見出し（兄弟）のうち少ないほうを指します。番号を持つ語（第1章、Chapter 1）と、番号を付けないのがふつうの前後の見出し（目次、参考文献）は言語ごとの語彙表にあります。

  直しかた: 兄弟の見出しで番号の付け方を揃えてください。番号の無い見出しを本文の外に置くつもりなら、親を分けてください。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

    strict   注意

```
