# 距離と合わない徒歩の分数（`walk-time-distance-mismatch`）

**こんな文書に:** 賃貸や売買の物件広告、物件概要の表、店舗の案内。距離を測り直したときに、徒歩の分数を直し忘れる、という形がよくあります。

## 直し方

交通の欄は「徒歩5分（約640m）」です。物件広告では、道路距離80mを1分とし、1分未満の端数は切り上げると決められているので、640mなら徒歩8分です。距離を測り直したときに、分数を前のまま残したのでしょう。
物件を探す人は、駅からの分数で候補を絞ります。5分と書いた物件を見に来た人が実際に歩いて8分かかると、ほかの欄まで疑うようになります。物件広告では、分数そのものが表示の決まりに沿っているかも問われます。

距離に「約」が付いているので、chaff は書いた桁の幅を持たせて、合う分数を「8–9分」と示します。

直した文章では、分数を「徒歩8分」にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  walk-time-distance-mismatch: strict
```

徒歩の語の付いた分数と、そのすぐ前か後ろの括弧などに書いた距離だけを組にして比べます。速さは文書に書いたもの（道路距離80mを1分、分速80m）を使います。書いていなければ、物件広告だけを80mで1分、端数は切り上げとして比べます。この見本のように物件概要の項目が並ぶ文書は、設定が無くても物件広告と読みます。「約」の付いた距離は書いた桁の幅を持たせます。「徒歩10分以内」「徒歩約5分」、幅で書いた分数、物件広告でない観光案内のような文書は比べません。
