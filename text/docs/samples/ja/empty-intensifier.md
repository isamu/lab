# 空虚な強調（`empty-intensifier`）

**こんな文書に:** 提案書、報告書、お願いのメール、記事。大事だと伝えたい所ほど、「非常に重要です」と強める言葉だけで済ませがちです。

## 元の文章

```markdown chaff-before
# 請求書の電子化の提案

経理課の森です。取引先に送る請求書を、紙から電子のファイルに切り替えることを提案します。

いまは毎月およそ200通の請求書を印刷し、封筒に入れて郵送しています。
作業には、毎月二人で丸一日かかります。

請求書を期日どおりに届けることは、非常に重要です。
電子のファイルに切り替えれば、印刷と封入の手間が無くなり、届くまでの日数も縮まります。
```

## 直した文章

```markdown chaff-after
# 請求書の電子化の提案

経理課の森です。取引先に送る請求書を、紙から電子のファイルに切り替えることを提案します。

いまは毎月およそ200通の請求書を印刷し、封筒に入れて郵送しています。
作業には、毎月二人で丸一日かかります。

請求書が締め日に間に合わないと、取引先の支払いが翌月に回り、こちらへの入金も一か月遅れます。
電子のファイルに切り替えれば、印刷と封入の手間が無くなり、届くまでの日数も縮まります。
```

## 直し方

「請求書を期日どおりに届けることは、非常に重要です」は、誰もが頷く文ですが、なぜ重要なのかを言っていません。
提案を読んで決める人が知りたいのは、遅れると何が起きるかです。それが分からなければ、切り替えに手間をかける理由も伝わりません。

直した文章では、強める言葉の代わりに、遅れたときに起きることを書きました。
取引先の支払いが翌月に回り、こちらへの入金が一か月遅れる、という中身があれば、「重要」と書かなくても重さが伝わります。
書けることが無いなら、その一文は消してかまいません。

## 設定

一覧にある言い回しが1つあれば指摘します。`relaxed` にすると、3つからです。

```yaml chaff-settings
rules:
  empty-intensifier: relaxed
```

見るのは一覧にある言い回しだけで、「重要です」のあとに理由が続くかどうかは読みません。
「店を続けるためには、人手が不可欠です」のように、何のために要るのかを同じ文で言った「不可欠です」は指摘しません。
文学（`literature`）と話し言葉の書き起こし（`speech/transcript`）では動きません。
