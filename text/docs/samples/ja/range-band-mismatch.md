# 重なるか、間が空いた区分の幅（`range-band-mismatch`）

**こんな文書に:** 料金表、薬の量の表、保険料や送料の表。一つの区分の端だけを書き換えたときに、隣の区分と重なったり、間が空いたりします。

```markdown chaff-before
# ご利用の案内

## 入場料

| 年齢 | 入場料 |
| --- | --- |
| 13歳以上 | 1,200円 |
| 6〜13歳 | 600円 |
| 3〜5歳 | 300円 |

2歳までのお子さまは、入場料がいりません。
```

## 直した文章

```markdown chaff-after
# ご利用の案内

## 入場料

入場料は、入口の券売機でお支払いください。

| 年齢 | 入場料 |
| --- | --- |
| 13歳以上 | 1,200円 |
| 6〜12歳 | 600円 |
| 3〜5歳 | 300円 |
```

## 直し方

「13歳以上」と「6〜13歳」の二つの区分に、13歳が入っています。13歳のお子さまは1,200円なのか600円なのか、窓口でも読み手でも決められません。
区分の片方の端だけを書き換えたときによく起きます。

13歳からを大人の料金とする決まりなので、下の区分を「6〜12歳」に直しました。
chaff は、以上・以下は端を含み、未満・超は含まないと読みます。年齢のように間に値の無い数は、「6〜12歳」のあとの「13歳以上」を続いていると読みます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  range-band-mismatch: strict
```

区分は、表の一つの列の続いた行か、一つの箇条書きの続いた項目の頭に、同じ単位で書いたものだけを比べます。
重さや金額のように間に値のある量は、「〜」で同じ数に接する区分（50〜60kg と 60〜70kg）を続いていると読みます。
「〜100万円」「〜200万円」のように一方の端だけを書いて重なっていく段階、時刻、日付、負の数は読みません。文芸のジャンルでは、はじめから動きません。
