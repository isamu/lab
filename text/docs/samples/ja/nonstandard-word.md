# 標準的でない語（`nonstandard-word`）

**こんな文書に:** お詫びや訂正のメール、社内の連絡、ブログ。急いで書くと、話すときの言い方がそのまま文字になる所です。

## 直し方

「違かった」「すいません」は、話すときにはよく聞きますが、書き言葉では誤りと読まれます。
このメールは請求書のまちがいを詫びる文書です。その中で語が崩れていると、謝る気持ちよりも、手入れの足りなさのほうが伝わってしまいます。

直した文章では、「違っていた」と「申し訳ありません」にしました。
chaff が示す標準の形は「すみません」ですが、取引先へのお詫びなので、もう一段改まった言い方を選んでいます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  nonstandard-word: strict
```

見るのは語彙表にある形だけです。書き誤り（シュミレーション）は `known-misspelling` が、ら抜き（見れる）は `ra-nuki` が見ます。
台詞や話したとおりの言葉を書く文学（`literature`）と話し言葉（`speech`）、特許（`legal/patent`）のジャンルでは動きません。
