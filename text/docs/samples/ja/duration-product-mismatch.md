# 回数と1回の長さを掛けた時間が、書いた合計と合わない（`duration-product-mismatch`）

**こんな文書に:** 研修や講座の案内、授業の計画、作業の見積もり。回数か1回の長さを変えたときに、合計の時間を直し忘れると、三つの数のどれが正しいのか分からなくなります。

## 元の文章

```markdown chaff-before
# 新任の課長向け研修のお知らせ

人事課から、この秋に課長になった人に向けた研修のお知らせです。

- 内容：部下との面談の進め方、評価の付け方、労務の基本
- 日程：毎週木曜日の15時から
- 時間：1回120分、全8回、合計20時間
- 場所：本社7階の研修室

欠席するときは、前の日までに人事課へ連絡してください。
```

## 直した文章

```markdown chaff-after
# 新任の課長向け研修のお知らせ

人事課から、この秋に課長になった人に向けた研修のお知らせです。

- 内容：部下との面談の進め方、評価の付け方、労務の基本
- 日程：毎週木曜日の15時から
- 時間：1回120分、全8回、合計16時間
- 場所：本社7階の研修室

欠席するときは、前の日までに人事課へ連絡してください。
```

## 直し方

1回120分を8回なら、合計は16時間です。元の文章は「合計20時間」と書いています。
去年の研修は全10回でした。今年は回数を8回に減らしたのに、合計の時間を去年のまま残していました。
受ける人は、自分の仕事をどれだけ空ければよいのかを合計の時間で見積もります。上司に研修の時間を届け出る人もいるので、食い違ったままだと、届け出と出欠の記録が合いません。

直した文章では、合計を16時間に直しました。
chaff は、一行か一つの箇条書きの中に、回数・1回の長さ・合計がちょうど一つずつあるときに、回数×長さを合計と比べます。
「約90分」のように1回の長さが目安の所は比べません。合計が「約16時間」のような目安なら、書いた単位より小さい差は合っていると読みます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  duration-product-mismatch: relaxed
```

回数・1回の長さ・合計のどれかが欠けている所や、どれかが二つ以上ある所は見ません。
