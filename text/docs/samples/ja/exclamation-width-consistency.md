## 直した文章

```markdown chaff-after
# 夏休み親子工作教室のご案内

今年も、図書館の夏休み工作教室を開きます！
牛乳パックと割りばしで、走る車を作ってみませんか？

日にちは8月9日（土）、時間は午前10時から正午までです。
材料はこちらで用意するので、手ぶらで来てください。
小学1年生から参加できます！

申し込みは、図書館の受付カウンターか電話で受け付けています。

```

## 直し方

この案内の感嘆符は、ほとんどが全角の「！」です。「参加できます」の後ろだけが半角の「!」になっています。
半角は幅が狭いので、そこだけ文字が詰まって見え、あとから書き足した一文だと分かってしまいます。

少ないほうの半角を、全角の「！」に直しました。
chaff は、感嘆符と疑問符を別々に数えます。どちらの幅が正しいかは決めず、文書の中で少ないほうを指します。

## 設定

```yaml chaff-settings
rules:
  exclamation-width-consistency: relaxed
```

ふだんは、少ないほうが1か所でもあれば指摘します。
`relaxed` にすると、少ないほうが3か所あるときだけ指摘します。見たくなければ `off` にします。
日本語の字に接するものだけを数え、URL やコードの中、英語の文の中のものは数えません。日本語の文書で、どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain exclamation-width-consistency --genre blog/owned-media

  ！？ の全角と半角の混在   (exclamation-width-consistency)

  日本語の文の中で、感嘆符と疑問符を全角（！？）と半角（!?）で混ぜて書くと、別々の所から貼り合わせた文書に見えます。どちらが正しいかは決めません。日本語の字に接するものだけを、感嘆符と疑問符それぞれで数え、少ないほうを指します。

  直しかた: 文書の多いほうの書き方に合わせてください。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値:
    strict   少ないほうの書き方が 1 箇所あれば指摘
  → normal   少ないほうの書き方が 1 箇所あれば指摘
    relaxed  少ないほうの書き方が 3 箇所あれば指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax exclamation-width-consistency --why "理由"
```
