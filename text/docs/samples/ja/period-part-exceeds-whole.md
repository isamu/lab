# 全体の期間より長い、その一部の期間（`period-part-exceeds-whole`）

**こんな文書に:** 保証の規定、契約の期間と試用の期間、研修の全体と実習の期間。全体の期間を短くしたときに、その中の期間を直し忘れる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 保証について

本製品の保証期間は、お買い上げの日から12か月です。
保証期間の中で、取扱説明書に沿った使い方で故障したときは、無料で修理します。

保証期間のうち、バッテリーの無償交換期間は18か月です。
バッテリーの持ちが新品の半分より短くなったときに、新しいバッテリーと交換します。

修理や交換のときは、保証書とレシートをご用意ください。
```

## 直した文章

```markdown chaff-after
# 保証について

本製品の保証期間は、お買い上げの日から12か月です。
保証期間の中で、取扱説明書に沿った使い方で故障したときは、無料で修理します。

保証期間のうち、バッテリーの無償交換期間は6か月です。
バッテリーの持ちが新品の半分より短くなったときに、新しいバッテリーと交換します。

修理や交換のときは、保証書とレシートをご用意ください。
```

## 直し方

保証期間はお買い上げの日から12か月と書いてあり、そのうちのバッテリーの無償交換期間が18か月になっています。全体より長い一部はありえないので、どちらかが誤りです。保証期間を前の製品の24か月から12か月に短くしたとき、バッテリーの期間を直し忘れたのでしょう。
保証の規定は、故障したときにお客さまが読み返す文書です。13か月目にバッテリーが弱ったお客さまは交換を頼みますが、窓口は保証期間が過ぎていると答えるかもしれません。書いたとおりに扱うか断るかで、もめごとになります。

直した文章では、バッテリーの無償交換期間を6か月にしました。保証期間が終わった後に続く期間なら、「保証期間の終了後」のようにそう分かる書き方にします。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  period-part-exceeds-whole: strict
```

「のうち」「の中で」「期間内の」の前に書いた期間を全体とし、同じ文のもう一つの期間を部分として、部分が全体より長ければ指します。全体の長さは、その名前の括弧の中か直前に書いたもの、無ければ同じ節で全体の名前に書いた長さを読みます。年は月に、週は日に換算して比べます。「約」「最長」「以内」の付いた長さ、幅で書いた長さ、延長や追加の語のある文、月と日のように換算できない組は比べません。
