# 単位の無い数（`number-without-unit`）

**こんな文書に:** 見積書、予算案、作業の計画表。表を手で書き足したときに、一つの値だけ単位を落とす形がよくあります。

## 元の文章

```markdown chaff-before
# 会員向けアプリ制作のお見積り

ご依頼いただいた会員向けアプリの制作について、作業ごとの費用をお知らせします。

| 作業 | 費用 |
| --- | --- |
| 画面の設計 | 450,000円 |
| アプリの開発 | 1,800,000 |
| 動作の確認 | 300,000円 |
| ストアへの公開の手続き | 80,000円 |

お支払いは、公開が済んだ月の末日に、まとめてお願いいたします。
```

## 直し方

この見積りの表では、「アプリの開発」の費用だけ「1,800,000」と、単位がありません。
ほかの行はどれも「円」が付いているので、たぶん円だろうとは推し量れます。
けれども、見積りは相手が社内で稟議に回す書類です。一番大きな金額だけ単位が無いと、千円単位なのか、別の通貨なのかと聞き返されたり、写し間違えられたりします。

直した文章では、「1,800,000円」と単位を書きました。
列の値がすべて円なら、見出しを「費用（円）」として、値からは単位を外す書き方もあります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  number-without-unit: relaxed
```

同じ列や同じ見出しの語のほかの値に、二つ以上、同じ一つの単位が付いているときだけ指します。
単位の無い値のほうが多い列、分と時間のように単位が混ざる列、「未定」のような数でない値は見ません。表の見出しに書いた単位（「金額（円）」）は読みません。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain number-without-unit --genre business/proposal

  単位の無い数   (number-without-unit)

  表の同じ列や、同じ見出しの語（「予算：」）のほかの値には単位があるのに、一つだけ数しか書いていない所です。円なのか千円なのか、分なのか時間なのかを、読み手が推し量ることになります。本文でも、「83,494百万円」のように桁の語（百万、千、億）に単位を付けて何度も書く文書で、一つだけ「83,494百万」と単位を落とした数を指します。

  直しかた: 単位を書いてください。列のすべての値が同じ単位なら、見出しに書いて（「金額（円）」）値から外す書き方もあります。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax number-without-unit --why "理由"
```
