# さ入れ言葉（`sa-ire`）

**こんな文書に:** 社内外のメール、挨拶状、案内。へりくだって書こうとすると、「休まさせていただきます」「読まさせていただきました」が入ります。

## 元の文章

```markdown chaff-before
件名：来週の休暇について

営業部のみなさま

お疲れさまです。営業二課の森です。

来週の水曜日から金曜日まで、休暇を取らさせていただきます。
休みのあいだの問い合わせは、同じ課の西田さんにお願いしてあります。

先日いただいた来期の計画案は、すべて読まさせていただきました。
気づいたことは、休暇の前にまとめてお送りします。

よろしくお願いいたします。
```

## 直した文章

```markdown chaff-after
件名：来週の休暇について

営業部のみなさま

お疲れさまです。営業二課の森です。

来週の水曜日から金曜日まで、休暇を取らせていただきます。
休みのあいだの問い合わせは、同じ課の西田さんにお願いしてあります。
```

## 直し方

「取らさせていただきます」「読まさせていただきました」は、話し言葉ではよく聞く言い方ですが、書き言葉では誤りと読まれます。「取る」「読む」のような五段動詞の使役の形は「取らせる」「読ませる」で、「さ」は入りません。
丁寧に書こうとした所ほど、言葉の誤りが目立ちます。

直した文章では、「取らせて」「読ませて」と、「さ」を抜いただけです。ほかの所は変えていません。
「見させる」「食べさせる」のような一段動詞や、「説明させる」のようなサ変動詞は「させる」が正しいので、chaff は指しません。どの動詞がどの形かは品詞解析で読みます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  sa-ire: strict
```

鉤括弧や引用符で引いた言葉（話した言葉をそのまま引いたもの）は数えません。日本語の文書だけを読みます。
