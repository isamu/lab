# 一覧に無い材料や道具を手順で使っている（`unlisted-item-used`）

**こんな文書に:** 作業の手順書、店舗の清掃の手引き、料理の作り方。「用意するもの」を先に書き、手順を書き進めるうちに一覧に無い道具を使ってしまう形がよくあります。

## 元の文章

```markdown chaff-before
# コーヒーマシンの週ごとの洗浄

毎週月曜日の開店前に、店のコーヒーマシンを洗う手順です。

## 用意するもの

- 洗浄用の錠剤 1個
- 柔らかい布

## 手順

1. 給水タンクに水を満たし、洗浄用の錠剤を入れます。
2. 「洗浄」のボタンを押し、10分ほど待ちます。
3. 抽出口のまわりを、専用のブラシで磨きます。
4. 外側を、柔らかい布で拭きます。
```

## 直した文章

```markdown chaff-after
# コーヒーマシンの週ごとの洗浄

毎週月曜日の開店前に、店のコーヒーマシンを洗う手順です。

## 用意するもの

- 洗浄用の錠剤 1個
- 専用のブラシ
- 柔らかい布

## 手順

1. 給水タンクに水を満たし、洗浄用の錠剤を入れます。
2. 「洗浄」のボタンを押し、10分ほど待ちます。
3. 抽出口のまわりを、専用のブラシで磨きます。
4. 外側を、柔らかい布で拭きます。
```

## 直し方

この手引きの「用意するもの」には、洗浄用の錠剤と柔らかい布しかありません。
ところが手順3では、「専用のブラシで磨きます」と、一覧に無い道具を使っています。
一覧を見て道具を揃えた人は、マシンの前で手順3まで来てから、ブラシが無いことに気づきます。開店前の限られた時間に、ブラシを探しに行くことになります。

直した文章では、「用意するもの」に「専用のブラシ」を足しました。
ブラシを使わずに済むなら、反対に手順を、一覧にある物で書き直します。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  unlisted-item-used: relaxed
```

「材料」「用意するもの」のような一覧の見出しがあり、番号を振った手順がある文書だけを見ます。
手順の中で物を使う形の名詞だけを読みます。「〜を入れる」「〜を加える」の物と、道具も入る一覧（用意するもの）がある文書では「〜で磨く」「〜に沈める」の物です。
手順より前に書いた物と、水・湯・手・皿のようにいつも手元にある物は言いません。
文学（`literature`）のジャンルでは動きません。
