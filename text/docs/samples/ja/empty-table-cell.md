# 表の空欄（`empty-table-cell`）

**こんな文書に:** 議事録、作業の分担表、進み具合の報告。担当や期限の列に、会議で決めきれなかった所が空欄のまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# 社内報 春号 編集会議 議事録

4月8日の会議で、春号の記事と担当を決めました。

| 記事 | 担当 | 原稿の締め切り |
| --- | --- | --- |
| 新入社員の紹介 | 総務課 | 4月18日 |
| 新しい工場の見学記 | 製造部 | 4月22日 |
| 社員食堂の新メニュー |  | 4月22日 |
| 部活動の便り | 広報課 | 4月25日 |

次回は4月28日に、集まった原稿を読み合わせます。
```

## 直した文章

```markdown chaff-after
# 社内報 春号 編集会議 議事録

4月8日の会議で、春号の記事と担当を決めました。

| 記事 | 担当 | 原稿の締め切り |
| --- | --- | --- |
| 新入社員の紹介 | 総務課 | 4月18日 |
| 新しい工場の見学記 | 製造部 | 4月22日 |
| 社員食堂の新メニュー | 未定（4月11日までに広報課が決める） | 4月22日 |
| 部活動の便り | 広報課 | 4月25日 |

次回は4月28日に、集まった原稿を読み合わせます。
```

## 直し方

この表では、「社員食堂の新メニュー」の行だけ、担当の欄が空いています。
ほかの記事にはどれも担当が書いてあるので、書き忘れたのか、会議で決まらなかったのかが読む人には分かりません。
担当の欄が空いたままだと、誰も自分の仕事だと思わず、締め切りの4月22日に原稿が一本足りなくなります。

直した文章では、会議では決まらなかったことと、いつまでに誰が決めるかを書きました。
担当が決まっていたのなら、その名前を書きます。該当しない欄なら「なし」や「—」と書くと、書き忘れでないことが伝わります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  empty-table-cell: relaxed
```

一番左の列は、空欄で「上と同じ」を表す書き方があるので見ません。
同じ列に空欄が二つ以上ある列、本文の行が三つより少ない表、合計や小計の行の空欄は指しません。
Markdown の表でだけ動きます。どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain empty-table-cell --genre business/meeting-notes

  表の空欄   (empty-table-cell)

  表のほかの行がすべて埋めている列で、一つの行だけが空欄です。書き忘れたのか、該当しないのか、まだ決まっていないのかが読み手には分かりません。担当や期限の列なら、その行の仕事は誰もしないまま残ります。

  直しかた: 中身を書いてください。該当しないなら「なし」「—」、まだ決まっていないなら「未定（いつ決めるか）」と書きます。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax empty-table-cell --why "理由"
```
