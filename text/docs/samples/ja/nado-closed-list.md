# 「等」で開いた一覧を限っている（`nado-closed-list`）

**こんな文書に:** 募集の案内、申し込みの要項、受け付けの決まり、規約。誰が対象なのか、何を受け付けるのかを書く文書です。

## 元の文章

```markdown chaff-before
# 子ども向け料理教室の参加者を募集します

市民センターでは、1月25日の土曜日に、子ども向けの料理教室を開きます。
地元の農家から届いた野菜を使って、みそ汁とおにぎりを作ります。

参加できるのは、市内に住む小学生、中学生等に限ります。
定員は20人で、申し込みが多いときは抽選で決めます。

申し込みは、1月10日までに、市民センターの窓口でお願いします。
```

## 直した文章

```markdown chaff-after
# 子ども向け料理教室の参加者を募集します

市民センターでは、1月25日の土曜日に、子ども向けの料理教室を開きます。
地元の農家から届いた野菜を使って、みそ汁とおにぎりを作ります。

参加できるのは、市内に住む小学生と中学生に限ります。
定員は20人で、申し込みが多いときは抽選で決めます。

申し込みは、1月10日までに、市民センターの窓口でお願いします。
```

## 直し方

「小学生、中学生等」の「等」は、ほかにもいることを言います。ところが、すぐ後ろの「に限ります」は、挙げた人だけだと言っています。
読んだ家族は、小学校に上がる前の子どもや高校生が申し込めるのかを決められません。窓口に問い合わせが来るのは、こういう所です。

直した文章では、対象が小学生と中学生だけなので「等」を消しました。
ほかにも対象にしたい人がいるなら、その人を書き足すか、「〜などが対象です」と限る言い方をやめてください。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  nado-closed-list: relaxed
```

「等」「など」のすぐ後ろに「に限り」「のみ」「だけ」が来た所だけを見ます。
「に限らず」「のみならず」のように限らない言い方や、「同等」「平等」のように「等」が語の一部のものは指摘しません。
文学（`literature`）と話し言葉（`speech`）のジャンルでは動きません。
