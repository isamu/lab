# まとめの段落が前の段落の言い直し（`paragraph-restatement`）

**こんな文書に:** 報告書、提案書、調べたことのまとめ。段落の終わりに「このように」と書いて、いま書いたことをもう一度言いがちな文書です。

## 元の文章

```markdown chaff-before
# 配送の遅れについての報告

物流課の報告です。

10月は、配送の遅れが先月の2倍に増えました。
遅れの多くは、新しく契約した倉庫からの出荷で起きています。
倉庫の作業員が新しい仕分けの手順に慣れておらず、出荷の準備に時間がかかっているためです。

このように、10月の配送の遅れは、新しい倉庫の作業員が仕分けの手順に慣れていないため、出荷の準備に時間がかかって増えています。
```

## 直した文章

```markdown chaff-after
# 配送の遅れについての報告

物流課の報告です。

10月は、配送の遅れが先月の2倍に増えました。
遅れの多くは、新しく契約した倉庫からの出荷で起きています。
倉庫の作業員が新しい仕分けの手順に慣れておらず、出荷の準備に時間がかかっているためです。

11月の第一週に、本社の倉庫の担当者を二人送り、仕分けの手順を現場で教えます。
11月末に遅れの件数をもう一度数え、先月の水準に戻ったかを確かめます。
```

## 直し方

最後の段落は「このように、」で始まりますが、書いてあることは前の段落と同じです。
chaff は、この段落の内容語の100%が前の段落の繰り返しだと言っています。
読み手は同じことを二度読み、報告を受けた人が知りたい「それで、どうするのか」が書かれないまま終わります。

直した文章では、言い直しの段落を消し、前の段落に無いことを書きました。
いつ、誰が、何をするのか（本社の担当者を送って手順を教える）と、いつ確かめるのか（11月末に数え直す）です。
まとめの段落は、結論や次の一手を足してはじめて役に立ちます。

chaff が見るのは、「つまり」「このように」のような言い直しを告げる語で始まる段落だけです。

## 設定

内容語の50%以上が前の段落の繰り返しなら指摘します。`strict` にすると40%、`relaxed` にすると60%からです。
法務・文学・話し言葉のジャンルでは、既定で止めています。

```yaml chaff-settings
rules:
  paragraph-restatement: relaxed
```

見ないことにするなら `paragraph-restatement: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax paragraph-restatement --why "章ごとに要点を言い直す教材のため"
```
