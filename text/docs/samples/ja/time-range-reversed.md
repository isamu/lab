# 時刻の範囲の終わりが始まりより前（`time-range-reversed`）

**こんな文書に:** 勉強会や式典の進め方、会議の次第、勤務表。時刻を一つだけ打ち間違えて、終わりが始まりより前になる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 物流の現場の改善を考える勉強会

日時：2026年12月9日（水）13:30〜16:30

会場：本社 5階の研修室

当日の進め方は次のとおりです。

| 時間 | 内容 |
| --- | --- |
| 13:30〜13:40 | 開会のあいさつ |
| 13:40〜14:30 | 倉庫の動線を見直した話 |
| 14:30〜14:40 | 休憩 |
| 14:40〜13:30 | 配送の遅れを減らした話 |
| 15:30〜16:30 | 意見の交換 |

資料は当日に会場で配ります。
```

  ⚠  時刻の範囲の終わりが始まりより前

     時刻の範囲「14:40〜13:30」の終わりが始まりより前です
     「15:15〜14:15」のように、時刻の範囲の終わりが始まりより前だと、読み手はいつ終わるのかを問い合わせることになり、次の予定の時刻も信じられなくなります。時刻を一つだけ直したときや、前の行から書き写したときに起きます。二つの時刻の間が範囲の記号（〜、–）だけのとき、「から」でつなぎ「まで」で閉じるとき、「from … to」のときを範囲として比べます。片方にだけ午前・午後を書いた範囲は、もう片方も同じと読みます。勤務表のように始まりと終わりを別の列（始業と終業、出勤と退勤、開始と終了）に書いた表も、行ごとに比べます。

## 直した文章

```markdown chaff-after
# 物流の現場の改善を考える勉強会

日時：2026年12月9日（水）13:30〜16:30

会場：本社 5階の研修室

当日の進め方は次のとおりです。

| 時間 | 内容 |
| --- | --- |
| 13:30〜13:40 | 開会のあいさつ |
| 13:40〜14:30 | 倉庫の動線を見直した話 |
| 14:30〜14:40 | 休憩 |
| 14:40〜15:30 | 配送の遅れを減らした話 |
| 15:30〜16:30 | 意見の交換 |

資料は当日に会場で配ります。
```

## 直し方

二つ目の話は14:40に始まるのに、終わりが13:30になっています。次の意見の交換が15:30に始まるので、終わりは15:30のつもりで「15」を「13」と打ち間違えたのでしょう。
話す人は、自分の持ち時間が何分あるのかを決められません。表を見て途中から来る人も、いつ着けばよいのかが分かりません。

直した文章では、終わりを15:30にしました。夜をまたぐ範囲なら、終わりに「翌」を付けます（22:00〜翌6:00）。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  time-range-reversed: strict
```

二つの時刻の間が「〜」のような範囲の記号だけのときと、「から」でつなぎ「まで」で閉じるときを比べます。勤務表のように始業と終業を別の列に書いた表も、行ごとに比べます。終わりに「翌」がある範囲と、三時間以上戻る範囲（夜をまたぐ22:00〜6:00や、十二時間制の9:00〜5:00）は言いません。
文学のジャンルでは止めています。日付の期間は `date-range-reversed` が見ます。
