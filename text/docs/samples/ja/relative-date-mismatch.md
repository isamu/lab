# 「3日後の10月5日」の日付が、基準の日付から数えた日と合わない（`relative-date-mismatch`）

**こんな文書に:** 募集や選考の案内、手続きの流れを書いたお知らせ。「1週間後の」と日付を一緒に書いて、数え方を一日ずらす、という形がよくあります。

## 元の文章

```markdown chaff-before
# 市民の写真展の作品を募集します

「わたしの町の四季」をテーマに、市民の方が撮った写真を募集します。

応募は2026年11月30日に締め切り、1週間後の12月8日に、選んだ作品を市のホームページでお知らせします。
選んだ作品は、1月の写真展で市役所の1階に飾ります。

一人につき3枚まで応募できます。
```

## 直し方

11月30日の1週間後は12月7日ですが、案内には12月8日と書いてあります。数え方を一日取り違えたのでしょう。
応募した人は、7日に結果を見に行って何も無いことに戸惑うか、8日まで待つかを迷います。「1週間後」と日付のどちらを信じればよいかが、文面からは決まりません。

直した文章では、日付を12月7日にしました。8日に知らせるつもりなら、「1週間後の」を消して日付だけを書くほうが確かです。

## 設定

ふだんは「注意」として出します。`relaxed` にすると「参考」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  relative-date-mismatch: relaxed
```

「1週間後の」「3日後の」のすぐ後ろの日付を、同じ文で前にある日付に期間を足した日と比べます。「3営業日後」のように単位が日・週・月・年でないものと、基準の日付が同じ文に無いものは見ません。メールや議事録の「来週月曜（10月12日）」「明日（10月7日）」も、頭の日付の欄から数えて比べます。
どのジャンルでも動きます。
