# 条件を言う「時」（`toki-as-condition`）

**こんな文書に:** 契約書、利用規約、社内規程。法令にならって書く文書で、条件の「とき」を漢字の「時」で書いてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 駐車場賃貸借契約書

大家の山の上不動産（以下「甲」という。）と、株式会社ひだまり（以下「乙」という。）は、次のとおり駐車場の賃貸借契約を結ぶ。

## 第1条（目的）

甲は、甲が持つ駐車場のうち、区画番号12の区画を、乙に貸す。

## 第2条（賃料）

乙は、毎月末日までに、翌月分の賃料1万5千円を甲の指定する口座に振り込む。

## 第3条（通知）

乙は、区画を使う車を替えた時は、7日以内に、新しい車の登録番号を甲に知らせる。

## 第4条（解約）

乙は、解約しようとするときは、1か月前までに、書面で甲に申し出る。
```

## 直した文章

```markdown chaff-after
# 駐車場賃貸借契約書

大家の山の上不動産（以下「甲」という。）と、株式会社ひだまり（以下「乙」という。）は、次のとおり駐車場の賃貸借契約を結ぶ。

## 第1条（目的）

甲は、甲が持つ駐車場のうち、区画番号12の区画を、乙に貸す。

## 第2条（賃料）

乙は、毎月末日までに、翌月分の賃料1万5千円を甲の指定する口座に振り込む。

## 第3条（通知）

乙は、区画を使う車を替えたときは、7日以内に、新しい車の登録番号を甲に知らせる。

## 第4条（解約）

乙は、解約しようとするときは、1か月前までに、書面で甲に申し出る。
```

## 直し方

法令の書き方では、「時」は時点（契約の終了の時に）、「とき」は条件（解約しようとするときは）を言います。第3条の「車を替えた時は」は、条件なのか時点なのかが読み手に決まりません。
同じ契約書の第4条は「解約しようとするときは」と書いているので、二つを並べて読んだ人は、わざと書き分けたのかと考えます。

直した文章では、第3条を「車を替えたときは」と直しました。「車を替えた場合は、7日以内に」という条件の意味が、第4条と同じ書き方で読めます。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  toki-as-condition: strict
```

動詞や助動詞で終わる節の後ろの「時」に、「は」「には」「も」が続くときだけ指します。「事故の時は」「その時は」のような名詞の後ろの「時」や、「時点」「随時」のような語は指しません。
