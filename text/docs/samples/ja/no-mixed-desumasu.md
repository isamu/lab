# 文末の調子が混ざっている（`no-mixed-desumasu`）

**こんな文書に:** 社内のお知らせ、メール、手順書、ブログ。何人かで書き足した文書や、ほかの資料から文を写した文書で起きやすいまちがいです。

## 直した文章

```markdown chaff-after
# 健康診断のお知らせ

総務課の佐藤です。今年の健康診断の日程が決まりましたので、お知らせします。

会場は本社3階の大会議室で、受付は午前9時から始まります。
都合のよい日を選んで、今月20日までに総務課へ連絡してください。

当日の朝は、何も食べずに来てください。水やお茶は飲んでもかまいません。
薬を飲んでいる人は、前もってかかりつけの医師に相談しておいてください。

分からないことがあれば、内線201番までお問い合わせください。
```

## 直し方

このお知らせは「です・ます」で書かれていますが、「かまわない。」と「必要がある。」の2文だけが「だ・である」の調子です。
読み手は、急に命令されたように感じたり、ここだけ別の決まりから写したのかと気になったりします。
健康診断の注意は読み飛ばされると困る所なので、調子をそろえて、ほかの文と同じ重さで読めるようにします。

直すのは少ないほうです。この文書では「です・ます」が多いので、2文を「かまいません。」「相談しておいてください。」に直しました。
chaff は、どちらの調子が正しいかは決めません。文書の中で多いほうにそろっているかだけを見ます。

## 設定

少ないほうの文が3文までなら、そろえ忘れと読んで指摘します。
それより多いときは、わざと書き分けていると読んで指摘しません。

```yaml chaff-settings
rules:
  no-mixed-desumasu: strict
```

`strict` にすると、少ないほうが5文まで指摘します。
引用や会話を多く含み、わざと調子を混ぜる文書では `relaxed`（1文だけのとき指摘）か `off` にします。
小説や講演の書き起こしのジャンル（`literature/*`、`speech/transcript`）では、はじめから動きません。

```text chaff-explain

  直しかた: 多いほうに揃えてください。少数派のほうを直すのが、いちばん手数が少なくて済みます。

```
