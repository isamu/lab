# 箇条書きの項目の形がそろっていない（`list-item-form-mix`）

**こんな文書に:** 企画書、提案書、作業の計画。箇条書きを書いている途中で書き方の勢いが変わり、名詞で終わる項目の中に、文で終わる項目が一つだけ混ざります。

## 元の文章

```markdown chaff-before
# 社員食堂の改善の提案

昼の混雑と、食べ残しの多さを減らすために、次の取り組みを提案します。

## 取り組み

- 注文の受付をスマートフォンから先にできる仕組みの導入
- 日替わりの献立の量を、小・中・大の三つから選べる形への変更
- 食べ残しの量の記録
- 混む時間を知らせる画面を入口に置く

## 進め方

来月に試しの期間を設け、利用者の声を聞いてから本番に移ります。
```

## 直した文章

```markdown chaff-after
# 社員食堂の改善の提案

昼の混雑と、食べ残しの多さを減らすために、次の取り組みを提案します。

## 取り組み

- 注文の受付をスマートフォンから先にできる仕組みの導入
- 日替わりの献立の量を、小・中・大の三つから選べる形への変更
- 食べ残しの量の記録
- 混む時間を知らせる画面の入口への設置

## 進め方

来月に試しの期間を設け、利用者の声を聞いてから本番に移ります。
```

## 直し方

取り組みの箇条書きは、「導入」「変更」「記録」と名詞で終わる形で並んでいます。最後の項目だけが「置く」と文の形で終わっています。
読み手には、そこだけ別の種類のこと、たとえばもう決まった作業のように見えます。並べて読み比べたいときに、形の違いが引っかかります。

最後の項目を、ほかと同じ名詞で終わる「設置」に書き直しました。
chaff は、名詞で終わる形と文で終わる形のどちらが正しいかは決めません。一つの箇条書きの中で少ないほうを指します。
中身が本当に違う種類のことなら、別の箇条書きか段落に分けます。

## 設定

少ないほうの形の項目が、箇条書きの一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと書き分けていると読みます。

```yaml chaff-settings
rules:
  list-item-form-mix: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
法務と文芸、講演のジャンル、議事録（`business/meeting-notes`）では、はじめから動きません。です・ます と だ・である の混ざりは `no-mixed-desumasu` が見ます。

```text chaff-explain
$ npx chaffjs explain list-item-form-mix --genre business/proposal

  箇条書きの項目の形がそろっていない   (list-item-form-mix)

  一つの箇条書きの項目は、同じ形で並んでいると読み比べやすくなります。名詞で終わる項目（「申込書の提出」）の中に文で終わる項目（「期限を確認する」）が一つだけ混ざると、そこだけ別の種類のことに見えます。chaff はどちらの形が正しいかを決めず、一つの箇条書きの中で少ないほうの形の項目を指摘します。英語の文書では、動詞で始まる項目（Install …）と名詞で始まる項目（The server …）の混ざりも見ます。です・ます と だ・である の混ざりは no-mixed-desumasu が見るので、ここでは見ません。

  直しかた: 少ないほうの項目を、ほかの項目と同じ形に書き直してください。中身が違う種類のことなら、別の箇条書きか段落に分けます。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

    strict   少ないほうの形が、箇条書きの項目の 49% 以下のとき指摘

    relaxed  少ないほうの形が、箇条書きの項目の 20% 以下のとき指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax list-item-form-mix --why "理由"
```
