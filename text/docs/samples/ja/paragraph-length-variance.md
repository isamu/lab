# 段落の長さが揃いすぎている（`paragraph-length-variance`）

**こんな文書に:** ブログ、ふりかえり、社内報の記事。AI の下書きは、どの段落も二文ずつ、同じくらいの長さに埋めます。

## 元の文章

```markdown chaff-before
# 週一回の定例会議を三十分にした

私のいるチームでは、毎週月曜の朝に、一時間の定例会議を開いていました。
半年前に、半分にしました。

一時間の会議は、いつも延びていました。
議題が決まっていないので、話が思いついた順に広がり、誰も止めなかったからです。

最初に変えたのは、議題を前の週の金曜までに出すことです。
これが一番効きました。

報告だけの議題は、会議の前に文章で回し、質問がある人だけが会議の場で聞きます。
会議で読み上げはしません。

最後の五分は、決まったことを読み上げる時間です。
誰が、いつまでに、何をするかを、その場で書記が確かめて、議事録に書きます。

最初の一か月は、三十分では終わらない日が何度もありました。
締め切りに、皆が慣れていなかったのです。

二か月目からは、ほとんどの週で三十分のうちに終わっています。
早く終わった日は、そのまま解散します。

困ったのは、雑談の時間が無くなり、新しく入った人がほかの人の仕事を知る機会が減ったことです。
これは予想外でした。

そこで、月に一度、昼休みに自由に話す時間を作りました。
出るかどうかは自由です。

決まることの数は、変わっていません。
浮いた三十分は、毎週ほかの仕事に回しています。
```

## 直し方

元の文章は、十の段落がどれも二文で、長さもほとんど同じです。
人が書くと、言いたいことの重さで段落の長さは揺れます。
揃いすぎていると、「議題を金曜までに出す」という一番効いた変更も、「早く終わった日は解散する」という小さな話も、同じ重さで読まれます。

直した文章では、段落を中身でまとめ直しました。
三つの変更は一つの段落にまとめて、そこが記事の中心だと分かるようにしています。
最初の一か月の話と、雑談の時間の話は、それぞれ一つの段落にしました。
結びは二文だけです。

## 設定

段落の長さのばらつきが30%より小さいと指摘します。段落が9より少ない文書は測りません。

```yaml chaff-settings
rules:
  paragraph-length-variance: relaxed
```

`relaxed` にすると20%より小さいときだけ、`strict` なら40%より小さいときに指摘します。
測る段落の数の下限は、`options` の `min_paragraphs` で変えられます。

```yaml chaff-settings
options:
  paragraph-length-variance:
    min_paragraphs: 12
```

ビジネス文書（`business`）と技術文書（`technical`）では見ません。法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでも、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain
$ npx chaffjs explain paragraph-length-variance --genre blog/tech

  段落の長さが揃いすぎている   (paragraph-length-variance)

  人が書くと、言いたいことの重さで段落の長さは揺れます。揃いすぎは、埋めるために長さを合わせた跡です。

  直しかた: 短くできる段落を短くしてください。全部を同じ長さにしないこと。

  設定できる値:
    strict   段落の長さのばらつきが 40% 未満なら指摘
  → normal   段落の長さのばらつきが 30% 未満なら指摘
    relaxed  段落の長さのばらつきが 20% 未満なら指摘
    off      見ない

  オプション（chaff.yaml の options で決めます）:
    min_paragraphs: 9   (既定)
      測る段落の数の下限。段落が少ないと長さのばらつきは偶然で小さく出て、人の書いた文書でも揃って見えます

  決める:  chaff.yaml に options: { paragraph-length-variance: { <名前>: <値> } } を書く

  いまは normal です。

  変える:  npx chaffjs relax paragraph-length-variance --why "理由"
```
