# 検査結果の単位が基準値の単位と違う（`reference-unit-mismatch`）

**こんな文書に:** 健康診断や血液検査の結果、水質や土の検査の報告書。別の検査機関の値を貼ったり、単位を写し間違えたりすると、結果と基準値の単位が食い違います。

## 元の文章

```markdown chaff-before
# 血液検査の結果

2026年11月に受けた血液検査の結果です。次の受診のときに、この表を持ってきてください。

| 項目 | 結果 | 基準値 |
| --- | --- | --- |
| HDLコレステロール | 64 mmol/L | 40〜96 mg/dL |
| LDLコレステロール | 118 mg/dL | 60〜139 mg/dL |
| 中性脂肪 | 88 mg/dL | 30〜149 mg/dL |
```

## 直した文章

```markdown chaff-after
# 血液検査の結果

2026年11月に受けた血液検査の結果です。次の受診のときに、この表を持ってきてください。

| 項目 | 結果 | 基準値 |
| --- | --- | --- |
| HDLコレステロール | 64 mg/dL | 40〜96 mg/dL |
| LDLコレステロール | 118 mg/dL | 60〜139 mg/dL |
| 中性脂肪 | 88 mg/dL | 30〜149 mg/dL |
```

## 直し方

HDLコレステロールの結果は「64 mmol/L」、同じ行の基準値は「40〜96 mg/dL」です。単位が違うので、64 と 40〜96 を比べても、基準の内か外かは分かりません。
数だけを見て「基準内」と読む人も、mmol/L を見て驚く人も出ます。

検査機関の報告を確かめると、結果は mg/dL の値だったので、結果の単位を直しました。
単位が本当に違うときは、同じ単位に換算して書きます。
chaff は数を換算しません。mg/dL と mg/dl のように、換算せずに比べられる書き方の違いは同じ単位と読みます。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になります。

```yaml chaff-settings
rules:
  reference-unit-mismatch: relaxed
```

見出しが「結果」と「基準値」の列を行ごとに読みます。升に単位が無ければ、列の見出しの括弧の中の単位、次にその行の「単位」の列を使います。
どちらにも単位が無いとき、数の無い升（陰性、—）、「5.5 mmol/L（99 mg/dL）」のように換算した値を並べて書いた升は比べません。
文芸のジャンルでは、はじめから動きません。
