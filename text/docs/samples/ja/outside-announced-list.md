# 挙げた一覧に無い名前（`outside-announced-list`）

**こんな文書に:** 製品の説明、利用の案内、よくある質問。対応する先をあとで足したとき、最初に挙げた一覧を直し忘れて、別の所にだけ新しい名前が出てくることがあります。

## 元の文章

```markdown chaff-before
# 勤怠アプリの使い方

## 使える環境

動作環境はWindowsとmacOSです。
アプリは、社内の配布ページから入れられます。

## 打刻する

アプリを開き、「出勤」か「退勤」を押します。
押した時刻が、そのまま勤怠の記録に残ります。

## 外出先から打刻する

外出先では、スマートフォンからも打刻できます。
Androidにも対応しているので、会社の携帯電話でもそのまま使えます。
```

## 直した文章

```markdown chaff-after
# 勤怠アプリの使い方

## 使える環境

動作環境はWindowsとmacOSとAndroidです。
アプリは、社内の配布ページから入れられます。

## 打刻する

アプリを開き、「出勤」か「退勤」を押します。
押した時刻が、そのまま勤怠の記録に残ります。

## 外出先から打刻する

外出先では、スマートフォンからも打刻できます。
Androidにも対応しているので、会社の携帯電話でもそのまま使えます。
```

## 直し方

この手引きは、初めに「動作環境はWindowsとmacOSです」と挙げています。ところが最後の段では「Androidにも対応している」と書いています。
読み手は、どちらが本当の一覧なのか決められません。Android の携帯電話を持つ人は、使える環境の段だけを読んで、自分は使えないと思ってしまうかもしれません。

Android でも使えるのが正しいので、最初の一覧に Android を足しました。
もし Android の段がほかの製品から写したまちがいなら、そちらを消します。
chaff は、どちらが正しいかは決めません。一覧に無い名前を指して、書いた人に確かめてもらいます。

## 設定

```yaml chaff-settings
rules:
  outside-announced-list: relaxed
```

指摘の重さを変えるだけで、見つける所は変わりません。
`strict` にするとまちがいとして、`relaxed` にすると参考として出します。見たくなければ `off` にします。
どのジャンルでも動きます。比べるのは、対応する OS や言語のように、同じ組の名前どうしだけです。
