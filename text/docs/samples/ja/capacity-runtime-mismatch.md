# 電池の容量を消費電流で割った時間より長い使用時間（`capacity-runtime-mismatch`）

**こんな文書に:** 製品の仕様表、取扱説明書、通販の商品ページ。風量や明るさの違う条件の値を一つの表に写すと、容量と消費電流から出る時間より長い使用時間が書かれます。

## 元の文章

```markdown chaff-before
# 首かけ扇風機 KF-20 の仕様

| 項目 | 仕様 |
| --- | --- |
| バッテリー容量 | 4000 mAh |
| 消費電流 | 800 mA |
| 連続使用時間 | 8時間 |
| 重さ | 260 g |

充電には、付属のケーブルを使ってください。
```

  ⚠  電池の容量を消費電流で割った時間より長い使用時間

## 直した文章

```markdown chaff-after
# 首かけ扇風機 KF-20 の仕様

| 項目 | 仕様 |
| --- | --- |
| バッテリー容量 | 4000 mAh |
| 消費電流 | 800 mA |
| 連続使用時間 | 5時間 |
| 重さ | 260 g |

充電には、付属のケーブルを使ってください。
```

## 直し方

4000 mAh の電池から800 mA ずつ使うと、4000 ÷ 800 で5時間で空になります。どんなにうまく作っても、8時間は動きません。
元の文章の「8時間」は、風量を「弱」にしたときの時間でした。消費電流は「強」のときの値なので、二つの条件の値が一つの表に混ざっていました。
買った人が8時間もつと思って外に持ち出すと、半日たたずに止まります。通販の商品ページなら、返品や悪い口コミにつながります。

直した文章では、消費電流に合わせて使用時間を5時間にしました。
「弱」の8時間も載せたいときは、「連続使用時間（風量 弱）」のように条件を項目名の括弧に書き、その条件の消費電流と並べます。chaff は、括弧の中の条件が同じ値どうしだけを組にします。
変換の損失があるので、実際の使用時間は割り算の値より短いのが普通です。短いほうは指摘しません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  capacity-runtime-mismatch: relaxed
```

容量と消費電流と使用時間を、同じ表か「項目名：値」の行にそろえて書いたときだけ読みます。文の中に書いた値は読みません。
mAh は mA で、Wh は W で割ります。mAh を W で割ることはしません。
