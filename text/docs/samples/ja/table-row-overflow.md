# 表の行のセルが見出しの行より多い（`table-row-overflow`）

**こんな文書に:** 予算案、見積書、作業の一覧。一つの行にだけ注記を書き足したときに、見出しの行に列を足し忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 創立20周年記念式典 予算案

式典は10月3日に、本社近くのホテルの宴会場で開きます。招待する人は、社員と取引先を合わせて約120人です。

| 項目 | 金額 |
| --- | --- |
| 会場の使用料 | 35万円 |
| 料理と飲み物 | 84万円 | 一人7千円で見込んだ金額 |
| 記念品 | 24万円 |
| 案内状の印刷 | 6万円 |

合わせて149万円を、来年度の広報費から出すことを提案します。
```

## 直した文章

```markdown chaff-after
# 創立20周年記念式典 予算案

式典は10月3日に、本社近くのホテルの宴会場で開きます。招待する人は、社員と取引先を合わせて約120人です。

| 項目 | 金額 | 見込みの根拠 |
| --- | --- | --- |
| 会場の使用料 | 35万円 | ホテルの見積り |
| 料理と飲み物 | 84万円 | 一人7千円で見込んだ金額 |
| 記念品 | 24万円 | 一つ2千円で見込んだ金額 |
| 案内状の印刷 | 6万円 | 印刷会社の見積り |

合わせて149万円を、来年度の広報費から出すことを提案します。
```

## 直し方

この表の見出しの行は「項目」と「金額」の二列です。
ところが「料理と飲み物」の行にだけ、三つ目のセル「一人7千円で見込んだ金額」が書いてあります。
Markdown の表は、見出しの行にある列の数だけを表示し、多いセルは何も言わずに捨てます。
書いた人の画面の原稿には注記が見えていても、読む人の画面には出てきません。予算の一番大きな項目の根拠が、伝わらないままになります。

直した文章では、見出しの行に「見込みの根拠」の列を足し、ほかの行にも根拠を書きました。
注記が一つだけなら、表の下に「料理と飲み物は、一人7千円で見込んだ金額です」と文で書いても伝わります。
値の中に「|」を書きたいときは、「\|」と書きます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  table-row-overflow: strict
```

見出しの行よりセルが少ない行は、空のセルとして表示されるので指しません。
「\|」と書いた値と、コードや引用の中の表も指しません。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain table-row-overflow --genre business/proposal

  表の行のセルが見出しの行より多い   (table-row-overflow)

  Markdown の表（GFM）は、見出しの行にある列の数だけセルを表示し、それより多いセルは黙って捨てます。値の中に「|」を書いた、列を足したのに見出しを直していない、といったときに起き、書いたはずの値が読み手には見えません。

  直しかた: 見出しの行に列を足すか、行のセルを減らしてください。値の中の「|」は「\|」と書きます。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax table-row-overflow --why "理由"
```
