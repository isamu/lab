# 数と単位の間の空白が混ざっている（`unit-spacing-consistency`）

**こんな文書に:** 製品やサービスの案内、提案書、仕様の説明。料金表や仕様書から数字を写すと、そこだけ数と単位の間の空け方が変わります。

```markdown chaff-before
# 写真共有サービスの社内導入のご提案

各部署で撮った写真を、一か所で見られるようにするための提案です。

使う容量は、部署ごとに 50 GB を見込んでいます。
写真の多い広報部だけは、別に 200 GB を割り当てます。
全社では、予備を含めて 1,000GB の契約をおすすめします。

一枚あたりの大きさは、ふつう 5 MB ほどです。
```

## 直した文章

```markdown chaff-after
# 写真共有サービスの社内導入のご提案

各部署で撮った写真を、一か所で見られるようにするための提案です。

使う容量は、部署ごとに 50 GB を見込んでいます。
写真の多い広報部だけは、別に 200 GB を割り当てます。
全社では、予備を含めて 1,000 GB の契約をおすすめします。
```

## 直し方

この提案は、容量を「50 GB」「200 GB」のように、数と単位の間を空けて書いています。全社の契約の量だけが「1,000GB」と詰まっています。
読み手には、そこだけ別の資料から写したように見えます。提案の中でいちばん大事な数字なので、ほかと同じ見た目で読めるほうが目に留まります。

少ないほうを、ほかと同じ「1,000 GB」に直しました。
chaff は、空けるか詰めるかは決めません。単位ごとに、文書の中で少ないほうを指します。

## 設定

少ないほうが、その単位の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  unit-spacing-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
どのジャンルでも動きます。

