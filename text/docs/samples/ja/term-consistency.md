# チームが一つにそろえる語のまざり（`term-consistency`）

**こんな文書に:** 報告書、案内、お客さま向けの手紙。書いた時期や人が違う節や、AI に節ごとに書かせた文書で、同じものを指す正しい語が二つまざりやすい文書です。

## 元の文章

```markdown chaff-before
# 満足度調査の進め方

今月は顧客の声を集めます。
集めた声は顧客ごとにまとめ、担当を決めます。
結果は来月の会議で報告し、お客様には再来月に知らせます。
```

```yaml chaff-config
consistent:
  - [顧客, お客様]
```

## 直した文章

```markdown chaff-after
# 満足度調査の進め方

今月は顧客の声を集めます。
集めた声は顧客ごとにまとめ、担当を決めます。
結果は来月の会議で報告し、顧客には再来月に知らせます。
```

## 直し方

「顧客」も「お客様」も正しい語で、チームはどちらを使ってもよいと決めています。決めているのは、一つの文書の中ではまぜないことです。
元の文章は「顧客」を 2 箇所、「お客様」を 1 箇所で使っていたので、読み手は「お客様」が別の人たちを指すのかと迷います。

直した文章では、文書の中で多いほうの「顧客」にそろえました。お客さま向けの手紙なら「お客様」にそろえてかまいません。

## 設定

この規則は、chaff.yaml の `consistent` に並べた組だけを見ます。組には、どちらも正しいけれど一つの文書でまぜない語を並べます。
chaff は組を持っていません。表記の決まりや、レビューで何度も直している組から、チームで並べます。

```yaml chaff-settings
consistent:
  - [顧客, お客様]
  - [申込, 申し込み]
  - [問合せ, 問い合わせ]
```

同じ数ずつ使っているときは側に立たず、まざっていることを 1 件だけ言います。
ファイルを一度に渡すと、`cross-doc-term-variant` がほかのファイルと違う語を使うファイルも指します。
並べた時点で一つにそろえると決めた組なので、1 箇所でも指摘します。`relaxed` にすると 3 箇所から指摘します。

```yaml chaff-settings
rules:
  term-consistency: relaxed
```

二つの語を使い分けている所は、stet で理由を添えて黙らせます。
どのジャンルでも動きます。`consistent` が空なら動かず、動かなかった rule の一覧にそう出ます。
