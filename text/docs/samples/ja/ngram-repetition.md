# 同じ言い回しが何度も出る（`ngram-repetition`）

**こんな文書に:** 製品の紹介、技術記事、手引き。売りにしたい一言を、段落のたびに書き直しがちな文章です。

## 元の文章

```markdown chaff-before
# 家計簿アプリを自分で作ってみた

週末に、自分のための家計簿アプリを作りました。
使ったのは、いつも仕事で書いている言語と、手元のノートパソコンだけです。
二日で動くものになったので、作り方と使ってみた感想を書いておきます。
思ったより簡単でした。

## できること

このアプリは、レシートの写真を撮ると金額と日付を読み取ります。
読み取った金額は、ボタンを一つ押すだけで、食費や交通費などの分類に振り分けられます。
月の終わりには、ボタンを一つ押すだけで、分類ごとの合計がグラフになります。
家族と共有したいときも、ボタンを一つ押すだけで招待のリンクが作れます。
古いデータは、ボタンを一つ押すだけで、表計算ソフトで開ける形に書き出せます。
スマートフォンに移したいときも、ボタンを一つ押すだけです。
間違えて消したレシートも、ボタンを一つ押すだけで元に戻せます。

## 作ってみて

一番時間がかかったのは、レシートの読み取りでした。
店によって並び方が違うので、合計の行を見つける処理を何度も書き直しました。
ここが一番の山です。
コンビニのレシートは割引の行が多く、最初は割引の前の金額を合計と読んでしまっていました。
いまは、レシートの下から順に「合計」という語を探すようにして、ほとんどの店で正しく読めています。
次は、毎月の固定費を自動で入れられるようにするつもりです。
わが家の固定費は家賃と電気代と通信費の三つで、毎月ほぼ同じ金額なので、月のはじめに自動で入るようにすれば、手で打ち込む手間はさらに減るはずです。
楽しい週末でした。
```

## 直し方

元の記事は「ボタンを一つ押すだけで」を何度も繰り返していて、chaff は「ボタンを一つ押す」が6回出てくると言っています。
売りにしたい一言でも、繰り返すたびに読み手は同じことを読まされ、二回目からは読み飛ばします。
どの機能が何をするのかという、肝心の違いのほうが見えにくくなります。

直した文章では、それぞれの文を、その機能がすることだけで書きました。
「ボタン一つで済む」ことは、「どの操作も、画面の下のボタン一つで済むようにしました」と一度だけ言っています。
繰り返さなくても、売りは伝わります。

数えるのは、文書の題や見出しに無い言い回しだけです。一つの文の中の繰り返しは一回と数え、節の最初の文に出たぶんも数えません。
日本語で500字より短い文書は測りません。

## 設定

同じ言い回しが五回までなら指摘しません。`strict` にすると三回、`relaxed` にすると九回までです。
法務・文学のジャンル、用語集、話し言葉の書き起こしでは、既定で止めています。

繰り返しているのが組織や製品の名前なら、chaff.yaml の `names` に並べると数えません。

```yaml chaff-settings
names:
  - ワンタッチ記帳ボタン
```

```yaml chaff-settings
rules:
  ngram-repetition: relaxed
```

見ないことにするなら `ngram-repetition: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax ngram-repetition --why "決まった言い回しで書く手順書のため"
```
