# 通貨の書き方が混ざっている（`currency-notation-consistency`）

**こんな文書に:** 料金の案内、見積もりのメール、請求の知らせ。値段の表から一行だけ写したり、海外向けの資料から文を借りたりすると、同じ円の金額が二通りの書き方になります。

## 直し方

このメールの金額は、どれも「2,200円」のように数字の後ろに「円」を付けています。プロプランの新しい料金だけが「¥8,800」と、前に記号を付けた書き方です。
受け取った人は、ここだけ別の通貨か、税の扱いの違う金額なのかと気になります。料金の改定は相手が社内で回して確かめる知らせなので、こうした迷いは問い合わせのもとになります。

金額は変えずに、ほかと同じ「8,800円」に書き直しました。
chaff は、どちらの書き方が正しいかは決めません。通貨ごとに、文書の中で少ないほうを指します。円とドルが並ぶのは混ざりではありません。

## 設定

少ないほうが、その通貨の金額の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  currency-notation-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
どのジャンルでも動きます。表の升の金額も数え、コードの中は読みません。

```text chaff-explain
$ npx chaffjs explain currency-notation-consistency --genre business/email

  通貨の書き方が混ざっている   (currency-notation-consistency)

  同じ通貨の金額を「1,000円」と「¥1,000」、「$20」と「USD 20」のように二通りに書くと、読み手は別の通貨か、別の扱いの金額かと迷います。見積もりや資料を寄せ集めたときに起きます。どの書き方が正しいかは決めず、通貨ごとに文書の中で少ないほうを指します。表の升の金額も数えます。

  直しかた: 文書の多いほうの書き方に合わせてください。チームで決めているなら、STYLE.md に書いておくと迷いません。

  設定できる値:
    strict   少ないほうの書き方が、その通貨の金額の 49% 以下のとき指摘
  → normal   少ないほうの書き方が、その通貨の金額の 34% 以下のとき指摘
    relaxed  少ないほうの書き方が、その通貨の金額の 20% 以下のとき指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax currency-notation-consistency --why "理由"
```
