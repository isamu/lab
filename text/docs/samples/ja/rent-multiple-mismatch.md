# 賃料の月数分と合わない敷金・礼金（`rent-multiple-mismatch`）

**こんな文書に:** 賃貸物件の案内、募集の図面、事務所の賃貸の提案書。賃料を書き直したときや、別の部屋の行を写したときに、敷金や礼金の金額だけが前のまま残ります。

## 元の文章

```markdown chaff-before
# さくら台ハイツ 203号室

駅から歩いて7分の、南向きの1LDKです。12月から入居できます。

| 項目 | 金額 |
| --- | --- |
| 賃料 | 92,000円 |
| 管理費 | 5,000円 |
| 敷金 | 1か月（85,000円） |
| 礼金 | 1か月（92,000円） |

内見をご希望の方は、さくら台不動産までお電話ください。
```

  ⚠  賃料の月数分と合わない敷金・礼金

     物件の案内で「敷金 1か月（85,000円）」のように月数と金額を並べて書くと、読み手は金額を確かめずに用意します。賃料を書き直したときや、別の部屋の行を写したときに、月数か金額のどちらかが残って食い違います。敷金・礼金・保証金・償却などの見出しの後に月数と金額が一つずつ並んでいるとき、その金額を、前に書いた賃料のその月数分と比べます。一つのページに物件がいくつもあれば、それぞれ直前の賃料と比べます。管理費・共益費が書いてあれば、賃料だけの月数分と、賃料に管理費を足した額の月数分のどちらでもよいとします（どちらで計算するかを書かない案内が多いため）。賃料が「85,000円〜90,000円」のように幅で書いてあれば、その幅に入る額を認めます。「9.8万円」は書いた桁までの丸めを認めます。

## 直した文章

```markdown chaff-after
# さくら台ハイツ 203号室

駅から歩いて7分の、南向きの1LDKです。12月から入居できます。

| 項目 | 金額 |
| --- | --- |
| 賃料 | 92,000円 |
| 管理費 | 5,000円 |
| 敷金 | 1か月（92,000円） |
| 礼金 | 1か月（92,000円） |

内見をご希望の方は、さくら台不動産までお電話ください。
```

## 直し方

敷金は「1か月（85,000円）」と書いてあります。けれどもこの部屋の賃料は92,000円なので、1か月分は92,000円です。
読む人は、括弧の中の金額を確かめずに、入居の費用として用意します。契約の日に足りないと分かると、申し込みそのものが揺らぎます。

礼金の行は賃料の1か月分と合っているので、敷金の行だけ、賃料を上げる前の額か、別の部屋の額が残ったと読めます。敷金を92,000円に直しました。
賃料に管理費を足した額で計算する決まりなら、その額に直し、そう書き添えます。chaff は、賃料だけの月数分と、管理費を足した額の月数分のどちらも合っていると見ます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  rent-multiple-mismatch: strict
```

敷金・礼金・保証金・償却などの見出しの後に、月数と金額が一つずつ並んでいるときだけ比べます。一つのページに物件がいくつもあれば、それぞれ直前の賃料と比べます。
月数だけ、金額だけの記載、「1〜2か月」のような月数の幅、税込みの記載、年額や坪単価の語がある文書は比べません。
文芸のジャンルでは、はじめから動きません。
