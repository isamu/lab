# 打ち消しを伴わない「全然」「決して」（`adverb-without-negation`）

**こんな文書に:** 取引先へのメール、お客さまへの返事、社内の報告。急いで返事を書くと、話すときの口ぐせがそのまま出やすい所です。

いつもお世話になっております。ひかり家具の木村です。

お問い合わせいただいた会議用の机12台の納品日について、お返事します。
ご希望の12月5日の納品は、全然大丈夫です。

どうぞよろしくお願いいたします。

## 直し方

「全然」は、書き言葉では「全然足りない」「全然分からない」のように、打ち消しと組んで使う副詞です。
「全然大丈夫です」は話すときにはよく言いますが、取引先へのメールでは砕けて聞こえます。
せっかく納品の日に間に合うという良い知らせなのに、軽い返事に読まれてしまいます。

直した文章では、「全然大丈夫です」を「十分に間に合います」に替えました。
「大丈夫」よりも、何が大丈夫なのか（希望の日に間に合うこと）がはっきりします。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  adverb-without-negation: strict
```

後ろに打ち消しの語（ない、ません、ず、違う）や、「不〜」「無〜」で始まる語があれば指摘しません。
「まったく」は「まったく同じ」が正しい使い方なので見ません。
話し言葉をそのまま書く文書では、見ないことにできます（`adverb-without-negation: off`）。
ブログ、文学（`literature`）、話し言葉（`speech`）のジャンルでは、はじめから動きません。
