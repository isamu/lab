# 比べる相手の無い比較（`comparative-without-baseline`）

**こんな文書に:** プレスリリース、新しい版のお知らせ、製品の紹介、提案書。良くなったことを伝えたい文書ほど、「さらに」「より」が増えます。

## 元の文章

```markdown chaff-before
# 家計簿アプリ「まめ帳」の新しい版を公開しました

家計簿アプリ「まめ帳」の新しい版を、12月1日に公開しました。今回の版では、レシートの読み取りと、月ごとのグラフを作り直しています。

新しい版では、レシートを撮影してから金額が入るまでが、さらに速くなりました。
月ごとのグラフも、さらに見やすくなりました。

新しい版は、アプリの更新画面から無料で入れられます。
```

## 直した文章

```markdown chaff-after
# 家計簿アプリ「まめ帳」の新しい版を公開しました

家計簿アプリ「まめ帳」の新しい版を、12月1日に公開しました。今回の版では、レシートの読み取りと、月ごとのグラフを作り直しています。

新しい版では、レシートを撮影してから金額が入るまでが、前の版の5秒から2秒になりました。
月ごとのグラフは、食費や光熱費などの費目ごとに色を分けて表示します。

新しい版は、アプリの更新画面から無料で入れられます。
```

## 直し方

「さらに速くなりました」「さらに見やすくなりました」は、何と比べて速いのか、どれくらい見やすいのかを言っていません。
読み手は、更新する前に確かめようがありません。言い切ったように見えて、何も約束していない文です。

直した文章では、一つ目には比べる相手と数を書きました（前の版の5秒から2秒）。
二つ目は、比べるのをやめて、何が変わったのかを書いています（費目ごとに色を分けて表示）。
どちらも、読み手が自分の目で確かめられる文になります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  comparative-without-baseline: strict
```

同じ文か直前の文に比べる相手（従来、以前、前回、「〜より」「〜に比べて」）があれば指摘しません。
「より多くの」「より詳しく」のような決まった言い方や、目当てを言う比較（より良い社会を目指す）も見ません。
文学（`literature`）と話し言葉（`speech`）のジャンルでは動きません。
