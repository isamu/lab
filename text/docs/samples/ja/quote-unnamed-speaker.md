# 名前の無い話し手の言葉を引いている（`quote-unnamed-speaker`）

**こんな文書に:** プレスリリース、調査の報告書、営業の資料。主張を支えるために専門家の言葉を引いたのに、誰が言ったのかを書かない形がよくあります。

## 元の文章

```markdown chaff-before
# 在庫管理アプリ「たなおろし」に、発注の予測を加えます

株式会社ひなた商会は、12月1日から、在庫管理アプリ「たなおろし」に発注の予測を加えます。
過去の売れ行きから、次に発注する数と日を画面に出します。

流通業界のアナリストは「発注の量を勘で決めている小売店は、まだ半分を超える」と述べています。
「たなおろし」は、こうしたお店が少ない手間で発注を決められるようにします。

発注の予測は、いまお使いのすべてのお客さまに、追加の料金なしでお使いいただけます。
```

## 直した文章

```markdown chaff-after
# 在庫管理アプリ「たなおろし」に、発注の予測を加えます

株式会社ひなた商会は、12月1日から、在庫管理アプリ「たなおろし」に発注の予測を加えます。
過去の売れ行きから、次に発注する数と日を画面に出します。

みなと流通研究所のアナリストの森花子氏は「発注の量を勘で決めている小売店は、まだ半分を超える」と述べています。
「たなおろし」は、こうしたお店が少ない手間で発注を決められるようにします。

発注の予測は、いまお使いのすべてのお客さまに、追加の料金なしでお使いいただけます。
```

## 直し方

「流通業界のアナリスト」が誰なのかが書いてありません。
記者や取引先は、その言葉を確かめることも、言った人の立場を量ることもできません。名前の無い誰かに、自分たちの言いたいことを言わせていると読まれるおそれもあります。

直した文章では、話し手の所属と名前を書きました。
名前を出せない相手なら、その言葉に頼らず、調査の報告書のように題名のある資料を出典にします。
chaff は、その人が本当にそう言ったかは知りません。確かめる相手が書かれていないことだけを言います。

## 設定

ふだんは「参考」として出します。`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  quote-unnamed-speaker: strict
```

話し手の句に名前に付く語（氏、さん、教授）があるものや、「同アナリスト」のように前に名前を出した人を指し直すものは見ません。
「代表取締役社長」のように一人に決まる役も見ません。10字に満たない短い引用は、語や名前を引いたものと読みます。
プレスリリースと報告書だけで動きます。ほかの文書で人の言葉に出典が無いことは `quote-without-source` が見ます。
