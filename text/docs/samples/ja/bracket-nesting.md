有給休暇は、休む日の3日前までに勤怠システムから申請してください。

## 直し方

元の文は「（全日・半日（午前または午後（13時で区切ります）））」と、括弧の中に括弧が三重に入っています。
読み手は開いた括弧を三つ覚えたまま読み進め、最後に閉じ括弧が三つ並んだ所で、どこから本文に戻ったのかを数え直すことになります。
選ぶ項目が何なのか、一度では頭に入りません。

直した文章では、選べる種類を「全日・午前の半日・午後の半日」と一段で並べ、「13時で区切ります」を次の文に出しました。
括弧は一重になり、選ぶ項目と補足の説明が分かれて読めます。

## 設定

括弧の重なりは二重まで認めます。`strict` にすると一重まで、`relaxed` にすると三重までです。
文学のジャンルでは、別の数字を持っています。

```yaml chaff-settings
rules:
  bracket-nesting: relaxed
```

見ないことにするなら `bracket-nesting: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax bracket-nesting --why "法令の名前を引くと括弧が重なるため"
```
