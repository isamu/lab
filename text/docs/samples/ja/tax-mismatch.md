# 税額が小計に税率を掛けた額と合わない（`tax-mismatch`）

**こんな文書に:** 請求書、見積書、税込と税抜を並べた価格表。小計を直したのに、税の行を前の額のままにする、という形がよくあります。

## 元の文章

```markdown chaff-before
# 請求書

株式会社あおば商事 御中

10月の社内報の制作について、次のとおりご請求します。

| 項目 | 金額 |
| --- | --- |
| 記事の取材と執筆 | 120,000円 |
| 写真の撮影 | 60,000円 |
| 誌面の組版 | 66,000円 |
| 小計 | 246,000円 |
| 消費税（10%） | 24,000円 |
| 合計 | 270,000円 |

お支払いは、11月30日までに、下記の口座へお振り込みください。
```

  ✖  税額が小計に税率を掛けた額と合わない

     税額「24,000円」が、上の金額の10%（24,600円）と合いません
     見積書や請求書の「消費税（10%）」の金額が、小計の10%と合わないと、読み手は税の計算を確かめ直し、合計も信じられなくなります。合計の額に税率を掛けてしまったときや、小計を直して税を直し忘れたときに起きます。表か箇条書きで、税の語（消費税・税額）で始まり率を書いた行の金額を、上の小計の行の金額（小計の行が無ければ上の項目の和）に率を掛けた額と比べます。価格表で税抜と税込の価格を並べた表（「1箱の価格（税抜）」と「1箱の価格（税込・10%）」）では、行ごとに、税込の価格を税抜の価格に率を足した額と比べます。率は税込の列の見出しの率、無ければ文書が「消費税10%」のように書いた率です。サービス料（10%）の行も同じように比べ、その下の税は小計にサービス料を足した額に掛けたものとしても読みます。

     → 小計と税率を確かめて、税額を計算し直してください。合計も一緒に直します。

     このルールをゆるめる:  npx chaffjs relax tax-mismatch

## 直した文章

```markdown chaff-after
# 請求書

株式会社あおば商事 御中

10月の社内報の制作について、次のとおりご請求します。

| 項目 | 金額 |
| --- | --- |
| 記事の取材と執筆 | 120,000円 |
| 写真の撮影 | 60,000円 |
| 誌面の組版 | 66,000円 |
| 小計 | 246,000円 |
| 消費税（10%） | 24,600円 |
| 合計 | 270,600円 |

お支払いは、11月30日までに、下記の口座へお振り込みください。
```

## 直し方

小計は246,000円なので、10%の消費税は24,600円です。請求書には24,000円と書いてあります。小計が240,000円だったときの税を残したまま、組版の額を直したのでしょう。
この請求書は、合計の行だけを見ると、小計と税の和の270,000円で合っています。足し算が合っているので、読む人は誤りに気づかず、そのまま600円少なく支払います。あとで差額を請求し直すのは、書いた側にとっても手間です。

直した文章では、税を24,600円にし、合計も270,600円に直しました。税を直したら、合計も一緒に直します。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  tax-mismatch: relaxed
```

「消費税（10%）」のように、税の語で始まり率を書いた行だけを比べます。端数は切り捨て、四捨五入、切り上げのどれでも合っていると読みます。率を書いていない税の行、「うち消費税」のように合計に含まれる税、8%と10%が並ぶ表、小計と税の間に値引きや送料の行がある表は比べません。
文学のジャンルでは止めています。合計が内訳の和と合うかどうかは、`total-mismatch` が見ます。
