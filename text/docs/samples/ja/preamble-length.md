# 本題に入るまでが長い（`preamble-length`）

**こんな文書に:** 企画書、提案書、報告書。経緯や背景を順に書いていくうちに、何を決めてほしいのかが、最初の見出しのずっと後になる形がよくあります。

```markdown chaff-before
# 営業部の名刺のデジタル化について

営業部では、これまで紙の名刺を、各自が名刺入れや机の引き出しで管理してきました。

担当が替わるときには、名刺の束を手渡しで引き継いでいます。引き継ぎには、半日ほどかかります。

ところが、この春の異動では、引き継ぎの漏れから、取引先への連絡が遅れる件がありました。

ほかの部でも、同じような困りごとを耳にします。

名刺の情報を探すのに、一人あたり週に一時間ほどかかっているという声もあります。

## 提案

名刺を読み取って共有するサービスを、来年の4月から営業部で使い始めることを提案します。費用は、一人あたり月500円です。
```

## 直した文章

```markdown chaff-after
# 営業部の名刺のデジタル化について

名刺を読み取って共有するサービスを、来年の4月から営業部で使い始めることを提案します。費用は、一人あたり月500円です。

## これまでの困りごと

営業部では、これまで紙の名刺を、各自が名刺入れや机の引き出しで管理してきました。

担当が替わるときには、名刺の束を手渡しで引き継いでいます。引き継ぎには、半日ほどかかります。

ところが、この春の異動では、引き継ぎの漏れから、取引先への連絡が遅れる件がありました。ほかの部でも、同じような困りごとを耳にします。名刺の情報を探すのに、一人あたり週に一時間ほどかかっているという声もあります。
```

## 直し方

この提案書は、最初の見出し「提案」が出てくるまでに、経緯の段落が五つ続いています。
読む人は、提案を決める立場の人です。何を、いつから、いくらで始めたいのかを探しに来ているのに、それが一番下まで出てきません。
経緯を読んでいるあいだは、何の話をしているのかも分かりません。

直した文章では、提案の中身を題のすぐ下に移し、経緯は「これまでの困りごと」という見出しの下にまとめました。
読む人は最初の二文で提案をつかみ、理由を知りたい人だけが先を読めます。

## 設定

この規則は、最初の見出しまでに置いてよい段落の数が変わります。ふだんは4段落まで、`strict` では2段落まで、`relaxed` では6段落までです。

```yaml chaff-settings
rules:
  preamble-length: relaxed
```

文の閉じない段落（分類の札や著者の行）と、本文の語に付けた注（※1 …）の段落は数えません。
題より下の見出しが一つもない文書は測りません。
法令や契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、話し言葉（`speech`）、メール（`business/email`）のジャンルでは動きません。
