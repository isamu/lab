# 中身の無い箇条書きの項目（`empty-list-item`）

**こんな文書に:** 研修や会議の案内、議事録、申請の手引き。決まっていない項目を後で埋めるつもりで空けておき、そのまま配ってしまう形がよくあります。

## 元の文章

```markdown chaff-before
# 新任管理職研修のご案内

この春に課長になった方を対象に、部下との面談の進め方を学ぶ研修を開きます。

- 日時：5月21日（木）午後1時から5時まで
- 会場：本社 7階 大会議室
- 講師：人事部 研修担当
- 持ち物：

参加する方は、5月14日までに人事部へ届け出てください。
```

## 直した文章

```markdown chaff-after
# 新任管理職研修のご案内

この春に課長になった方を対象に、部下との面談の進め方を学ぶ研修を開きます。

- 日時：5月21日（木）午後1時から5時まで
- 会場：本社 7階 大会議室
- 講師：人事部 研修担当
- 持ち物：筆記用具と、事前に配る面談の記録用紙

参加する方は、5月14日までに人事部へ届け出てください。
```

## 直し方

この案内の「持ち物：」には、何も書いてありません。
日時、会場、講師には値があるので、読む人には、持ち物が要らないのか、書き忘れなのか、まだ決まっていないのかが分かりません。
人によっては問い合わせ、人によっては何も持たずに来て、当日に記録用紙が足りなくなります。

直した文章では、持ち物を書きました。
まだ決まっていないなら「未定（5月14日までにお知らせします）」のように、いつ決まるかを書きます。
持ち物が無いなら「なし」と書くか、項目ごと消します。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  empty-list-item: relaxed
```

同じ箇条書きのほかの項目に「見出し：値」の形が一つも無いものは、記入用の書式と読んで指しません。
下に入れ子の箇条書きや段落が続く項目（「手順：」の下に手順を並べたもの）も指しません。
Markdown の箇条書きでだけ動きます。どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain empty-list-item --genre business/report

  中身の無い箇条書きの項目   (empty-list-item)

  「担当：」のように見出しの語だけを書いて値の無い項目や、記号だけの項目です。同じ箇条書きのほかの項目には値が書いてあるので、書き忘れか、まだ決まっていないことが読み手には分かりません。

  直しかた: 値を書いてください。まだ決まっていないなら「未定（いつ決めるか）」と書きます。要らない項目なら消します。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax empty-list-item --why "理由"
```
