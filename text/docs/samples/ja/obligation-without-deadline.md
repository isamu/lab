# 時を決めてする義務に、期限が無い（`obligation-without-deadline`）

**こんな文書に:** 業務委託や売買の契約書、利用規約。納品・通知・修正には期限を書いたのに、支払いだけ期限を書き忘れる、という形がよくあります。

## 元の文章

```markdown chaff-before
# ウェブサイト制作業務委託契約書

株式会社こもれび（以下「甲」という。）と、デザイン工房ふたば（以下「乙」という。）は、甲のウェブサイトの制作について、次のとおり契約を結ぶ。

## 第1条（納品）

乙は、2026年3月31日までに、完成したウェブサイトのデータを甲に納品する。

## 第2条（検収）

甲は、納品を受けた日から10日以内に検収を行い、その結果を乙に通知する。

## 第3条（修正）

乙は、検収で見つかった不具合を、通知を受けた日から7日以内に修正する。

## 第4条（委託料の支払い）

甲は、検収に合格したときは、委託料を乙に支払う。
```

## 直した文章

```markdown chaff-after
# ウェブサイト制作業務委託契約書

株式会社こもれび（以下「甲」という。）と、デザイン工房ふたば（以下「乙」という。）は、甲のウェブサイトの制作について、次のとおり契約を結ぶ。

## 第1条（納品）

乙は、2026年3月31日までに、完成したウェブサイトのデータを甲に納品する。

## 第2条（検収）

甲は、納品を受けた日から10日以内に検収を行い、その結果を乙に通知する。

## 第3条（修正）

乙は、検収で見つかった不具合を、通知を受けた日から7日以内に修正する。

## 第4条（委託料の支払い）

甲は、検収に合格した日の属する月の翌月末日までに、委託料を乙に支払う。
```

## 直し方

この契約書は、納品（3月31日までに）、検収（10日以内に）、修正（7日以内に）と、ほかの義務にはきちんと期限を書いています。
ところが第4条の支払いだけは、「委託料を乙に支払う」で終わり、いつまでに払うのかがありません。
これでは、甲が半年後に払っても、契約に反したとは言えません。乙にとっては、一番大事な条です。

直した文章では、「検収に合格した日の属する月の翌月末日までに」と、起点と日付で期限を書きました。
何日以内にするかは、甲と乙が話し合って決めることです。chaff は、ほかの義務と比べて期限が抜けている所を指すだけです。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  obligation-without-deadline: strict
```

期限を書いた義務の文が、期限の無い義務の文より多い文書でだけ、少ないほうを指摘します。期限をほとんど書かない契約書は、書き手がそう決めたとみなして指摘しません。
「速やかに」「遅滞なく」だけの期限は、`vague-deadline` が見ます。
契約書・規約のジャンルで動き、法令（`legal/statute`）、判決（`legal/judgment`）、特許（`legal/patent`）では動きません。
