# 回数×毎回の額と合わないお支払総額（`installment-total-mismatch`）

**こんな文書に:** ローンや分割払いの案内、月払いの申込書、修学旅行の積立の案内。回数を変えて作り直したときに、毎回の額か総額の片方だけが前のまま残る、という形がよくあります。

## 元の文章

```markdown chaff-before
# 分割払いのご案内

電動アシスト自転車「ハルカゼ」は、分割払いでもお求めいただけます。
金利は当店が負担しますので、お支払いの合計は現金でのお支払いと同じです。

- 本体価格：196,800円（税込）
- お支払回数：24回
- 毎月のお支払額：8,600円
- お支払総額：196,800円

お申し込みには、本人を確認できる書類と、お支払いに使う口座の通帳をお持ちください。
```

## 直した文章

# 分割払いのご案内

電動アシスト自転車「ハルカゼ」は、分割払いでもお求めいただけます。

- 本体価格：196,800円（税込）
- お支払回数：24回
- 毎月のお支払額：8,200円
- お支払総額：196,800円

## 直し方

毎月のお支払額は8,600円で、24回払うと206,400円です。ところがお支払総額は196,800円と書いてあり、9,600円合いません。総額は本体価格と同じで、案内の冒頭にも「お支払いの合計は現金でのお支払いと同じ」とあるので、誤っているのは毎月の額です。前の回数の案内から額を写したのでしょう。
分割払いを考える人は、毎月の額を見て家計に入るかを決めます。申し込んでから毎月の引き落としが案内と違うと分かると、店への信頼が損なわれます。

直した文章では、毎月のお支払額を、196,800円を24回で割った8,200円にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  installment-total-mismatch: strict
```

支払回数、毎回のお支払額、お支払総額の見出しにそれぞれ一つの額があるときに、回数と毎回の額の掛け算を総額と比べます。初回や最終回の額が別に書いてあれば、それも足して比べます。「約」の付いた額、幅で書いた額、ボーナス払いや頭金のある案内、支払い方をいくつも並べた案内は比べません。
文学のジャンルでは止めています。表の一行の掛け算は `line-amount-mismatch` が見ます。
