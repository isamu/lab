# あいまいな語が多い（`vague-word-density`）

**こんな文書に:** 手順書、社内の決まり、業務の引き継ぎ。書き手には当たり前のことを、「適宜」「必要に応じて」「適切に」で済ませると、新しく来た人が迷います。

## 元の文章

```markdown chaff-before
# 来客の受付の手順

総務課で受付当番をする人のための手順です。
当番は、午前と午後で一人ずつ交代します。

## 来客が着いたら

来客が着いたら、名前と訪問先を聞き、来客の名簿に書いてもらいます。
訪問先の担当者には、内線で着いたことを伝えます。
担当者が電話に出ないときは、同じ部署の人を呼んでください。
来客には、ロビーの椅子で待ってもらいます。
待つ時間が長くなりそうなときは、適宜お茶を出してください。

## 入館証を渡す

名簿に書いてもらったら、入館証を一枚渡します。
入館証は、受付の机にある右の引き出しに入っています。
入館証の番号は、名簿の右の欄に書き写します。
入館証が足りなくなったら、必要に応じて総務課の係長に伝えてください。

## 荷物を預かる

大きな荷物を持った来客には、荷物を預かるかどうかを聞きます。
預かった荷物には、番号札を付けて、受付の奥の棚に置きます。
番号札の半分は、来客に渡します。
預かった荷物は、なるべく受付の近くに置いてください。

## 来客が帰るとき

来客が帰るときは、入館証を受け取り、名簿に帰った時刻を書きます。
預かった荷物は、番号札と引き換えに返します。
入館証を返さずに帰った来客がいたら、適切に対応してください。

## 一日の終わりに

午後の当番は、受付を閉める前に、その日の名簿を総務課の棚に戻します。
入館証の数を数え、名簿と合うかを確かめます。
```

## 直し方

この手順書は、受付の流れを丁寧に書いていますが、迷いやすい所ほど「適宜」「必要に応じて」「なるべく」「適切に」で済ませています。はじめて当番をする人は、いつお茶を出すのか、入館証が何枚になったら伝えるのか、何をすれば「適切」なのかを、自分で決めることになります。人によってやり方が変わり、手順書を書いた意味が薄れます。

直した文章では、「待つ時間が10分を過ぎたら」「残りが5枚になったら」「重い荷物は、棚の下の段に」「その日のうちに訪問先の担当者に伝えてください」と、いつ・どこで・何をするのかを書きました。

## 設定

1000字あたりのあいまいな語の数で見ます。ふだんは 2 個まで、`relaxed` にすると 4 個まで、`strict` にすると 1 個までです。短い文書は測りません。

```yaml chaff-settings
rules:
  vague-word-density: relaxed
```

すぐ後ろの括弧で中身を書いた語（一定の事項（請求書に書く事項））は数えません。
要求の文の中の「可能な限り」「必要に応じて」は、`requirement-smell` も見ます。
どのジャンルでも動きます。
