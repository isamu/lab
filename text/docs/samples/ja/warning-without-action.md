# することの書かれていない注意書き（`warning-without-action`）

**こんな文書に:** 手順書、ヘルプ、社内の操作説明。危ないことに気づいて注意書きを足したのに、どうすれば防げるのかを書き忘れる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 会員の名簿を新しい形式に移す

移した名簿は、会員の検索と一斉メールに使えます。ここでは、その移し方を説明します。

## 手順

注意：移行を始めると、古い形式の名簿は消え、元に戻せません。

1. 管理画面の「設定」を開き、「名簿の移行」を選びます。
2. 移す名簿を選び、「移行を始める」を押します。
3. 終わると、画面に移した会員の数が出ます。

## 移行の後

移した名簿は、「会員」の画面で確かめられます。
会員の数が合わないときは、サポート窓口に連絡してください。
```

## 直した文章

```markdown chaff-after
# 会員の名簿を新しい形式に移す

移した名簿は、会員の検索と一斉メールに使えます。ここでは、その移し方を説明します。

## 手順

注意：移行を始めると、古い形式の名簿は消え、元に戻せません。始める前に、「名簿の書き出し」で古い名簿を手元に保存してください。

1. 管理画面の「設定」を開き、「名簿の移行」を選びます。
2. 移す名簿を選び、「移行を始める」を押します。
3. 終わると、画面に移した会員の数が出ます。

## 移行の後

移した名簿は、「会員」の画面で確かめられます。
会員の数が合わないときは、サポート窓口に連絡してください。
```

## 直し方

「注意：移行を始めると、古い形式の名簿は消え、元に戻せません。」は、危険をきちんと書いています。けれども、読み手が何をすれば防げるのかがありません。注意書きを読んだ人は不安になるだけで、そのまま「移行を始める」を押すかもしれません。

直した文章では、同じ段落に「始める前に、「名簿の書き出し」で古い名簿を手元に保存してください。」と、読み手がすることを書き足しました。注意書きは手順の前に置いてあるので、読み手は始める前に保存できます。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  warning-without-action: strict
```

「注意」「警告」「危険」をそれだけで頭に置いた段落（「注意：」「**警告**」「> [!WARNING]」）だけを読みます。どれかの文が「〜してください」「〜しないこと」で終わっていれば指しません。
技術文書・説明書・ブログで動き、法務、学術、文学、話し言葉では止めています。
