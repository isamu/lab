# 出所を言わない「多くの専門家」（`weasel-word`）

**こんな文書に:** 会社のブログ、健康や暮らしの記事、提案書。自分たちで確かめた結果に、どこかで聞いた話を「〜と言われています」で足してしまいます。

## 元の文章

```markdown chaff-before
# 昼休みに十五分歩くと、午後の眠気が減るのか

## 試したこと

当社では、10月の一か月間、営業部の十人が、昼休みに十五分ずつ会社の周りを歩きました。
歩いた日と歩かなかった日に、午後三時の眠気を五段階で書いてもらいました。

## わかったこと

差ははっきり出ました。
歩いた日の眠気は、平均で五段階の2.1でした。
歩かなかった日は、平均で3.4でした。
食後に軽く歩くと、血糖値の上がり方がゆるやかになると言われています。
十人のうち八人が、来月も続けたいと答えました。

## これから

11月からは、ほかの部署にも声をかけます。
歩く道は、会社の裏の川沿いの道を勧めます。
```

## 直した文章

```markdown chaff-after
# 昼休みに十五分歩くと、午後の眠気が減るのか

## 試したこと

当社では、10月の一か月間、営業部の十人が、昼休みに十五分ずつ会社の周りを歩きました。
歩いた日と歩かなかった日に、午後三時の眠気を五段階で書いてもらいました。

## わかったこと

差ははっきり出ました。
歩いた日の眠気は、平均で五段階の2.1でした。
歩かなかった日は、平均で3.4でした。
眠気が減った理由は、まだわかりません。食後に体を動かしたからか、外の光を浴びたからかは、来月に調べます。
十人のうち八人が、来月も続けたいと答えました。

## これから

11月からは、ほかの部署にも声をかけます。
歩く道は、会社の裏の川沿いの道を勧めます。
```

## 直し方

この記事は、十人で試した結果をきちんと書いています。そこに一文だけ、「食後に軽く歩くと、血糖値の上がり方がゆるやかになると言われています」が混ざっています。誰がそう言ったのかがないので、読み手は確かめられず、記事の自分たちで測った数字まで、同じくらいあやふやに見えてしまいます。

直し方は二つです。出典（誰が、いつ、どの研究で）を書くか、書けないならその文を落とすか、書き手自身の考えとして書きます。
直した文章では、出典を挙げずに、「眠気が減った理由は、まだわかりません。食後に体を動かしたからか、外の光を浴びたからかは、来月に調べます。」と、分かっていないことを分かっていないと書きました。記事の数字は、自分たちが測ったものだけになります。

## 設定

ふだんは当てはまる言い回しが 1 箇所あれば指摘し、`relaxed` にすると 2 箇所からになります。

```yaml chaff-settings
rules:
  weasel-word: relaxed
```

日本語では、「と言われる」は「と言われている」の形だけを見ます。「研究によると」は「ある」「多くの」などが付いた形だけを見ます。その場で相手から言われた言葉を引いて伝える形（業者から「…」と言われている）は指しません。
法務、文学、話し言葉のジャンルでは止めています。
