# 同じ項目の量を違う単位で書いて、換算すると合わない（`unit-mismatch`）

**こんな文書に:** イベントの案内、製品の仕様書、レシピ。片方の単位を書き換えたときに、数を直し忘れます。

## 元の文章

```markdown chaff-before
# 秋の社内ウォーキング大会

川沿いの遊歩道を歩いて、公園で昼食をとります。雨のときは、次の週に延ばします。

距離：8 km

- 集合：西口の広場
- 距離：6500 m
- 持ち物：飲み物、雨具、歩きやすい靴

申し込みは、11月14日までに総務課へお願いします。
```

## 直した文章

```markdown chaff-after
# 秋の社内ウォーキング大会

川沿いの遊歩道を歩いて、公園で昼食をとります。雨のときは、次の週に延ばします。

距離：8 km

- 集合：西口の広場
- 距離：8000 m
- 持ち物：飲み物、雨具、歩きやすい靴

申し込みは、11月14日までに総務課へお願いします。
```

## 直し方

同じ案内に「距離：8 km」と「距離：6500 m」があります。8 km は 8000 m なので、二つは合いません。
読む人は、どちらの距離を歩くのかを換算して確かめることになり、歩けるかどうかを決められません。

コースの地図を確かめると8 kmだったので、箇条書きの距離を8000 mに直しました。
一つの文書では、同じ項目の単位をそろえると、読み手が比べやすくなります。
chaff は、長さ、重さ、時間、体積、温度などの量を換算して比べます。丸めた書き方（1 mile と 1.6 km）は、2% までの差なら合っていると見ます。

## 設定

ふだんは「注意」として出します。`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  unit-mismatch: relaxed
```

「項目：量」と表の升では、同じ節の同じ項目の量を比べます。ほかに、180℃（350°F）のように一つの量を括弧で二つの単位に並べた所と、材料の表に書いた品物を手順で違う単位で書いた所も比べます。
単位が同じ量（食い違いは `fact-conflict` が見ます）、長さと重さのように種類の違う量、違う見出しの下の量は見ません。
どのジャンルでも動きます。
