# 構成が人の記事から外れている（`ai-structure`）

**こんな文書に:** 提案書、企画書、報告書、ブログ。AI に「提案書の形で」と頼むと、文より先に構成に型が出ます。

## 元の文章

```markdown chaff-before
# 社員食堂の昼の混雑を減らす提案

## 背景

社員食堂は、正午から十二時半までに利用者の六割が集中しています。
列に十五分以上並ぶ日もあり、昼休みの半分が待ち時間で終わるという声が、社内のアンケートで多く寄せられました。

## 課題

混む時間に、席と配膳の両方が足りなくなっています。
とくに配膳の列は、定食を選ぶ人と麺類を選ぶ人が同じ列に並ぶため、なかなか進みません。

## 提案

昼休みの時間を、部署ごとに十二時からと十二時半からの二つに分けます。
あわせて、配膳の列を定食と麺類の二つに分けます。

## 期待される効果

一度に食堂に来る人が半分ほどになり、並ぶ時間は五分以内に収まる見込みです。
席を探して歩き回る人も減り、食堂の中の混雑も和らぎます。

## 費用

列を分けるための案内の看板と、配膳台の移動に、合わせて十二万円ほどかかります。
昼休みを分けることには、費用はかかりません。

## リスクと対策

昼休みが遅い組になる部署から、不満が出るおそれがあります。
三か月ごとに、早い組と遅い組を入れ替えることで、公平にします。

## まとめ

昼休みを二つに分け、配膳の列を分けることで、昼の混雑を減らせます。
費用は十二万円ほどで、来月から始められます。
```

## 直した文章

```markdown chaff-after
# 社員食堂の昼の混雑を減らす提案

社員食堂は、正午から十二時半までに利用者の六割が集中しています。
列に十五分以上並ぶ日もあり、昼休みの半分が待ち時間で終わるという声が、社内のアンケートで多く寄せられました。
混む時間には、席と配膳の両方が足りません。
とくに配膳の列は、定食を選ぶ人と麺類を選ぶ人が同じ列に並ぶため、なかなか進みません。

## 昼休みを二つに分け、配膳の列も分ける

昼休みの時間を、部署ごとに十二時からと十二時半からの二つに分けます。
一度に食堂に来る人が半分ほどになり、並ぶ時間は五分以内に収まる見込みです。
あわせて、配膳の列を定食と麺類の二つに分けます。

遅い組になる部署からは、不満が出ると思います。
そこで、三か月ごとに早い組と遅い組を入れ替えます。
外のお客さまとの打ち合わせが昼にかかりやすい営業部は、希望すれば遅い組に固定できるようにします。

## 費用と始める時期

列を分けるための案内の看板と、配膳台の移動に、合わせて十二万円ほどかかります。
来月の部長会で決まれば、その翌月から始められます。
```

## 直し方

元の文章は、「背景」「課題」「提案」「期待される効果」「費用」「リスクと対策」「まとめ」と、教科書どおりの見出しを七つ並べています。
どの節も一、二文で、長さもほとんど同じです。
「まとめ」は、本文で言ったことを言い直しているだけです。
一つ一つは本物の提案書にもある形ですが、そろうと、中身より先に枠を埋めた文書に見えます。

直した文章では、構成から書き直しました。
背景と課題は見出しを外して書き出しにまとめ、提案と効果とリスクは「昼休みを二つに分け、配膳の列も分ける」という一つの節にしています。
不満が出るおそれは、対策と一緒にその節の中で書きました。
「まとめ」は消し、最後の節で費用と始める時期を言って終えています。

## 設定

見出しの多さや節の長さのばらつきなどの項目を、人の記事と比べます。人の記事の9割を超えた項目が3個そろうと指摘します。
提案書・報告書の定型の見出しが4種類以上あれば1項目に数え、見出しのほとんど（4分の3以上）が定型なら、もう1項目に数えます。

```yaml chaff-settings
rules:
  ai-structure: relaxed
```

`relaxed` にすると4個から、`strict` なら2個からです。
項目ごとの値と人の記事の値は、`npx chaffjs outline proposal.md` で見られます。直す前と後を並べて比べることもできます。
見出しの無い文書は見ません。法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、講演（`speech`）のジャンルでは、はじめから動きません。
これでも、AI が書いたとは言いません。構成を見直す目印です。
