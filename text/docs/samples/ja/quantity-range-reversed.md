# 量の範囲の上限が下限より小さい（`quantity-range-reversed`）

**こんな文書に:** 製品の仕様書、取扱説明書の仕様の表、作業の基準。負の温度を書くときに、符号を余計に付けてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 温湿度ロガー TL-20 の仕様

| 項目 | 仕様 |
| --- | --- |
| 測定範囲（温度） | -20〜60℃ |
| 測定範囲（湿度） | 10〜90% |
| 使用温度範囲 | -10〜50℃ |
| 保存温度範囲 | -20〜-60℃ |
| 電源 | 単3形アルカリ乾電池 2本 |
| 重さ | 約85 g（電池を含まない） |

結露した状態では使わないでください。
```

  ⚠  量の範囲の上限が下限より小さい

     量の範囲「-20〜-60℃」の上限が下限より小さくなっています
     「使用温度範囲：-10〜-40℃」「重さ 5〜2 kg」のように、測った量の範囲の終わりが始まりより小さいと、読み手はどちらの値が正しいのか、範囲がどこからどこまでなのかを確かめることになります。仕様書の温度や寸法で、片方の値だけを書き換えたときや、負の符号を書き足したとき、二つを入れ替えて書いたときに起きます。同じ単位の二つの量の間が範囲の記号（〜、–）だけのときと、「から」でつなぎ終わりの量のあとに「まで」が続くときを範囲として比べます。単位を一度だけ書いた範囲（30〜10 cm）も読みます。負の数は符号ごと読むので、-10〜-40℃ は終わりが小さく、-40〜-10℃ はそのままです。数の直後のハイフン（5-10 kg）は負の符号ではなく範囲の記号と読みます。同じ行に下限と上限を書いた二つの量も比べます。

## 直した文章

```markdown chaff-after
# 温湿度ロガー TL-20 の仕様

| 項目 | 仕様 |
| --- | --- |
| 測定範囲（温度） | -20〜60℃ |
| 測定範囲（湿度） | 10〜90% |
| 使用温度範囲 | -10〜50℃ |
| 保存温度範囲 | -20〜60℃ |
| 電源 | 単3形アルカリ乾電池 2本 |
| 重さ | 約85 g（電池を含まない） |

結露した状態では使わないでください。
```

## 直し方

保存温度範囲は「-20〜-60℃」と書いてあり、終わりの「-60℃」が始まりの「-20℃」より低くなっています。上の行の測定範囲は「-20〜60℃」なので、60℃の前に負の符号を書き足してしまったのでしょう。
仕様の表を読む人は、この範囲を見て倉庫や車の中に置いてよいかを決めます。「-20〜-60℃」のままでは、真夏の倉庫に置けるのか、零下でしか保存できないのかが分からず、問い合わせるか、自分の読みで決めることになります。

直した文章では、符号を外して「-20〜60℃」にしました。負の数は符号ごと読むので、「-40〜-10℃」のように下から上へ書いた範囲はそのままで指摘されません。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  quantity-range-reversed: strict
```

同じ単位の二つの量の間が「〜」のような範囲の記号だけのときと、「から」でつなぎ終わりの量のあとに「まで」が続くときを、範囲として比べます。「5-10 kg」のように数の直後にあるハイフンは、負の符号ではなく範囲の記号と読みます。「40℃から10℃まで冷却」のように値を変える語のある文、単位の違う二つの量、百分率は比べません。
文学のジャンルでは止めています。金額の範囲は `amount-range-reversed` が見ます。
