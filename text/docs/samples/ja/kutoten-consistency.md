# 句読点の書き方がそろっていない（`kutoten-consistency`）

**こんな文書に:** 報告書、申請書、研究室や役所とやり取りする文書。「，」を使う書式の資料から段落を写すと、そこだけ読点が違って見えます。

## 元の文章

```markdown chaff-before
# 地域清掃活動の報告

10月の第2日曜日に、川沿いの遊歩道で清掃活動を行いました。
参加したのは、町内会の会員と近くの中学生、合わせて42人です。

集めたごみは、燃えるごみが袋で18袋、空き缶とペットボトルが袋で9袋でした。
昨年に比べて，たばこの吸い殻が目立って減りました．
川に近い草むらでは、捨てられた自転車が1台見つかり、市の担当課に引き取りを頼みました。

次回は、来年の3月に行う予定です。
```

## 直した文章

```markdown chaff-after
# 地域清掃活動の報告

10月の第2日曜日に、川沿いの遊歩道で清掃活動を行いました。
参加したのは、町内会の会員と近くの中学生、合わせて42人です。

集めたごみは、燃えるごみが袋で18袋、空き缶とペットボトルが袋で9袋でした。
```

## 直し方

この報告は「、」と「。」で書かれていますが、吸い殻の一文だけが「，」と「．」になっています。
横書きの論文や公用文では「，」を使うこともあり、どちらも正しい書き方です。困るのは一つの文書の中で混ざることで、読み手には、そこだけ別の資料から写したように見えます。

少ないほうの一文を、ほかと同じ「、」と「。」に直しました。
chaff は、読点と句点を別々に数え、それぞれ文書の中で少ないほうを指します。この一文では読点と句点の両方が少ないほうですが、一つの文の中の違いは一件にまとめるので、指摘は一つです。数の中の「，」や、番号の後ろの「．」は数えません。

## 設定

```yaml chaff-settings
rules:
  kutoten-consistency: relaxed
```

ふだんは、少ないほうが1か所でもあれば指摘します。
`relaxed` にすると、少ないほうが3か所あるときだけ指摘します。見たくなければ `off` にします。
日本語の文書で、どのジャンルでも動きます。
