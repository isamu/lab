# 引用と文献一覧が合っていない（`citation-reference-mismatch`）

**こんな文書に:** 論文、研究の報告書、卒業論文。文献を一つ消して番号を振り直したとき、本文の番号だけが古いまま残ります。

## 元の文章

```markdown chaff-before
# 在宅勤務の日の睡眠時間

## はじめに

在宅勤務が広がり、会社員が通勤にかける時間は大きく減った[1]。通勤が無くなった時間は、家事や育児に回るという調査がある[2]。
一方で、その時間が睡眠に回るかどうかは、まだよく分かっていない。寝る時刻が遅くなるだけで、睡眠の長さは変わらないという報告もある[4]。

## 参考文献

- [1] 山本健一. 在宅勤務と通勤時間の変化. 2022.
- [2] 中村由美. 在宅勤務をした日の時間の使い方. 2023.
- [3] 小林誠. 在宅勤務と寝る時刻. 2024.
```

## 直した文章

```markdown chaff-after
# 在宅勤務の日の睡眠時間

## はじめに

在宅勤務が広がり、会社員が通勤にかける時間は大きく減った[1]。通勤が無くなった時間は、家事や育児に回るという調査がある[2]。
一方で、その時間が睡眠に回るかどうかは、まだよく分かっていない。寝る時刻が遅くなるだけで、睡眠の長さは変わらないという報告もある[3]。

## 参考文献

- [1] 山本健一. 在宅勤務と通勤時間の変化. 2022.
- [2] 中村由美. 在宅勤務をした日の時間の使い方. 2023.
- [3] 小林誠. 在宅勤務と寝る時刻. 2024.
```

## 直し方

本文は [4] を引いていますが、文献一覧には3番までしかありません。そして3番の文献は、本文で一度も引かれていません。
この論文では、下書きの段階で文献を一つ消し、文献一覧の番号を振り直しました。本文の [4] だけを直し忘れたので、二つの指摘が一度に出ます。
読む人は4番の文献を探して見つけられず、「寝る時刻が遅くなる」という主張の根拠を確かめられません。査読では、まずここを指されます。

直した文章では、本文の [4] を [3] に直しました。
引用が一覧に無いのか、一覧の文献を引き忘れたのかは、機械では決められません。どちらがずれたかは、書いた人が確かめます。
chaff は、番号で引く論文は番号どうしを、「（山本, 2022）」のように著者と年で引く論文は姓と年どうしを比べます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  citation-reference-mismatch: strict
```

投稿の前に必ず止めたいなら `strict` にします。
論文のジャンルでだけ動きます。「参考文献」「References」のような見出しの下に文献一覧が無い文書は見ません。

    strict   エラー

  変える:  npx chaffjs relax citation-reference-mismatch --why "理由"
