# 会話の返事の名残（`assistant-residue`）

**こんな文書に:** 社内の報告やメモ、ブログ。チャットの AI に調べさせた答えを、そのまま文書に貼ったときに出ます。

## 元の文章

```markdown chaff-before
# 社用車の入れ替え候補について

来年度に入れ替える営業用の社用車三台について、候補を二つに絞りました。
どちらも五人乗りで、いまの車より燃費のよいハイブリッド車です。

候補Aは、車両の価格が候補Bより一台あたり二十万円ほど安く、荷室も広めです。
候補Bは、運転を助ける装置が標準で付いていて、夜の高速道路を走ることの多い営業二課からの評判がよい車です。

なお、私の知識は2024年初めまでの情報に基づいているため、最新の価格や装備は販売店にご確認ください。

どちらを選ぶかは、価格を優先するか、安全装置を優先するかで決まります。
来月の部長会で決めていただければ、納車は四月に間に合います。

お役に立てれば幸いです。
```

## 直し方

元の文章には、「私の知識は2024年初めまでの情報に基づいているため」と「お役に立てれば幸いです」が残っています。
どちらも、チャットで AI が質問した人に返した言葉です。
部長会の資料として読む人には「私」が誰なのか分からず、価格がいつの情報なのかも分かりません。

直した文章では、知識の期限の断り書きを、確かめた日と出典に置き換えました（「10月20日に近くの販売店二つで見積もりを取って確かめたものです」）。
これで、読み手は数字をどこまで信じてよいかを自分で判断できます。
結びの「お役に立てれば幸いです」は、資料の読み手に向けた言葉ではないので消しました。

## 設定

言い回しごとに重みがあり、合計が10点で指摘します。
AI としての断り書きや知識の期限（「私の知識は」「言語モデルとして」）は10点で、一つで指摘します。
人も書く礼の言葉（「お役に立てれば幸いです」）は5点で、二つ重なったときだけ指摘します。

```yaml chaff-settings
rules:
  assistant-residue: relaxed
```

`relaxed` にすると20点からになり、断り書きが一つだけなら指摘しません。
講演の書き起こし（`speech/transcript`）では、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score memo.md` で見られます。
