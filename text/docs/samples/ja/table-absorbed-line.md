# 表に取り込まれた行（`table-absorbed-line`）

**こんな文書に:** 報告書、予算書、見積書。表のすぐ下に注意書きや合計を書く Markdown の文書。

## 元の文章

```markdown chaff-before
# 部の合宿の予算

| 項目 | 金額 |
| --- | --- |
| 会場 | 12万円 |
| 昼食 | 4万5千円 |
| 交通 | 3万円 |
金額はすべて税込みです。会場の手付金は5月2日までに払います。
```

## 直した文章

```markdown chaff-after
# 部の合宿の予算

| 項目 | 金額 |
| --- | --- |
| 会場 | 12万円 |
| 昼食 | 4万5千円 |
| 交通 | 3万円 |

金額はすべて税込みです。会場の手付金は5月2日までに払います。
```

## 直し方

税込みと手付金の注意書きを、表のすぐ下の行に書いていました。
Markdown の表は空行が来るまで続くので、注意書きは表の四つ目の行になり、「項目」の列に押し込まれて表示されます。手付金の期限が金額の中に埋もれます。

直した文章では、表と注意書きのあいだに空行を一つ入れ、注意書きを表の外の段落に戻しました。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  table-absorbed-line: relaxed
```

「|」を含む行、列が一つだけの表、空行を空けた文、表の後のリストや見出し、コードと引用の中の表は指しません。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain table-absorbed-line --genre business/report

  表に取り込まれた行   (table-absorbed-line)

  Markdown の表（GFM）は、空行が来るまで続きます。表のすぐ下に空行を空けずに文を書くと、その文は表の行として読まれ、最初の列のセルに入って表示されます。表の後の説明や合計の一文が、表の中の行に化けます。区切りの「|」が一つも無い行なので、書いた人は表の外のつもりです。

  直しかた: 表とこの行のあいだに空行を一つ入れてください。表の行のつもりなら、セルを「|」で区切ってください。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax table-absorbed-line --why "理由"
```
