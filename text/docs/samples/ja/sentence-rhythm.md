# 文の長さが単調（`sentence-rhythm`）

**こんな文書に:** ブログのエッセイ、体験記、README。AI の下書きや、一文ずつ丁寧に書きそろえた文章で、どの文も同じ長さになります。

## 元の文章

```markdown chaff-before
# 近所のパン屋が店を閉めた

駅前の小さなパン屋が、先月の終わりに店を閉めました。
私はこの町に越してきてから、十年ほどその店に通っていました。
朝の七時に開く店で、通勤の前に寄るのが習慣になっていました。
いつも買っていたのは、くるみの入った丸いパンと牛乳でした。

店を切り盛りしていたのは、六十代くらいのご夫婦でした。
最後の日には、開店の前から店の外に長い列ができていました。
私も並びましたが、くるみのパンは私の前で売り切れました。
レジで奥さんに、長いあいだありがとうございましたと言われました。

何か言おうとしましたが、うまく言葉が出てきませんでした。
いまは駅の反対側にある大きな店で、朝のパンを買っています。
```

## 直した文章

```markdown chaff-after
# 近所のパン屋が店を閉めた

駅前の小さなパン屋が、先月の終わりに店を閉めました。
十年通った店です。
朝の七時に開くので、通勤の前に寄って、くるみの入った丸いパンと牛乳を買うのが習慣になっていました。

店を切り盛りしていたのは、六十代くらいのご夫婦でした。
最後の日には、開店の前から店の外に長い列ができていました。
私も並びました。
くるみのパンは、私の二人前で売り切れました。
レジで奥さんに、長いあいだありがとうございましたと言われ、何か言おうとしたのに、言葉が出てきませんでした。

いまは駅の反対側にある大きな店で、朝のパンを買っています。
くるみのパンも売っています。
```

## 直し方

元の文章は、十の文がどれも30字前後で、「〜でした。」「〜ました。」と同じ形で終わります。
一文ずつは正しいのに、読むと同じ速さの足音が続くようで、どこが山なのかが伝わりません。

直した文章では、短い文を混ぜ、つながっている文はまとめました。
「十年通った店です。」「私も並びました。」と短く切り、レジでのやりとりは一文にまとめて、言葉が出なかった所までを一息で読ませています。
最後に「くるみのパンも売っています。」と短く足すと、書き手が何を思っているのかを、説明しなくても読み手が受け取れます。

## 設定

文の長さのばらつきが36%より小さいと指摘します（ブログのエッセイ `blog/essay` の値です）。地の文が8文より少ない文書は測りません。

```yaml chaff-settings
rules:
  sentence-rhythm: relaxed
```

`relaxed` にすると30%より小さいときだけ、`strict` なら40%より小さいときに指摘します。
箇条書きの項目は数えません（そろえて書くのが正しい形です）。
ビジネス文書（`business`）では見ません。法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでも、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain

```
