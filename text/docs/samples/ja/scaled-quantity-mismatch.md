# 人数の列で、一行だけ量が比のとおりに増えていない（`scaled-quantity-mismatch`）

**こんな文書に:** レシピのページ、給食や社員食堂の献立、仕込みの手順書。人数の列を足したときに、一行だけ量を直し忘れます。

## 元の文章

```markdown chaff-before
# 煮込みハンバーグ

週末にまとめて作って、冷凍しておけるハンバーグです。

## 材料

| 材料 | 4人分 | 8人分 |
| --- | --- | --- |
| 合いびき肉 | 500g | 1000g |
| 玉ねぎ | 1個 | 2個 |
| 牛乳 | 60ml | 120ml |
| パン粉 | 30g | 60g |
| ケチャップ | 大さじ4 | 大さじ4 |
| 塩 | 少々 | 少々 |

## 作り方

玉ねぎをみじん切りにして、きつね色になるまで炒めます。
冷ました玉ねぎと残りの材料をよくこねて、形を整えて焼きます。
```

## 直した文章

```markdown chaff-after
# 煮込みハンバーグ

週末にまとめて作って、冷凍しておけるハンバーグです。

## 材料

| 材料 | 4人分 | 8人分 |
| --- | --- | --- |
| 合いびき肉 | 500g | 1000g |
| 玉ねぎ | 1個 | 2個 |
| 牛乳 | 60ml | 120ml |
| パン粉 | 30g | 60g |
| ケチャップ | 大さじ4 | 大さじ8 |
| 塩 | 少々 | 少々 |

## 作り方

玉ねぎをみじん切りにして、きつね色になるまで炒めます。
冷ました玉ねぎと残りの材料をよくこねて、形を整えて焼きます。
```

## 直し方

8人分の列は、ひき肉も玉ねぎも牛乳もパン粉も、4人分のちょうど2倍です。ケチャップだけが、4人分と同じ大さじ4のままです。
8人分を作る人は、表のとおりに入れて、味の薄いソースを作ることになります。

8人分の列を足したときの直し忘れと読めるので、ケチャップを大さじ8に直しました。
わざと増やさない量なら、塩のように「少々」「適量」と書きます。chaff はそうした行を比べません。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  scaled-quantity-mismatch: strict
```

見出しが人数や倍数（4人分、8人前、×2）だけの列を二つ以上持つ表で、少なくとも3行がちょうど列の比のとおりに増え、比のとおりでない行がちょうど一行のときに指します。
g と kg のように換算できる単位は換算して比べます。「大さじ1と1/2」のように数が一つでない升、単位の違う升、比のとおりでない行が二行以上ある表は言いません。
文芸のジャンルでは、はじめから動きません。
