# 数に合わない序数の字（`ordinal-suffix-mismatch`）

**こんな文書に:** 社内の案内メール、催しの告知、議事録。回の番号を「1st」「2nd」と英語の序数で並べた箇条で、前の回を写して数だけを書き換えると、字が残ります。

## 元の文章

```markdown chaff-before
件名：社内勉強会のご案内（11月28日）

開発部のみなさま

お疲れさまです。広報の森です。

今月の社内勉強会は、11月28日（金）の午後4時から、3階の大会議室で開きます。
春に始めたこの会も、今回で三回目になりました。
これまでの回と今回のテーマは、次のとおりです。

- 1st（6月20日）：社内の道具の使い方
- 2nd（9月19日）：設計の書き方
- 3th（11月28日）：問い合わせの返事を早くする工夫

参加する方は、11月26日（水）までに、このメールに返信してください。
席は30人分です。

よろしくお願いします。
```

```text chaff-output
  ⚠  数に合わない序数の字

     「3th」は「3rd」と書きます
     英語の序数は、数の終わりで付く字が決まっています（1st、2nd、3rd、4th、11th、12th、13th、21st）。「3th」「22th」「11st」は打ち間違いか、数だけを書き換えて字を残したもので、読み手はどの数が正しいのかを疑います。数と字の対応は決まっているので、機械で言えます。

     → 数が正しいかを確かめ、その数に合う字に直してください。

     このルールをゆるめる:  npx chaffjs relax ordinal-suffix-mismatch
```

## 直し方

勉強会の回を「1st」「2nd」と並べた箇条の三つ目が「3th」になっています。英語の序数は数の終わりで字が決まっていて、3 なら「3rd」です。
前の行を写して数だけを書き換えると、こういう字が残ります。読み手は「3th」を見て、数が違うのか字が違うのか、どちらを信じればよいか迷います。

直した文章では、数が今回の「三回目」と合っていることを確かめてから、字を「3rd」に直しました。chaff は数と字の対応だけを見ます。数そのものが正しいかどうかは、書き手が確かめます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  ordinal-suffix-mismatch: relaxed
```

語や番号の一部（v1th、0x2nd）と、コードの中は読みません。
どのジャンルでも動きます。

```text chaff-explain

  直しかた: 数が正しいかを確かめ、その数に合う字に直してください。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
```
