# 「#」の後ろに空白が無く、見出しにならない（`heading-marker-no-space`）

**こんな文書に:** 社内の手引き、操作マニュアル、README。日本語の文書では語のあいだに空白を入れないので、「##」の後ろの空白も抜けがちです。

## 元の文章

```markdown chaff-before
# 経費精算の手引き

## 申請のしかた

精算システムに領収書の写真を載せ、金額と用途を入れて申請します。

##承認

上長が申請を確かめ、承認すると経理に回ります。
```

```text chaff-output
  ⚠  「#」の後ろに空白が無く、見出しにならない

     Markdown の見出しは、「#」と言葉のあいだに空白が要ります。「#見出し」「##手順」のように空白を抜くと、見出しにならず、「#」の付いた本文の一行として表示されます。目次にも画面読み上げにも載らず、見出しへのリンクも張れません。空白を入れない書き方に慣れた日本語の文書で特に起きます（markdownlint の MD018 と MD020）。
```

## 直した文章

```markdown chaff-after
# 経費精算の手引き

## 申請のしかた

精算システムに領収書の写真を載せ、金額と用途を入れて申請します。

## 承認
```

## 直し方

Markdown の見出しは、「#」と言葉のあいだに空白が要ります。「##承認」は空白が無いので見出しにならず、「##承認」という本文の一行として表示されます。
目次にも画面の読み上げにも載らず、この節へのリンクも張れません。

直した文章では、「##」の後ろに空白を一つ入れて「## 承認」にしました。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」になります。

```yaml chaff-settings
rules:
  heading-marker-no-space: strict
```

「#」の後ろが字でない行（電話の短縮番号「#9110」や「#1」のような番号）は指しません。
「#」が一つだけの行はタグ（「#chaff」）と同じ書き方なので、それだけで一つの段落になっていて、文書がほかに見出しを書いているときだけ指します。

```text chaff-explain
$ npx chaffjs explain heading-marker-no-space --genre docs/manual

  「#」の後ろに空白が無く、見出しにならない   (heading-marker-no-space)

  Markdown の見出しは、「#」と言葉のあいだに空白が要ります。「#見出し」「##手順」のように空白を抜くと、見出しにならず、「#」の付いた本文の一行として表示されます。目次にも画面読み上げにも載らず、見出しへのリンクも張れません。空白を入れない書き方に慣れた日本語の文書で特に起きます（markdownlint の MD018 と MD020）。

  直しかた: 「#」の後ろに空白を一つ入れてください（「##手順」を「## 手順」に）。見出しでなく、タグや番号として書いたものなら、行の頭から外してください。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax heading-marker-no-space --why "理由"
```
