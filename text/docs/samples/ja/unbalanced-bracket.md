# 括弧が組になっていない（`unbalanced-bracket`）

**こんな文書に:** 議事録、報告書、規程。括弧の中に補足を書き足したり、文を切り貼りしたりすると、閉じか開きの片方だけが残ります。

## 元の文章

```markdown chaff-before
# 防災訓練の打ち合わせ 議事録

日時：11月18日（火）15時から16時
出席：総務課、各フロアの防災担当

## 決まったこと

- 訓練は12月5日（金）の14時から行う。避難の経路は、去年と同じ（東側の非常階段を使う。
- 集まる場所は、駐車場の北の端とする。
- 各フロアの担当は、訓練の後に「人数の確認表」を総務課に出す」。

## 次回

11月28日（金）の15時から。当日の役割を決める。
```

```markdown chaff-after
# 防災訓練の打ち合わせ 議事録

日時：11月18日（火）15時から16時
出席：総務課、各フロアの防災担当

## 決まったこと

- 訓練は12月5日（金）の14時から行う。避難の経路は、去年と同じ（東側の非常階段を使う）。
```

## 直し方

「（東側の非常階段を使う。」は閉じの「）」が抜けていて、「総務課に出す」。」は、開きの無い「」」が余っています。
読み手は、括弧がどこまで続くのか、どこからどこまでが引用なのかが分かりません。

直した文章では、足りない「）」を足し、余分な「」」を消しました。

chaff は、見出しで区切った節ごとに括弧の組を数えます。「1)」「a)」のような番号の印、コードと URL は数えません。

## 設定

ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  unbalanced-bracket: strict
```

全角の「（」を半角の「)」で閉じたものも、組になっていないと指します。
