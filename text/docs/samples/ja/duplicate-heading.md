# 同じ見出しが兄弟に二つある（`duplicate-heading`）

**こんな文書に:** 社内の手引き、操作マニュアル、報告書。似た節を写して書き換えたときに、見出しだけを直し忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 経費精算の手引き

出張や外出でかかった費用を精算するときの手順をまとめました。

## 交通費の申請

電車やバスの運賃は、乗った区間と金額を精算の画面に入力します。領収書の無い運賃は、経路の検索結果の画面を添えてください。

## 交通費の申請

ホテルの代金は、泊まった日数と金額を入力し、ホテルが発行した領収書の写真を添えます。一泊の上限は1万2千円です。

## 申請の締め日

毎月の申請は、翌月の5日までに済ませてください。
```

## 直した文章

```markdown chaff-after
# 経費精算の手引き

出張や外出でかかった費用を精算するときの手順をまとめました。

## 交通費の申請

電車やバスの運賃は、乗った区間と金額を精算の画面に入力します。領収書の無い運賃は、経路の検索結果の画面を添えてください。

## 宿泊費の申請

ホテルの代金は、泊まった日数と金額を入力し、ホテルが発行した領収書の写真を添えます。一泊の上限は1万2千円です。
```

## 直し方

この手引きには「交通費の申請」という見出しが二つ並んでいます。
二つ目の節の中身はホテルの代金で、交通費の節を写して書き換えたとき、見出しだけが元のまま残った形です。
目次には同じ見出しが二つ出るので、宿泊費の申請のしかたを探す人は、そこに書いてあると気づけません。
ページの中のリンクも、二つ目の節には行けません。

直した文章では、二つ目の見出しを中身に合わせて「宿泊費の申請」にしました。
同じ話を二か所に書いてしまったのなら、二つの節を一つにまとめます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  duplicate-heading: relaxed
```

比べるのは、同じ親の見出しの下に並ぶ見出しどうしだけです。章ごとの「まとめ」や、版ごとの「追加」「修正」のように、親が違えば同じ言葉でもかまいません。
全角と半角、大文字と小文字、空白の数の違いは、同じ見出しとして比べます。
文学（`literature`）のジャンルでは動きません。
