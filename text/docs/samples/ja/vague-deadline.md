# 期限を「速やかに」のような語で残している（`vague-deadline`）

**こんな文書に:** 業務委託や売買の契約書、利用規約。報告や支払いの期限は数で書いたのに、事故や破損の報告だけ「速やかに」で済ませる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 清掃業務委託契約書

株式会社こもれび（以下「甲」という。）と、きらり清掃株式会社（以下「乙」という。）は、甲の本社の清掃について、次のとおり契約を結ぶ。

## 第1条（作業）

乙は、毎週月曜日と木曜日に、甲の本社の床と窓を清掃する。

## 第2条（報告）

乙は、毎月5日までに、前月の作業の記録を甲に提出する。

## 第3条（委託料）

甲は、記録を受け取った日から10日以内に、前月分の委託料を乙に支払う。

## 第4条（破損）

乙は、作業中に甲の備品を壊したときは、速やかに甲に報告する。
```

## 直した文章

```markdown chaff-after
# 清掃業務委託契約書

株式会社こもれび（以下「甲」という。）と、きらり清掃株式会社（以下「乙」という。）は、甲の本社の清掃について、次のとおり契約を結ぶ。

## 第1条（作業）

乙は、毎週月曜日と木曜日に、甲の本社の床と窓を清掃する。

## 第2条（報告）

乙は、毎月5日までに、前月の作業の記録を甲に提出する。

## 第3条（委託料）

甲は、記録を受け取った日から10日以内に、前月分の委託料を乙に支払う。

## 第4条（破損）

乙は、作業中に甲の備品を壊したときは、壊した日から3日以内に、壊した備品と壊れた様子を書面で甲に報告する。
```

## 直し方

この契約書は、報告（毎月5日までに）と支払い（10日以内に）の期限を数で書いています。ところが第4条の破損の報告だけは「速やかに」です。
備品を壊したとき、乙が一週間後に報告しても、乙は「速やかに報告した」と言え、甲は「遅い」と言えます。どちらが正しいかを決める物差しがありません。

直した文章では、「壊した日から3日以内に」と、起点と日数で期限を書きました。何を報告するか（壊した備品と壊れた様子）も書き足しています。日数は甲と乙が決めることです。chaff は、ほかの期限と比べて数の無い所を指すだけです。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  vague-deadline: strict
```

数の期限を書いた文が、「速やかに」「遅滞なく」を書いた文より多い文書でだけ指摘します。同じ文に「遅くとも7日以内に」のような数の期限があれば指しません。
契約書・規約のジャンルで動きます。法令は「速やかに」「遅滞なく」「直ちに」を段の違う決まった語として使うので見ません。判決と特許、説明書、学術、文学、話し言葉でも止めています。
期限そのものが無い義務は、`obligation-without-deadline` が見ます。
