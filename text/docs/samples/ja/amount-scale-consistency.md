# 同じ桁の金額を二通りに書いている（`amount-scale-consistency`）

**こんな文書に:** 見積書、提案書、予算の申請。担当ごとに出した見積もりを一つにまとめたとき、金額の書き方が担当者の癖のまま残ります。

## 元の文章

```markdown chaff-before
# 店舗サイト改装のお見積もり

このたびはご相談いただき、ありがとうございます。
打ち合わせでうかがった内容をもとに、費用を次のとおり見積もりました。

- 画面の設計：40万円
- 写真の撮影：15万円
- ページの制作：680,000円
- 予約機能の組み込み：25万円

合計は128万円（税抜）です。
お支払いは、納品の翌月末までにお願いします。
撮影の日程は、お店の定休日に合わせて決めさせていただきます。
```

## 直した文章

```markdown chaff-after
# 店舗サイト改装のお見積もり

このたびはご相談いただき、ありがとうございます。
打ち合わせでうかがった内容をもとに、費用を次のとおり見積もりました。

- 画面の設計：40万円
- 写真の撮影：15万円
- ページの制作：68万円
- 予約機能の組み込み：25万円

合計は128万円（税抜）です。
お支払いは、納品の翌月末までにお願いします。
撮影の日程は、お店の定休日に合わせて決めさせていただきます。
```

## 直し方

内訳の金額はどれも十万円台ですが、「ページの制作」だけが「680,000円」と数字で書かれています。
ほかの行が「万円」で並んでいるので、読み手はここだけ桁を数え直し、6万8千円なのか68万円なのかを確かめることになります。
制作の担当者から届いた見積もりを、そのまま貼り付けたときに起きやすい形です。

金額は変えずに、ほかの行と同じ「68万円」に書き直しました。
これで内訳を上から読みながら、合計の128万円と頭の中で照らし合わせられます。
chaff は「万円」と数字のどちらが正しいかは決めません。同じ桁の金額の中で少ないほうを指します。

## 設定

```yaml chaff-settings
rules:
  amount-scale-consistency: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
桁の違う金額（「480円」と「30万円」）や、「約130万円」のような目安の金額は比べません。
どのジャンルでも動きます。
