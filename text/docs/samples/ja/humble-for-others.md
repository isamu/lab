# 謙譲語を相手の動作に使っている（`humble-for-others`）

**こんな文書に:** 説明会や催しの案内、来店のお知らせ、受付の手引き。来てくださる人に向けて、丁寧に書こうとした所で起きやすいまちがいです。

## 元の文章

```markdown chaff-before
# 会社説明会のご案内

株式会社ながれ製作所 採用担当の岡田です。
12月14日に開く会社説明会の会場と持ち物をお知らせします。

会場は本社ビルの5階です。当日は、1階の受付に伺ってください。
受付で名前を伝えると、入館証と当日の資料をお渡しします。
資料は、説明が始まる前に拝見してください。

筆記用具と、学生証をお持ちください。
```

## 直した文章

```markdown chaff-after
# 会社説明会のご案内

株式会社ながれ製作所 採用担当の岡田です。
12月14日に開く会社説明会の会場と持ち物をお知らせします。

会場は本社ビルの5階です。当日は、1階の受付にお越しください。
受付で名前を伝えると、入館証と当日の資料をお渡しします。
資料は、説明が始まる前にご覧ください。

筆記用具と、学生証をお持ちください。
```

## 直し方

「伺う」「拝見する」は謙譲語で、自分の側の動作を低めて、相手を立てる言葉です。
「受付に伺ってください」「資料を拝見してください」は、その謙譲語を、来てくださる学生の動作に使っています。
丁寧に書いたつもりでも、読み手を低めることになり、採用の案内では会社の印象にもかかわります。

直した文章では、相手の動作を立てる尊敬語にしました。
「伺ってください」は「お越しください」、「拝見してください」は「ご覧ください」です。

## 設定

一覧にある形が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  humble-for-others: relaxed
```

見るのは一覧にある形だけです。「何とも申されません」のように、自分が言えないことを言う決まった言い回しは見ません。
「お伺いください」「ご持参ください」のように、認める手引きがある形も指摘しません。
小説の台詞にはわざと崩した敬語があるので、文学（`literature`）のジャンルでは動きません。

  直しかた: 尊敬語に直してください。「伺ってください」は「お越しください」、「拝見してください」は「ご覧ください」、「申されました」は「おっしゃいました」です。
