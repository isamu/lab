# 引用の書き方が揃っていない（`citation-style-mix`）

**こんな文書に:** 論文、卒業論文、研究の報告。共著者が自分の書き方で段落を足したときや、前に書いた原稿から文を移したときに起きます。

## 元の文章

```markdown chaff-before
# 地方の路線バスの利用者の変化

## はじめに

地方の路線バスは、この二十年で利用者が大きく減った[1]。
特に、高校の統廃合が進んだ地域では、通学の利用が落ちている[2]。
一方で、運転免許を返した高齢者が、通院のために乗る例は増えている（中村, 2021）。
本稿では、三つの町の乗降記録を比べ、利用者の年齢の移り変わりを調べる[4]。

## 参考文献

- [1] 小林健. 地方交通の二十年. 2018.
- [2] 松本由紀. 通学と路線バス. 2020.
- [3] 中村修. 高齢者の移動. 2021.
- [4] 森田亮. 乗降記録の読み方. 2019.
```

  ⚠  引用と文献一覧が合っていない

     この文献は、本文で一度も引いていません
     本文が [5] を引いているのに文献一覧に 5 番が無いと、読み手は根拠を確かめられません。文献一覧にあるのに本文で一度も引かない文献は、消し忘れか、引用を消してしまったかのどちらかです。文献を足したり消したりして番号を振り直したときに起きます。番号で引く論文は番号どうしを、著者と年で引く論文は著者の姓と年どうしを比べます。読み取れる引用が文献の半分に満たない文書（上付きの番号がコピーで消えた文書など）では、引かれていない文献を指しません。

## 直した文章

```markdown chaff-after
# 地方の路線バスの利用者の変化

## はじめに

地方の路線バスは、この二十年で利用者が大きく減った[1]。
特に、高校の統廃合が進んだ地域では、通学の利用が落ちている[2]。
一方で、運転免許を返した高齢者が、通院のために乗る例は増えている[3]。
本稿では、三つの町の乗降記録を比べ、利用者の年齢の移り変わりを調べる[4]。

## 参考文献

- [1] 小林健. 地方交通の二十年. 2018.
- [2] 松本由紀. 通学と路線バス. 2020.
- [3] 中村修. 高齢者の移動. 2021.
- [4] 森田亮. 乗降記録の読み方. 2019.
```

## 直し方

この論文の引用は、ほとんどが番号の「[1]」で書かれています。高齢者の段だけが「（中村, 2021）」と著者と年で書かれています。
読み手は、文献一覧を番号で探せばよいのか、著者の名前で探せばよいのか迷います。番号の並びも [2] から [4] に飛んで見えます。
chaff が文献一覧の [3] を「本文で一度も引いていません」と言うのも、同じ書き方の揺れから来ています。

文献一覧ではこの文献が [3] なので、本文も「[3]」に直しました。
これで本文の番号が一覧と一つずつ対応し、[1] から [4] まで順に並びます。
chaff は、番号と著者・年のどちらが正しいかは決めません。いちばん多い書き方と違う少数を指します。

## 設定

少ないほうの書き方が数か所までなら、書き忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  citation-style-mix: strict
```

`strict` にすると、少ないほうが少し多くても指摘します。`relaxed` にすると、1か所だけのときに指摘します。見たくなければ `off` にします。
論文のジャンル（`academic/*`）でだけ動きます。

```text chaff-explain
$ npx chaffjs explain citation-style-mix --genre academic/paper

  引用の書き方が揃っていない   (citation-style-mix)

  一つの論文の中で、引用を [1] と書いた所と（山田, 2020）と書いた所が混ざっていると、読み手は文献一覧をどちらの引き方で探せばよいか迷います。別の原稿から文を移したときや、共著者が自分の書き方で足したときに起きます。chaff は、番号の角括弧（[1]）、亀甲括弧（〔1〕）、文の後ろの番号と片括弧（…である1)。）、著者と年（(Smith, 2020)、山田（2020））、年を書いた脚注（[^1]）を見分け、最も多い書き方と違う少数の書き方を指します。どの書き方が正しいかは決めません。

  直しかた: 多いほうの書き方に揃えてください。番号に揃えるなら、文献一覧にも番号を付けます。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値:
    strict   少ないほうの書き方が 3 箇所以下のとき指摘
  → normal   少ないほうの書き方が 2 箇所以下のとき指摘
    relaxed  少ないほうの書き方が 1 箇所以下のとき指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax citation-style-mix --why "理由"
```
