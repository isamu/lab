# 見出しに書いた計算と合わない金額（`formula-amount-mismatch`）

**こんな文書に:** 不動産の売買の精算書、手数料を率で決める請求書、報酬の明細。見出しに計算のしかたを書いた行は、決まった額や税を足し忘れたときに金額だけが合わなくなります。

## 元の文章

```markdown chaff-before
# 売買代金の精算書

物件：横浜市港北区の中古マンション（3階、70.2平方メートル）

| 項目 | 金額 |
| --- | --- |
| 売買代金 | 25,000,000円 |
| 手付金（契約の日に受け取り済み） | 1,000,000円 |
| 仲介手数料（売買代金の3%＋60,000円、消費税10%込み） | 825,000円 |
| 登記の費用 | 186,000円 |
```

## 直した文章

```markdown chaff-after
# 売買代金の精算書

物件：横浜市港北区の中古マンション（3階、70.2平方メートル）

| 項目 | 金額 |
| --- | --- |
| 売買代金 | 25,000,000円 |
| 手付金（契約の日に受け取り済み） | 1,000,000円 |
| 仲介手数料（売買代金の3%＋60,000円、消費税10%込み） | 891,000円 |
| 登記の費用 | 186,000円 |
```

## 直し方

仲介手数料の見出しには、計算のしかたが「売買代金の3%＋60,000円、消費税10%込み」と書いてあります。売買代金25,000,000円の3%は750,000円で、60,000円を足すと810,000円、消費税を足すと891,000円です。
元の文章の「825,000円」は、750,000円に消費税だけを足した額でした。60,000円を足し忘れていました。
買う人は、見出しの計算を信じて金額を確かめずに払います。足りない分は決済の日に分かり、その場で追加の振り込みをお願いすることになります。

直した文章では、仲介手数料を891,000円に直しました。
chaff は、見出しの「売買代金の3%」を読み、文書が「売買代金」の行に書いた金額に率を掛け、「＋」の後の額と税を足して比べます。
端数は切り捨て・四捨五入・切り上げのどれでも、円の位で合っていれば合っていると読みます。文の中に書いた計算は読みません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  formula-amount-mismatch: strict
```

精算書や請求書を出す前に必ず止めたいなら `strict` にします。
「売買代金」の行が無い文書、売買代金の行が二つあって額が違う文書、「165万円」のように桁の語で書いた金額は比べません。文芸のジャンルでは、はじめから動きません。
