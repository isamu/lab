# 結果と基準値に合わない判定の印（`reference-flag-mismatch`）

**こんな文書に:** 健康診断の結果、検査の報告書、水質や設備の点検の記録。前の回の表を写して値だけを書き換えると、判定の印が前の回のまま残ります。

## 元の文章

```markdown chaff-before
# 定期健康診断の結果

10月14日に受けた定期健康診断の結果です。基準値から外れた項目には、判定の列に「高」か「低」と書いています。

| 項目 | 結果 | 基準値 | 判定 |
| --- | --- | --- | --- |
| 中性脂肪 | 88 mg/dL | 30〜149 mg/dL | 高 |
| γ-GTP | 92 U/L | 79 U/L 以下 | 基準内 |
| 空腹時血糖 | 94 mg/dL | 70〜99 mg/dL | 基準内 |

基準値から外れた項目があるときは、産業医との面談の日を人事課からご連絡します。
```

# 定期健康診断の結果

## 直し方

中性脂肪の 88 は基準値の 30〜149 の中にあるのに「高」、γ-GTP の 92 は基準値の 79 以下を超えるのに「基準内」と付いています。
読む人は、印を信じて表を読みます。気にしなくてよい中性脂肪を気にして、見るべき γ-GTP を見落とします。

前の回の表から印を写したまま、値だけを書き換えたと読めるので、二つの行の印を結果と基準値に合わせて直しました。
chaff は、列の見出し（結果、基準値、判定）で列を見つけ、行ごとに結果を基準値と照らします。「30〜149」のように範囲の印で書いた基準値は、両端を含むと読みます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  reference-flag-mismatch: strict
```

結果・基準値・判定の列が、見出しでそれぞれ一つに決まる表だけを読みます。
「<0.5」「陰性」のように一つの数でない結果、男女で分けた基準値、単位の違う行、A〜E のような判定区分は見ません。判定区分は、健診機関ごとの判定基準で決まり、基準値とは別だからです。
文芸のジャンルでは、はじめから動きません。
