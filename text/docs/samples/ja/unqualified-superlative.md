# 比べる相手のない最上級（`unqualified-superlative`）

**こんな文書に:** プレスリリース、製品の紹介、営業の資料。新しい製品を強く打ち出したいときに、「最も静か」「最も簡単」と、何と比べたのかを書かずに言い切ります。

## 元の文章

```markdown chaff-before
# 家庭用の生ごみ処理機「くるりん」を発売します

株式会社みどり電機は、12月10日に、家庭用の生ごみ処理機「くるりん」を発売します。

## 製品の特長

くるりんは、最も静かな生ごみ処理機です。
夜に動かしても、隣の部屋まで音が届きません。
一日分の生ごみを、約3時間で乾いた粉にします。
粉は、そのまま庭や鉢植えの肥料に使えます。
操作のボタンは一つだけで、手入れも最も簡単です。

## 価格と販売店

希望小売価格は、税込み3万9,800円です。
全国の家電量販店と、当社の通信販売で扱います。
```

## 直した文章

```markdown chaff-after
# 家庭用の生ごみ処理機「くるりん」を発売します

株式会社みどり電機は、12月10日に、家庭用の生ごみ処理機「くるりん」を発売します。

## 製品の特長

くるりんは、運転中の音が38デシベルで、当社の従来品より4割静かです。
夜に動かしても、隣の部屋まで音が届きません。
一日分の生ごみを、約3時間で乾いた粉にします。
粉は、そのまま庭や鉢植えの肥料に使えます。
操作のボタンは一つだけで、手入れは中の容器を水で洗うだけです。

## 価格と販売店

希望小売価格は、税込み3万9,800円です。
全国の家電量販店と、当社の通信販売で扱います。
```

## 直し方

「最も静かな生ごみ処理機です」「手入れも最も簡単です」は、何と比べて最もなのかがありません。記者や買う人は、それが本当かを確かめようがなく、宣伝の決まり文句として読み飛ばします。
次の文の「夜に動かしても、隣の部屋まで音が届きません」のほうが、ずっと伝わります。

直した文章では、「運転中の音が38デシベルで、当社の従来品より4割静かです」と、数と比べる相手を書きました。手入れは「中の容器を水で洗うだけです」と、何をするのかを書きました。数字は書き手が測ったものに替えてください。

## 設定

ふだんは比べる相手のない最上級が 2 箇所あれば指摘し、`strict` にすると 1 箇所から、`relaxed` にすると 4 箇所からになります。

```yaml chaff-settings
rules:
  unqualified-superlative: strict
```

「当社比」「〜の中で」のように比べる相手や範囲が同じ文にあれば指しません。「国内最大」「業界最速」のように範囲を言う形、「最高の使いやすさを目指し」のように目指すものとして述べた最上級も指しません。
ビジネス、ブログ、学術、演説で動き、法務、説明書、文学と、話し言葉の書き起こし（`speech/transcript`）では止めています。
