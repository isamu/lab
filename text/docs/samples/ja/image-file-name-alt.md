# 画像の代替テキストがファイル名（`image-file-name-alt`）

**こんな文書に:** 操作マニュアル、社内の手引き、よくある質問。画面の写しを貼り付けたとき、編集の道具が入れたファイル名が、画像の説明として残る形がよくあります。

```markdown chaff-before

交通系ICカードの利用の履歴を、経費精算の画面に取り込む手順です。

## 履歴を取り込む

経費精算の画面の右上にある「カードから取り込む」を押し、カードを読み取り機に置きます。

![スクリーンショット 2026-04-01 10.15.32.png](screenshot-import.png)

読み取った履歴の一覧から、仕事で乗った区間だけに印を付けて「登録」を押します。
```

# 交通系ICカードの経費の取り込み

交通系ICカードの利用の履歴を、経費精算の画面に取り込む手順です。

## 履歴を取り込む

経費精算の画面の右上にある「カードから取り込む」を押し、カードを読み取り機に置きます。

![経費精算の画面。右上に「カードから取り込む」のボタンがある](screenshot-import.png)

読み取った履歴の一覧から、仕事で乗った区間だけに印を付けて「登録」を押します。

## 直し方

この手引きの画面の写しには、「スクリーンショット 2026-04-01 10.15.32.png」という説明が付いています。
これは画像を貼った道具が入れたファイル名で、何が写っているかを何も言っていません。
画面の読み上げで読む人には、日付と時刻が読み上げられるだけです。画像が読み込めないときも、ボタンの場所が分かりません。

直した文章では、画像が伝えること（どの画面の、どこにボタンがあるか）を一言で書きました。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  image-file-name-alt: strict
```

画像の拡張子で終わらず、カメラや画面の撮影が付ける名前でもない代替テキスト（![構成図](diagram.png)）は指しません。
撮影が付ける名前の始まりは、言語ごとの語彙表 `image-file-name` にあります。
代替テキストが空の画像は、`image-alt-text` が見ます。どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain image-file-name-alt --genre docs/manual

  画像の代替テキストがファイル名   (image-file-name-alt)

  「![IMG_1234.png](IMG_1234.png)」「![スクリーンショット 2026-04-01](a.png)」のように、代替テキストが画像のファイル名のままの所です。画像が読み込めないときと画面読み上げで読むときは代替テキストだけが画像の代わりに伝わりますが、ファイル名は何が写っているかを言いません。画像を貼った道具が名前を入れたまま残ったものがほとんどです。代替テキストが空の画像は image-alt-text が指します。

  直しかた: 画像が伝えることを一言で書いてください（![4月の売上の推移](IMG_1234.png)）。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax image-file-name-alt --why "理由"
```
