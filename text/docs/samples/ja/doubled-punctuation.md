# 句読点が重なっている（`doubled-punctuation`）

**こんな文書に:** 取引先へのメール、案内、報告書。文を打ち直したり、別の文から貼り付けたりした所に残ります。

## 元の文章

```markdown chaff-before
件名：見積書をお送りします

株式会社みなと印刷
購買部 森様

いつもお世話になっております。たちばな紙工の佐伯です。

先日お問い合わせいただいた封筒の見積書を、添付でお送りします。。
数量は5,000枚と10,000枚の二通りで、どちらも送料を含めています、。
納期は、ご注文から2週間です。

ご不明な点があれば、お気軽にお知らせください。
```

## 直した文章

```markdown chaff-after
件名：見積書をお送りします

株式会社みなと印刷
購買部 森様

いつもお世話になっております。たちばな紙工の佐伯です。

先日お問い合わせいただいた封筒の見積書を、添付でお送りします。
数量は5,000枚と10,000枚の二通りで、どちらも送料を含めています。
納期は、ご注文から2週間です。

ご不明な点があれば、お気軽にお知らせください。
```

## 直し方

「お送りします。。」は句点を打ち直した跡、「含めています、。」は読点を消し忘れた跡です。
見積書を受け取った相手は、そこで一瞬止まり、急いで書いたメールだと感じます。金額や納期を伝えるメールほど、細かい所の雑さが中身の信頼に響きます。

直した文章では、余分な「。」と「、」を一つずつ消しました。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  doubled-punctuation: strict
```

「...」「。。。」のように三つ以上並べたものは、わざと伸ばした書き方なので数えません。「!!」「??」も文体の選び方として見ません。
「e.g.,」のような略語の点の後ろ、「1..10」のような範囲、コードと URL も数えません。
