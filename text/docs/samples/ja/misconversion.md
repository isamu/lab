# 変換の誤り（`misconversion`）

**こんな文書に:** ブログ、社内報、エッセイ。読みが同じで、どちらも正しい語なので、変換の取り違えは見落とされます。

## 元の文章

```markdown chaff-before
# はじめての自家製パン

週末に、はじめてパンを焼きました。

材料は、小麦粉と水と塩と酵母だけです。
こねるのは大変だろうと思っていましたが、以外と簡単でした。
十分ほどこねると、生地が手につかなくなります。

パンがこんなに手軽に焼けるとは、始めて知りました。
来週は、くるみを入れて焼くつもりです。
```

## 直した文章

```markdown chaff-after
# はじめての自家製パン

週末に、はじめてパンを焼きました。

材料は、小麦粉と水と塩と酵母だけです。
こねるのは大変だろうと思っていましたが、意外と簡単でした。
十分ほどこねると、生地が手につかなくなります。

パンがこんなに手軽に焼けるとは、初めて知りました。
来週は、くるみを入れて焼くつもりです。
```

## 直し方

「以外と簡単」は「意外と簡単」の、「始めて知りました」は「初めて知りました」の、変換の取り違えです。
どちらも正しい語なので、一字ずつ見ても誤りに気づきにくい所です。読み手には、言葉を知らないのか、見直していないのかと見えます。

直した文章では、二つの語だけを正しい字に直しました。

chaff は、前後の語で誤りと決まる形だけを語彙表から探します。「日本以外と比べて」のような正しい「以外と」と区別するために、「以外と簡単」「以外と多い」のように後ろの語まで決めた形を探します。
語彙表に無い組み合わせ（「始めて食べた」）や、前後で決まらない取り違えは指しません。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  misconversion: strict
```

店や商品の名前として、その字のまま書く語は、chaff.yaml の `names` に足すと、その名前の中は指さなくなります。
