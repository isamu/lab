# 逃げの表現が多い（`excessive-hedging`）

**こんな文書に:** 障害の報告、調査の結果、見通しを伝える文書。責任を問われそうな所ほど、言い切りを避ける言い方が重なります。

## 元の文章

```markdown chaff-before
# 社内システムの停止についての報告

情報システム課の小林です。11月18日の朝に、社内の経費精算システムが止まった件を報告します。

システムは午前8時から10時までの2時間、使えませんでした。
原因は、夜のうちに入れた更新が、データベースの設定と合わなかったことにあるのではないかと考えられます。
同じ更新は来月も予定されているため、また止まる可能性があるかもしれません。

今後は、更新を入れる前に、試験用の環境で一晩動かしてから本番に入れます。
```

## 直した文章

```markdown chaff-after
# 社内システムの停止についての報告

情報システム課の小林です。11月18日の朝に、社内の経費精算システムが止まった件を報告します。

システムは午前8時から10時までの2時間、使えませんでした。
原因は、夜のうちに入れた更新が、データベースの設定と合わなかったことです。更新を外すと、システムはすぐに動きました。
同じ更新は来月も予定されていますが、設定を直してから入れるので、同じ原因では止まりません。

今後は、更新を入れる前に、試験用の環境で一晩動かしてから本番に入れます。
```

## 直し方

「〜にあるのではないかと考えられます」は、「〜ではないか」と「考えられます」の二つで、言い切りを避けています。
「止まる可能性があるかもしれません」も、「可能性がある」と「かもしれません」が重なっています。
一つなら慎重な書き方ですが、重ねると、読み手は原因が分かったのか、まだ分からないのかを決められません。来月の更新を止めるべきかどうかも判断できません。

直した文章では、分かっていることを言い切りました。原因を言い切れる理由（更新を外すとすぐに動いた）も添えています。
来月の見通しも、「設定を直してから入れるので、同じ原因では止まりません」と、何をするから止まらないのかを書きました。
まだ言い切れないことがあるなら、何が分かれば言い切れるのかを書いてください。

## 設定

一つの文に逃げの表現を重ねたものは、文書の長さによらず指摘します。
文書全体の多さは1000字あたりの数で見て、ふだんは6個までです。短い文書では、全体の多さは測りません。

```yaml chaff-settings
rules:
  excessive-hedging: relaxed
```

`relaxed` にすると1000字あたり12個まで、`strict` にすると3個までです。
鉤括弧や引用符で引いた発言の中の逃げは、話した人のものなので数えません。
法令・契約（`legal`）、論文（`academic`）、文学（`literature`）、話し言葉の書き起こし（`speech/transcript`）では動きません。
