# 日付と曜日の食い違い（`date-weekday-mismatch`）

**こんな文書に:** 日程を知らせるメール、会議や行事の案内、旅程。前の行の「（木）」を写したまま日付だけを書き換える、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：年末の棚卸しの日程について

倉庫課のみなさま

お疲れさまです。管理部の森です。

年末の棚卸しの日程が決まりましたので、お知らせします。

- 一回目：2026年12月10日（木）　第一倉庫
- 二回目：2026年12月17日（木）　第二倉庫
- 予備日：2026年12月23日（火）

どの日も、朝9時に第一倉庫の前に集まってください。
当日に休みの予定がある方は、12月4日（金）までに森へ知らせてください。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：年末の棚卸しの日程について

倉庫課のみなさま

お疲れさまです。管理部の森です。

年末の棚卸しの日程が決まりましたので、お知らせします。

- 一回目：2026年12月10日（木）　第一倉庫
- 二回目：2026年12月17日（木）　第二倉庫
- 予備日：2026年12月23日（水）

どの日も、朝9時に第一倉庫の前に集まってください。
当日に休みの予定がある方は、12月4日（金）までに森へ知らせてください。
```

## 直し方

予備日の「2026年12月23日（火）」は、暦では水曜日です。上の二行が木曜日なので、行を写して日付だけを直し、曜日を直し忘れたのでしょう。
読む人は、火曜日に空けておけばよいのか、23日に空けておけばよいのかを決められません。曜日で予定を覚える人は火曜日に来て、日付で覚える人は水曜日に来ます。

直した文章では、日付を正しいものとして、曜日を「（水）」にしました。どちらが正しいかは書いた人にしか分かりません。火曜日のつもりなら、日付のほうを22日に直します。
年を書いていない「12月4日（金）」も、すぐ前の2026年の日付から年を決めて、暦と比べています。こちらは合っているので指摘されていません。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  date-weekday-mismatch: relaxed
```

年を書いていない日付は、年を書いたすぐ前の日付（前に無ければ文書で最初のもの）から5か月以内に収まる年として暦と比べます。文書のどこにも年が無いときは比べません。
文学のジャンルでは止めています。ほかのジャンルではすべて動きます。
