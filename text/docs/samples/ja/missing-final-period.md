# 「。」で終わらない段落（`missing-final-period`）

**こんな文書に:** 社内のお知らせ、案内、報告書。書いている途中で文を直したり、チャットから一文を貼ったりすると、段落の終わりの「。」が抜けることがあります。

## 元の文章

```markdown chaff-before
# 駐輪場の工事のお知らせ

本社の裏にある駐輪場で、屋根の張り替えの工事を行います。

工事は11月10日から11月21日までで、作業は平日の昼間だけです。

工事のあいだは、駐輪場の半分が使えなくなります。

止められないときは、隣の市営駐輪場をお使いください。利用料は会社が負担します

工事について分からないことは、総務課の山本までお問い合わせください。
```

## 直した文章

```markdown chaff-after
# 駐輪場の工事のお知らせ

本社の裏にある駐輪場で、屋根の張り替えの工事を行います。

工事は11月10日から11月21日までで、作業は平日の昼間だけです。

工事のあいだは、駐輪場の半分が使えなくなります。

止められないときは、隣の市営駐輪場をお使いください。利用料は会社が負担します。

工事について分からないことは、総務課の山本までお問い合わせください。
```

## 直し方

このお知らせの段落は、どれも「。」で終わっています。市営駐輪場の段落だけが「負担します」で止まっています。
読み手は、続きの一文が消えてしまったのか、書きかけなのかと気になります。利用料をだれが持つかという大事な所なので、そこが書きかけに見えるのは困ります。

段落の終わりに「。」を付けました。
chaff は、句点を付けるかどうかは決めません。文書の中で少ないほうを指します。見出しのような短い行や、名詞で終わる行、「：」で次へ続く行は数えません。

## 設定

「。」の無い段落が、段落の一定の割合までなら、付け忘れと読んで指摘します。それより多いときは、わざと付けない書き方と読みます。

```yaml chaff-settings
rules:
  missing-final-period: relaxed
```

`relaxed` にすると、「。」の無い段落がもっと少ないときだけ指摘します。`strict` にすると、もう少し多くても指摘します。見たくなければ `off` にします。
文芸と講演のジャンルでは、はじめから動きません。日本語の文書だけを見ます。
