# 見えない字がある（`invisible-character`）

**こんな文書に:** 操作の手引き、手順書、ほかのページから写した URL やコマンド。Web ページや PDF から貼り付けると、画面に出ない字が一緒に入ります。

## 直し方

「https://intra.example.jp/」と「wifi」のあいだに、ゼロ幅の空白（U+200B）が一字入っています。
画面では普通の URL に見えますが、写して開くと、行き先のページが見つかりません。つながらずに手引きを開いた人が、ここでもう一度つまずきます。
chaff の画面は、見えない字を ⟨U+200B⟩ と書いて、場所を見せます。

直した文章では、見えない字を消しました。エディタの「不可視文字を表示」を使うと、どこにあるかが見えます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  invisible-character: strict
```

コードの中も数えます。写したコマンドが動かなくなるからです。
絵文字をつなぐ字、ファイルの頭の BOM、英文の語と語のあいだのノーブレークスペースは指しません。文字の向きを強制する印（LRO・RLO）は、どこにあっても指します。
