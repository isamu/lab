# 自分や読み手の呼び方が揃っていない（`person-consistency`）

**こんな文書に:** お知らせ、案内状、会社の紹介。何人かで書き足した文書では、自分の会社を「当社」と書く人と「私たち」と書く人が混ざります。

## 元の文章

```markdown chaff-before
# 店頭での傘の貸し出しを始めます

当社は、12月1日から、全国の店舗で傘の無料の貸し出しを始めます。
急な雨の日でも、お買い物のあとに安心して帰っていただけるようにするためです。

貸し出す傘は、当社の店舗で回収した忘れ物の傘を手入れしたものです。
返すときは、借りた店でなくても、当社のどの店舗でもかまいません。

私たちは、この取り組みで、捨てられる傘を減らしたいと考えています。
当社は、貸し出しの数と戻った数を、来年の春に店頭とホームページでお知らせします。
```

# 店頭での傘の貸し出しを始めます

当社は、12月1日から、全国の店舗で傘の無料の貸し出しを始めます。
急な雨の日でも、お買い物のあとに安心して帰っていただけるようにするためです。

## 直し方

このお知らせは、自分の会社を「当社」と呼んでいます。取り組みのねらいを書いた一文だけが「私たち」になっています。
読み手は、そこで話し手が変わったのか、会社ではなく社員の気持ちを言っているのかと考えます。

同じ会社のことなので、ほかと同じ「当社」にそろえました。
会社と書き手個人のように、本当に別の相手を指すときは、その違いが読み手に分かるように書きます。
chaff は、どの呼び方が正しいかは決めません。呼び方ごとに文書の中で多いほうを文書の書き方とし、少ないほうを指します。鉤括弧の中や引用は数えません。

## 設定

少ないほうの呼び方が全体の一定の割合までなら、書き分け忘れと読んで指摘します。

```yaml chaff-settings
rules:
  person-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが少し多くても指摘します。見たくなければ `off` にします。
文芸のジャンルと、講演の書き起こし（`speech/transcript`）では、はじめから動きません。
