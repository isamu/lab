## 直した文章

```markdown chaff-after
# 見積もり金額のご確認のお願い

株式会社あおば工務店
経理部 中村様

いつもお世話になっております。こだま設備の田村です。

お忙しいところ恐れ入りますが、先日お送りした給湯器交換工事のお見積もりの金額をご確認のうえ、12月10日までにご返信ください。
お見積書をもう一度添付します。

どうぞよろしくお願いいたします。

こだま設備 田村
```

## 直し方

「お忙しいところ恐れ入りますが」は、お願いの前に置く礼儀の言葉です。一つなら、丁寧な書き出しです。
ところが元のメールでは、用件の三つの文に、さらに「念のため」「差し支えなければ」「取り急ぎ」と重なっています。短いメールの中に五つあり、何をいつまでにしてほしいのかが見えにくくなっています。
読み手は、前置きをかき分けて用件を探すことになります。

直した文章では、最初の「お忙しいところ恐れ入りますが」だけを残し、あとは用件を先に書きました。
「ご確認のうえ、12月10日までにご返信ください」と、してほしいことと期限が一文で分かります。

## 設定

1000字あたりのクッション言葉の数で見ます。ふだんは5個までです。
メールのような短い文書は、短い手紙ほどの長さとして測り、三つ目から指摘します。一つだけなら、どの強さでも指摘しません。

```yaml chaff-settings
rules:
  cushion-phrase-density: relaxed
```

`relaxed` にすると1000字あたり10個まで、`strict` にすると2個までです。
法令・契約（`legal`）、説明書（`docs`）、論文（`academic`）、文学（`literature`）、話し言葉の書き起こし（`speech/transcript`）では動きません。
