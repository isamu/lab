# 対比の枠が多い（`contrast-framing`）

**こんな文書に:** ブログのエッセイ、コラム、紹介記事。AI に「深みのある文章で」と頼んだ下書きに、「単なる X ではなく Y」が何度も出ます。

## 元の文章

```markdown chaff-before
# 朝の三十分を散歩に使う

去年の秋から、出勤前に三十分だけ近所を歩いています。
きっかけは、健康診断で運動不足を言われたことでした。
最初の月は、決めた道を一周するだけで息が上がり、帰ってからシャワーを浴びて着替えると、家を出る時間ぎりぎりでした。

散歩は単なる運動ではなく、一日の段取りを考える時間になりました。
歩きながら、その日に会う人と、片づけたい仕事を順に思い浮かべます。
着くころには、一つ目の仕事が決まっています。

体の調子だけでなく、眠りも変わりました。
以前は夜中に一度は目が覚めていたのに、いまは朝までほとんど起きません。
寝る前に携帯を見る時間も減りました。

近所の景色も、ただ通り過ぎる道ではなく、季節の変わり目を知らせてくれるものになりました。
三月の終わりには川沿いの桜のつぼみがふくらみ、六月には紫陽花の色が日ごとに変わります。
いつも同じ角で犬の散歩をしている人とも、会釈をするようになりました。
夏の朝は、六時を過ぎると日差しが強くなるので、出る時間を三十分早めました。
冬は逆に、明るくなるのを待ってから出ます。暗い道で車にひかれそうになったことが一度あり、それからは反射材の付いた上着を着るようにしています。

続けるコツは、気合いではなく、仕組みです。
前の晩に靴と上着を玄関に出しておき、雨の日は傘を差して、いつもの半分の道を歩きます。
寒い朝は、さすがにつらいです。
それでも、休んだのは熱を出した二日だけです。
```

## 直し方

元の文章は、「散歩は単なる運動ではなく」「体の調子だけでなく」「続けるコツは、気合いではなく、仕組みです」と、段落ごとに対比の枠で書いています。
一つなら論点を整理できますが、重なると、誰も言っていない「単なる運動」「気合い」を打ち消し続ける文章になります。
読み手が知りたいのは、打ち消された側ではなく、書き手が実際に何をしたかです。

直した文章では、打ち消した側を消して、言いたいことだけを書きました。
「続けるコツは仕組み」は、「前の晩に靴と上着を玄関に出しておくようにしたから」と、その仕組みそのものに置き換えています。

## 設定

対比の枠で書いた文が、文全体の4.8%を超えると指摘します（ブログのエッセイ `blog/essay` の値です）。短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  contrast-framing: relaxed
```

`relaxed` にすると7%まで、`strict` なら4%までです。
一つだけの対比、「紙ではなく、画面で確認します」のような手順の言い方、「一杯だけでなく、二杯目も」のような量を言う枠は数えません。
法令・契約（`legal`）、手順書（`docs`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain
$ npx chaffjs explain contrast-framing --genre blog/essay

  対比の枠が多い   (contrast-framing)

  「単なる X ではなく Y」「X だけでなく Y も」は、1 つなら論点を整理します。重なると、誰も言っていない X を打ち消し続ける文章になります。生成文によく見られる癖として知られています。

  直しかた: 打ち消した側（X）を消して、言いたいこと（Y）だけを書いてください。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

    strict   対比の枠で書いた文が 4% まで

  変える:  npx chaffjs relax contrast-framing --why "理由"
```
