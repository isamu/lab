# 使う間隔の下限と回数の上限が両立しない、または表の回数と合わない（`interval-count-mismatch`）

**こんな文書に:** 薬や動物の薬の説明書、点検や作業の手順、機械の使い方の注意。間隔と回数を別々に直すと、「8時間以上あけて、1日4回まで」のように守りようのない決まりが書かれます。

## 元の文章

```markdown chaff-before
# 頭痛と熱の薬の飲み方

## 飲む量と回数

| 年齢 | 1回の量 | 1日の服用回数 |
| --- | --- | --- |
| 15歳以上 | 2錠 | 3回まで |
| 15歳未満 | 飲まないでください | 飲まないでください |

飲む間隔は8時間以上あけ、1日4回を超えて飲まないでください。
```

## 直した文章

```markdown chaff-after
# 頭痛と熱の薬の飲み方

## 飲む量と回数

| 年齢 | 1回の量 | 1日の服用回数 |
| --- | --- | --- |
| 15歳以上 | 2錠 | 3回まで |
| 15歳未満 | 飲まないでください | 飲まないでください |

飲む間隔は8時間以上あけ、1日3回を超えて飲まないでください。
```

## 直し方

8時間以上あけて4回飲むと、1回目から4回目までに 3 × 8 で24時間かかります。4回目は次の日になるので、1日に4回は飲めません。
すぐ上の表も「1日の服用回数」を3回までと書いています。前の版の「1日4回」を、文の中だけ直し忘れていました。
飲む人は、文と表のどちらに従えばよいか決められません。多いほうの4回を信じて飲めば、決められた量を超えてしまいます。

直した文章では、文の回数を表と同じ「1日3回」に直しました。8時間ずつあけても、3回なら16時間で収まります。
chaff は、一つの段落に下限のある間隔（8時間以上あけ）と、上限のある回数（1日4回を超えて）がちょうど一つずつあるときに計算します。両立するときは、同じ見出しの下の表にある回数の列のいちばん大きい回数とも比べます。
「4時間以上あけて1日6回」のように、ちょうど収まるものは指摘しません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  interval-count-mismatch: strict
```

説明書を出す前に必ず止めたいなら `strict` にします。
間隔に「以上」のような下限の印が無い所や、回数に「まで」「を超えて」のような上限の語が無い所は見ません。文芸のジャンルでは、はじめから動きません。
