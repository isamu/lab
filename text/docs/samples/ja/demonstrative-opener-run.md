# 指示語で始まる文が続く（`demonstrative-opener-run`）

**こんな文書に:** 調べた結果の報告、分析のメモ、提案書。前の文を受けて「これは」「その」と書き継ぎがちな文書です。

## 元の文章

```markdown chaff-before
# 週末の来店者数の調べ

10月の週末に、駅前店の来店者を時間ごとに数えました。

土曜は開店直後と夕方に来店が集まり、昼の時間はほとんど来店がありませんでした。
これは平日と大きく違う点です。
その理由として、近くの商業施設の催しが昼に集中していたことが考えられます。
それを確かめるため、11月は催しの予定と並べて数え直します。
```

## 直した文章

```markdown chaff-after
# 週末の来店者数の調べ

10月の週末に、駅前店の来店者を時間ごとに数えました。

土曜は開店直後と夕方に来店が集まり、昼の時間はほとんど来店がありませんでした。
昼に来店が落ちるのは、平日には見られない形です。
理由として、近くの商業施設の催しが昼に集中していたことが考えられます。
催しとの関係を確かめるため、11月は催しの予定と並べて数え直します。
```

## 直し方

元の段落は「これは」「その理由として」「それを確かめるため」と、指示語で始まる文が三つ続きます。
読み手は一文ごとに、「これ」は何を指すのか、「それ」は理由なのか集中していたことなのかを、前に戻って確かめることになります。
三つ目の「それ」は、すぐ前の文ではなく、催しが昼に集中していたという推測を指しています。

直した文章では、指示語を指しているものの名前に置き換えました。
「これは」は「昼に来店が落ちるのは」に、「それを確かめるため」は「催しとの関係を確かめるため」になり、どの文も単独で何の話か分かります。
二つ目の「その理由として」は「理由として」とし、指示語を一つ残すだけにしました。

数えるのは同じ段落の中の連続だけです。

## 設定

指示語で始まる文は、二つ続くまでなら指摘しません。`strict` にすると二つ続いただけで、`relaxed` にすると四つ続いたら指摘します。
文学のジャンルでは既定で止めています。

```yaml chaff-settings
rules:
  demonstrative-opener-run: relaxed
```

見ないことにするなら `demonstrative-opener-run: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax demonstrative-opener-run --why "前の文を受けて短く書く議事録の形のため"
```
