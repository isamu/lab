# 製造番号やロットの範囲の終わりが始まりより小さい（`serial-range-reversed`）

**こんな文書に:** 製品の回収や無償交換のお知らせ、ロットごとの出荷の記録、部品の交換の案内。番号を片方だけ書き換えて、範囲が逆になる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 電気ケトル KT-1 の無償交換のお知らせ

株式会社ひなた家電は、電気ケトル KT-1 の一部で、ふたの留め具が外れるおそれがあることを確認しました。
お客さまに深くおわび申し上げます。対象の製品は、無償で新しい製品と交換します。

## 対象の製品

- 製品名：電気ケトル KT-1
- 製造番号：KT-21500〜KT-20800
- 販売期間：2026年3月〜2026年8月

製造番号は、本体の底面のラベルに書いてあります。

## お問い合わせ

ひなた家電 お客さま窓口（受付時間 9時〜18時）
```

## 直し方

対象の製造番号は「KT-21500〜KT-20800」と書いてあり、終わりの番号が始まりより小さくなっています。範囲の始まりと終わりを、逆の順に書き写したのでしょう。
回収のお知らせを読む人は、自分の製品の底のラベルを見て、この範囲に入るかどうかを確かめます。逆の範囲では、たとえば「KT-21000」が対象なのかを決められません。対象の製品を見落とすか、対象でない製品の問い合わせが窓口に届くことになります。

直した文章では、小さいほうから「KT-20800〜KT-21500」と書きました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  serial-range-reversed: strict
```

同じ行の前に「製造番号」「シリアル」「ロット」「バッチ」のある番号の範囲だけを読みます。英字とハイフンと数字の桁数が両端でそろうときだけ数字を比べるので、「A2400〜B0100」のように別の系列の番号は比べません。読点で並べた番号や、数字が二桁以下の番号も比べません。
文学のジャンルでは止めています。
