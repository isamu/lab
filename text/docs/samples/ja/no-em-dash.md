# ダッシュが多い（`no-em-dash`）

**こんな文書に:** 社内のお知らせ、報告書、ブログ。英語の文書を下敷きにした文章や、AI に下書きさせた文章で、挟み込みや補足をダッシュで書いてしまう所に出ます。

## 元の文章

```markdown chaff-before
# 新しい経費精算システムへの切り替え

来月1日から、経費の精算は新しいシステム——社内ポータルの「申請」から開くもの——で受け付けます。
紙の申請書は、今月末に提出されたもの——消印ではなく総務課の受付日で数えます——までで終わりです。

## 何が変わるか

新しいシステムでは、領収書を写真で送れます。スマートフォンで撮って、申請の画面に貼るだけです——原本は三か月保管してください。
承認は、これまでどおり所属長が行います。承認が済むと、申請した人にメールで知らせが届きます。
差し戻されたときは、所属長のコメントが申請の画面に出ます。直してから同じ画面で出し直せば、最初から書き直す必要はありません。

振込の日は変わりません。毎月15日までに承認された分を、その月の25日に給与と同じ口座へ振り込みます。
交通費の定期券の申請——通勤経路を変えたときのもの——も、同じ画面から出せるようになります。

## 説明会

使い方の説明会を、来週の水曜と金曜の午後に開きます。どちらも本社5階の会議室で、時間は30分ほどです。
参加できない人のために、録画も社内ポータルに載せます。

ログインできないときや、画面の使い方で分からないことがあれば、総務課の経理担当（内線305）までお問い合わせください。
```

## 直し方

元の文章は、「新しいシステム——社内ポータルの「申請」から開くもの——で受け付けます」のように、補足をダッシュで挟んでいます。
日本語の組版でダッシュは扱いが難しく、画面や印刷によって長さも見えかたも変わります。
挟み込みが一文に入ると、読み手は文の骨組みを探しながら読むことになります。

直した文章では、挟み込みは括弧に（「（消印ではなく、総務課の受付日で数えます）」）、補足は文を分けて書きました（「社内ポータルの「申請」から開けます」）。
「定期券の申請——通勤経路を変えたときのもの——」は、「通勤経路を変えたときの定期券の申請」と、前から説明する形にしています。

## 設定

1000字あたりダッシュが3個を超えると指摘します。短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  no-em-dash: strict
```

`strict` にすると1000字あたり1個まで、`relaxed` なら8個までです。
数字のあいだの範囲（10:00–10:15）、行の頭に置くダッシュ（インタビューの聞き手を示す「――」、署名の前の「— 名前」）、段落の終わりで次の箇条を導くダッシュは数えません。
文学（`literature`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score notice.md` で見られます。
