# 語句の途中に空白がある（`stray-space`）

**こんな文書に:** 社内のメール、手順書、報告書。文を書き直したり、別の所から写したりすると、語句の途中に空白が残ります。

## 元の文章

```markdown chaff-before
件名：12月の棚卸しの日程

倉庫課のみなさま

お疲れさまです。物流部の石井です。

12月の棚卸しは、12月20日（土）の朝9時から行います。
当日は出荷を止めるので、前の日までに出荷の予定を 片づけてください。
数えた結果は表に入れ、その日の17時までに物流部に送ってください。

去年の結果は、共有フォルダの「棚卸し」に入れて あります。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：12月の棚卸しの日程

倉庫課のみなさま

お疲れさまです。物流部の石井です。

12月の棚卸しは、12月20日（土）の朝9時から行います。
当日は出荷を止めるので、前の日までに出荷の予定を片づけてください。

```

## 直し方

「出荷の予定を 片づけて」「入れて あります」は、一続きに読む語句の途中に空白が入っています。
読み手は、そこで何かが抜けたのかと迷います。空白は目で見ても気づきにくく、書いた人も見落とします。

直した文章では、二つの空白を消して詰めました。

chaff は、この文書が文節のあいだをふつう詰めて書いていることを数え（19 箇所のうち 2 箇所だけが空いている）、少ないほうの空け方だけを指します。
子ども向けの文のように、文節ごとに空けて書く文書なら、空けたほうがふつうなので指しません。どちらが正しいかは決めず、文書の中でそろっているかだけを見ます。

## 設定

ふだんは「参考」として出します。少ないほうの空け方が1箇所あれば指摘し、`relaxed` にすると、3箇所からです。

```yaml chaff-settings
rules:
  stray-space: relaxed
```

名詞と名詞のあいだ（「担当 田中」）、句点で終わらない行、見出し、表、鉤括弧の中、英字や数字との境目は数えません。
