# 表の一つの列に、違う通貨の金額が一つだけある（`currency-column-mix`）

**こんな文書に:** 輸入や出張の費用の見積もり、経費の精算書、外国の取引先からの請求をまとめた表。外国の請求書から行を写したとき、円に直すのを忘れると、一つの列に違う通貨が混ざります。

## 元の文章

```markdown chaff-before
# 輸入の諸費用の見積もり

株式会社ひかり商会 御中

ベトナムから届く家具（20フィートのコンテナ1本）の、輸入にかかる費用の見積もりです。

| 費目 | 金額 |
| --- | --- |
| 海上運賃 | 152,000円 |
| 海上保険料 | USD 60 |
| 通関の手数料 | 11,800円 |
| 港での荷役料 | 38,500円 |
| 国内の配送料 | 45,000円 |
```

## 直した文章

```markdown chaff-after
# 輸入の諸費用の見積もり

株式会社ひかり商会 御中

ベトナムから届く家具（20フィートのコンテナ1本）の、輸入にかかる費用の見積もりです。

| 費目 | 金額 |
| --- | --- |
| 海上運賃 | 152,000円 |
| 海上保険料 | 9,000円 |
| 通関の手数料 | 11,800円 |
| 港での荷役料 | 38,500円 |
| 国内の配送料 | 45,000円 |
```

## 直し方

円の金額が並ぶ列に、海上保険料だけが「USD 60」とドルで書いてあります。保険会社の請求書から金額を写して、円に直すのを忘れていました。
受け取った人が列を足して総額を出すと、60 を60円として足してしまいます。社内の稟議に、9,000円ほど少ない額が上がることになります。

直した文章では、見積もりの日の為替で円に直した9,000円を書きました。
ドルのまま載せたいときは、「通貨」や「為替レート」の列を足して、どの行がどの通貨かを表に書きます。chaff は、通貨や為替の列がある表を、わざと通貨を混ぜた表と読んで指摘しません。
「¥」と「円」は同じ通貨と読みます。一つの通貨の金額が二つ以上並び、ほかの通貨がちょうど一つのときだけ指します。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  currency-column-mix: strict
```

見積書や請求書を送る前に必ず止めたいなら `strict` にします。
見出しに二つの通貨を書いた列（金額（円/USD））や、「送金手数料（USD）」のように行の名前に通貨を書いた行は指摘しません。文芸のジャンルでは、はじめから動きません。
