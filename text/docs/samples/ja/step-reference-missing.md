# 無い手順を指す参照（`step-reference-missing`）

**こんな文書に:** 操作マニュアル、作業の手順書、よくある質問。手順を一つ減らしたり、二つをまとめたりしたあとに、「手順5に戻って」の番号だけが古いまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# 店舗のレジの締め方

閉店のあとに、その日の売上を締める手順です。

1. レジの画面で「締め」を選びます。
2. 引き出しの現金を数え、金種ごとの枚数を入れます。
3. 画面に出た差額が0円であることを確かめます。
4. 売上の記録を印刷し、現金と一緒に金庫にしまいます。

差額が0円にならないときは、手順5からやり直してください。
```

## 直した文章

```markdown chaff-after
# 店舗のレジの締め方

閉店のあとに、その日の売上を締める手順です。

1. レジの画面で「締め」を選びます。
2. 引き出しの現金を数え、金種ごとの枚数を入れます。
3. 画面に出た差額が0円であることを確かめます。
4. 売上の記録を印刷し、現金と一緒に金庫にしまいます。

差額が0円にならないときは、手順2からやり直してください。
```

## 直し方

この手順は4つしかありませんが、最後の文は「手順5からやり直してください」と言っています。
前の版では、現金を数える前に「引き出しを開ける」という手順があり、番号が一つずつずれていた、という形です。
閉店のあと、差額が合わずに困っている店員は、手順5を探して手を止めてしまいます。

直した文章では、やり直すべき手順、つまり現金を数える手順2を指すように直しました。
手順を消したり並べ替えたりしたときは、本文の中の参照の番号も一緒に確かめます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  step-reference-missing: relaxed
```

手順と読むのは、「手順」「ステップ」と番号で始まる見出しと、番号付きの箇条書きの項目です。
手順が一つも無い文書の参照は、ほかの文書の手順かもしれないので言いません。番号付きの箇条書きがいくつかあれば、いちばん大きい番号を超える参照だけを言います。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain step-reference-missing --genre docs/manual

  無い手順を指す参照   (step-reference-missing)

  直しかた: 指したい手順の番号を確かめて、参照を直してください。手順を消したのなら、参照の文も直します。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax step-reference-missing --why "理由"
```
