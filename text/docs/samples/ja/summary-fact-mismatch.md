# 冒頭や要約の値が本文と違う（`summary-fact-mismatch`）

**こんな文書に:** 説明会やセミナーの案内、報告書の概要、提案書の要約。本文の締切や料金を直したあとに、冒頭の要約を直し忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 取引先向け説明会のご案内

新しい受発注の画面について、取引先の皆さまへの説明会を開きます。

## 概要

- 会場：本社 3階 大会議室
- 締切：11月28日
- 参加費：無料

## 申し込み

申し込みの画面から、参加する方の名前とメールアドレスを入れてください。

- 締切：12月5日
- 定員：40名

定員に達したときは、締切より前に受付を終えます。
```

  ⚠  冒頭や要約の値が本文と違う

     冒頭・要約の「締切」 11月28日 が、本文の 12月5日 と違います
     冒頭や「概要」の節は、本文を読まない人も読みます。そこに書いた値が本文と違うと、要約だけを読んだ人が間違った値を持ち帰ります。本文を直したあとに、要約を直し忘れると起きます。最初の見出しより前の文と、概要・要約・まとめの節の「項目：値」「項目は値です」を、本文の同じ項目の値と比べます。英語の文書では、名前の無い数も、数える動詞と数えるもの（We gained 52 new customers）が同じ本文の数と比べます。要約の「誤りの率は 2.4% から 1.6% に」は、本文が同じ項目を二つの条件（導入前と導入後、無いときとあるとき、2025年と2026年）で書いた二つの値と組にして比べます。冒頭の「11月9日から提供します」のような出来事の日付は、本文で同じ出来事の語（提供、発売、開催）と日付を一つずつ持つ文の日付と比べます。本文の値が一通りに揃っていて、要約の値がそれと違うときだけ指します。

## 直した文章

```markdown chaff-after
# 取引先向け説明会のご案内

新しい受発注の画面について、取引先の皆さまへの説明会を開きます。

## 概要

- 会場：本社 3階 大会議室
- 締切：12月5日
- 参加費：無料

## 申し込み

申し込みの画面から、参加する方の名前とメールアドレスを入れてください。

- 締切：12月5日
- 定員：40名

定員に達したときは、締切より前に受付を終えます。
```

## 直し方

概要の締切は11月28日、申し込みの節の締切は12月5日です。
概要は、本文を読まない人も読みます。概要だけを見た取引先は、11月28日を過ぎたら申し込めないと思い込み、参加をあきらめます。

申し込みの画面の設定を確かめると12月5日だったので、概要の締切を本文に合わせました。
chaff は、最初の見出しより前の文と、概要・要約・まとめの節の「項目：値」を、本文の同じ項目の値と比べます。本文の値が一通りにそろっていて、要約の値がそれと違うときだけ指します。

## 設定

ふだんは「注意」として出します。`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  summary-fact-mismatch: relaxed
```

本文に同じ項目の値が二通り以上あるとき（回ごと、対象ごとの値）は、要約がどれと合うべきか決まらないので言いません。
単位の違う値や、「3,000円から」のように条件の付いた値も比べません。
文芸のジャンルでは、はじめから動きません。
