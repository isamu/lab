# 誰も言っていない前提の打ち消しが多い（`unprompted-denial`）

**こんな文書に:** ブログ、コラム、説明の記事。AI に下書きさせると「これは〜の話ではありません」で段落を始め、何の話なのかを後回しにします。

## 元の文章

```markdown chaff-before
# 小さな事務所のバックアップを見直した

先月、事務所の共有フォルダが入ったパソコンの記憶装置が壊れました。
前の晩までのファイルは外付けの装置に写してあったので、失ったのはその日の午前中に作った見積書二通だけでした。
それでも、復旧には丸一日かかりました。

これは装置の容量の話ではありません。
外付けの装置には、まだ半分以上の空きがありました。
困ったのは、どの装置にどの日のファイルがあるのかを、誰も覚えていなかったことです。

高価な機材を買う話ではありません。
いまある外付けの装置二台を、週ごとに交互に使うようにしただけです。
一台は事務所に置き、もう一台は金曜の夕方に私が家へ持ち帰ります。
火事や盗難があっても、どちらか一台は残ります。
持ち帰る役は、私が休みの週だけ事務長に代わってもらいます。

写す作業は、毎晩八時に自動で始まるようにしました。
朝、出社した人が画面の右下の知らせを見て、「完了」になっているかを確かめます。
失敗していたら、その日のうちに手で写し直します。
それだけです。
半年たって、写し直したのは二回でした。
どちらも、前の晩にパソコンの電源を切って帰った日です。

手順は紙一枚にまとめて、パソコンの横に貼りました。
覚えておくのは、交互に使うことと、朝に一度確かめることの二つです。
新しく入った人にも、五分で説明できます。
特別な知識が要るわけではありません。
```

## 直し方

元の文章は、「これは装置の容量の話ではありません」「高価な機材を買う話ではありません」「特別な知識が要るわけではありません」と、三度打ち消しています。
けれども、容量の話だとも、機材を買う話だとも、誰も言っていません。
読み手は、持っていなかった思い込みを打ち消されながら、何の話なのかを待たされます。

直した文章では、打ち消しをやめて、何であるかを直接書きました。
時間がかかった理由は「誰も覚えていなかったから」と言い切り、機材については「新しく買ったものはありません」と事実だけを書いています。
最後の打ち消しは、すぐ上の「二つだけです」で十分に伝わるので消しました。

## 設定

誰も言っていない前提を打ち消して終わる文が、文全体の3%を超えると指摘します。打ち消しが二つまでの文書と、短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  unprompted-denial: relaxed
```

`relaxed` にすると5%まで、`strict` なら2%までです。
理由を添えた打ち消し（「〜のため、対象ではありません」）、前の文の問いや「〜と思うかもしれません」に答える打ち消し、「だけではない」「すべきではない」「簡単ではない」は数えません。
法令・契約（`legal`）、手順書（`docs`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。
