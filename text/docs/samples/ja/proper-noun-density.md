# 固有名詞が多すぎる（`proper-noun-density`）

**こんな文書に:** 勉強会や展示会の参加の記録、技術記事、業界のニュースのまとめ。登壇した人や会社、製品の名前を、説明を添えずに並べがちな文章です。

## 元の文章

```markdown chaff-before
# 福岡で開かれた勉強会に行ってきた

先週の土曜、福岡の天神で開かれた勉強会に、大阪から参加しました。
会場は天神の駅から歩いて三分ほどの貸し会議室で、六十人ほどが集まっていました。
満席です。
受付では、主催の一人で久留米から来た古賀さんが、参加者の名札を一枚ずつ手渡していました。

最初は、北九州の山口さんが、熊本の工場で動かしている検品の仕組みについて話しました。
次に、佐賀の中島さんが、長崎と鹿児島の店をつなぐ在庫の仕組みを紹介しました。
昼のあとは、名古屋の松本さんと神戸の石井さんが、京都と奈良の旅館に入れた予約の仕組みを比べました。
最後は、仙台の佐々木さんが、札幌と函館の倉庫を結ぶ配送の話をしました。
お昼は、天神の屋台で、久留米から来た古賀さんにすすめられた豚骨のラーメンを、石井さんや村上さんと一緒に食べました。

懇親会では、広島の藤田さんと岡山の村上さんに、松山と高松の支店の話を聞きました。
次の回は、那覇で開かれる予定です。
沖縄の金城さんが、宮古島と石垣島にある病院の予約の仕組みについて話すそうです。

帰りは博多から新幹線に乗り、小倉、広島、岡山を過ぎて新大阪まで戻りました。
車内では、隣に座った高知の西村さんと、徳島と松江の取引先の話で盛り上がりました。
とても楽しい一日でした。
```

## 直した文章

```markdown chaff-after
# 福岡で開かれた勉強会に行ってきた

先週の土曜、福岡で開かれた勉強会に参加しました。
会場は駅から歩いて三分ほどの貸し会議室で、六十人ほどが集まっていました。
満席です。

次は、離れた店どうしで在庫を分け合う仕組みの紹介です。

懇親会では、支店を持つ会社の人たちと、支店ごとに違う仕組みをどうそろえるかを話しました。
```

## 直し方

元の記事は、登壇した人の名前と出身地、話に出た町の名前が次々に出てきて、1000字あたり86個の固有名詞があります。
その場にいた人には思い出になりますが、読み手には、誰が何の話をしたのかが名前の列に埋もれます。
知りたいのは、勉強会でどんな話を聞けたのかのほうです。

直した文章では、名前を外し、それぞれの話の中身で書きました。
「工場で動かしている検品の仕組み」「離れた店どうしで在庫を分け合う仕組み」と書けば、名前を知らない人にも読めます。
名前を残したい人がいるなら、二度目からは「その人」と受けるか、初めに何者かを一言添えます。

月・曜日・元号は数えません。日本語で500字より短い文書は測りません。

## 設定

ふだんは1000字あたり55個までです。`strict` にすると20個、`relaxed` にすると80個までになります。
法務・論文・文学・話し言葉のジャンル、`docs` のジャンル（手引き・よくある質問・用語集）、プレスリリースでは、既定で止めています。

chaff.yaml の `names` に並べた名前は、何語に分かれても一つの名前と数えます。名前そのものは数えます。

```yaml chaff-settings
rules:
  proper-noun-density: relaxed
```

見ないことにするなら `proper-noun-density: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax proper-noun-density --why "人の名前を並べる参加の記録のため"
```
