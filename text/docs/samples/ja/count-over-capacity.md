# 定員より多い申込の人数（`count-over-capacity`）

**こんな文書に:** セミナーや勉強会の案内、説明会の申込の状況、イベントの集客の報告。会場を変えて定員を直したときに、申込の人数の行を見直さない、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：12月の勉強会のお知らせ（会場が変わりました）

会員のみなさま

いつもお世話になっております。勉強会の幹事です。
12月の勉強会は、会場を市民会館の第2会議室に移して開きます。
第2会議室は前の会場より狭いため、定員を変えました。

- 日時：12月12日（土）14時〜16時
- 会場：市民会館 第2会議室
- 定員：40名（先着順）

11月20日の時点で、46名の方にお申し込みいただいています。
当日は、名札をお持ちください。

どうぞよろしくお願いいたします。
```

## 直し方

定員は40名と書いてあるのに、申し込んだ人は46名と書いてあります。会場を狭い部屋に移して定員を減らしたのに、申込の状況の行を前の会場のつもりで書いたか、数字を打ち間違えたのでしょう。
案内を受け取った会員は、まだ申し込めるのか、申し込んだ自分は当日入れるのかを問い合わせることになります。定員を超えて受け付けたのが本当なら、超えた人をどうするかを書かないと、当日の会場が混乱します。

直した文章では、申込の人数を36名にしました。定員を超えた申込をキャンセル待ちや抽選にするなら、そう書けば指摘されません。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  count-over-capacity: strict
```

定員の語（定員、先着、募集人数）と、申込の語（申込、お申し込み、招待者）を付けた人の数だけを比べ、語の無い数は読みません。文書に定員が一つだけ書いてあるときだけ比べます。キャンセル待ちや抽選の語のある文書、「各回定員20名」のような一回あたりの定員、昨年や前回の人数、数える物の違う数（30組と45名）は比べません。
文学のジャンルでは止めています。
