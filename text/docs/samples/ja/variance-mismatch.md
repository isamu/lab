# 予算と決算の差が、増減の列と合わない（`variance-mismatch`）

**こんな文書に:** 予算と実績の報告、町内会や部の決算の報告、事業の費用の見通し。増減の列を手で打つときに、数字を一つ入れ替える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 営業部 経費の予算と実績（上期）

| 費目 | 予算額 | 決算額 | 増減 |
| --- | --- | --- | --- |
| 旅費交通費 | 1,800,000円 | 1,652,400円 | △147,600円 |
| 交際費 | 600,000円 | 684,300円 | 84,300円 |
| 広告宣伝費 | 2,400,000円 | 2,518,000円 | 181,000円 |
| 消耗品費 | 300,000円 | 271,800円 | △28,200円 |

交際費と広告宣伝費は、秋の展示会の分だけ予算を超えました。
```

## 直し方

広告宣伝費は、予算額2,400,000円に対して決算額が2,518,000円なので、増減は118,000円です。表には181,000円と書いてあり、「1」と「8」が入れ替わっています。
予算と実績の表を読む人は、増減の列だけを見て、どの費目がどれだけ予算を超えたかを判断します。この表のとおりなら、広告宣伝費の超過は交際費の倍に見え、来期の予算の話し合いで実際より大きな削減を求められかねません。

直した文章では、広告宣伝費の増減を118,000円にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  variance-mismatch: strict
```

見出しの語で予算の列（予算額、予算）、決算の列（決算額、実績）、増減の列（増減、差異、差額）が一つずつ分かる表で、行ごとに決算額から予算額を引いた額と、書いた増減を比べます。「△」「▲」の付いた額と括弧に入れた額は負の数と読みます。増減を「予算額から決算額を引いた額」で書く表もあるので、向きは表のほかの行が多く従うほうに決めます。当初予算と補正予算が並ぶ表や、増減率の列は比べません。
文学のジャンルでは止めています。合計の足し算は `total-mismatch` が見ます。
