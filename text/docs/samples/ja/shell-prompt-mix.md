## 直し方

この手順のコマンドは、どれも頭に何も付けずに書かれています。最後の「動かす」のブロックだけ、「$ yarn dev」と頭に「$」が付いています。
入ったばかりの人は、「$」まで打つのか迷います。ブロックごとコピーして貼り付けると、「$」が付いたままでコマンドが動きません。

ほかのブロックと同じく、「$」を外しました。
chaff は、プロンプトを付けるかどうかは決めません。全部の行に「$」を付けたブロックと、一つも付けないブロックを比べ、少ないほうを指します。コマンドと出力を一緒に書いたブロックは見ません。

## 設定

少ないほうのブロックが数個までなら、書き分け忘れと読んで指摘します。

```yaml chaff-settings
rules:
  shell-prompt-mix: relaxed
```

`relaxed` にすると、少ないほうが1ブロックだけのときに指摘します。`strict` にすると、もう少し多くても指摘します。見たくなければ `off` にします。
法務と論文、文芸、講演のジャンルでは、はじめから動きません。Markdown の文書だけを見ます。
