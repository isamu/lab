# 月給と賞与から計算した額と合わない年収例（`annual-pay-mismatch`）

**こんな文書に:** 求人票、募集要項、転職サイトに出す原稿。賞与の月数や月給を書き直したとき、年収例だけが古い数のまま残ります。

## 元の文章

```markdown chaff-before
# 法人営業の募集

株式会社あおば印刷では、企業向けの印刷物を提案する営業を募集します。

| 項目 | 内容 |
| --- | --- |
| 仕事の内容 | 取引先の企業を回り、パンフレットやカタログの印刷を提案します |
| 勤務地 | 本社（名古屋市中村区） |
| 賞与 | 年2回（合計で月給の3ヶ月分） |
| 年収例 | 480万円（入社3年目、月給30万円の場合） |

応募は、採用のページの申し込み画面からお願いします。
```

## 直した文章

```markdown chaff-after
# 法人営業の募集

株式会社あおば印刷では、企業向けの印刷物を提案する営業を募集します。

| 項目 | 内容 |
| --- | --- |
| 仕事の内容 | 取引先の企業を回り、パンフレットやカタログの印刷を提案します |

| 年収例 | 450万円（入社3年目、月給30万円の場合） |

応募は、採用のページの申し込み画面からお願いします。
```

## 直し方

年収例は、月給の12か月分に賞与の月数分を足した額です。月給30万円で賞与が3ヶ月分なら、30万円 × 15 で450万円になります。
元の文章の「480万円」は、賞与が4ヶ月分だった去年の求人の数でした。賞与の行だけを今年の3ヶ月分に直し、年収例を直し忘れていました。
応募する人は年収例を計算し直さずに信じます。入社してから「聞いていた額より少ない」となれば、会社への信頼をなくします。

直した文章では、年収例を450万円にしました。
年収例は書いた桁までの丸めを認めます。「450万円」と書けば、1万円に満たない差は合っていると読みます。
年俸制の求人や、年収例に残業代や手当を含めると書いた求人は、月給と賞与だけでは決まらないので比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  annual-pay-mismatch: strict
```

求人の原稿を出す前に必ず止めたいなら `strict` にします。文芸のジャンルでは、はじめから動きません。
