# 太字の強調が文書じゅうに散っている（`bold-emphasis`）

**こんな文書に:** 会社や団体のブログ、暮らしの記事、社内向けの案内。AI に「読みやすく」と頼んだ下書きは、段落ごとに語句を太字にします。

## 元の文章

```markdown chaff-before
# 引っ越しの前にやっておくこと

引っ越しは、決めてから当日までが**意外と短い**ものです。
この記事では、去年の春に家族四人で引っ越したときに、やってよかったことを順に書きます。

## 一か月前

まず、**引っ越し業者の見積もり**を三社から取りました。
見積もりのときは、業者に部屋の中を見てもらうと、当日になって荷物が多いと言われる心配がありません。
三月と四月は料金が高くなる時期なので、日をずらせるなら平日を選ぶと安くなります。
わが家は、**土曜を火曜に変えただけで**、二万円ほど下がりました。
大きな違いです。

同じころに、大家さんへ**解約の連絡**を入れます。
契約書に**一か月前までに**と書いてあることが多いので、先に確かめておきましょう。

## 二週間前

電気、ガス、水道の**止める日と始める日**を、それぞれの会社に伝えます。
ガスは、新しい部屋で**立ち会いが要る**ので、早めに予約しました。
インターネットの回線は、工事に**三週間ほど**かかることがあり、わが家はここで遅れました。

## 前の日

冷蔵庫は、前の日までに中を空にして、**電源を抜いておきます**。
当日すぐ使うもの（タオル、トイレットペーパー、充電器）は、**一つの箱にまとめて**、自分の車で運びました。

## 当日

業者が来るのは朝八時でした。
荷物を運び出したあと、**空になった部屋の写真**を撮っておくと、敷金の話し合いで役に立ちます。
最後に、鍵を大家さんに返します。
これで終わりです。
```

## 直し方

元の文章は、ほとんどの段落で文の途中の語句を太字にしています。
「意外と短い」「引っ越し業者の見積もり」「電源を抜いておきます」まで太字なので、どれが本当に見落とすと困ることなのか、読み手には分かりません。

直した文章では、太字をいったん全部外し、見落とすと損をする一か所だけを太字に戻しました。
解約の連絡の期限（「**一か月前までに**連絡する」）です。
ほかの語句は、太字にしなくても文の中で読めます。

## 設定

文の途中の太字が、1000字あたり10箇所を超えると指摘します。太字が2つまでの文書と、短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  bold-emphasis: strict
```

`strict` にすると1000字あたり6箇所まで、`relaxed` なら15箇所までです。
行や項目の頭に立つ太字（「- **速さ**：」「**差出人：**」）は、札や欄の名前なので数えません（箇条書きの札は `bold-label-list` が見ます）。
ボタンや設定の名前（「**Add Printer** を押す」）、表と見出しの中の太字も数えません。
README（`technical/readme`）、議事録（`business/meeting-notes`）、法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score article.md` で見られます。
