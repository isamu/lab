# 接続詞で始まる段落が続く（`repeated-conjunction`）

**こんな文書に:** ブログの記事、社内報のコラム、体験談。前の段落を受けて、段落の頭に接続詞を置き続けがちな文章です。

## 元の文章

```markdown chaff-before
# 朝の散歩を半年続けてみて

春から、出勤の前に三十分ほど近所を歩くようにしています。
きっかけは、健康診断で運動が足りないと言われたことでした。

しかし、最初の一か月は、起きるのがつらくて半分も歩けませんでした。
目覚ましを止めて、そのまま寝てしまう日が続きました。
前の晩に靴と上着を玄関に出しておくようにしてから、ようやく外に出られるようになりました。

そして、二か月目からは、ほとんど毎朝歩けるようになりました。
川沿いの道では、同じ時間に犬を連れて歩く人と、いつのまにかあいさつを交わすようになりました。
雨の日は休みます。

また、夜もよく眠れるようになった気がします。
次の健康診断の結果が、いまから楽しみです。
```

## 直し方

元の記事は、三つの段落が「しかし、」「そして、」「また、」で始まっています。
どの段落も前の段落の付け足しに見えて、話がどこへ向かっているのかが見えません。
最後の「また、」も、何に何を足しているのかが分かりにくくなっています。

直した文章では、接続詞を外して、どの段落も言いたいことから始めました。
「最初の一か月は」「二か月目からは」「夜も」と、段落の頭が時間の流れを運ぶので、接続詞が無くても筋は追えます。

数えるのは段落の頭の接続詞だけです。一つだけなら、流れをつなぐ普通の書き方なので指しません。

## 設定

接続詞で始まる段落が二つ続くまでなら指摘しません。`strict` にすると二つ続いただけで、`relaxed` にすると五つ続いたら指摘します。
文学のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  repeated-conjunction: relaxed
```

見ないことにするなら `repeated-conjunction: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax repeated-conjunction --why "段落ごとに論点を足していく意見書の形のため"
```
