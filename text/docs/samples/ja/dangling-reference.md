# 参照先が無い（`dangling-reference`）

**こんな文書に:** 契約書、利用規約、社内規程。条を削ったり並べ替えたりしたあとに、「第○条に定める」の番号だけが古いまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# 秘密保持契約書

株式会社あおば（以下「甲」という。）と株式会社しらかわ（以下「乙」という。）は、新商品の共同開発の検討にあたり、次のとおり契約を結ぶ。

## 第1条（秘密情報）

この契約で秘密情報とは、甲又は乙が相手方に開示した技術上及び営業上の情報をいう。

## 第2条（秘密の保持）

甲及び乙は、相手方の書面による承諾なく、秘密情報を第三者に開示しない。

## 第3条（有効期間）

この契約の有効期間は、締結の日から1年間とする。

## 第4条（秘密情報の返還）

甲及び乙は、この契約が終了したときは、相手方から受け取った資料を返還する。返還の手続は、第6条に定めるところによる。

## 第5条（返還の手続）

資料の返還は、受け取った側が費用を負担して、相手方の事務所に届ける方法で行う。
```

## 直し方

この契約書には第5条までしかありません。ところが第4条は「第6条に定めるところによる」と、無い条を指しています。
下書きの段階で条が一つ多く、どこかの条を削ったときに、参照の番号だけが古いまま残った、という形です。
読み手は第6条を探して行き止まりになり、返還の手続がどこに決めてあるのか分からなくなります。
契約書では、参照先が無いことは、決めたつもりの手続が決まっていないことになりかねません。

直した文章では、返還の手続を決めた第5条を指すように、番号を直しました。
条を削ったり振り直したりしたときは、その番号を引いている所も一緒に直します。
ほかの文書の条を指しているなら、「民法第3条」のように文書の名前を添えると、読み手に伝わります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「エラー」として出し、`relaxed` にすると「注意」になります。

```yaml chaff-settings
rules:
  dangling-reference: relaxed
```

「法第2条」「就業規則 第25条」のように、ほかの文書の条を指す参照は探しません。
条で番号を振っていない文書では、条で数える参照を見ません。
文学（`literature`）のジャンルでは動きません。
