# 暦に無い日付（`impossible-date`）

**こんな文書に:** 締め切りを知らせるメール、行事の案内、契約の期間。月末を「31日」と決めて書いてしまう、という形がよくあります。

```markdown chaff-before
件名：年末調整の書類の提出について

社員のみなさま

お疲れさまです。総務課の川村です。

今年の年末調整の書類を、各部署の棚に置きました。
扶養する家族や保険料の控除の欄を書いて、11月31日までに総務課へ出してください。
書き方が分からないところは、総務課の窓口でお聞きください。

よろしくお願いします。
```

## 直し方

11月は30日までしかないので、「11月31日」という日はありません。月末のつもりで、どの月も31日までと思って書いたのでしょう。
読む人は、11月30日までなのか、12月1日まで待ってもらえるのかを決められません。30日に出す人と、1日に出して遅れる人が出ます。

直した文章では、11月の最後の日の「11月30日」にしました。月末の締め切りを毎月書くなら、「11月の末日まで」と書く手もあります。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  impossible-date: relaxed
```

月の長さとうるう年は暦で決まるので、どのジャンルでも動きます。「令和6年（2023年）」のように和暦と西暦が違う年を指す日付も指摘します。元号の年と年の無い日付は、うるう年を決められないので2月29日を言いません。「2026-10-45」のように数字だけを並べたものは番号のこともあるので、月が1〜12、日が31までのときだけ月の長さと比べます。
