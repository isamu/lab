# 使い古された決まり文句（`cliche`）

**こんな文書に:** 技術ブログ、会社のお知らせ記事、入門の解説。題や書き出しに、どの記事にも付けられる言い回しを使いがちな文書です。

## 元の文章

```markdown chaff-before
# Git のブランチの使い方

この記事では、今さら聞けない Git のブランチの使い方を徹底解説します。

ブランチは、作業を本流から分けておくための仕組みです。
新しい機能を作るときは、`git switch -c` で自分用のブランチを作り、そこで変更を重ねます。

作業が終わったら、本流のブランチに戻って `git merge` で取り込みます。
取り込んだあとのブランチは、`git branch -d` で消しておくと一覧が散らかりません。
```

## 直した文章

```markdown chaff-after
# Git のブランチの使い方

この記事では、Git を使い始めたばかりの人向けに、ブランチを作ってから取り込むまでの三つのコマンドを説明します。

ブランチは、作業を本流から分けておくための仕組みです。
新しい機能を作るときは、`git switch -c` で自分用のブランチを作り、そこで変更を重ねます。

作業が終わったら、本流のブランチに戻って `git merge` で取り込みます。
取り込んだあとのブランチは、`git branch -d` で消しておくと一覧が散らかりません。
```

## 直し方

「今さら聞けない」「徹底解説」は、検索で見かける記事の書き出しによくある言い回しです。
見慣れているぶん、読み手は読み飛ばし、この記事が誰に向けて何を説明するのかが残りません。
それに、本文は短い入門なので、「徹底」と言うほどの中身でもありません。

直した文章では、決まり文句が指していた中身を書きました。
「今さら聞けない」は「Git を使い始めたばかりの人向けに」、「徹底解説」は「ブランチを作ってから取り込むまでの三つのコマンドを説明します」です。
読み手は、最初の一文で、自分に合う記事かどうかを決められます。

chaff は、一つの文には一つだけ指摘します。この文の「徹底解説」も同じ一覧にあるので、一緒に直してください。

## 設定

一覧にある言い回しが1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  cliche: relaxed
```

見出しの中は見ず、本文の文だけを見ます。言い回しを言葉として名指しているだけのもの（「徹底解説」という言い方）も指摘しません。
文学（`literature`）と話し言葉（`speech`）のジャンルでは、語り手や話し手の口調なので動きません。
