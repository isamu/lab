# 文字で書いた数と括弧の数字が違う（`number-word-figure-mismatch`）

**こんな文書に:** 契約書、借用書、領収書。金額を「金弐拾五万円（250,000円）」と二通りで書いたのに、片方だけを打ち間違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 業務委託契約書

株式会社つばめ物産（以下「甲」という。）と、ことり制作事務所（以下「乙」という。）は、甲の商品の写真の撮影について、次のとおり契約を結ぶ。

## 第1条（業務）

乙は、甲が指定する商品の写真を撮影し、甲に納品する。

## 第2条（委託料）

甲は、乙に対し、委託料として月額金弐拾五万円（205,000円）を、毎月末日までに支払う。

## 第3条（期間）

この契約の期間は、契約の日から六（6）か月とする。
```

## 第2条（委託料）

## 直し方

委託料は、文字では「金弐拾五万円」で250,000円ですが、括弧の数字は205,000円です。数字の「5」と「0」を入れ違えたのでしょう。
金額を二通りで書くのは、読み違いや書き換えを防ぐためです。その二つが食い違うと、どちらが約束した額なのかが文書からは決まらず、毎月45,000円の差が争いの種になります。

直した文章では、括弧の数字を250,000円にしました。数字のほうが正しいなら、文字のほうを「金弐拾萬五千円」のように直します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  number-word-figure-mismatch: strict
```

漢数字（壱・弐・参・拾・萬のような大字も）を数に直し、すぐ後ろの括弧の数字と比べます。括弧の中が数字だけでないもの（「三（第6条）」）、ほかの字に続く漢数字（「唯一（1）」）、二〇二六のように数字を並べただけの漢数字は読みません。
どのジャンルでも動きます。
