# 添付に触れているのに、添付が見当たらない（`attachment-not-attached`）

**こんな文書に:** 送ったメール、メーリングリストの保存分。本文で「添付のPDF」と書いたのに、ファイルを付け忘れて送る、という形がよくあります。

## 直し方

本文は「添付のPDFを、11月25日までにご確認ください」と頼んでいるのに、メールのどこにも添付のファイルの名前がありません。付け忘れて送ったのでしょう。
受け取った人は、届いていないPDFを探し、返信で送り直しを頼むことになります。一往復増えるうちに、11月25日の返事の期限が近づきます。

直した文章では、署名の前に「添付ファイル：冬のメニュー表_校正1.pdf」と書きました。何を付けたかを本文に書いておくと、受け取った人も、届いたファイルが全部そろっているかを確かめられます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  attachment-not-attached: strict
```

差出人や日時の欄のある、送ったメールや届いたメールでだけ見ます。送る前の下書きは、ファイルを送るときに付けるので、本文に添付の欄が無いのが普通だからです。本文が「添付」「別添」「同封」に触れているのに、添付の欄（添付ファイル：）もファイル名（見積書.pdf）も無いときに指摘します。
メールと手紙のジャンルでだけ動きます。
