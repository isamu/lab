# 同じ文末が続く（`repeated-sentence-ending`）

**こんな文書に:** 報告書、日報、お知らせ。決まったことを一つずつ書き並べて、どの文も同じ形で終わりがちな文書です。

## 元の文章

```markdown chaff-before
# 新しい受付の仕組みの準備について

総務課から、来月から使う来客の受付の仕組みについて報告します。

受付には、来客が自分で名前を打ち込むタブレットを置く予定です。
担当の社員には、来客が着いた時点で社内のチャットに通知が届く予定です。
入館証は、受付の機械からその場で印刷される予定です。

使い方の説明会は、今月の25日に開きます。
```

## 直した文章

```markdown chaff-after
# 新しい受付の仕組みの準備について

総務課から、来月から使う来客の受付の仕組みについて報告します。

受付には、来客が自分で名前を打ち込むタブレットを置きます。
来客が着くと、担当の社員に社内のチャットで通知が届き、入館証は受付の機械からその場で印刷されます。

使い方の説明会は、今月の25日に開きます。
```

## 直し方

元の段落は、三つの文がどれも「予定です。」で終わっていて、chaff は「〜です」で終わる文が3文続いていると言っています。
同じ調子が続くと、読み手には決まったことの一覧のように聞こえ、どれが要なのかが見えません。
本当は、タブレットを置くことが仕組みの中心で、通知と入館証はその結果です。

直した文章では、言い切れることは言い切り、二つ目と三つ目の文を一つにまとめました。
「来客が着くと、通知が届き、入館証が印刷されます」と、一つの流れとして読めます。

段落をまたいだ文は続きと見ません。名詞の後の「です」は、名詞が違っても同じ文末と見ます。

## 設定

同じ文末の文が二つ続くまでなら指摘しません。`relaxed` にすると、四つ続いたら指摘します。
法務・文学のジャンルでは、既定で止めています。

```yaml chaff-settings
rules:
  repeated-sentence-ending: relaxed
```

見ないことにするなら `repeated-sentence-ending: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax repeated-sentence-ending --why "決まった形で項目を並べる仕様の文書のため"
```

