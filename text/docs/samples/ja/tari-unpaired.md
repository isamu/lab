# 対にならない「〜たり」（`tari-unpaired`）

**こんな文書に:** 社内の案内、報告書、ブログ。話すときの調子で書くと、「〜たり」を一つだけ置いて、次の述語へそのまま続けてしまいます。

## 元の文章

```markdown chaff-before
# 図書室の使い方が変わります

## 開いている時間

12月から、社内の図書室は平日の午前9時から午後7時まで開きます。
これまでより、閉まる時間が一時間遅くなります。

## できること

図書室では、本を借りたり、雑誌を読めます。
窓ぎわの四つの席は、一人で集中したいときに使えます。
話し声の出る打ち合わせは、隣の小会議室を使ってください。

## 本の返し方

借りた本は、二週間以内に返してください。
返すときは、入口の返却箱に入れれば済みます。
```

## 直した文章

```markdown chaff-after
# 図書室の使い方が変わります

## 開いている時間

12月から、社内の図書室は平日の午前9時から午後7時まで開きます。
これまでより、閉まる時間が一時間遅くなります。

## できること

図書室では、本を借りたり、雑誌を読んだりできます。
窓ぎわの四つの席は、一人で集中したいときに使えます。
話し声の出る打ち合わせは、隣の小会議室を使ってください。

## 本の返し方

借りた本は、二週間以内に返してください。
返すときは、入口の返却箱に入れれば済みます。
```

## 直し方

「本を借りたり、雑誌を読めます」は、「〜たり」が一つで止まっています。「〜たり」は「〜たり〜たりする」と対で並べる言い方なので、読み手は、並べたはずのもう一つがどこにあるのかを探します。

直した文章では、「本を借りたり、雑誌を読んだりできます」と、後ろにも「〜たり」を付けて閉じました。図書室でできることが二つ並んでいることが、そのまま読めます。
「遅れたりする」のように、一つだけで例を挙げて「する」で閉じた形は正しいので、chaff は指しません。

## 設定

指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  tari-unpaired: strict
```

一文に「〜たり」が二つ以上ある文と、鉤括弧で引いた中は見ません。
文学のジャンルでは止めています。
