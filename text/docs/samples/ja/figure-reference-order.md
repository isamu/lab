# 図や表を参照する順番と位置（`figure-reference-order`）

**こんな文書に:** 論文、学会の予稿、研究の報告書。書き直しの途中で図を入れ替えたり、説明の順を変えたりしたあとに、図の番号と本文で参照する順が食い違う形がよくあります。

## 元の文章

```markdown chaff-before
# 図書館の開館時間の延長と利用者の変化

## 要旨

市立図書館の閉館を2時間遅らせ、延長の前と後で来館者の数を比べた。延ばした時間帯には、平日に一日あたり平均45人が来館した。

## 方法

閉館の時刻を、午後6時から午後8時に延ばした。延ばす前と後の半年で、時間帯ごとに来館者を数えた。

## 結果

時間帯ごとの来館者の数を図2に示す。午後6時から8時に来た人は、平日に一日あたり平均45人だった。月ごとに見た来館者の数は、図1のとおりである。

図1　月ごとの来館者の数

図2　時間帯ごとの来館者の数
```

## 直した文章

```markdown chaff-after
# 図書館の開館時間の延長と利用者の変化

## 要旨

市立図書館の閉館を2時間遅らせ、延長の前と後で来館者の数を比べた。延ばした時間帯には、平日に一日あたり平均45人が来館した。

## 方法

閉館の時刻を、午後6時から午後8時に延ばした。延ばす前と後の半年で、時間帯ごとに来館者を数えた。

## 結果

時間帯ごとの来館者の数を図1に示す。午後6時から8時に来た人は、平日に一日あたり平均45人だった。月ごとに見た来館者の数は、図2のとおりである。

図1　時間帯ごとの来館者の数

図2　月ごとの来館者の数
```

## 直し方

この論文の「結果」の節は、先に図2を参照し、そのあとで図1を参照しています。
論文の図は、本文で初めて参照する順に番号を振るのが決まりです。読む人は、図1を探してから図2へ戻る、と図と本文のあいだを行ったり来たりします。
説明の順を入れ替えたときに、図の番号を振り直し忘れた、という形です。

直した文章では、初めて参照する順に図の番号を振り直し、キャプションの順も揃えました。
番号を変えたくないなら、反対に本文の説明の順を入れ替えます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  figure-reference-order: strict
```

見るのは三つです。初めての参照が番号の順になっていない図、キャプションのある節を過ぎてから初めて参照する図、同じ種類のほかの図は参照しているのに一度も参照しない図です。
キャプション（行の頭の「図1　…」）を一つも書いていない種類の図と、「報告書の図5」のような他の文書の図は見ません。付録や別表は、参照の順だけを見ます。
論文（`academic/paper`）のジャンルでだけ動きます。
