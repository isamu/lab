# 利益率が二つの値の割り算と合わない（`ratio-mismatch`）

**こんな文書に:** 決算の説明資料、事業部の業績の表、予算と実績の報告。前の期の表を写して作るときに、金額だけを差し替えて、率を前の期のまま残す、という形がよくあります。

## 元の文章

```markdown chaff-before
# 2026年度 上期の業績

## 損益の概要

単位：百万円

| 項目 | 前上期 | 当上期 |
| --- | --- | --- |
| 売上高 | 4,820 | 5,360 |
| 売上総利益 | 1,446 | 1,662 |
| 営業利益 | 337 | 429 |
| 営業利益率 | 7.0% | 7.0% |

売上高は、新しい店舗の分だけ伸びました。営業利益は、仕入れの見直しで伸びました。
```

## 直した文章

```markdown chaff-after
# 2026年度 上期の業績

## 損益の概要

単位：百万円

| 項目 | 前上期 | 当上期 |
| --- | --- | --- |
| 売上高 | 4,820 | 5,360 |
| 売上総利益 | 1,446 | 1,662 |
| 営業利益 | 337 | 429 |
| 営業利益率 | 7.0% | 8.0% |

売上高は、新しい店舗の分だけ伸びました。営業利益は、仕入れの見直しで伸びました。
```

## 直し方

当上期の営業利益429百万円を売上高5,360百万円で割ると、営業利益率は8.0%です。表には7.0%と書いてあり、前上期の率と同じです。前の期の表を写して金額だけを差し替え、率の升を直し忘れたのでしょう。
業績の表を読む人は、率の行を見て、利益の出やすさが上がったのか下がったのかを判断します。この表のとおりなら、利益は伸びても率は横ばいに見え、仕入れを見直した効果が伝わりません。

直した文章では、当上期の営業利益率を8.0%にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  ratio-mismatch: strict
```

行の見出しが率の名前（営業利益率、経常利益率、売上総利益率）だけの行があり、同じ表にその分子の行と分母の行が一つずつあれば、列ごとに割り算して比べます。率は書いた桁の半分までの丸めを認め、金額は書いた最後の桁の一つ分までのずれを認めます。分子か分母の行が無い表、同じ名前の行が二つある表、単位の違う列、「自己資本比率」のように語彙表に無い率は比べません。
文学のジャンルでは止めています。増減の率は `change-rate-mismatch` が見ます。
