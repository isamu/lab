# 二重否定（`double-negative`）

**こんな文書に:** 社内のお知らせ、取引先へのメール、手順の案内。角を立てまいとして、打ち消しを重ねがちな文書です。

## 元の文章

```markdown chaff-before
# 新しい経費精算システムへの切り替え

いつもお世話になっております。経理課の佐藤です。
来月から、経費の精算を新しいシステムで行います。

いまの申請書の様式も使えないわけではありませんが、新しいシステムで申請しないと、承認が遅れないとは限りません。
切り替えの説明会は、10日と17日の2回開きます。

どうぞよろしくお願いいたします。

経理課 佐藤
```

## 直した文章

```markdown chaff-after
# 新しい経費精算システムへの切り替え

いつもお世話になっております。経理課の佐藤です。
来月から、経費の精算を新しいシステムで行います。

いまの申請書の様式も今月末までは使えますが、承認に一週間ほど余計にかかります。
来月からは新しいシステムで申請してください。
切り替えの説明会は、10日と17日の2回開きます。

どうぞよろしくお願いいたします。

経理課 佐藤
```

## 直し方

元の文の「使えないわけではありません」は、読み手が「使えない」を打ち消して「使える」と読み直すことになります。
しかも、使ってよいのか、使わないでほしいのか、書き手の頼みたいことが見えません。
後ろの「承認が遅れないとは限りません」も、遅れるのかどうかを言っていない二重否定です。

直した文章では、肯定で言い切りました。「今月末までは使えます」と期限を書き、「一週間ほど余計にかかります」とどの程度なのかを書いています。
そのうえで「新しいシステムで申請してください」と、頼みたいことを文にしました。
読み手は、何をすればよいかを一度で受け取れます。

chaff はこの文に一つだけ指摘を出し、その中で二つの二重否定をどちらも名指ししています。一文に二重否定が二つあっても、指摘は一つにまとまります。
直すときは、文の全体を読み直してください。

## 設定

二重否定のある文が一つあれば指摘します。`relaxed` にすると、二つ目から指摘します。
「ざるを得ない」「なければならない」のような決まった言い方は指しません。
法令・文学・話し言葉のジャンルでは、言い切らない言い方がその文書の書き方なので、既定で止めています。

```yaml chaff-settings
rules:
  double-negative: relaxed
```

見ないことにするなら `double-negative: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax double-negative --why "やわらかく断る言い方を残したい案内のため"
```
