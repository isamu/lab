# 変換し損ねた英字（`ime-residue`）

**こんな文書に:** 社内のメール、急いで打った連絡。ローマ字入力で母音を打ち損ねると、子音の字だけが語の中に残ります。

## 元の文章

```markdown chaff-before
件名：会議室の予約を変えました

開発課のみなさま

お疲れさまです。庶務の小林です。

来週の定例会は、参加sる人が増えたので、会議室を3階の大会議室に変えました。
時間は変わらず、火曜日の午後2時からです。
プロジェクターは会議室にあるので、持ってこなくてかまいません。

ほかの日の予約もかくにnしておきます。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：会議室の予約を変えました

開発課のみなさま

お疲れさまです。庶務の小林です。

来週の定例会は、参加する人が増えたので、会議室を3階の大会議室に変えました。
時間は変わらず、火曜日の午後2時からです。
プロジェクターは会議室にあるので、持ってこなくてかまいません。

ほかの日の予約も確認しておきます。

よろしくお願いします。
```

## 直し方

「参加sる」「かくにn」は、ローマ字入力で押したキーが仮名にならずに残った跡です。「かくにn」は、変換する前に送ってしまったので、仮名のまま残っています。
読み手はその語で止まって読み直し、検索でも「確認」には当たりません。

直した文章では、英字を消して、「参加する」「確認」と打ち直しました。
「A 社」のような大文字、「note」のような二字以上の英字、「変数 x が」のような一字の名前、「e ラーニング」のような母音の一字は指しません。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  ime-residue: strict
```

```text chaff-explain
$ npx chaffjs explain ime-residue --genre business/email

  変換し損ねた英字   (ime-residue)

  「おもしrおい」「対応sた」のように、日本語の語の中に英字が一字だけ残るのは、ローマ字入力で押したキーが仮名にならなかった跡です。読み手はその語で止まり、検索にも当たりません。打ち間違いなので、どちらの書き方が正しいかの話ではありません。

  直しかた: 英字を消して、語を打ち直してください（おもしrおい → おもしろい）。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax ime-residue --why "理由"
```
