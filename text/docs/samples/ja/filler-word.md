# 残ったつなぎの言葉（`filler-word`）

**こんな文書に:** 録音から作った議事録やメモ。手で起こしても、AI の文字起こしでも、「ええと」「まあ、」がそのまま残りがちです。

## 元の文章

```markdown chaff-before
# 仕入れ先の見直し 議事録

出席者: 森、田中、佐藤

ええと、いまの仕入れ先は4月から価格を6%上げました。
田中さんがほかの2社の見積もりを比べました。まあ、どちらも安いですが、納品が1週間遅くなります。
6月末までは、いまの仕入れ先を続けることにしました。
```

## 直した文章

```markdown chaff-after
# 仕入れ先の見直し 議事録

出席者: 森、田中、佐藤

いまの仕入れ先は4月から価格を6%上げました。
田中さんがほかの2社の見積もりを比べました。どちらも安いですが、納品が1週間遅くなります。
6月末までは、いまの仕入れ先を続けることにしました。
```

## 直し方

「ええと」「まあ、」は、話しながら考える間を埋めた声です。議事録に残っても、読む人には中身の無い字が増えるだけです。
消しても、値上げ、2社の見積もり、決まったことは、どれもそのまま残ります。
つなぎの言葉のほかは書き換えていないので、議事録は会議で言われたことだけを書いています。

## 設定

つなぎの言葉が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  filler-word: relaxed
```

「まあ」「なんか」「あの」「えー」は、文の頭か読点の後ろに立ち、後ろに読点が続くときだけ数えるので、「まあまあ」「あの件」は指摘しません。
鉤括弧で引いた発言は、言ったとおりに引いたものなので見ません。
ビジネス文書と手引きのジャンルだけで動き、言ったとおりに残す記録（`speech/transcript`）では動きません。

