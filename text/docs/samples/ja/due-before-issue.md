# 期限が発行日より前（`due-before-issue`）

**こんな文書に:** 請求書の支払期限、見積書の有効期限、予約の確認書。前の月の請求書を写して、発行日だけを新しくする、という形がよくあります。

## 元の文章

```markdown chaff-before
# 請求書

株式会社ひなた設計 御中

発行日：2026年12月1日

お支払期限：2026年11月30日

11月分の図面の清書について、次のとおりご請求します。

| 項目 | 金額 |
| --- | --- |
| 平面図の清書（12枚） | 96,000円 |
| 立面図の清書（4枚） | 40,000円 |
| 合計 | 136,000円 |

お振込みの手数料は、貴社でご負担ください。
```

## 直し方

請求書の発行日は12月1日なのに、支払の期限は前の日の11月30日です。受け取った人の手元に届いたときには、もう期限が過ぎています。10月分の請求書を写して、発行日だけを新しくしたのでしょう。
受け取った人は、すぐに払わないと遅れになるのか、期限の日付が誤りなのかを問い合わせることになります。経理の担当者によっては、期限切れの請求書として処理を止めます。

直した文章では、期限を12月31日にしました。期限をいつにするかは、取引の約束で決まります。chaff は、期限が発行日より前であることだけを示します。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  due-before-issue: relaxed
```

行の頭に発行日の語と期限の語がある日付どうしを比べます。「12月25日までにお支払いください」のように文の中に書いた日付、年の無い日付、一行に日付が二つある行は比べません。発行日から8行以上離れた期限と、「期限切れ」「延滞」と書いた行も、この文書の期限ではないと読んで比べません。
同じ形で、議事録の宿題の期限と会議の日、宿泊のチェックインとチェックアウト、発注日と納期のように、前後の決まった日付の組も比べます。法令、判決、特許、よくある質問、用語集、論文、文学、スピーチのジャンルでは止めています。
