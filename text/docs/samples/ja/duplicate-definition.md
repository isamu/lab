# 同じ語の二重定義（`duplicate-definition`）

**こんな文書に:** 利用規約、契約書、社内規程。あとから条を書き足したとき、すでに定義した語をもう一度、少し違う言葉で定義してしまう形がよくあります。

## 元の文章

```markdown chaff-before
# 料理教室 会員規約

## 第1条（定義）

この規約で「会員」とは、当教室に入会を申し込み、当教室が承認した個人をいう。

## 第2条（会費）

会員は、毎月の会費を前月の末日までに支払う。

## 第3条（予約）

会員は、受講する日の3日前までに、当教室のウェブサイトから受講の予約をする。

## 第4条（休会）

この条で「会員」とは、入会金を支払った個人をいう。会員は、所定の届出をして、最長3か月まで休会することができる。
```

## 直した文章

```markdown chaff-after
# 料理教室 会員規約

## 第1条（定義）

この規約で「会員」とは、当教室に入会を申し込み、当教室が承認した個人をいう。

## 第2条（会費）

会員は、毎月の会費を前月の末日までに支払う。

## 第3条（予約）

会員は、受講する日の3日前までに、当教室のウェブサイトから受講の予約をする。

## 第4条（休会）

会員は、所定の届出をして、最長3か月まで休会することができる。
```

## 直し方

この規約は、第1条で「会員」を「当教室が承認した個人」と定義しています。
ところが第4条の休会の条で、もう一度「会員」を「入会金を支払った個人」と定義し直しています。
入会金は払ったけれど、まだ承認されていない人は、休会の条だけでは会員になるのでしょうか。
読む人は二つの定義を見比べ、どちらが正しいのか、わざと違えたのかを考えなければなりません。

直した文章では、第4条の定義を消し、第1条の定義一つにまとめました。
休会の条だけ意味を変えたかったのなら、「入会金納付者」のように別の語を立てると、取り違えが起きません。
二つの定義が食い違っているかどうかは、chaff は決めません。二つ目の定義の場所を示すだけです。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  duplicate-definition: strict
```

「『会員』とは」を見出しにしただけの行は、語を掲げるだけなので定義に数えません。
添付した文書（別紙）の中の定義は、本文の定義とは比べません。
文学（`literature`）のジャンルでは動きません。ファイルをまたいだ二重定義は、`cross-doc-duplicate-definition` が見ます。
