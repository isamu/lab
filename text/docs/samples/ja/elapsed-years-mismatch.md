# 起点の年から数えた年数が、文書の日付と合わない（`elapsed-years-mismatch`）

**こんな文書に:** 会社の案内、創業記念のお知らせ、プロフィールや経歴。去年の文書を写して、日付だけを今年に直す、という形がよくあります。

## 元の文章

```markdown chaff-before
# 創業記念の感謝祭のお知らせ

2026年11月2日

株式会社まるや食品

当社は2001年に創業し、今年で創業20周年を迎えます。
これまで支えてくださった地域のみなさまに感謝を込めて、本店で感謝祭を開きます。

- 日時：2026年11月21日（土）10時〜16時
- 場所：まるや食品 本店の駐車場
- 内容：できたての餅のふるまい、工場の見学

雨の日は、本店の2階に会場を移して開きます。
```

## 直した文章

```markdown chaff-after
# 創業記念の感謝祭のお知らせ

2026年11月2日

株式会社まるや食品

当社は2001年に創業し、今年で創業25周年を迎えます。
これまで支えてくださった地域のみなさまに感謝を込めて、本店で感謝祭を開きます。

- 日時：2026年11月21日（土）10時〜16時
- 場所：まるや食品 本店の駐車場
- 内容：できたての餅のふるまい、工場の見学

雨の日は、本店の2階に会場を移して開きます。
```

## 直し方

文書の日付は2026年11月2日で、創業は2001年なので、今年は創業25周年です。文には「創業20周年」と書いてあります。前に作った記念の文書から年数を写したのでしょう。
創業の年と年数が並んでいると、読む人は引き算をして確かめます。取引先や地域の人に配るお知らせで、自社の年数を間違えると、文書全体を雑に作ったように見えます。

直した文章では、年数を「創業25周年」にしました。毎年変わる年数を書かずに、創業の年だけを書く手もあります。

## 設定

ふだんは「注意」として出します。`relaxed` にすると「参考」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  elapsed-years-mismatch: relaxed
```

文書の日付（日付だけの段落か「更新日：」の段落）の年から起点の年を引き、書いた年数と比べます。起点の語は創業、設立、創立、開業、開設、発足などで、年数は「年」「年目」「周年」で読みます。誕生日の前後や「10年目」の数え方があるので、一年までの違いは指しません。文書に日付が無いときと、「創業後3年で上場」のように起点の語に直接付いていない年数は見ません。
文学のジャンルでは止めています。
