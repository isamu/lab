# 期末の残高が、期首の残高に入金を足し出金を引いた額と合わない（`closing-balance-mismatch`）

**こんな文書に:** 子ども会や町内会の会計報告、預金の取引明細のまとめ、ポイントの残高のお知らせ。繰越金を書き写すときに、桁の一つを打ち間違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 子ども会 2026年度 会計報告

## 一般会計

- 前年度繰越金：84,320円
- 本年度の収入：412,000円
- 本年度の支出：389,650円
- 次期繰越：116,670円

収入は、会費と町内会からの助成金です。支出のうち、いちばん大きいのは夏祭りの費用です。

領収書は、会計の担当がまとめて保管しています。
```

## 直した文章

```markdown chaff-after
# 子ども会 2026年度 会計報告

## 一般会計

- 前年度繰越金：84,320円
- 本年度の収入：412,000円
- 本年度の支出：389,650円
- 次期繰越：106,670円

収入は、会費と町内会からの助成金です。支出のうち、いちばん大きいのは夏祭りの費用です。

領収書は、会計の担当がまとめて保管しています。
```

## 直し方

前年度繰越金84,320円に本年度の収入412,000円を足し、本年度の支出389,650円を引くと、次期繰越は106,670円です。報告には116,670円と書いてあり、ちょうど1万円多くなっています。
会計報告を受け取る人は、足し引きし直さずに次期繰越の額を承認し、その額が来年度の繰越金になります。1万円の差が手元の現金と合わないことに、来年度の担当が気づくことになります。

直した文章では、次期繰越を106,670円にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  closing-balance-mismatch: strict
```

同じ表か同じ節に、初めの残高（前年度繰越金、前月末残高）、入金の合計（本年度の収入、お預入れ合計）、出金の合計（本年度の支出、お引出し合計）、終わりの残高（次期繰越、当月末残高）の名前が一つずつあり、それぞれに金額があるときに比べます。通貨の印が付いた金額は一円まで合わなければ言います。四つの名前のどれかが無い節、名前が別々の節にあるもの、文の中の金額は読みません。日付と入出金と残高が並ぶ取引の表は、`running-balance-mismatch` が行ごとに見ます。
