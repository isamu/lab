# 題の決算期間と違う期間（`period-label-conflict`）

**こんな文書に:** 決算短信、四半期の業績の報告、株主向けのお知らせ。前の四半期の文書を写して作ると、表の見出しの期間だけが前のまま残ります。

## 元の文章

```markdown chaff-before
# 2027年3月期 第2四半期決算短信

株式会社みどり食品

## 経営成績

| 項目 | 前年同期 | 当第1四半期累計 |
| --- | --- | --- |
| 売上高 | 4,820百万円 | 5,130百万円 |
| 営業利益 | 312百万円 | 356百万円 |

冷凍の総菜の売上が、量販店向けを中心に伸びました。
```

## 直した文章

```markdown chaff-after
# 2027年3月期 第2四半期決算短信

株式会社みどり食品

## 経営成績

| 項目 | 前年同期 | 当第2四半期累計 |
| --- | --- | --- |
| 売上高 | 4,820百万円 | 5,130百万円 |
```

## 直し方

題は「第2四半期決算短信」なのに、業績の表の見出しは「当第1四半期累計」です。
この短信は、三か月前の第1四半期の短信を写して作りました。数字は第2四半期までの累計に入れ替えたのに、表の見出しを直し忘れていました。
投資家や記者は、表の数字がどちらの期間のものかを問い合わせることになります。決算短信は公に出す文書なので、訂正を出し直すことにもなります。

直した文章では、表の見出しを「当第2四半期累計」に直しました。
chaff は、題が「決算」「業績」の語と一緒に書いた期間（第2四半期、2027年3月期、上半期）を文書の期間として読み、今の業績を言う表の見出しや文に、同じ種類の別の期間があれば指します。
「前年同期」「前期」「予想」「次期」のような、比べる相手や先の期間の語がある所は比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  period-label-conflict: strict
```

開示の前に必ず止めたいなら `strict` にします。
題に「決算」「業績」の語と期間の名前が無い文書は読みません。源泉徴収の明細書のように題が「2026年分」と年を言う文書も読み、本文に別の年分があれば指します。文芸のジャンルでは、はじめから動きません。
