# 画像に代替テキストが無い（`image-alt-text`）

**こんな文書に:** 月次の報告書、社内報、ウェブに載せるお知らせ。図を貼り付けるだけで、画像の説明を書かない形がよくあります。

```markdown chaff-before
# 10月 オンラインストア 月次報告

10月の売上は1,240万円で、前の月より12パーセント増えました。秋の新作の販売を始めた10月10日から、売上が伸びています。

![](uriage-10gatsu.png)

11月は、年末の贈り物の特集を早めに始める予定です。
```

```markdown chaff-after
# 10月 オンラインストア 月次報告

10月の売上は1,240万円で、前の月より12パーセント増えました。秋の新作の販売を始めた10月10日から、売上が伸びています。

![10月の日ごとの売上。10日の新作の販売開始から伸びている](uriage-10gatsu.png)
```

## 直し方

この報告書には売上のグラフが貼ってありますが、「![](uriage-10gatsu.png)」と、画像の説明（代替テキスト）が空です。
画面の読み上げを使って読む人には、そこに何があるのか一言も伝わりません。
メールの設定や通信の具合で画像が読み込めないときも、空の枠が出るだけです。

直した文章では、グラフが伝えることを一言で書きました。
代替テキストには、画像の見た目ではなく、その画像で読み手に伝えたいことを書くのがこつです。
飾りの画像で何も伝えなくてよいなら、HTML で `alt=""` と書くと、読み上げはその画像を飛ばします。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  image-alt-text: strict
```

HTML で `alt=""` と書いた画像は、飾りと明示したものとして指しません。引用（>）とコードの中の画像も見ません。
代替テキストがファイル名のままの画像は、`image-file-name-alt` が見ます。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain image-alt-text --genre business/report

  画像に代替テキストが無い   (image-alt-text)

  画像が読み込めないときと、画面読み上げで読むときは、代替テキストだけが画像の代わりに伝わります。「![](図1.png)」のように空だと、そこに何があったのか読み手には分かりません。HTML の <img> は alt 属性が無いものだけを数え、alt="" は飾りの画像と書き手が明示したものとして数えません（markdownlint の MD045 と同じ）。

  直しかた: 画像が伝えることを一言で書いてください（![4月の売上の推移](図1.png)）。飾りの画像なら、HTML で alt="" と書くと読み上げが飛ばします。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax image-alt-text --why "理由"
```
