## 直し方

この記録の丸括弧は、ほとんどが全角の「（）」です。「両面刷り」を囲む一か所だけが半角の「()」になっています。
読み手は、そこだけ別の資料から貼ったのかと気になり、文字の詰まり方が違うので見た目もそろいません。

chaff は開き括弧と閉じ括弧を一つずつ数えるので、この一組に二つの指摘が出ています。
少ないほうの半角を、全角の「（両面刷り）」に直しました。
chaff は全角と半角のどちらが正しいかは決めません。日本語の字に接する括弧を数えて、文書の中で少ないほうを指します。

## 設定

```yaml chaff-settings
rules:
  bracket-width-consistency: relaxed
```

ふだんは、少ないほうが1か所でもあれば指摘します。
`relaxed` にすると、少ないほうが3か所あるときだけ指摘します。見たくなければ `off` にします。
英語の中の括弧（`f(x)`）や式の括弧、コードの中は数えません。日本語の文書で、どのジャンルでも動きます。
