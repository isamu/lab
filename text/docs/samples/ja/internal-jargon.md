# 社内でしか通じない言葉（`internal-jargon`）

**こんな文書に:** 取引先へのメール、お客様へのお知らせ、異動してきた人への引き継ぎ。社内の言い回しが、そのまま外に出ていく文書です。

```markdown chaff-before
件名: 新しい受注画面の公開日について

いつもお世話になっております。

新しい受注画面の公開日は、先週の打ち合わせで握った通り、3月3日の月曜日です。
古い画面に残っている注文は、こちらで巻き取りますので、御社での作業はありません。
今回の画面は、ほかの取引先様にも順に横展開する予定です。

ご不明な点があれば、このメールにご返信ください。

よろしくお願いいたします。
```

```yaml chaff-config
jargon:
  - 握る
  - 巻き取る
  - 横展開
```

## 直した文章

```markdown chaff-after
件名: 新しい受注画面の公開日について

株式会社みなと食品
購買部 ご担当者様

いつもお世話になっております。

新しい受注画面の公開日は、先週の打ち合わせで決めた通り、3月3日の月曜日です。
古い画面に残っている注文は、こちらで新しい画面に移しますので、御社での作業はありません。
今回の画面は、ほかの取引先様にも順にお使いいただく予定です。
```

## 直し方

「握る」「巻き取る」「横展開」は、社内の会議では毎日のように使う言葉です。書いた人は、普通の言葉のつもりで書いています。
ところが、取引先の担当者は「握った」が何を決めたことなのか、「巻き取ります」で自分の注文がどうなるのかを、読んでも決められません。
いちばん知りたい「こちらで何かする必要があるのか」が、社内の言葉の向こうに隠れています。

直した文章では、それぞれを外の人にも通じる言葉に置き換えました。「決めた」「新しい画面に移します」「お使いいただく」です。
言っていることは同じで、読み手が問い合わせなくても分かるようになりました。

## 設定

この規則は、chaff.yaml の `jargon` に並べた語だけを見ます。chaff は社内用語の一覧を持っていません。
どの言葉が外で通じないかはチームごとに違うので、チームで気づいた語を書き足していきます。

```yaml chaff-settings
jargon:
  # 打ち合わせでよく出るが、社外には通じない言葉
  - 握る
  - 巻き取る
  - 横展開
  - 刈り取る
  # 社内の略称
  - 情シス
```

動詞は辞書形で書けば、活用した形にも当たります。「握る」と書けば「握った」「握ります」も指摘します。語幹（「巻き取」）で書くこともできます。
名詞（「横展開」）は書いた形のまま当たります。
並べた時点で「外向けの文書では使わない」と決めた語なので、1 箇所でも指摘します。
社内向けの文書が多く、何度も出てから知らせてほしいときは、`relaxed` にすると 3 箇所から指摘します。

```yaml chaff-settings
rules:
  internal-jargon: relaxed
```

どのジャンルでも動きます。`jargon` が空なら、何も言いません。
