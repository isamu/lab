# 読点が多すぎる（`max-ten`）

**こんな文書に:** 議事録、日報、話したことをそのまま書き起こしたメモ。話すときの息継ぎのまま、読点を打っていきがちな文書です。

```markdown chaff-before
# 11月の店長会議の記録

日時は11月6日の午後2時から、場所は本社の第二会議室です。

## 決まったこと

年末の売り出しは、去年と同じく、12月の第二週から始め、チラシは、地域ごとに、中身を変えて、配ることになりましたが、配る枚数は、来週までに、各店で決めます。

## 次の会議
```

## 直した文章

```markdown chaff-after
# 11月の店長会議の記録

日時は11月6日の午後2時から、場所は本社の第二会議室です。

## 決まったこと

年末の売り出しは、去年と同じく12月の第二週から始めます。
チラシは地域ごとに中身を変えて配ります。
配る枚数は、来週までに各店で決めます。

## 次の会議

12月4日の午後2時から開きます。
```

## 直し方

元の文は、話すときの息継ぎのまま読点を打っていて、一文に読点が八つあります。
「チラシは、地域ごとに、中身を変えて、配ることに」と細かく切れるので、読み手は、どこまでが一つのまとまりなのかを追えません。
決まったことが三つあるのに、一文に詰め込まれているのも原因です。

直した文章では、決まったことごとに文を三つに分けました。
売り出しの始まり、チラシの配り方、枚数の決め方が一文に一つずつ入り、要らなくなった読点も外しています。

名詞を並べただけの読点（名前、会社名、連絡先）と、鉤括弧で引いたものの中は数えません。

## 設定

一文の読点が六つまでなら指摘しません。`strict` にすると四つ、`relaxed` にすると八つまでです。
法務と文学のジャンルでは、既定で止めています。

```yaml chaff-settings
rules:
  max-ten: relaxed
```

見ないことにするなら `max-ten: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax max-ten --why "読み上げる原稿で息継ぎの読点を残すため"
```
