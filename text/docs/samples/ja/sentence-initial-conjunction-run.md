# 接続詞で始まる文が続く（`sentence-initial-conjunction-run`）

**こんな文書に:** 企画書、報告書、ブログの記事。前の文を受けるたびに、文の頭に接続詞を置きがちな文書です。

## 元の文章

```markdown chaff-before
# 会議の資料を紙からタブレットに切り替える提案

総務課の吉田です。来年度から、毎月の役員会で配る資料を、紙の束から一人一台のタブレットに切り替えることを提案します。印刷と差し替えの手間を減らし、古い版の資料が残らないようにするためです。

いまは、毎月の役員会のたびに、一人あたり百枚ほどの資料を印刷しています。
しかし、会議の直前に差し替えが出ると、刷り直しに半日かかります。
そして、刷り直した資料の古い版が、机に残ったままになることもあります。
また、資料を綴じる作業に、毎回二人がかりで二時間ほどかけています。

タブレットなら、差し替えは配信し直すだけで済みます。
```

## 直した文章

```markdown chaff-after
# 会議の資料を紙からタブレットに切り替える提案

総務課の吉田です。来年度から、毎月の役員会で配る資料を、紙の束から一人一台のタブレットに切り替えることを提案します。印刷と差し替えの手間を減らし、古い版の資料が残らないようにするためです。
```

## 直し方

元の段落は「しかし、」「そして、」「また、」と、接続詞で始まる文が三つ続いています。
どの文も前の文の付け足しに見えて、紙の資料の何がいちばん困るのかが見えません。

直した文章では、「しかし」を一つだけ残し、刷り直しの手間と古い版が残ることを一つの文にまとめました。
綴じる作業の話は、「作業にも」と助詞で前の文に繋いでいます。
接続詞を減らすと、提案の根拠が三つではなく、二つのまとまりとして読めます。

「さらに」「加えて」は stock-transition が、「でも」「なので」のような話し言葉の文頭は colloquial-opener が見るので、ここでは数えません。

## 設定

接続詞で始まる文が二つ続くまでなら指摘しません。`strict` にすると二つ続いただけで、`relaxed` にすると五つ続いたら指摘します。
文学のジャンル、`docs` のジャンル（手引き・よくある質問・用語集）、話し言葉の書き起こしでは既定で止めていて、技術文書でも動きません。

```yaml chaff-settings
rules:
  sentence-initial-conjunction-run: relaxed
```

見ないことにするなら `sentence-initial-conjunction-run: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax sentence-initial-conjunction-run --why "論点を接続詞で積み上げる講演の原稿のため"
```
