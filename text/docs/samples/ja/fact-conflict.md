# 同じ項目に違う値が書いてある（`fact-conflict`）

**こんな文書に:** 催しや説明会の案内、手続きのお知らせ、社内の通知。日程や料金を直したときに、一か所だけ直し忘れると、同じ文書の中に二つの値が残ります。

## 元の文章

```markdown chaff-before
# 表計算の関数の勉強会のお知らせ

経理課が、表計算の関数を一から学ぶ勉強会を開きます。

- 日時：12月3日（木）15時から16時30分
- 場所：本社5階の会議室A
- 定員：30人
- 締切：11月20日

社内の掲示板の申し込み画面から申し込んでください。
締切は11月27日です。
定員になったときは、締切の前でも受付を終えます。
```

## 直し方

同じお知らせの中で、締切が「11月20日」と「11月27日」の二通りに書いてあります。
申し込みが少なかったので、締切を一週間延ばしました。そのとき、下の申し込みの段落だけを直し、上の一覧を直し忘れていました。
読む人は、どちらの日まで申し込めるのか分かりません。上の一覧だけを見た人は、もう締め切ったと思って申し込みをやめてしまいます。

chaff は、後から出てきたほうの値の所で知らせます。どちらが正しいかは決めないので、直すほうは書いた人が選びます。
直した文章では、上の一覧の締切も11月27日に直しました。
chaff は、「項目：値」「項目は値です」と書いた所と表の升を読み、同じ節の同じ項目名に、同じ単位で違う値があれば指します。
違う見出しの下の値は、別のものの値として比べません。同じ項目に三通り以上の値があれば、一覧と読んで指摘しません。「3,000円から」のように値の後ろに条件が続くものも比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  fact-conflict: relaxed
```

ファイルどうしの食い違いは `cross-doc-fact-conflict` が見ます。文芸のジャンルでは、はじめから動きません。
