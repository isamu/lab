# 状況も例もなく始まる書き出し（`cold-open`）

**こんな文書に:** ブログ、試してみた記録、社内の事例紹介。AI に書き出しを任せると、短い願いの一文と「それだけのことに見えて」で始まります。

## 元の文章

```markdown chaff-before
# 会議の録音から議事録の下書きを作る

会議の議事録を、録音から自動で作りたいです。
それだけのことに見えて、ここが一番難しいところです。
この「議事録」が、読む人によって違うからです。

私の部署では、週に一度の定例会議の議事録を、若手が交代で書いています。
一時間の会議でも、書き上げるのに一時間半ほどかかります。
そこで、録音を文字に起こす道具を使い、下書きまでを機械に任せてみました。
結果は半分だけ成功です。

文字起こしそのものは、思ったよりよくできていました。
困ったのは、話したことが全部、話した順に並ぶことです。
部長が読みたいのは決まったことと期限で、休んだ人が読みたいのは、なぜそう決まったかでした。

いまは、文字起こしを読みながら、決まったこと、期限、決まった理由の三つの欄に分けて書き直しています。
かかる時間は、三十分ほどに減りました。
一回で一時間の節約です。
```

## 直し方

元の文章は、「議事録を、録音から自動で作りたいです。」という短い願いで始まり、「それだけのことに見えて、ここが一番難しいところです」と難しさを予告しています。
誰がどんな場面で困っているのかは、まだ書かれていません。
読み手は、台本どおりの前振りを読まされてから、ようやく三段落目で本題にたどり着きます。

直した文章では、書き出しを具体的な場面にしました。
若手が交代で書いていること、一時間半かかること、当番の新人が二晩続けて残業したことです。
「この「議事録」が、読む人によって違う」という予告は消し、部長と休んだ人とで読みたいものが違ったという中身のあとに、一文で書いています。

## 設定

書き出しに、状況も例もない形が2つ重なると指摘します。形は三つあり、短い願いで終わる一文（「〜に任せたい。」）、前の文の語を引き直す「この「〜」が」、難しさの予告（「それだけのことに見えて」「一番難しいところ」）です。

```yaml chaff-settings
rules:
  cold-open: relaxed
```

`relaxed` にすると3つ重なったときだけ指摘します。`strict` も `normal` と同じ2つからです。
形が一つだけの書き出し（提案の「〜を導入したい。」）と、書き出しより後ろの文は見ません。
法令・契約（`legal`）、手順書（`docs`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。
