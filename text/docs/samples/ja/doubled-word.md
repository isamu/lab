# 語を二度書いている（`doubled-word`）

**こんな文書に:** 議事録、メモ、急いで書いた報告。会議の最中に打った文は、書き直した語が残りやすい所です。

## 元の文章

```markdown chaff-before
# 店舗運営会議 議事録

日時：11月12日（水）10時から11時
出席：店長、副店長、パートの代表2名

## 決まったこと

- 年末の営業時間を、12月26日から31日まで1時間延ばす。
- 延ばした分のシフトは、副店長が来週までに組む。
- レジの釣り銭の準備は、開店の30分前に二人で確認確認する。

## 次回

12月3日（水）の10時から。年末の売り場の配置をを話し合う。
```

## 直した文章

```markdown chaff-after
# 店舗運営会議 議事録

日時：11月12日（水）10時から11時
出席：店長、副店長、パートの代表2名

## 決まったこと

- 年末の営業時間を、12月26日から31日まで1時間延ばす。
- 延ばした分のシフトは、副店長が来週までに組む。
- レジの釣り銭の準備は、開店の30分前に二人で確認する。

## 次回

12月3日（水）の10時から。年末の売り場の配置を話し合う。
```

## 直し方

「確認確認する」は、打ち直したときに前の語が残った形で、「配置をを」は助詞の打ち間違いです。
議事録は、出られなかった人が後で読んで、決まったことを確かめる文書です。語の重なりに目が止まると、決まった中身まで読み違えていないか不安になります。

直した文章では、余分な「確認」と「を」を一つずつ消しました。
「一人一人」「毎年毎年」のように重ねて「それぞれ」を言う語、「もちもち」のような擬態語、「などなど」のような決まった言い回しは、重ねるのが正しい書き方なので指しません。どれがそうかは品詞解析で読みます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  doubled-word: strict
```
