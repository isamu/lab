# GPA が科目の評価と単位数から出る値と合わない（`gpa-mismatch`）

**こんな文書に:** 成績証明書、成績の通知、奨学金や留学の申請書に付ける成績の一覧。一つの科目の評価だけを直したときや、別の学期の値を写したときに、GPA が合わなくなります。

## 元の文章

```markdown chaff-before
# 成績証明書

学籍番号：E23-0417
学部：経済学部

| 科目 | 単位数 | 評価 |
| --- | --- | --- |
| 簿記論 | 2 | S |
| 経営学概論 | 2 | A |
| マーケティング論 | 2 | A |
| 統計学 | 4 | B |
| 英語I | 1 | S |
| 英語II | 1 | C |

GPA：3.25
```

## 直した文章

```markdown chaff-after
# 成績証明書

学籍番号：E23-0417
学部：経済学部

| 科目 | 単位数 | 評価 |
| --- | --- | --- |
| 簿記論 | 2 | S |
| 経営学概論 | 2 | A |
| マーケティング論 | 2 | A |
| 統計学 | 4 | B |
| 英語I | 1 | S |
| 英語II | 1 | C |

GPA：2.75
```

## 直し方

GPA は、科目ごとの評価の点に単位数を掛けて足し、単位数の和で割った値です。S を4、A を3、B を2、C を1とすると、この表の点の和は33、単位数の和は12なので、GPA は2.75です。
元の文章の「3.25」は、去年の成績証明書の GPA でした。今年の科目と評価で表を作り直したのに、GPA の行だけを去年のまま残していました。
奨学金や留学の審査では、GPA の数だけを見て足切りをすることがあります。高く書いた GPA が後で分かると、申請そのものを取り消されます。

直した文章では、GPA を2.75に直しました。
chaff は、列の見出しの語（科目、単位、評価、成績）で列を決めます。評価の点は、文書に「S（4）、A（3）」のような対応が書いてあればそれを、無ければ秀・優・良・可や S〜D のふつうの尺度を使います。
書いた GPA が、その桁までの四捨五入か切り捨てで届く差なら指摘しません。「前期GPA」のように一部の期間の GPA や、値の違う GPA が二つある文書は比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  gpa-mismatch: strict
```

証明書を出す前に必ず止めたいなら `strict` にします。
評価が尺度に無い科目や、単位数が数でない科目が一つでもあれば比べません。文芸のジャンルでは、はじめから動きません。
