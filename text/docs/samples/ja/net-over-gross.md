# 正味重量が総重量より重い（`net-over-gross`）

**こんな文書に:** 梱包明細書（パッキングリスト）、出荷の明細、輸入の書類。正味重量と総重量を別々に打ち込むときに、桁や数字を一つ取り違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 梱包明細書

送り先：株式会社みなと精機 物流センター

| 箱番号 | 品名 | 数量 | 正味重量 | 総重量 |
| --- | --- | --- | --- | --- |
| No.1 | 軸受けハウジング | 20個 | 96.0kg | 104.0kg |
| No.2 | 軸受けハウジング | 20個 | 96.0kg | 104.0kg |
| No.3 | 取付けボルト一式 | 40袋 | 38.5kg | 36.5kg |
| 合計 | | | 230.5kg | 244.5kg |

箱の重さは、1箱あたり8.0kgです。
```

## 直した文章

```markdown chaff-after
# 梱包明細書

送り先：株式会社みなと精機 物流センター

| 箱番号 | 品名 | 数量 | 正味重量 | 総重量 |
| --- | --- | --- | --- | --- |
| No.1 | 軸受けハウジング | 20個 | 96.0kg | 104.0kg |
| No.2 | 軸受けハウジング | 20個 | 96.0kg | 104.0kg |
| No.3 | 取付けボルト一式 | 40袋 | 28.5kg | 36.5kg |
| 合計 | | | 220.5kg | 244.5kg |

箱の重さは、1箱あたり8.0kgです。
```

## 直し方

3番の箱は、正味重量が38.5kg、総重量が36.5kgで、品物だけの重さが箱を含めた重さより重くなっています。箱の重さは1箱8.0kgなので、正味重量は28.5kgのはずです。「2」を「3」と打ち間違えたのでしょう。
梱包明細書は、運送の会社や税関がそのまま使う書類です。正味が総重量を上回る行があると、書類が差し戻されたり、どちらの数が正しいかの問い合わせで荷の受け取りが遅れたりします。

直した文章では、3番の箱の正味重量を28.5kgにし、合計の行も220.5kgに直しました。合計の行も同じように比べるので、合計だけを直し忘れても指摘されます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  net-over-gross: strict
```

どの列が正味重量で、どの列が総重量かは、列の見出しの語（正味重量、純重量、N.W.、総重量、グロス重量、G.W.）だけで決めます。どちらの升も書いた数である行だけを比べ、g、kg、t は換算して比べます。升が空や「未定」の行、「約」の付いた行、正味重量が総重量と同じか軽い行は言いません。
文学のジャンルでは止めています。数量の比べ方は `delivered-over-ordered` が同じ形で見ます。
