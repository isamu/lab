# 公用文でかなで書く補助動詞・形式名詞（`kana-function-word`）

**こんな文書に:** 役所や自治体のお知らせ、公用文の書き方に合わせる規程や案内。漢字で書いたほうが改まって見えると思いがちな語です。


## 直した文章

```markdown chaff-after
# 粗大ごみの出し方が変わります

令和7年4月から、粗大ごみの申し込みの方法が変わります。

これまでの電話での申し込みに加えて、市のホームページからも申し込めるようになります。
申し込むときは、ごみの種類と大きさを確認してください。
収集の日の朝8時までに、申し込んだ時に伝えた場所へ出しておいてください。

分からないことがあれば、市役所の環境課にお問い合わせください。
```

## 直し方

公用文では、「〜てください」の「ください」、「〜すること」の「こと」、「〜するときは」の「とき」のように、本来の意味から離れて使う語をかなで書きます。
漢字で書くのは本来の意味で使うときだけです（資料を下さい、事が起きる）。
字を使い分けておくと、読み手は、その語が本来の意味なのか、補助の働きなのかを字で見分けられます。

直した文章では、「下さい」を三つとも「ください」に、「事」を「こと」に、「申し込む時は」を「申し込むときは」にしました。
「申し込んだ時に伝えた場所」の「時」は、申し込んだ時点を言うので漢字のままです。chaff もここは指摘していません。

## 設定

この規則は、chaff.yaml の `style` を `koyobun` にしたときだけ動きます。この見本も、上の chaff.yaml で動かしています。

```yaml chaff-settings
style: koyobun
```

当てはまる語が1つあれば指摘します。`relaxed` にすると、3つからです。
「〜て行く」「〜て来る」「〜て見る」「所」「物」は、本来の意味（持って行く、家を建てる所）と見分けられないので見ません。
公用文の決まりに合わせない部分だけゆるめたいときは、`rules` で強さを変えてください。

```yaml chaff-settings
style: koyobun
rules:
  kana-function-word: relaxed
```
