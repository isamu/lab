# 内訳の割合を足しても 100% にならない（`percent-sum-mismatch`）

**こんな文書に:** アンケートの結果、売上の構成比、予算の配分。数字を一つだけ書き写し間違えて、足しても100%にならない、という形がよくあります。

## 元の文章

```markdown chaff-before
# 図書館の利用者アンケートの結果

10月に、図書館を訪れた方にアンケートをお願いし、412人から答えをいただきました。

## 答えた方の年代

答えた方の年代の構成比は次のとおりです。

- 20代まで：18%
- 30代と40代：27%
- 50代と60代：31%
- 70代から：34%

平日の昼は60代から上の方が多く、土曜と日曜は30代と40代の方が多く来ています。
```

## 直した文章

```markdown chaff-after
# 図書館の利用者アンケートの結果

10月に、図書館を訪れた方にアンケートをお願いし、412人から答えをいただきました。

## 答えた方の年代

答えた方の年代の構成比は次のとおりです。

- 20代まで：18%
- 30代と40代：27%
- 50代と60代：31%
- 70代から：24%

平日の昼は60代から上の方が多く、土曜と日曜は30代と40代の方が多く来ています。
```

## 直し方

四つの年代の割合を足すと110%になります。答えた人を年代で分けた構成比なので、足せば100%になるはずです。集計表から写すときに、70代からの「24%」を「34%」と打ち間違えたのでしょう。
このままでは、70代からの方がいちばん多いように読めます。結果を見て、高い年代に向けた催しを増やそうと決める人も出ます。

直した文章では、70代からを24%にしました。どの数字が誤りかは、集計表と照らして確かめます。項目が抜けているなら、「その他」の行を足します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  percent-sum-mismatch: strict
```

表の見出しか、箇条書きや表のすぐ上の文に、全体を分けた割合の語（構成比、内訳、シェア）があるときだけ足します。四捨五入のずれは、項目ごとに最後の桁の半分まで（少なくとも1ポイント）認めます。利用率や伸び率のように全体を分けたのでない割合、複数回答の集計、「+3%」のような増減は足しません。
