# 絵文字の付いた見出しが続く（`emoji-heading`）

**こんな文書に:** ブログ、社内報、お知らせのページ。AI に記事の形を整えさせると、見出しごとに 🚀 や ✅ が付きます。

## 元の文章

```markdown chaff-before
# 昼休みの読書会を半年続けてみた

## 🚀 始めたきっかけ

春に、開発部の四人で、昼休みに技術書を一章ずつ読む会を始めました。
一人で読むと、難しい章で止まってしまうからです。

## 📚 進め方

毎週火曜の昼に集まります。
場所は会議室で、時間は三十分です。
その週の担当が章の要点を五分で話し、残りの時間で分からなかった所を出し合います。
読んでこなかった人も、参加してかまいません。

## 💡 続いた理由

時間を三十分と決めたことが、一番効きました。
長引かないと分かっているので、忙しい週でも顔を出せます。
休んだのは、年度末の一回だけです。

## ✅ これから

今月から、営業部の二人も加わりました。
次は、技術書ではなく、お客さまからの問い合わせの記録を一緒に読む回も作るつもりです。
```

## 直し方

元の文章は、四つの見出しすべてに絵文字を付けています（🚀 📚 💡 ✅）。
どの見出しにも付くと、絵文字は節の中身を何も伝えません。
目次には記号が並び、画面の読み上げでは「ロケット 始めたきっかけ」のように読まれます。

直した文章では、絵文字を外し、見出しを節の中身が分かる言葉にしました。
「続いた理由」は「三十分で切り上げる」に、「これから」は「営業部の二人が加わった」にしています。
目次を読むだけで、記事の筋が分かります。

## 設定

絵文字の付いた見出しが3個あると指摘します。

```yaml chaff-settings
rules:
  emoji-heading: relaxed
```

`relaxed` にすると5個から、`strict` なら2個からです。
矢印（→）や ™ のように、絵文字として描かれない記号は数えません。
一つだけ目印にしたい見出しがあれば、それだけ残してもかまいません。
法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。
```
