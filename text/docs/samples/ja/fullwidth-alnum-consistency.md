# 英数字の全角と半角が混ざっている（`fullwidth-alnum-consistency`）

**こんな文書に:** 社内のお知らせ、案内状、報告書。前の年の文書や表計算の資料から日付を写すと、そこだけ全角の数字が残ることがあります。

```markdown chaff-before
荷物の運び出しは11月14日の金曜日に行い、新しい事務所は11月17日の月曜日から使えます。
机の中の私物は、１１月１３日までに段ボールへ詰めてください。
段ボールは、各課に20箱ずつ配ります。

新しい事務所は5階で、受付は入口の右側にあります。
```

## 直した文章

```markdown chaff-after
# 事務所の引っ越しのお知らせ

総務課からのお知らせです。事務所を、同じ通りの新しいビルへ移します。

荷物の運び出しは11月14日の金曜日に行い、新しい事務所は11月17日の月曜日から使えます。
机の中の私物は、11月13日までに段ボールへ詰めてください。
```

## 直し方

このお知らせの数字は、ほとんどが半角です。私物を詰める期限の「１１月１３日」だけが全角になっています。
読み手には、そこだけ字の幅が違って見えます。それに、全角の「１１」と半角の「11」は、検索では別の文字です。日付で探した人がこの期限を見落とすかもしれません。

chaff は数字の並びを一つずつ数えるので、「１１」と「１３」に一つずつ指摘が出ています。
少ないほうの全角を、半角の「11月13日」に直しました。
chaff は、全角と半角のどちらが正しいかは決めません。英字一字、英字の語、数字一字、数字の並びの組ごとに、少ないほうを指します。
「1桁は全角、2桁以上は半角」と決めている文書は、組の中でそろっているので指しません。

## 設定

少ないほうが組の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  fullwidth-alnum-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
鉤括弧で引いたもの、箇条書きの頭の番号、URL を含む文は数えません。日本語の文書で、どのジャンルでも動きます。
