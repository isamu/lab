# 同じ名前の書き分け（`name-variant`）

**こんな文書に:** 取引先へのメール、見積もりや請求の知らせ、議事録。人の名前の変換をまちがえたり、前のメールから文を写したりすると、同じ人の名前が二通りに書かれます。

## 元の文章

```markdown chaff-before
件名：店舗の内装工事の日程について

株式会社ことり珈琲
店舗開発部 ご担当者さま

いつもお世話になっております。内装を担当する工務店の佐々木です。

来週の現地での打ち合わせには、当社の設計担当の藤原健一が伺います。
図面の細かい点は、藤原健一から当日ご説明します。
工事の日程が決まりましたら、藤原健市から改めて工程表をお送りします。

どうぞよろしくお願いいたします。

佐々木
```

## 直した文章

```markdown chaff-after
件名：店舗の内装工事の日程について

株式会社ことり珈琲
店舗開発部 ご担当者さま

いつもお世話になっております。内装を担当する工務店の佐々木です。

来週の現地での打ち合わせには、当社の設計担当の藤原健一が伺います。
図面の細かい点は、藤原健一から当日ご説明します。
```

## 直し方

このメールは、設計の担当者を「藤原健一」と書いていますが、最後の段だけ「藤原健市」になっています。
受け取った人は、工程表を送ってくるのが同じ人なのか、別の人なのかが分かりません。名前を一字まちがえるのは、相手にも失礼です。

正しい名前を確かめて、「藤原健一」にそろえました。
chaff は、どちらの形が正しいかは決めません。文書の中で少ないほうを指します。本当に別の人なら、そのままでかまいません。

## 設定

```yaml chaff-settings
rules:
  name-variant: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain name-variant --genre business/email

  同じ名前の書き分け   (name-variant)

  人や会社や製品の名前を、ある所では「山田太郎」、別の所では「山田太朗」と書くと、読み手は同じ人か別の人か分かりません。契約書なら当事者の特定が揺らぎます。多いのは打ち間違いと、別の文書から写した段落です。どちらの形が正しいかは決めず、文書の中で少ないほうを指します。

  直しかた: 正しい形を確かめ、一つに揃えてください。本当に別の人や会社なら、そのままで構いません。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax name-variant --why "理由"
```
