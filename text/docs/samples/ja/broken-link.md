# 行き先の無いリンク（`broken-link`）

**こんな文書に:** よくある質問、操作マニュアル、社内の手引き。見出しの言葉を書き換えたときに、その見出しを指すページの中のリンクだけが古いまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# オンラインストア よくある質問

## 届いた商品が注文と違うときは

お手数ですが、届いた日から7日以内にご連絡ください。お取り替えの品をお送りします。違う商品の送り返し方は、[返品の手順](#返品の手順)をご覧ください。

## 返品のしかた

送り状を同じ箱に入れ、着払いでお送りください。送料は当店が負担します。
```

## 直し方

最初の答えには、「[返品の手順](#返品の手順)」というリンクがあります。
ところがこのページには「返品の手順」という見出しはなく、あるのは「返品のしかた」です。
見出しの言葉を書き換えたときに、リンクの行き先だけを直し忘れた形です。
困って質問のページを開いたお客様は、リンクを押しても何も起きず、答えが見つからないと思ってしまいます。

直した文章では、リンクの言葉と行き先を、今の見出し「返品のしかた」に合わせました。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  broken-link: strict
```

見るのは三つです。行き先が空のリンク（[資料]()）、ページに無い見出しを指すリンク、定義の行（「[1]: URL」）の無い参照の形のリンクです。
見出しの名前は字と数字だけで比べ、大文字と小文字や記号の違いは問いません。
「[1][2]」のような文献の番号は指しません。ほかのファイルへのリンクは、`cross-doc-broken-link` が見ます。
どのジャンルでも動きます。
