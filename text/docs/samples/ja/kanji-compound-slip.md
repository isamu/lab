# 長い漢字の語の一字違い（`kanji-compound-slip`）

**こんな文書に:** 自治体のお知らせ、規程、報告書。同じ長い語を何度も書く文書で、一か所だけ変換を取り違えると見落とされます。

## 元の文章

```markdown chaff-before
# 高齢者の暮らしの相談窓口を開きます

みどり市は、12月1日から、市役所の東館1階に地域包括支援センターの相談窓口を開きます。

地域包括支援センターは、介護、健康、暮らしのお金のことを、まとめて相談できる所です。
相談は無料で、予約は要りません。ご家族からの相談も受けます。

窓口に来られない方には、地域包活支援センターの職員がご自宅に伺います。
訪問を望む方は、地域包括支援センター（電話 0120-000-000）までお電話ください。
```

## 直した文章

```markdown chaff-after
# 高齢者の暮らしの相談窓口を開きます

みどり市は、12月1日から、市役所の東館1階に地域包括支援センターの相談窓口を開きます。

地域包括支援センターは、介護、健康、暮らしのお金のことを、まとめて相談できる所です。
```

## 直し方

この文書は「地域包括支援」を三回書いていて、一か所だけ「地域包活支援」になっています。
「括」と「活」は形が似ていて、書き手も読み手も見落とします。窓口の名前で検索して調べる人には、この一か所が見つかりません。

直した文章では、「活」を「括」に直しました。ほかの字は変えていません。

chaff は、文書の中で三回以上書いた四字以上の漢字の語と、同じ長さで一字だけ違う語を比べます。違う字の所で語として読めず（包・活 とばらばらになる）、いつもの形ではそこが一つの語（包括）であるときだけ指します。
「関係会社」と「関連会社」のようにどちらも普通の語のときや、「第一条」と「第二条」のように数や順の字が違うときは指しません。

## 設定

`strict` でも `normal` でも「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  kanji-compound-slip: relaxed
```

いつもの形が三回より少ないときや、違う形も三回以上書いているときは、書き分けと読んで指しません。
