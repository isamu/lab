# かなで書く副詞を漢字で書いている（`hiragana-fukushi`）

**こんな文書に:** ブログの記事、社内報、お知らせ。変換の候補をそのまま選んで、かなで書くのが普通の副詞が漢字になりがちな文章です。

## 元の文章

```markdown chaff-before
# 子どもと行く日帰りのいちご狩り

先週の日曜、子ども二人を連れて、隣の町の農園へいちご狩りに行ってきました。

予約の時間に着くと、既にハウスの前には列ができていました。
勿論、いちごは食べ放題です。下の子は最初の十分で殆ど満腹になり、あとはハウスの中を走り回っていました。
帰りの車では、二人とも直ぐに眠ってしまいました。
```

## 直した文章

```markdown chaff-after
# 子どもと行く日帰りのいちご狩り

先週の日曜、子ども二人を連れて、隣の町の農園へいちご狩りに行ってきました。

予約の時間に着くと、すでにハウスの前には列ができていました。
もちろん、いちごは食べ放題です。下の子は最初の十分でほとんど満腹になり、あとはハウスの中を走り回っていました。
帰りの車では、二人ともすぐに眠ってしまいました。
```

## 直し方

「勿論」「殆ど」「直ぐ」は、常用漢字の表に無い字や、公用文でかなで書くと決まっている副詞です。
読める人には何でもありませんが、読めない人は、そこで止まります。かなで書いても意味は変わりません。

直した文章では、「もちろん」「ほとんど」「すぐに」とかなに開きました。
「既に」も「すでに」と開いていますが、これは chaff の指摘ではなく、文章の調子をそろえるためです。
chaff が見るのは一覧にある語だけで、「既に」のように漢字でも公用文で認められている語は指しません。

## 設定

当てはまる語が一つあれば指摘します。`relaxed` にすると、三つ目から指摘します。
文学のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  hiragana-fukushi: relaxed
```

見ないことにするなら `hiragana-fukushi: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax hiragana-fukushi --why "漢字で書く決まりの社内用語集に合わせるため"
```
