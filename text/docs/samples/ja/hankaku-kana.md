# 半角の片仮名がある（`hankaku-kana`）

**こんな文書に:** 操作の手引き、社内の手順書、古いシステムから写した案内。画面の表示や古い資料を貼り付けると、半角の片仮名が残ります。

```markdown chaff-before
1. 社内のパソコンで勤怠システムを開き、社員番号とﾊﾟｽﾜｰﾄﾞでログインします。
2. 出勤したら、画面の左上の「出勤」を押します。
3. 退勤するときは「退勤」を押し、その日の作業の区分を選びます。

## 打刻を忘れたとき

打刻を忘れた日は、ﾒﾆｭｰの「申請」から直してください。上長が承認すると、記録が直ります。
```

## 直し方

「ﾊﾟｽﾜｰﾄﾞ」「ﾒﾆｭｰ」は半角の片仮名です。
同じ語でも、全角の「パスワード」で手引きを検索した人には見つかりません。読み上げのソフトで正しく読まれないこともあり、字の幅もほかの行とそろいません。

直した文章では、二つとも全角の片仮名に直しました。
画面のボタンの名前のように、システムの表示をそのまま見せたいときは、鉤括弧で囲めば数えません。コードとリンクの中も数えません。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  hankaku-kana: strict
```

半角の句読点・鉤括弧・中黒（｡｢｣､･）も、同じように指します。
