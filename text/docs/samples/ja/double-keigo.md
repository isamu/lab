# 二重敬語（`double-keigo`）

**こんな文書に:** 社内の報告、議事の要約、お客さまへの案内。目上の人の言ったことを伝えるとき、丁寧にしようとして敬語を重ねやすい所です。

## 元の文章

```markdown chaff-before
# 新しい勤怠システムの説明会の報告

総務課の佐藤です。11月20日に開いた、新しい勤怠システムの説明会について報告します。

説明会には、各部から32人が参加しました。
はじめに、山田部長が、紙の出勤簿を12月で終えるとおっしゃられました。
そのあと、システム会社の担当者が、スマートフォンから打刻する手順を画面で見せてくださいました。

当日の資料は、社内のポータルからご覧になられます。
```

## 直した文章

```markdown chaff-after
# 新しい勤怠システムの説明会の報告

総務課の佐藤です。11月20日に開いた、新しい勤怠システムの説明会について報告します。

説明会には、各部から32人が参加しました。
はじめに、山田部長が、紙の出勤簿を12月で終えるとおっしゃいました。
そのあと、システム会社の担当者が、スマートフォンから打刻する手順を画面で見せてくださいました。

当日の資料は、社内のポータルからご覧になれます。
```

## 直し方

「おっしゃる」は、それだけで「言う」の尊敬語です。そこに尊敬の「れる」を足した「おっしゃられる」は、敬語が二重になっています。
「ご覧になられる」も、「ご覧になる」に「れる」を重ねた形です。
丁寧さは増えず、敬語に慣れた読み手には、かえって不自然に読まれます。

直した文章では、「おっしゃいました」と「ご覧になれます」にしました。
資料の文は、読む人が見られることを言いたいので、尊敬の形ではなく、できることを言う「ご覧になれます」です。

## 設定

一覧にある形が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  double-keigo: relaxed
```

見るのは一覧にある形だけです。一覧に無い形は、二重敬語でも指摘しません。
説明書（`docs`）、論文（`academic`）、文学（`literature`）、話し言葉の書き起こし（`speech/transcript`）では動きません。
