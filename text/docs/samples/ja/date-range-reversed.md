# 期間の終わりが始まりより前（`date-range-reversed`）

**こんな文書に:** 休業や工事のお知らせ、申込の期間、契約の期間。年をまたぐ期間で、終わりの年を始まりと同じに書いてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：年末年始の休業のお知らせ

お取引先のみなさま

いつもお世話になっております。株式会社まるや食品の営業部です。

弊社は、2026年12月29日〜2026年1月4日を年末年始の休業とさせていただきます。
休業の間にいただいたご注文は、2027年1月5日（火）から順に発送します。

ご不便をおかけしますが、よろしくお願いいたします。
```

```markdown chaff-after
件名：年末年始の休業のお知らせ
```

## 直し方

休業の期間は、12月29日に始まって年明けの1月4日に終わります。ところが終わりの年も「2026年」と書いたので、期間の終わりが始まりより一年近く前になっています。年をまたぐ期間で、始まりの年を写したのでしょう。
人が読めば年末年始の休みだと察しますが、この文面を取引先の予定表や受注の仕組みに写すと、日付どおりに扱われます。読む人が察してくれることに頼るより、正しい年を書くほうが確かです。

直した文章では、終わりを「2027年1月4日」にしました。次の行の発送を始める日は、もとから「2027年1月5日（火）」と書いてあります。同じメールの中で、二つの日付の年が食い違っていたわけです。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  date-range-reversed: strict
```

二つの日付の間が「〜」のような範囲の記号だけのときと、「から」でつなぎ終わりの日付のあとに「まで」が続くときを、期間として比べます。年の無い期間（12月28日〜1月4日）は年をまたぐかもしれないので比べません。年を片方にだけ書いた期間は同じ年と読み、逆になるときは、曜日がその年に合うときか、年をまたぐと一年近くになるときだけ指摘します。
文学のジャンルでは止めています。時刻の範囲は `time-range-reversed` が見ます。
