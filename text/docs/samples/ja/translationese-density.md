# 翻訳調が多い（`translationese-density`）

**こんな文書に:** 提案書、報告書、製品の説明。英語の資料を下敷きにした文章や、AI に下書きさせた文章で、英語の構文がそのまま残ります。

## 元の文章

```markdown chaff-before
# 来客の受付を端末に切り替える件

## いまの受付

本社の一階では、来客の受付を総務課の二人が交代で受け持っています。
来客は一日に平均三十人ほどで、そのたびに名前と訪問先を紙の名簿に書いてもらい、内線で担当者を呼んでいます。
昼の時間と、会議が重なる午後二時ごろには、受付の前に列ができることがあります。

## 切り替えの案

受付に端末を一台置き、来客が自分で訪問先を選べるようにします。
新しい端末は、来客が到着したことを担当者の携帯に直接知らせることを可能にします。
紙の名簿は無くなり、入館の記録は端末に残ります。

端末は、事前に登録した来客にQRコードを送れるという利点を持ちます。
登録した来客は、コードを読ませるだけで受付が済みます。
登録していない来客も、画面で会社名と名前を打てば受付できます。

## 総務課の仕事

総務課は、端末の画面を見て、困っている来客に声をかける役に変わります。
受付の二人は、引き続き来客の案内において重要な役割を果たします。
入館の記録は三か月で自動的に消えるように設定されることができる点に注意してください。
記録を長く残したい部署は、総務課に申し出てください。

## 費用と日程

端末の費用は、一年あたり二十四万円です。
来月の部長会で決まれば、六月から試しに使い始め、九月に本格的に切り替えます。
```

## 直し方

元の文章は、「知らせることを可能にします」「という利点を持ちます」「重要な役割を果たします」「設定されることができる」と、英語の構文を写した言い回しが続きます。
一つなら読めますが、重なると提案書全体が翻訳の文のように読め、読み手は頭の中で英語に戻して意味を取ることになります。

直した文章では、日本語として素直な言い方にしました。
「端末は〜を可能にします」のように道具を主語にせず、「来客が着いたことは、担当者の携帯に直接届きます」と、起きることを主語にしています。
「重要な役割を果たします」は、受付の二人が実際に何をするのか（会議室まで案内する）に置き換えました。

## 設定

翻訳調の言い回しが、1000字あたり1個を超えると指摘します。短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  translationese-density: relaxed
```

`relaxed` にすると1000字あたり2個まで、`strict` なら一つでも指摘します。
人の書いた技術記事でもふつうに使う言い回し（〜を提供する、〜することができる）は数えません。
読み手への呼びかけ（あなたは）だけの文書も、語りかける書き方を選んだものとして指摘しません。
文学（`literature`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score proposal.md` で見られます。
