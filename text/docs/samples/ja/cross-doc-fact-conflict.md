# ファイルによって違う値が書いてある項目（`cross-doc-fact-conflict`）

**こんな文書に:** 何ページにも分かれた説明書、ヘルプのサイト、料金や窓口を何か所にも書く社内の手引き。値を変えたときに一つのページだけ直し忘れると、ページによって値が食い違います。

## 元の文章

```markdown chaff-before
# 料金のプラン

家族みんなの写真を、一つの場所に置いておけるプランです。

- 月額料金：1,500円
- 保存できる量：200GB
- 使える人数：5人まで

申し込んだ月は、料金がかかりません。
```

```markdown chaff-file faq.md
# よくある質問

## 料金はいくらですか

月額料金：1,200円

申し込んだ月は、料金がかかりません。

## 解約はいつでもできますか

はい。設定の画面から、いつでも解約できます。
```

```markdown chaff-file signup.md
# 申し込みの手順

1. アプリを開き、「プランを選ぶ」を押します。
2. 支払いに使うカードを登録します。
3. 「申し込む」を押します。

月額料金：1,200円

申し込みが終わると、確認のメールが届きます。
```

## 直した文章

```markdown chaff-after
# 料金のプラン

家族みんなの写真を、一つの場所に置いておけるプランです。

- 月額料金：1,200円
- 保存できる量：200GB
- 使える人数：5人まで

申し込んだ月は、料金がかかりません。
```

## 直し方

このヘルプは三つのページに分かれています。「よくある質問」と「申し込みの手順」は月額料金を1,200円と書き、「料金のプラン」のページだけが1,500円と書いています。
春に値下げをしたとき、「料金のプラン」のページを直し忘れていました。一つのページの中では値がそろっているので、ページを一枚ずつ読み直しても気づきません。
読む人は、どちらの料金を払うのか分かりません。高いほうを見て申し込みをやめる人も、安いほうを見て申し込んで請求に驚く人も出ます。

少ないほうのページを、ほかの二つと同じ1,200円に直しました。
chaff は、一度に渡したファイルどうしで「項目：値」と書いた所と表の升を読み、同じ項目に同じ単位で違う値を書いたファイルを指します。どちらが正しいかは決めず、その値を書いたファイルの少ないほうを指します。
ヘルプの束をまとめて `npx chaffjs docs/` のように渡すと、この食い違いが見つかります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  cross-doc-fact-conflict: relaxed
```

一つのファイルの中で同じ項目に二つ以上の値を書いたファイルは数えません（プランごとの料金の一覧かもしれず、ファイルの中の食い違いは `fact-conflict` が見ます）。
ファイルどうしで値が三通り以上に分かれる項目と、「1,200円から」のように値の後ろに条件が続くものも比べません。
