# 太字の一行を見出しの代わりにしている（`pseudo-heading`）

**こんな文書に:** 社内の手引き、操作マニュアル、チャットや生成 AI の答えを貼り付けた文書。見出しで節を分けた中に、太字の一行だけの「見出し」が混ざる形がよくあります。

## 元の文章

```markdown chaff-before
# 経費精算の手引き

## 申請のしかた

精算システムに領収書の写真を載せ、金額と用途を入れて申請します。

**出張の経費**

交通費と宿泊費は、出張の申請番号を添えて申請します。

## 承認

上長が申請を確かめ、承認すると経理に回ります。
```

## 直した文章

```markdown chaff-after
# 経費精算の手引き

## 申請のしかた

精算システムに領収書の写真を載せ、金額と用途を入れて申請します。

### 出張の経費

交通費と宿泊費は、出張の申請番号を添えて申請します。

## 承認

上長が申請を確かめ、承認すると経理に回ります。
```

## 直し方

この手引きは、節を `##` の見出しで分けています。その中で「出張の経費」だけが、太字の一行で書かれています。
画面では小見出しのように見えますが、Markdown にとってはただの段落です。目次にも画面の読み上げにも載らず、この節へのリンクも張れません。

直した文章では、「出張の経費」を、上の見出しより一段深い `###` の見出しにしました。
見出しにするほどの区切りでなければ、太字を外して本文の一文にします。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  pseudo-heading: strict
```

見出しが一つも無い文書や、題の他に見出しが無い文書は見ません。太字の行で節を分けるのが、その文書の書き方だからです。
句読点やコロンで終わる太字（「**参考:**」）、太字の後ろに同じ段落で文が続くもの、すぐ後ろが見出しで本文の無い太字の行も指しません。

```text chaff-explain
$ npx chaffjs explain pseudo-heading --genre docs/manual

  太字の一行を見出しの代わりにしている   (pseudo-heading)

  見出しで節を分けている文書の中で、「**次の手順**」のような太字の一行を見出しの代わりに置く形です。画面では見出しのように見えても、Markdown にとってはただの段落なので、目次にも画面読み上げにも載らず、見出しへのリンクも張れません。必要な節や目次との食い違いを確かめる検査も、この節を見ません。生成文やチャットから貼った文書によく見られます（markdownlint の MD036）。

  直しかた: 見出しにしてください（「**次の手順**」を、前の見出しより一段深い「### 次の手順」に）。見出しにするほどの区切りでなければ、太字を外して本文の一文にします。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax pseudo-heading --why "理由"
```
