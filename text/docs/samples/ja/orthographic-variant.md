# 同じ語の書き方がゆれている（`orthographic-variant`）

**こんな文書に:** 社内の案内、手続きの説明、報告書。何人かで書き足したり、前の年の文書から段落を写したりすると、「できる」と「出来る」のように同じ語が二通りに書かれます。

## 元の文章

```markdown chaff-before
# 引っ越しをしたときの届け出

住所が変わったときは、2週間以内に人事課へ届け出てください。
届け出は、社内の申請画面からできます。

紙の届出書は、人事課の窓口に置いてあります。郵送で出すこともできます。

通勤の経路が変わる人は、定期券の代金も同じ画面で申請します。
家族の住所も変わったときは、扶養の届け出も一緒に出来ます。
申請した内容は、あとから画面で確かめることができます。

分からないときは、人事課の窓口に聞いてください。
```

## 直し方

この案内では「できます」とかなで書いた所が多く、扶養の届け出の一文だけが「出来ます」と漢字で書かれています。
読み手には、そこだけ別の人が書いたように見えます。社内の検索で「できます」と探すと、この一文だけが出てきません。

少ないほうを、ほかと同じ「できます」に直しました。
chaff は語の一覧を持たず、文書の中の語を読みで束ねて、少ないほうを指します。どちらの書き方が正しいかは決めません。
「書く」と「描く」のように、漢字の違う同じ読みの語は別の語と見ます。

## 設定

少ないほうが、その語の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
prefer:
  出来る: できる
rules:
  orthographic-variant: relaxed
```

チームで書き方を決めているなら、`prefer` に「使わない書き方: 使う書き方」の組を書きます。そのあとは `preferred-term` が、決めた向きで見ます。
`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
文芸のジャンルでは、はじめから動きません。
