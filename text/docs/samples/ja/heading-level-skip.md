# 見出しの深さが飛んでいる（`heading-level-skip`）

**こんな文書に:** 操作マニュアル、社内の手引き、仕様書。小見出しの文字を小さくしたくて、見出しの深さを一段飛ばして選ぶ形がよくあります。

## 元の文章

```markdown chaff-before
# 会議室予約システムの使い方

## 予約のしかた

画面の左上の「新しい予約」を押し、日時と会議室を選びます。参加者の名前を入れると、予約の知らせが届きます。

#### 注意

一度に予約できるのは、2時間までです。

## 予約の取り消し

予約の一覧から取り消したい予約を選び、「取り消す」を押します。
```

```markdown chaff-after
# 会議室予約システムの使い方

## 予約のしかた

画面の左上の「新しい予約」を押し、日時と会議室を選びます。参加者の名前を入れると、予約の知らせが届きます。
```

## 直し方

「予約のしかた」は二段目の見出し（`##`）です。その下の「注意」は、一段深い三段目（`###`）にするはずの所を、四段目（`####`）にしています。
画面では、小さな見出しとして表示されるので、気づきにくいまちがいです。
けれども目次や画面の読み上げは、見出しの深さで文書の組み立てを伝えます。三段目が抜けていると、どこかの節が消えたように読めます。

直した文章では、「注意」を一段だけ深い `###` にしました。
文字の大きさを変えたいだけなら、見出しの深さではなく、表示の設定で変えます。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  heading-level-skip: strict
```

最初の見出しは何段から始めてもかまいません。一つ前の見出しより二段以上深いときだけ指摘します。
浅くなる見出し（`####` の次の `##`）は指しません。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain heading-level-skip --genre docs/manual

  見出しの深さが飛んでいる   (heading-level-skip)

  「##」の次に「####」が来ると、間の一段が抜けます。目次や画面読み上げは見出しの深さで文書の形を伝えるので、抜けた段は「どこかの節が消えた」ように読めます。見た目の大きさのために深さを選ぶと起きます。最初の見出しは何段から始めてもよく、一つ前の見出しより二段以上深いときだけ指摘します（markdownlint の MD001 と同じ数え方）。

  直しかた: 一つ前の見出しより一段だけ深くしてください。文字の大きさを変えたいだけなら、深さではなく表示の設定で変えてください。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax heading-level-skip --why "理由"
```
