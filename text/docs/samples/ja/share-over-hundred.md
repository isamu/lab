# 100% を超える一部の割合（`share-over-hundred`）

**こんな文書に:** アンケートの報告、利用者の調査、社員の満足度の集計。小数点を一つ落として、12.5% を 125% と書いてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 働き方アンケートの結果

10月に、全社員を対象に働き方のアンケートを行いました。回答者は412名でした。

在宅勤務を「週1日以上したい」と答えたのは、回答者の68.4%でした。
そのうち「週3日以上したい」と答えたのは、回答者の125%にとどまりました。
いちばん多かった理由は、通勤の時間を減らしたいことです。

来年度の制度の見直しでは、この結果をもとに、週1日から2日の在宅勤務を軸に検討します。
```

## 直した文章

そのうち「週3日以上したい」と答えたのは、回答者の12.5%にとどまりました。

## 直し方

「週3日以上したい」と答えたのは「回答者の125%」と書いてあります。回答者の一部が回答者の数を超えることはありません。前の文で、週1日以上と答えたのが68.4%なので、その中の週3日以上は12.5%だったのでしょう。小数点を落としています。
読む人は、125%を見て誤植だと気づいても、正しい数が12.5%なのか25%なのかを決められません。来年度の制度を決める材料の報告で、肝心の数が読めなくなります。

直した文章では、「回答者の12.5%」にしました。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  share-over-hundred: relaxed
```

語彙表にある集まり（回答者、社員、利用者、会員、参加者など）の一部と書いた百分率だけを見ます。「前年の120%」「予算の110%」のような伸びや比べる元、集まりを書いていない百分率（120%の達成率）は言いません。どのジャンルでも動きます。
