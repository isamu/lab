# 一文に逆接の「が」が二度（`adversative-ga-repeat`）

**こんな文書に:** 社内のお知らせ、取引先へのメール、報告書。事情を順に書き足していくうちに、一文が長くなりがちな文書です。

## 元の文章

```markdown chaff-before
# 来週の定例会議の時刻について

営業企画課のみなさま

お疲れさまです。総務課の山本です。
来週火曜の定例会議の時刻についてお知らせします。

いつもの3階の会議室を予約していましたが、当日の午前は空調の工事が入ることになりましたが、午後からなら使えるそうです。
そこで、開始の時刻を10時から14時に移します。

資料は前日までに共有フォルダへ置いてください。

よろしくお願いします。

総務課 山本
```

## 直した文章

```markdown chaff-after
# 来週の定例会議の時刻について

営業企画課のみなさま

お疲れさまです。総務課の山本です。
来週火曜の定例会議の時刻についてお知らせします。

いつもの3階の会議室を予約していました。
ところが、当日の午前は空調の工事が入ることになりました。午後からなら使えるそうです。
そこで、開始の時刻を10時から14時に移します。

資料は前日までに共有フォルダへ置いてください。

よろしくお願いします。

総務課 山本
```

## 直し方

元の文は「予約していましたが」「入ることになりましたが」と、逆接の「が」で二度ひっくり返ります。
読み手は、一つ目の「が」で「予約できなかったのか」と受け取り、二つ目の「が」で「やはり使えるのか」と向きを変えさせられます。
最後まで読まないと、会議室が使えるのか使えないのかが分かりません。

直した文章では、一つ目の「が」の所で文を切り、次の文を「ところが」で始めました。
「予約していた」「工事が入った」「午後なら使える」と、事情が一つずつ一文に収まり、次の「そこで、時刻を移します」につながります。

chaff が数えるのは、文をつなぐ逆接の「が」だけです。「工事が入る」のような主語を示す「が」は数えません。

## 設定

一文に逆接の「が」が二つ以上あると指摘します。強さを `strict` にしても上限は一つのままで、`relaxed` にすると二つまで認めます。

```yaml chaff-settings
rules:
  adversative-ga-repeat: relaxed
```

見ないことにするなら `adversative-ga-repeat: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax adversative-ga-repeat --why "話し言葉に近い文体の社内報のため"
```
