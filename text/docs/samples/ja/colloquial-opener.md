# 文頭の話し言葉の接続詞（`colloquial-opener`）

**こんな文書に:** 社内の報告書、お知らせ、手順書。チャットで話すように書き始めると、文の頭に話し言葉のつなぎが入りやすい文書です。

## 元の文章

```markdown chaff-before
# 11月の出荷についての報告

物流課の石井です。11月の出荷の状況をまとめました。

月の半ばに、梱包に使う段ボール箱の入荷が一週間遅れました。なので、20日までの注文のうち30件は、出荷が2日ずつ遅れています。
遅れたお客さまには、営業課から一件ずつ電話で連絡しました。

12月からは、段ボール箱をもう一つの取引先からも仕入れます。でも、価格は一箱あたり5円ほど上がります。
```

## 直した文章

```markdown chaff-after
# 11月の出荷についての報告

物流課の石井です。11月の出荷の状況をまとめました。

月の半ばに、梱包に使う段ボール箱の入荷が一週間遅れました。そのため、20日までの注文のうち30件は、出荷が2日ずつ遅れています。
遅れたお客さまには、営業課から一件ずつ電話で連絡しました。

12月からは、段ボール箱をもう一つの取引先からも仕入れます。ただし、価格は一箱あたり5円ほど上がります。
```

## 直し方

「なので」「でも」で文を始めるのは、話すときの言い方です。
報告書のほかの文は丁寧な書き言葉なのに、この二か所だけ口調が砕けて聞こえます。
出荷の遅れと値上がりという、読み手が気にする二つの知らせが、どちらも軽い調子で書かれてしまっています。

直した文章では、書き言葉の接続詞に替えました。
「なので」は理由を受けるので「そのため」に、「でも」は前の文の良い知らせに条件を付け足すので「ただし」にしています。
前の文とのつながりが、語でも分かるようになります。

## 設定

話し言葉の接続詞で始まる文が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  colloquial-opener: relaxed
```

文の途中の「〜なので」は普通の書き方なので指摘しません。
文書全体を砕けた口調で書いているとき（問いの見出しや「！」で終わる文が多いとき）も、その口調に合うので指摘しません。
ブログ、文学（`literature`）、話し言葉（`speech`）のジャンルでは、はじめから動きません。
