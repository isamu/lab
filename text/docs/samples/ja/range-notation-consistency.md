# 範囲の記号が混ざっている（`range-notation-consistency`）

**こんな文書に:** 教室や催しの案内、料金や営業時間の知らせ、募集の要項。表計算の資料から一行写すと、そこだけ「〜」が「-」になることがあります。

## 元の文章

```markdown chaff-before
# 冬のそば打ち教室の生徒を募集します

公民館の調理室で、冬のそば打ち教室を開きます。

一回の定員は8〜12名で、時間は2〜3時間ほどです。
材料費は、打ったそばの量によって1,500〜2,000円かかります。
対象は、10-15歳のお子さんと、その保護者の方です。

打ったそばは、その場で食べることも、持ち帰ることもできます。
```

## 直した文章

```markdown chaff-after
# 冬のそば打ち教室の生徒を募集します

公民館の調理室で、冬のそば打ち教室を開きます。

一回の定員は8〜12名で、時間は2〜3時間ほどです。
材料費は、打ったそばの量によって1,500〜2,000円かかります。
対象は、10〜15歳のお子さんと、その保護者の方です。

打ったそばは、その場で食べることも、持ち帰ることもできます。
```

## 直し方

この案内の範囲は、「8〜12名」「2〜3時間」のように「〜」で書かれています。対象の年齢だけが「10-15歳」とハイフンです。
ハイフンは引き算や番号にも使うので、読み手は「10の15歳」のような番号なのか、範囲なのかと一瞬迷います。年齢は申し込めるかどうかを決める所なので、ほかと同じ書き方で読めるほうが安心です。

少ないほうを、ほかと同じ「10〜15歳」に直しました。
chaff は、どの記号が正しいかは決めません。文書の中で少ないほうを指します。

## 設定

少ないほうの記号が、範囲の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  range-notation-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain range-notation-consistency --genre blog/owned-media

  範囲の記号が混ざっている   (range-notation-consistency)

  数の範囲を「10〜20」と「10-20」、「10–20」と「10-20」のように二通りの記号で書くと、読み手は記号の違いに意味があるのか（ハイフンは引き算や番号か）と迷います。資料を寄せ集めたときや、入力のしかたが人によって違うときに起きます。どの記号が正しいかは決めず、文書の中で少ないほうを指します。

  直しかた: 文書の多いほうの記号に合わせてください。チームで決めているなら、STYLE.md に書いておくと迷いません。

  設定できる値:
    strict   少ないほうの記号が、範囲の 49% 以下のとき指摘
  → normal   少ないほうの記号が、範囲の 34% 以下のとき指摘
    relaxed  少ないほうの記号が、範囲の 20% 以下のとき指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax range-notation-consistency --why "理由"
```
