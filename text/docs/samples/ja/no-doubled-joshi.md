# 同じ助詞が続いている（`no-doubled-joshi`）

**こんな文書に:** 企画書、報告書、社内の提案。名詞を「の」でつないでいくうちに、何が何に係るのか分からなくなりがちな文書です。

## 元の文章

```markdown chaff-before
# 店舗の受け取り窓口を広げる提案

通販課の中村です。

来年の春から、当社の通販の商品の受け取りの窓口を、駅前の三店にも広げることを提案します。
いまは本店でしか受け取れず、遠くに住むお客さまからは、送料がかかるという声が多く届いています。
受け取りの窓口が増えれば、送料を払わずに済むお客さまが増えます。
```

## 直した文章

```markdown chaff-after
# 店舗の受け取り窓口を広げる提案

通販課の中村です。

来年の春から、通販で買った商品を受け取れる窓口を、駅前の三店にも広げることを提案します。
いまは本店でしか受け取れず、遠くに住むお客さまからは、送料がかかるという声が多く届いています。
受け取りの窓口が増えれば、送料を払わずに済むお客さまが増えます。
```

## 直し方

元の文の「当社の通販の商品の受け取りの窓口」は、「の」が読点を挟まずに4回続いています。
読み手は、「当社の」が「通販」に係るのか「窓口」に係るのかを、頭の中で組み立て直すことになります。
何を広げる提案なのかが、一度で読めません。

直した文章では、「通販で買った商品を受け取れる窓口」と、「の」のいくつかを動詞と助詞に言い換えました。
「当社の」は、提案書の中では言わなくても分かるので外しています。

読点で区切った並び、鉤括弧で引いた題名、法律の題名のように書き手が言い換えられない名前は数えません。

## 設定

同じ助詞が二回続くまでなら指摘しません。`strict` にすると二回続いただけで、`relaxed` にすると四回続いたら指摘します。
法務・文学のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  no-doubled-joshi: relaxed
```

見ないことにするなら `no-doubled-joshi: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax no-doubled-joshi --why "部署の正式な名前に「の」が重なるため"
```
