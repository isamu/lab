# 二通りに書いた画面の札（`ui-label-variant`）

**こんな文書に:** 操作の手引き、ヘルプのページ、社内システムの使い方。画面の文言が変わったあとに手引きの一部だけを直すと、同じボタンが二通りの名前で書かれます。

## 元の文章

```markdown chaff-before
# 経費を申請する

## 申請する

1. 経費の画面で、［新しい申請を作成］を押します。
2. 日付と金額を入れ、領収書の写真を付けます。
3. ［申請を送信］を押すと、上司に届きます。

## 差し戻されたとき

上司から差し戻されたときは、知らせの画面から申請を開きます。
直したい所を書き直して、もう一度［申請送信］を押します。
```

## 直した文章

```markdown chaff-after
# 経費を申請する

## 申請する

1. 経費の画面で、［新しい申請を作成］を押します。
2. 日付と金額を入れ、領収書の写真を付けます。
3. ［申請を送信］を押すと、上司に届きます。

## 差し戻されたとき

上司から差し戻されたときは、知らせの画面から申請を開きます。
直したい所を書き直して、もう一度［申請を送信］を押します。
```

## 直し方

この手引きは、送るボタンを、申請の段では［申請を送信］、差し戻しの段では［申請送信］と書いています。
読み手は、画面に二つのボタンがあるのかと探します。差し戻されて急いで直している人ほど、ボタンが見つからずに手が止まります。

画面の文字を確かめて、［申請を送信］にそろえました。
chaff は、太字か［］で囲んだ札のうち、空白や「を」「の」だけが違う二つを同じ札と見て、少ないほうを指します。どちらが画面の文字かは決めないので、直す前に画面で確かめてください。

## 設定

```yaml chaff-settings
rules:
  ui-label-variant: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
法務と論文、文芸、講演のジャンルでは、はじめから動きません。
