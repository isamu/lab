# ほかのファイルへの行き先の無いリンク（`cross-doc-broken-link`）

**こんな文書に:** いくつものページに分けた操作マニュアル、社内の手引きの束、説明書のサイト。行き先のページの見出しを書き換えたときに、ほかのページからのリンクだけが古いまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# はじめての方へ

社内の勤怠システムを初めて使う方は、このページから読み始めてください。

最初に、[パスワードの決め方](./account.md#パスワードの決め方)を読んで、自分のパスワードを決めます。
```

```markdown chaff-file account.md
# アカウントの設定

## パスワードを設定する

パスワードは、英字と数字を混ぜて12字以上にします。誕生日や電話番号は使わないでください。
```

## 直した文章

```markdown chaff-after
# はじめての方へ

社内の勤怠システムを初めて使う方は、このページから読み始めてください。
```

## 直し方

「はじめての方へ」のページは、`account.md` の「パスワードの決め方」という見出しへリンクしています。
ところが `account.md` の見出しは、いまは「パスワードを設定する」に書き換わっています。
リンクを押すと、ページは開いても、パスワードの説明の所へは飛びません。初めて使う人は、ページの頭で何を読めばよいのか分からず止まります。
一つのページだけを見ても、ほかのページの見出しが変わったことには気づけません。

直した文章では、リンクの行き先を今の見出し「パスワードを設定する」に合わせ、リンクの言葉も「パスワードの設定」に揃えました。
この見本では、`start.md` と `account.md` の二つのファイルを一度に chaff に渡しています。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  cross-doc-broken-link: strict
```

ファイルを二つ以上か、フォルダを渡したときだけ動きます。一度に渡したファイルどうしを突き合わせ、行き先のファイルが無いリンクと、行き先のファイルに無い見出しを指すリンクを指します。
URL、サイトの根からのパス（/guide/）、画像のような Markdown でないファイルへのリンクは見ません。同じページの中へのリンクは、`broken-link` が見ます。
どのジャンルでも動きます。

```text chaff-explain
$ npx chaffjs explain cross-doc-broken-link --genre docs/manual

  ほかのファイルへの行き先の無いリンク   (cross-doc-broken-link)

  説明書や文書の束では、ページどうしを相対パスのリンクでつなぎます（[料金](./pricing.md#月額料金)）。ファイルの名前を変えたり見出しを書き換えたりすると、ほかのページからのリンクが行き先を失います。一つのファイルだけを見ても、行き先のファイルや見出しがあるかは分かりません。一度に渡したファイルどうしを突き合わせ、行き先のファイルが無いリンクと、行き先のファイルに無い見出しを指すリンクを指します。見出しの名前は字と数字だけで比べます。

  直しかた: 行き先のファイルの今の名前と、今の見出しの言葉に合わせてください。ファイルや見出しを消したなら、リンクも消すか、代わりのページを指してください。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   エラー
  → normal   注意
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax cross-doc-broken-link --why "理由"
```
