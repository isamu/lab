# 漢字が続きすぎている（`max-kanji-continuous`）

**こんな文書に:** 社内の報告書、お知らせ、議事録、提案書。会議や施策の名前を、漢字のまま詰めて書きがちな文書です。

## 元の文章

```markdown chaff-before
# 10月の営業報告

営業二課の田中です。10月の結果をまとめました。

今月は新規顧客獲得施策検討会議を2回開き、展示会で受け取った名刺に連絡する順番を決めました。
商談は先月の12件から18件に増えています。

来月は既存顧客満足度調査結果報告会を開き、解約したお客さまから聞いた理由を共有します。
```

## 直した文章

```markdown chaff-after
# 10月の営業報告

営業二課の田中です。10月の結果をまとめました。

今月は、新しいお客さまを増やす方法を話し合う会議を2回開き、展示会で受け取った名刺に連絡する順番を決めました。
商談は先月の12件から18件に増えています。

来月は、いまのお客さまに満足度を尋ねた調査の報告会を開き、解約したお客さまから聞いた理由を共有します。
```

## 直し方

「新規顧客獲得施策検討会議」は漢字が12字続きます。読み手は「新規・顧客・獲得・施策・検討・会議」と、どこで語が切れるかを自分で探すことになり、何の会議なのかが一度で頭に入りません。
書いた本人には見慣れた名前でも、ほかの課の人や、あとから読む人にはそうではありません。

直した文章では、助詞と送り仮名を足して「新しいお客さまを増やす方法を話し合う会議」と、何をする会議なのかを言葉で書きました。
もう一つの「既存顧客満足度調査結果報告会」も同じように開いています。
字数は増えますが、読む速さは上がります。

社内で決まった正式な名前で、言い換えられないものもあります。そのときは文章を変えずに、下の `names` に名前を並べてください。
鉤括弧でまるごとくくった名前（「新規顧客獲得施策検討会議」）も数えません。

## 設定

報告書（`business/report`）などビジネス文書では、漢字は10字まで続いても指摘しません。
ジャンルを決めないときの既定は8字までです。強さを変えると、この字数が変わります（下の `explain` の出力を見てください）。

ゆるめるときは:

```yaml chaff-settings
rules:
  max-kanji-continuous: relaxed
```

言い換えられない正式な名前だけを数えないようにするときは:

```yaml chaff-settings
names:
  - 新規顧客獲得施策検討会議
```

見ないことにするなら `max-kanji-continuous: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax max-kanji-continuous --why "社内の正式な会議名が多いため"
```

```text chaff-explain
$ npx chaffjs explain max-kanji-continuous --genre business/report

  漢字が続きすぎている   (max-kanji-continuous)

  漢字が続くと、どこで語が切れるのか読み手が探すことになります。「情報処理推進機構認定試験」は 12 字あり、区切りが見えません。

  直しかた: ひらがなを 1 つ挟むか、助詞で割ってください。「情報処理推進機構の認定試験」に。割れない正式名称なら、chaff.yaml の names に並べると数えません。鉤括弧でまるごとくくった名前（「英国大使館別荘記念公園」）も数えません。

  オプション（chaff.yaml の options で決めます）:
    headword_genres: [docs/glossary]   （既定）

  決める:  chaff.yaml に options: { max-kanji-continuous: { <名前>: <値> } } を書く

  いまは normal です。

  変える:  npx chaffjs relax max-kanji-continuous --why "理由"
```
