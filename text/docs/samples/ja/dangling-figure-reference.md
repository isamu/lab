# 図や表の参照先が無い（`dangling-figure-reference`）

**こんな文書に:** 社内の報告書、調査のまとめ、提案書。図を一つ消したり順番を入れ替えたりしたあとに、本文の「図3」だけが古い番号のまま残ります。

## 元の文章

```markdown chaff-before
# 上期の来店客数の報告

駅前店の営業課です。4月から9月までの来店客数をまとめました。

## 来店客数

上期の来店客数は、前の年の上期より8%増えました。月ごとの数は図1のとおりです。
増えた分の多くは、土曜日と日曜日の午前でした。曜日と時間帯ごとの数は図3に載せています。

図1　月ごとの来店客数

図2　曜日と時間帯ごとの来店客数

## 下期に向けて

土曜日と日曜日の午前に、レジの人を一人増やします。
```

## 直し方

本文は「図3に載せています」と書いていますが、この報告書の図は図1と図2の二つだけです。
下書きでは、二つの図のあいだに「年代ごとの来店客数」の図がありました。それを消して番号を詰めたときに、本文の「図3」だけを直し忘れていました。
読む人は図3を探して見つけられず、図が抜けたのか、番号がずれたのかを確かめることになります。会議で配った資料なら、その場で質問が出ます。

直した文章では、本文の番号を図2に直しました。
chaff は、行の頭に書いた「図1　月ごとの来店客数」のようなキャプションと、「## 付録A」のような見出しを図の置き場所として読みます。
図を行の頭に一つも書いていない文書は、図を別の紙に付けているかもしれないので見ません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  dangling-figure-reference: strict
```

資料を配る前に必ず止めたいなら `strict` にします。
「地図3」「一覧表2」のような長い語の一部や、「図3枚」のような図の数は読みません。文芸のジャンルでは、はじめから動きません。
