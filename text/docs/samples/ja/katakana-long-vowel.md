# カタカナ語の語末の「ー」がそろっていない（`katakana-long-vowel`）

**こんな文書に:** 操作の手引き、社内の案内、製品の説明。メーカーの説明書から文を写すと、そこだけ「プリンタ」のように語末の「ー」を省いた書き方が入ります。

```markdown chaff-before
# 複合機の使い方

3階の複合機は、コピーとスキャンと印刷に使えます。

## 印刷する

パソコンで印刷を選び、プリンターの一覧から「3階複合機」を選びます。
社員証をかざすと、印刷が始まります。

## 紙が詰まったとき

画面に場所が出るので、その扉を開けて紙を取り除きます。
取れないときは、プリンタの電源を切らずに総務課へ連絡してください。
```

# 複合機の使い方

## 印刷する

## 直し方

この手引きは、印刷の段では「プリンター」と書き、紙が詰まったときの段では「プリンタ」と書いています。
読み手は、同じ機械のことか、別の機械があるのかと一瞬迷います。社内の検索で「プリンター」と探した人には、紙詰まりの段が出てきません。

少ないほうを、ほかと同じ「プリンター」に直しました。
chaff は、語末の「ー」を付けるか省くかは決めません。同じ語が両方の書き方で出てきた所を指します。「サーバー」と「ブラウザ」のような違う語どうしは比べません。

## 設定

```yaml chaff-settings
rules:
  katakana-long-vowel: normal
options:
  katakana-long-vowel:
    ending: keep
    except: [ドライバ]
```

`options` の `ending` を `keep`（語末の「ー」を付ける）か `drop`（省く）にすると、文書の多いほうではなく、決めた書き方に合わない語をすべて指摘します。
製品名のように、そのままにしたい語は `except` か、chaff.yaml の `names` に並べます（上の例では「ドライバ」を見ません）。
ふだんは、違う書き方が1か所でもあれば指摘します。`relaxed` にすると3か所あるときだけ指摘します。日本語の文書で、どのジャンルでも動きます。

  → normal   違う書き方の語が 1 箇所あれば指摘
    relaxed  違う書き方の語が 3 箇所あれば指摘
