# 見出しを繰り返すだけの書き出し（`heading-echo`）

**こんな文書に:** 企画書、報告書、社内の提案。見出しを立てたあと、まず見出しを言い直してから本題に入りがちな文書です。

## 元の文章

```markdown chaff-before
# 在宅勤務の手当を見直す提案

人事課の高橋です。来年度からの在宅勤務の手当について提案します。

## 在宅勤務の手当を見直す理由

在宅勤務の手当を見直す理由について説明します。
いまの手当は月三千円で、出社が週一日の人にも週四日の人にも同じ額を払っています。
在宅の日が多い人ほど、電気代や通信費の負担が大きくなっています。

## 新しい手当の決め方

在宅で働いた日数に応じて、一日あたり二百円を払います。
上限は月四千円とし、勤怠システムの記録から毎月計算します。
```

# 在宅勤務の手当を見直す提案

人事課の高橋です。来年度からの在宅勤務の手当について提案します。

## 在宅勤務の手当を見直す理由

## 直し方

見出しが「在宅勤務の手当を見直す理由」と言ったあと、最初の文が「在宅勤務の手当を見直す理由について説明します」と同じことを言っています。
読み手は、見出しを読んだ時点で理由を待っています。その一文では何も受け取れず、本当の書き出しは二文目になります。

直した文章では、その一文を消し、いまの手当の額と、誰に不公平なのかから書き始めました。
見出しが約束した理由が、すぐに出てきます。

見出しに無い数（金額・番号・日付）を述べる文は、見出しの語を繰り返していても中身を渡しているので指摘しません。

## 設定

見出しと直後の文で、語が60%以上重なっていると指摘します。`strict` にすると45%、`relaxed` にすると75%からです。
法務・文学のジャンル、`docs` のジャンル（手引き・よくある質問・用語集）、話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  heading-echo: relaxed
```

見ないことにするなら `heading-echo: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax heading-echo --why "見出しを書き出しで言い直す社内の書式のため"
```
