# 着が発より前（`arrival-before-departure`）

**こんな文書に:** 出張や旅行の旅程、乗る便や列車を知らせるメール。時刻表から写すときに、着の時刻の一桁を打ち間違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 福岡出張の旅程

12月8日から一泊で、福岡の取引先へ新しい設備の説明に行きます。

## 12月8日（火）

- 07:45 ANA 241便（羽田 07:45発、福岡 07:30着）
- 11:00 天神の取引先で設備の説明
- 15:00 博多の支店で打合せ

## 12月9日（水）

- 10:00 取引先の工場を見学
- 16:30 ANA 266便（福岡 16:30発、羽田 18:05着）
```

## 直した文章

```markdown chaff-after
# 福岡出張の旅程

12月8日から一泊で、福岡の取引先へ新しい設備の説明に行きます。

## 12月8日（火）

- 07:45 ANA 241便（羽田 07:45発、福岡 09:30着）
- 11:00 天神の取引先で設備の説明
- 15:00 博多の支店で打合せ

## 12月9日（水）

- 10:00 取引先の工場を見学
- 16:30 ANA 266便（福岡 16:30発、羽田 18:05着）
```

## 直し方

行きの便は羽田を7時45分に発つのに、福岡に着くのが7時30分になっています。発つより前に着く便はありません。「09:30」を「07:30」と打ち間違えたのでしょう。
この旅程を見て、福岡に着いてすぐ打合せを入れる人や、空港へ迎えを頼む人が出ます。迎えの車は二時間早く空港で待つことになります。

直した文章では、着を09:30にしました。日をまたぐ便なら、着に「翌」か「+1」を書きます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  arrival-before-departure: strict
```

同じ行の発と着（時刻のすぐ後ろの「発」「着」や、表の出発と到着の列）を比べます。着に「翌」や「+1」があれば一日足して比べます。「現地時間」のように時間帯の違う時刻は、そのまま比べられないので言いません。
文学のジャンルでは止めています。着いてから次の予定までの間が短すぎる所は、`connection-time-short` が見ます。
