# 動詞を名詞にして回りくどく書いている（`nominalization`）

**こんな文書に:** 報告書、議事録、点検や調査の記録。改まって書こうとすると、「〜を行いました」「〜を実施しました」が並ぶ文書です。

## 元の文章

```markdown chaff-before
# 10月の品質点検の報告

品質管理課の山下です。10月に行った、出荷前の品質点検の結果を報告します。

## 点検の結果

今月は、出荷する前の製品から200個を抜き取り、外観と寸法の確認を行いました。
寸法は、200個すべてが図面の許す範囲に収まっていました。
抜き取りは、毎日の生産の終わりに、その日に作った製品の中から決まった数を選んで行っています。
外観では、3個に塗装のむらが見つかりました。どれも、側面の下の角に近い所です。
むらのあった製品は、塗装の工程に戻して再塗装を実施しました。塗り直した3個は、もう一度点検して、出荷に回しています。

## 原因と対策

原因の調査を行ったところ、塗装の機械の吹き出し口に、乾いた塗料が詰まっていました。
詰まった所から塗料が細く出ていたため、角の近くだけ塗りが薄くなったと見ています。
吹き出し口の清掃を実施し、そのあとに塗った50個では、むらは一つもありませんでした。

11月からは、毎朝の始業前の点検に、吹き出し口を見る項目を加えます。
点検表の書式は、今週中に製造課と相談して直します。
吹き出し口の詰まりは、塗料を替えた日や、機械を長く止めた次の朝に起きやすいと、製造課の担当者から聞いています。
そのため、塗料を替えた日には、昼にも一度吹き出し口を見ることにします。

## 来月の予定

来月も、同じ数を抜き取って点検し、結果をこの報告と同じ形でお知らせします。
```

## 直し方

「確認を行いました」は「確認しました」で、「調査を行った」は「調べた」で足ります。
動詞を名詞にして「行う」「実施する」に運ばせると、文が長くなり、何をしたのかが文の後ろへ遠のきます。
一つ二つなら普通の言い方ですが、この報告では四か所に重なり、どの文も同じ硬い調子になっています。

直した文章では、名詞を動詞に戻しました。
「確かめました」「塗り直しました」「調べた」「掃除した」と、した動作がそのまま読めます。chaff が示す「確認する」「調査する」に直してもかまいません。ここでは、ふだん話すときの言い方を選んでいます。
「点検」のように、報告の中心になる語は、名詞のまま使ってかまいません。

## 設定

1000字あたりの数で見ます。ふだんは2個までです。短すぎる文書は測りません。

```yaml chaff-settings
rules:
  nominalization: relaxed
```

`relaxed` にすると1000字あたり4個まで、`strict` にすると1個までです。
「研修を実施する」「授業を行う」のように、「実施する」が催す意味になる語は見ません。
法令・契約（`legal`）と文学（`literature`）のジャンルでは動きません。
