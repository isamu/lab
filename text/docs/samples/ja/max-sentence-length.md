# 一文が長すぎる（`max-sentence-length`）

**こんな文書に:** 取引先へのメール、社内の手続きの案内、お客さまへのお知らせ。条件や頼みごとを一つの文に詰め込みがちな文書です。

## 直した文章

```markdown chaff-after
# 展示会の搬入について

株式会社あおば工芸
川口様

いつもお世話になっております。展示会事務局の森です。
```

## 直し方

元の文は96字あり、搬入の時間、大きな什器のときの搬入口、事務局へ知らせることの三つが一文に入っています。
読み手は、最後の「お知らせいただけますでしょうか」まで読んで、ようやく自分が何を頼まれているのかが分かります。
時間だけを知りたい人も、頼みごとだけを知りたい人も、全部を読むことになります。

直した文章では、接続助詞の所で文を三つに割りました。
時間、搬入口、頼みごと、と一文に一つずつ収まり、頼みごとは「お知らせください」とはっきり言い切っています。

## 設定

メール（`business/email`）では、一文が70字までなら指摘しません。`strict` にすると50字、`relaxed` にすると100字までです。
ジャンルごとに別の数字を持っていて、報告書は140字まで、ブログの技術記事は160字までです。
文学・論文・法務のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  max-sentence-length: relaxed
```

見ないことにするなら `max-sentence-length: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax max-sentence-length --why "取引先の書式に合わせて長い文を残すため"
```
