# ページに無い関数をコード例で呼んでいる（`undefined-function-call`）

**こんな文書に:** ライブラリの README、API リファレンス、社内ツールの使い方。関数の名前を変えたあとに、コード例だけが古い名前のまま残ります。

## 元の文章

````markdown chaff-before
# textwrap

日本語の文章を、決まった幅で折り返すライブラリです。

## wrap

文章を、指定した幅で折り返します。戻り値は、折り返した行の配列です。

```js
import { wrap } from "textwrap";

const lines = wrapText("折り返したい長い文です。", 10);
```

句読点が行の頭に来ないように、折り返す位置を一文字ずらします。
````

# textwrap

日本語の文章を、決まった幅で折り返すライブラリです。

## wrap

const lines = wrap("折り返したい長い文です。", 10);

## 直し方

このページは wrap を説明し、例でも wrap を import しています。ところが例が呼んでいるのは wrapText で、ページのどこにも説明がありません。
読み手が例を写して動かすと、そのとたんに「wrapText がありません」で止まります。

関数の名前を wrapText から wrap に変えたときに、例だけが残ったと読めるので、例の呼び出しを wrap に直しました。
本当に別の関数なら、その関数をページで説明します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  undefined-function-call: strict
```

見出しの最初の語（## wrap）と import した名前を、ページが説明する関数と読みます。コードブロックの中で、その名前を頭に持つより長い名前を呼んでいて、その名前がページのほかのどこにも無いときに指します。
宣言、コメントの中の呼び出し、parseInt のようにプログラミング言語が用意する関数、`console.log(` のようなメンバーの呼び出し、4文字より短い名前を頭に持つものは見ません。
技術の文書、手順書、記事で動きます。契約や法令、論文では、はじめから動きません。
