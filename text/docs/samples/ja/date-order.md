# 日程の順番が前後している（`date-order`）

**こんな文書に:** 出張や旅行の日程、行事の予定、変更の記録。日付を一つだけ打ち間違えて、並びから外れる、という形がよくあります。

## 元の文章

```markdown chaff-before
# 九州出張の日程

営業二課の三人で、12月の第一週に福岡・久留米・熊本・鹿児島の取引先を回ります。日程は次のとおりです。

- 2026年12月1日　羽田から福岡へ移動し、博多の支店で打合せ
- 2026年12月2日　久留米の工場を見学
- 2026年11月3日　熊本の取引先へ新しい製品を説明
- 2026年12月4日　鹿児島の取引先と来年の契約を相談
- 2026年12月5日　鹿児島から羽田へ帰着

宿は、どの日も駅の近くのビジネスホテルを取ります。
```

# 九州出張の日程

- 2026年12月3日　熊本の取引先へ新しい製品を説明
- 2026年12月4日　鹿児島の取引先と来年の契約を相談
- 2026年12月5日　鹿児島から羽田へ帰着

## 直し方

日程は12月1日から5日まで一日ずつ進むのに、三日目だけが「11月3日」です。12月の「12」を「11」と打ち間違えたのでしょう。
このまま宿や取引先との約束を取ると、熊本での説明だけが11月の日付で手配されるおそれがあります。読む人は、三日目が本当に11月なのか、打ち間違いなのかを書いた人に確かめることになります。

直した文章では、三日目を12月3日にしました。順番が違うだけで日付は正しいなら、行を並べ替えます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  date-order: strict
```

並びが古い順か新しい順かは、多いほうで決めます。その向きに逆らう日付だけを指摘し、向きに沿う日付が半分以下の並びは、名前や版の順に並べた一覧として扱って何も言いません。表の最初の列でない期限の列（宿題ごとの期限）は、日程ではないので並びに入れません。
文学のジャンルでは止めています。
