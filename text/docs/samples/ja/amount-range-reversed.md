# 金額の範囲の上限が下限より小さい（`amount-range-reversed`）

**こんな文書に:** 求人票の給与、見積もりの幅、予算の上限と下限。下限を上げたときに、上限を直さずに数字だけ並べ替えてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 求人票：店舗スタッフ（正社員）

| 項目 | 内容 |
| --- | --- |
| 仕事の内容 | 店舗での接客、発注、売り場づくり |
| 勤務地 | 青葉台店（あおば線「青葉台」駅から徒歩5分） |
| 給与 | 月給28万円〜24万円（経験と能力を考えて決めます） |
| 賞与 | 年2回（昨年度の実績は計3.2か月分） |
| 休日 | 月9日（シフト制）、夏季と冬季に連続休暇 |

応募の方は、履歴書を人事部の採用担当までお送りください。
```

## 直し方

給与の欄は「月給28万円〜24万円」で、終わりの額が始まりより4万円小さくなっています。下限を24万円から28万円へ上げるつもりで、二つの額を入れ替えてしまったか、上限と下限を逆の順に書いたのでしょう。
求人票を見る人は、自分がいくらからいくらの幅に入るのかを、この一行で判断します。逆になった範囲では、下限が24万円なのか28万円なのかが決まらず、応募をためらうか、面接で確かめることになります。

直した文章では、小さいほうから「月給24万円〜28万円」と書きました。下限を上げたのが本当なら、上限の額も一緒に確かめます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  amount-range-reversed: strict
```

同じ通貨の二つの金額の間が「〜」のような範囲の記号だけのときと、「から」でつなぎ終わりの金額のあとに「まで」が続くときを、範囲として比べます。「30〜25万円」のように単位を一度だけ書いた範囲も読みます。「月額を5,000円から3,000円に値下げ」のように値段を変える語のある文、通貨の違う二つの金額、計算の式は比べません。
文学のジャンルでは止めています。温度や重さの範囲は `quantity-range-reversed` が、日付の範囲は `date-range-reversed` が見ます。
