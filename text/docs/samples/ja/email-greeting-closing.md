# メールの挨拶か結びが無い（`email-greeting-closing`）

**こんな文書に:** 取引先や社外の人に送る仕事のメール。前のメールから本文だけを写したときや、下書きを貼り付けたときに、挨拶や結びが抜ける形がよくあります。

## 元の文章

```markdown chaff-before
件名: 新商品の撮影の日程について

株式会社ひなた企画
撮影担当 様

新商品の撮影の日程をお知らせします。

12月9日（水）の午前10時から、弊社の2階の会議室で行います。撮影する商品は、前日までにこちらで会議室に運んでおきます。

当日は、ビルの裏手にある来客用の駐車場をお使いください。

株式会社つばめ食品 広報課
```

## 直した文章

```markdown chaff-after
件名: 新商品の撮影の日程について

株式会社ひなた企画
撮影担当 様

いつもお世話になっております。株式会社つばめ食品の広報課です。
新商品の撮影の日程をお知らせします。

12月9日（水）の午前10時から、弊社の2階の会議室で行います。撮影する商品は、前日までにこちらで会議室に運んでおきます。

当日は、ビルの裏手にある来客用の駐車場をお使いください。

当日はどうぞよろしくお願いいたします。

株式会社つばめ食品 広報課
```

## 直し方

このメールは、宛名のすぐ後に「新商品の撮影の日程をお知らせします。」と用件から始まり、駐車場の案内で終わっています。
社内の連絡から本文だけを写して送った、という形です。
用件ははっきりしていますが、社外の相手には、いきなり用件を突きつけられたように読めます。終わりに結びが無いと、途中で切れたようにも見えます。

直した文章では、書き出しに「いつもお世話になっております。」と名乗りを、終わりに「当日はどうぞよろしくお願いいたします。」を足しました。
用件の中身は変えていません。挨拶と結びの言い方は決まっておらず、どれか一つがあれば足ります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「参考」として出し、`strict` にすると「注意」になります。

```yaml chaff-settings
rules:
  email-greeting-closing: strict
```

本文の最初の数行に挨拶（お世話になっております、拝啓）が無いか、最後の数行に結び（よろしくお願いいたします、敬具）が無いときに指します。語は言語ごとの語彙表から読みます。
引用した返信（「>」の行）と、署名（「-- 」の後ろ）は見ません。日付や宛名のような文で終わらない行が頭に続くときは、その後ろの最初の文までに挨拶を探します。
同僚あての「お疲れさま。」「よろしく。」も、挨拶と結びに数えます。
メールと手紙のジャンル（`business/email`）でだけ動きます。
