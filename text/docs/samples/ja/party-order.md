# 当事者の呼び名を、ほかの所と逆の順に並べている（`party-order`）

**こんな文書に:** 業務委託や売買の契約書、覚書。よその契約の条文を貼り合わせたり、条を書き直したりすると、「甲及び乙」と書く契約の中に「乙及び甲」が紛れ込みます。

## 元の文章

```markdown chaff-before
# 配送業務委託契約書

株式会社みどり食品（以下「甲」という。）と株式会社はやて運輸（以下「乙」という。）は、甲の商品の配送について、次のとおり契約を結ぶ。

## 第1条（秘密の保持）

甲及び乙は、この契約で知った相手方の秘密を、ほかの者に漏らしてはならない。

## 第2条（解除）

甲又は乙は、相手方がこの契約に違反したときは、この契約を解除することができる。

## 第3条（協議）

この契約に定めのない事項は、乙及び甲が協議して定める。
```

# 配送業務委託契約書

株式会社みどり食品（以下「甲」という。）と株式会社はやて運輸（以下「乙」という。）は、甲の商品の配送について、次のとおり契約を結ぶ。

## 直し方

この契約は、第1条で「甲及び乙」、第2条で「甲又は乙」と、甲を先に書いています。第3条だけが「乙及び甲」と逆の順です。
契約を読む人は、乙を先に立てた理由があるのかと探して止まります。協議の条は争いになったときに読み返される所なので、意味の無い違いは残さないほうが安心です。

ほかの条と同じ「甲及び乙」に並べ替えました。
乙を先に立てる理由が本当にあるときは、そのままにします。chaff は、同じ二つの呼び名が逆の順に並んだ所が、ふだんの順より少ないときだけ指します。

## 設定

```yaml chaff-settings
rules:
  party-order: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
契約のジャンル（`legal/contract`）で動きます。法令や判決、特許、説明書、論文などのジャンルでは、はじめから動きません。日本語の文書だけを見ます。
