# 月払の何か月分と合わない額（`period-multiple-mismatch`）

**こんな文書に:** 保険やサービスの料金の案内、申込書、見積書。月払の料金を改めたときに、横に書いた年払の額だけが前の料金のまま残る形がよくあります。

## 元の文章

```markdown chaff-before
# 見守りサービスの料金

ご家族の家に置いたセンサーで、毎日の暮らしを見守るサービスです。
4月から、月払の料金を改めました。

| 払い方 | 料金 |
| --- | --- |
| 月払 | 1,980円 |
| 年払（月払の12か月分） | 22,760円 |

年払は、申し込みの月にまとめてお支払いいただきます。
途中で解約したときは、残りの月数分をお返しします。
```

# 見守りサービスの料金

ご家族の家に置いたセンサーで、毎日の暮らしを見守るサービスです。

| 払い方 | 料金 |
| --- | --- |
| 月払 | 1,980円 |
| 年払（月払の12か月分） | 23,760円 |

年払は、申し込みの月にまとめてお支払いいただきます。

## 直し方

年払の行には「月払の12か月分」と書いてあります。けれども月払の1,980円の12か月分は23,760円で、書いてある22,760円より1,000円多くなります。
読み手は「12か月分」という言葉を信じて、計算せずに申し込みます。あとで請求の額が違うと、問い合わせや返金の手間が生まれます。

月払の料金を改めたときに、年払の額を直し忘れたと読めるので、年払の額を23,760円に直しました。
年払を割り引くなら、「12か月分」とは書かずに「年払 22,760円（月払より1,000円お得）」のように書きます。
chaff は、「月払の12か月分」「月額の2倍」のように、もとの額の見出しと数を書いた所だけを計算します。何か月分と書いていない年払の額は比べません。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  period-multiple-mismatch: strict
```

「9.8万円」のように丸めて書いた額は、書いた桁までの丸めを認めます。
割引・税込・約・各などの語がある記載、一つの行に金額が二つ以上ある記載、「11〜12か月分」のような数の幅は比べません。
文芸のジャンルでは、はじめから動きません。
