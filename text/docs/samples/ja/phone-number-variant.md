# 電話番号の数字の入れ違い（`phone-number-variant`）

**こんな文書に:** 町内会や学校のお知らせ、催しの案内、申込書。申込先と問合せ先のように同じ番号を二度書いて、片方だけ数字を入れ違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 粗大ごみの回収のお知らせ

12月の第二土曜日に、町内会で粗大ごみをまとめて回収します。

回収を頼みたい方は、前の週の金曜日までに、町内会の事務所へ電話でお申し込みください。

申込先　電話：045-000-1234（平日の10時〜16時）

出せるものは、家具と自転車と小さな電気の製品です。テレビや冷蔵庫は回収できません。

回収の日の様子や、出せるものについてのご質問は、次へどうぞ。

問合せ先　電話：045-000-1243
```

申込先　電話：045-000-1234（平日の10時〜16時）

## 直し方

申込先は「045-000-1234」で、問合せ先は「045-000-1243」です。終わりの二つの数字だけが入れ替わっています。隣り合う二つの数字の入れ違いは、打ち間違いでいちばん多い形です。
問合せ先の番号にかけた人は、つながらないか、知らない家にかかります。番号が二つあると、読む人はどちらが町内会の番号かを決められません。

直した文章では、問合せ先の番号を申込先と同じにしました。本当に別の番号なら、chaff はこの形の違いを指摘しません。数字が一つだけ違う番号（代表と直通）も、よくある別の番号として指摘しません。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  phone-number-variant: strict
```

同じ行で前に「電話」「TEL」「お問合せ」のような語か窓口の名前がある番号だけを読み、隣り合う二つの数字だけが入れ違った番号を指摘します。数字が9桁から13桁で、ハイフンか括弧で区切ったものを番号と見ます。電話とFAXのように種類の違う番号どうしは比べません。
文学と、話した言葉を書き起こした記録のジャンルでは止めています。物語の番号は作りもので、書き起こしは言い間違いも含めて書くからです。メールアドレスと住所の書き違いは、`contact-variant` が見ます。
