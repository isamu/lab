# 段落が長すぎる（`max-paragraph-length`）

**こんな文書に:** 報告書、議事録、調べたことのまとめ。書いた順に文を足していき、段落を割らないまま話題が移りがちな文書です。

## 元の文章

```markdown chaff-before
# 社員食堂の利用についての調べ

総務課で、9月に社員食堂の利用者を調べました。

昼の利用者は一日平均で210人で、去年の同じ月と比べると40人ほど減っています。
減ったのは主に入社して数年の若い社員で、近くのコンビニで弁当を買って自分の席で食べる人が増えているようです。
利用しない理由を尋ねたアンケートでは、料理を受け取るまでの待ち時間が長いことと、メニューが毎週同じことを挙げる人が多くいました。
夜まで残っている人からは、夕食の時間にも食堂を開けてほしいという声が届いています。
一方で、値段については、外で食べるより安いと答えた人が80%を超えています。
食堂を運営する会社とは、来月の定例の打ち合わせで、メニューを週ごとに入れ替えられないか相談します。
待ち時間については、混み合う12時台だけ、料理を受け取る列を二つに分けることを試してみる予定です。
十二月にもう一度同じやり方で利用者を数え、変えたことの効き目を確かめます。
```

## 直し方

元の段落は八つの文でできていて、利用者が減ったこと、アンケートの答え、これから試すことが、一つの塊に入っています。
読み手は、どこで話が変わったのかを自分で探すことになり、息継ぎの場所がありません。

直した文章では、話題の変わり目で段落を三つに割りました。
「いまの様子」「利用者の声」「これからすること」と段落ごとに一つの話になり、読み返すときも探す場所がすぐ分かります。

chaff は文の数だけでは決めません。短い文を重ねただけの段落は壁にならないので、普通の長さの文を上限の数だけ並べたより長い段落だけを指します。

## 設定

報告書（`business/report`）では、一つの段落に五文までなら指摘しません。`strict` にすると三文、`relaxed` にすると八文までです。
法務と論文のジャンルでは別の数字を持ち、文学のジャンルと話し言葉の書き起こしでは既定で止めています。

```yaml chaff-settings
rules:
  max-paragraph-length: relaxed
```

見ないことにするなら `max-paragraph-length: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax max-paragraph-length --why "段落ごとに一つの事例を書く報告の形のため"
```
