# 表の見出しの書き方が表ごとに違う（`table-header-variant`）

**こんな文書に:** 当番表や担当の割り振り、週ごとの報告、計画表。前の週の表を写して作り直すと、表ごとに見出しの言葉が少しずつ変わります。

| --- | --- |

## 2階

| 場所 | 担当者 |
| --- | --- |

## 3階

| 場所 | 担当 |
| --- | --- |
| 倉庫 | 情報システム課 |
| 書庫 | 人事課 |

掃除の道具は、1階の倉庫の前にまとめて置いておきます。

| --- | --- |

## 2階

| 場所 | 担当者 |
| --- | --- |
| 会議室 | 企画部 |
| 給湯室 | 経理課 |

| --- | --- |

## 直し方

この分担表は、1階と2階の表の見出しを「担当者」としています。3階の表だけが「担当」です。
読み手は、3階だけ欄の意味が違うのか、たとえば当日に来る人ではなく、まとめ役の名前なのかと迷います。表を並べて見比べるときに、手が止まります。

同じ欄なので、ほかの表と同じ「担当者」にそろえました。
chaff は、「者」「欄」「名」のように名前を変えない字を外すと同じになる見出しを、同じ欄と見ます。どちらの書き方が正しいかは決めず、少ないほうを指します。

## 設定

少ないほうの書き方が、その見出しの一定の割合までなら、書き分け忘れと読んで指摘します。

```yaml chaff-settings
rules:
  table-header-variant: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。見たくなければ `off` にします。
本当に別の欄なら、違いが分かる名前にします。どのジャンルでも動きます。Markdown の文書だけを見ます。

```text chaff-explain
$ npx chaffjs explain table-header-variant --genre business/report

  表の見出しの書き方が表ごとに違う   (table-header-variant)

  同じ欄を、ある表では「担当者」、別の表では「担当」と書くと、読み手は別の欄かと迷い、表を見比べるときに手が止まります。chaff は表の見出しの行と、二列の表の左の欄（項目名）を集め、幅・大文字小文字・空白・ハイフン・中黒をそろえたうえで、名前を変えない字（者・欄・名・等）を外すと同じになる見出しを、同じ欄の書き方と見ます。そのうえで、文書の中で少ないほうの書き方を指摘します。どちらが正しいかは決めません。

  直しかた: 同じ欄なら、文書の多いほうの書き方にそろえてください。本当に別の欄なら、違いが分かる名前にします。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値:
    strict   少ないほうの書き方が、その見出しの 50% 以下のとき指摘
  → normal   少ないほうの書き方が、その見出しの 50% 以下のとき指摘
    relaxed  少ないほうの書き方が、その見出しの 34% 以下のとき指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax table-header-variant --why "理由"
```
