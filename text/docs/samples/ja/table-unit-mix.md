# 表の中で金額の桁の単位が混ざっている（`table-unit-mix`）

**こんな文書に:** 決算の資料、予算の報告書、事業計画の数表。別の資料から一行だけ写したときに、その行だけ千円で書いた数が「（単位：百万円）」の表に紛れ込みます。

## 元の文章

```markdown chaff-before
# 上期の業績

上期は、業務用の冷蔵庫の出荷が伸び、売上高と利益がともに前の年を上回りました。

（単位：百万円）

| 項目 | 前期 | 当期 |
| --- | --- | --- |
| 売上高 | 1,200 | 1,320 |
| 営業利益 | 84 | 96 |
| 経常利益 | 80 | 92 |
| 当期純利益 | 52,000 | 60,000 |

下期も、同じ伸びを見込んでいます。
```

## 直した文章

```markdown chaff-after
# 上期の業績

上期は、業務用の冷蔵庫の出荷が伸び、売上高と利益がともに前の年を上回りました。

（単位：百万円）

| 項目 | 前期 | 当期 |
| --- | --- | --- |
| 売上高 | 1,200 | 1,320 |
| 営業利益 | 84 | 96 |
| 経常利益 | 80 | 92 |
| 当期純利益 | 52 | 60 |

下期も、同じ伸びを見込んでいます。
```

## 直し方

表は「（単位：百万円）」ですが、当期純利益の行だけが、ほかの行の千倍ほどの数です。百万円の表として読むと、純利益が売上高の40倍を超えてしまいます。
読む人は、表の単位を信じてその行を千倍に読み違えるか、表全体を疑います。

経理の資料の千円の表から、この行だけを写したと読めるので、百万円に直しました。
行の単位が本当に違うなら、「従業員数（人）」のように行の名前に単位を書きます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  table-unit-mix: strict
```

表のすぐ上に「単位」と桁の単位（百万円、千円）を書いた短い行があれば、それを表の単位と読みます。無ければ、升の多くに付いた桁の単位を表の単位と読みます。
千倍の行は、表のすぐ上に単位を書いた表でだけ探します。行の数がどの列でもちょうど千の倍数で、ほかのどの行よりも十倍以上大きいときだけ指します。
合計の行、名前に括弧で単位を書いた行、千倍に見える行が二行以上ある表は言いません。文芸のジャンルでは、はじめから動きません。
