# 注の無い注の印と、印の無い注（`footnote-mismatch`）

**こんな文書に:** プレスリリース、商品の案内、報告書。注を一つ消したり、順番を入れ替えたりしたときに、本文の「※」と注の番号が合わなくなる形がよくあります。

## 元の文章

```markdown chaff-before
# 駅前店で、夜9時まで受け取れる「夕方便」を始めます

株式会社さくら青果は、12月1日から、駅前店で夕方便※1を始めます。午後3時までにアプリで注文した野菜と果物を、その日の夜9時まで店頭で受け取れます。

受け取りの手数料※2は、いただきません。

※1 平日のみの取り扱いです。
```

## 直した文章

```markdown chaff-after
# 駅前店で、夜9時まで受け取れる「夕方便」を始めます

株式会社さくら青果は、12月1日から、駅前店で夕方便※1を始めます。午後3時までにアプリで注文した野菜と果物を、その日の夜9時まで店頭で受け取れます。

受け取りの手数料※2は、いただきません。

※1 平日のみの取り扱いです。
※2 注文の金額が1,000円に満たないときは、手数料100円をいただきます。
```

## 直し方

本文には「手数料※2」と注の印がありますが、注は「※1」しか書いてありません。
読む人は注2を探して見つけられず、手数料には何か条件があるのか、無いのかが分かりません。
プレスリリースは、そのまま記事に引かれることがあります。条件を書いたつもりの注が抜けたまま「手数料は無料」と広まると、あとで訂正を出すことになります。

直した文章では、抜けていた注2を書きました。
注が要らないのなら、反対に本文の「※2」を消します。注の番号を振り直したときは、本文の印も同じ番号に直します。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  footnote-mismatch: relaxed
```

Markdown の脚注（[^1] と行頭の [^1]:）と、※ に一桁か二桁の番号を付けた印（※1、（※2））を読みます。
※ の注が文書に一つも無いときは、注を表や別紙に置いた文書と読んで指摘しません。
「※2018年度」のように ※ の後ろに数が続くものは、注の番号と読みません。コードの中は読みません。
どのジャンルでも動きます。
