# 数の書き方が混ざっている（`number-style-consistency`）

**こんな文書に:** アンケートの報告、月次の報告、社内の調べもの。表の数字を写した所と、文で書いた所とで、数の書き方が分かれることがあります。

## 元の文章

```markdown chaff-before
# 在宅勤務についてのアンケートの結果

10月に、全社員を対象にアンケートを行いました。答えてくれたのは212人です。

在宅勤務を週に2日以上している人は128人で、そのうち71人が「今の日数を続けたい」と答えました。
困っていることとして多かったのは、机と椅子が合わない、という声で、四十人が挙げています。
会社の支給する備品について、具体的な希望を書いてくれた人も56人いました。

結果をもとに、来月の会議で備品の補助を話し合います。
```

## 直した文章

```markdown chaff-after
# 在宅勤務についてのアンケートの結果

10月に、全社員を対象にアンケートを行いました。答えてくれたのは212人です。

在宅勤務を週に2日以上している人は128人で、そのうち71人が「今の日数を続けたい」と答えました。
困っていることとして多かったのは、机と椅子が合わない、という声で、40人が挙げています。
会社の支給する備品について、具体的な希望を書いてくれた人も56人いました。

結果をもとに、来月の会議で備品の補助を話し合います。
```

## 直し方

この報告の人数は、「212人」「128人」のように算用数字で書かれています。机と椅子の声の人数だけが「四十人」と漢数字です。
読み手は、そこだけ別の数え方なのか、おおよその数なのかと迷います。人数を見比べて読む報告なので、一つだけ見た目が違うと、数を拾い損ねます。

ほかと同じ「40人」に直しました。
chaff は、漢数字と算用数字のどちらが正しいかは決めません。数え方の語の前の数、位取りのコンマ、百分率の書き方のそれぞれで、文書の中で少ないほうを指します。

## 設定

少ないほうの書き方が、その種類の数の一定の割合までなら、書き分け忘れと読んで指摘します。それより多いときは、わざと使い分けていると読みます。

```yaml chaff-settings
rules:
  number-style-consistency: relaxed
```

`relaxed` にすると、少ないほうがもっと少ないときだけ指摘します。`strict` にすると、少ないほうが半分近くまで指摘します。見たくなければ `off` にします。
法務と文芸、講演のジャンルでは、はじめから動きません。
