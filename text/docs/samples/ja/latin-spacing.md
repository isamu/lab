# 英数字の前後の空白がそろっていない（`latin-spacing`）

**こんな文書に:** 技術記事、社内の手順、製品の案内。日本語と英字のあいだを空けるか詰めるかは人によって癖があり、何人かで書いた記事や、あとから一文を足した記事で混ざります。

```markdown chaff-before
慣れてきたら、PDFの資料も同じ仕組みで管理したいと考えています。
```

## 直し方

この記事は、「Git の」「Excel の」のように、日本語と英字のあいだに空白を入れて書いています。最後の文の「PDFの」だけが詰めて書かれています。
空けるか詰めるかは、どちらでも読めます。けれども一つの記事の中で混ざると、読み手には違いに何か意味があるように見えます。

少ないほうを、ほかと同じ「PDF の」に直しました。
chaff は、空けるか詰めるかは決めません。英字、数字の前、数字の後ろを別々に数え、文書の中で少ないほうを指します。
「3回」のように数と助数詞を詰める書き方や、日付と時刻の中の境目は数えません。

## 設定

```yaml chaff-settings
rules:
  latin-spacing: relaxed
```

ふだんは、少ないほうが1か所でもあれば指摘します。
`relaxed` にすると、少ないほうが3か所あるときだけ指摘します。見たくなければ `off` にします。
鉤括弧で引いた題名や発言の中、リンクの文字の中は数えません。日本語の文書で、どのジャンルでも動きます。
