# ら抜き言葉（`ra-nuki`）

**こんな文書に:** 社内外のメール、案内、報告書。話すときの言い方のまま書くと、「見れます」「来れない」が入ります。

## 元の文章

```markdown chaff-before
件名：新しい経費精算の画面について

経理課のみなさま

お疲れさまです。情報システム課の川口です。

来週の月曜日から、経費精算は新しい画面で行います。
新しい画面は、社内のどの端末からでも見れます。
領収書は、携帯で撮った写真をそのまま添付できます。

使い方の説明会は、11月25日（火）の午後3時から、2階の会議室で開きます。
当日に来れない方のために、説明会の録画も残します。

よろしくお願いします。
```

## 直し方

「どの端末からでも見れます」「当日に来れない方」は、話し言葉では普通の言い方ですが、書き言葉では誤りと読まれます。「見る」「来る」の可能の形は「見られる」「来られる」です。
社外の人にも転送されるかもしれない案内で、言葉の誤りに目が行くと、中身の信頼まで下がります。

直した文章では、「見られます」「来られない」と、「ら」を入れただけです。ほかの所は変えていません。
「走れる」「帰れる」のような五段動詞の可能の形は正しいので、chaff は指しません。どの動詞がどの形かは品詞解析で読みます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  ra-nuki: strict
```

鉤括弧や引用符で引いた言葉（話した言葉をそのまま引いたもの）は数えません。
文学と話し言葉のジャンルでは止めています。
