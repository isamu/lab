# 「とても + 形容詞」（very + 形容詞）の多用（`very-adjective`）

**こんな文書に:** ブログ、社内報、店の便り。その日の気持ちをそのまま書くと、「とても寒かった」「すごく嬉しかった」が続きます。

## 元の文章

```markdown chaff-before
# 商店街の朝市に、はじめて店を出しました

## 出すまで

うちの店は、駅の北口でパンを焼いて売っています。
十月の第一日曜日に、商店街の朝市にはじめて店を出しました。
朝市は朝七時から十一時までで、二十ほどの店が並びます。

前の晩は、いつもの倍のパンを焼き、焼き上がったものから順に、一つずつ袋に詰めていきました。
並べる台と値札は、近くの文具店で借りました。
雨の予報が出ていたので、テントも借りています。

## 当日

当日の朝は、とても寒かったです。
それでも、七時前から人が集まり始めました。
いちばん売れたのは、くるみと干しぶどうを入れた丸いパンです。
九時には、焼いた分がなくなりました。

隣は八百屋でした。
朝市に出るのは十年目だそうで、並べ方を教えてくれました。
値札は大きく書き、パンは箱の上に高く積むほうが目に留まるそうです。
教わったとおりに並べ直すと、足を止める人がすぐに増えました。

買ってくれたお客さんの多くは、近くに住む家族連れで、小さな子どもが丸いパンを両手で抱えて帰っていく姿も見られました。
店のことを知らなかった人が多く、来週、店にも来てくれると言ってくれました。
すごく嬉しかったです。

## 次に向けて

一回目の朝市は、とても楽しかったです。
ただ、パンが早くなくなったのは、非常に残念でした。
次の朝市では、今回の一倍半のパンを焼くつもりです。
くるみのパンは、別に予約も受けます。

次の朝市は、十一月の第一日曜日です。
店の前にも、朝市の案内を貼っておきます。
```

## 直し方

はじめて朝市に店を出した日の記事です。出来事は具体的に書けているのに、気持ちの所だけ「とても寒かった」「すごく嬉しかった」「とても楽しかった」「非常に残念」と、強め + 形容詞が続きます。どれも同じ強さで並ぶので、どれも効かなくなり、読み手にはその日の様子が浮かびません。

直した文章では、強めを外して、何がどうだったのかを書きました。寒さは「手がかじかんで値札の字が書けないほど」、楽しさは「店では話す機会のない近所の人と、たくさん話せました」、残念だったことは「後から来た人には何も売れませんでした」です。嬉しかった所は「前の晩の疲れが消えました」と、短く言い切りました。

## 設定

1000字あたりの強め + 形容詞の数で見ます。ふだんは 3 個まで、`relaxed` にすると 4 個まで、`strict` にすると 1 個までです。短い文書は測りません。

```yaml chaff-settings
rules:
  very-adjective: relaxed
```

強めの後ろが形容詞のときだけ数えます（「とても助かる」は数えません）。「とても重要」のような強めは `empty-intensifier` が見ます。「大変お世話になりました」のような挨拶の「大変」も数えません。
文学と話し言葉のジャンルでは止めています。
