# 比べられない形容詞に付けた程度（`uncomparable-graded`）

**こんな文書に:** 報告書、提案書、製品の紹介。良さを強く言いたいときに、「より最適な」「とても完璧」と、程度の無い語に程度を付けてしまいます。

## 元の文章

```markdown chaff-before
# 社員食堂の業者を選んだ報告

## 選んだ業者

3社から見積もりを取り、株式会社はなまるに決めました。
はなまるは、3社の中で一食あたりの値段が最も安く、420円です。

## 決めた理由

はなまるの献立は、日替わりの定食が3種類あり、より最適な組み合わせを選べます。
試食会では、参加した20人のうち16人が、はなまるの定食を選びました。
衛生の管理も、とても完璧でした。

## これから

1月の第2週から、はなまるの定食を出します。
3か月後に、もう一度、社員に食べた感想を聞きます。
```

## 直した文章

```markdown chaff-after
# 社員食堂の業者を選んだ報告

## 選んだ業者

3社から見積もりを取り、株式会社はなまるに決めました。
はなまるは、3社の中で一食あたりの値段が最も安く、420円です。

## 決めた理由

はなまるの献立は、日替わりの定食が3種類あり、その日の好みに合わせて選べます。
試食会では、参加した20人のうち16人が、はなまるの定食を選びました。
衛生の検査でも、調べた12項目すべてで基準を満たしていました。

## これから

1月の第2週から、はなまるの定食を出します。
3か月後に、もう一度、社員に食べた感想を聞きます。
```

## 直し方

「最適」は一番よいこと、「完璧」は欠けが無いことを言う語で、もともと程度がありません。「より最適な」「とても完璧」と書いても何も足されず、読み手は、書き手が語の意味を確かめずに強めたと受け取ります。
報告を読む人が知りたいのは、どこがどう良かったのかです。

直した文章では、「より最適な組み合わせを選べます」を「その日の好みに合わせて選べます」に、「衛生の管理も、とても完璧でした」を「衛生の検査でも、調べた12項目すべてで基準を満たしていました」に替えました。強める語の代わりに、確かめられることを書いています。

## 設定

ふだんは当てはまる言い回しが 1 箇所あれば指摘し、`relaxed` にすると 2 箇所からになります。

```yaml chaff-settings
rules:
  uncomparable-graded: relaxed
```

語彙表にある組み合わせだけを見ます。「ほぼ完璧」のように近さを言う語は指しません。「最も最適」のように最上を重ねた形は `redundant-expression` が見ます。
文学のジャンルでは止めています。
