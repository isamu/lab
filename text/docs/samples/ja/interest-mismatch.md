# 利息が残高に利率を掛けた額と合わない（`interest-mismatch`）

**こんな文書に:** 預金の満期のお知らせ、利息の計算書、貸付の明細。利率を見直したときに、計算の式の利率だけを直して、利息の額を前のままにする、という形がよくあります。

## 元の文章

```markdown chaff-before
件名：定期預金の満期のお知らせ

田中様

いつもありがとうございます。みどり信用金庫 青葉台支店です。

お預けいただいている定期預金が、12月15日に満期を迎えます。
金利の見直しにより、今回の利率は0.20%になりました。

お利息の計算：対象残高1,200,000円 × 利率0.20% ＝ 240円

お利息は、税金を差し引いて、満期の日に普通預金へお入れします。
ご不明な点は、窓口までお問い合わせください。
```

## 直した文章

```markdown chaff-after
件名：定期預金の満期のお知らせ

田中様

いつもありがとうございます。みどり信用金庫 青葉台支店です。

お預けいただいている定期預金が、12月15日に満期を迎えます。
金利の見直しにより、今回の利率は0.20%になりました。

お利息の計算：対象残高1,200,000円 × 利率0.20% ＝ 2,400円

お利息は、税金を差し引いて、満期の日に普通預金へお入れします。
ご不明な点は、窓口までお問い合わせください。
```

## 直し方

残高1,200,000円に利率0.20%を掛けると、利息は2,400円です。式の右側には240円と書いてあり、ちょうど十分の一になっています。前の利率0.02%のときの利息を残したまま、利率だけを直したのでしょう。
満期のお知らせを受け取った人は、この一行で、満期の日にいくら増えるのかを確かめます。式を書いてあるので計算し直す人もいて、そこで額が合わないと、お知らせ全体を信じられなくなります。

直した文章では、利息を2,400円にしました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  interest-mismatch: strict
```

一つの行に、残高の語（残高、元本）の後の金額、「×」、利率の語（利率、年利）の後の率、「＝」、利息の額と書いた行のうち、利息の語（利息、利子）がある行だけを比べます。端数は切り捨て、四捨五入、切り上げのどれでも合っていると読みます。日数を掛ける行のように「×」と「＝」が一つずつでない行、税引後の利息の行、表の中の数は比べません。年利のように期間を書いた利率は、利息の期間も同じと書いた行だけで比べます。
文学のジャンルでは止めています。税額の掛け算は `tax-mismatch` が見ます。
