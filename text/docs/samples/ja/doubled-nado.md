# 「など」と「等」の重ね（`doubled-nado`）

**こんな文書に:** 社内の通知、申請の案内、規程。「等」で書く文書と「など」で書く文書を行き来すると、書き直しの途中で両方が残ります。

## 元の文章

```markdown chaff-before
件名：出張の精算の締め切りについて

営業部のみなさま

お疲れさまです。経理課の大野です。

10月の出張の精算は、11月7日（金）までに出してください。
精算のときは、領収書等などの写しを、申請の画面に添付してください。
新幹線の切符は、乗車券と特急券の両方の写しが要ります。

分からないことがあれば、経理課の大野までお知らせください。

よろしくお願いします。
```

## 直し方

「領収書等など」は、「等」と「など」のどちらも「ほかにもある」と言っていて、意味は何も増えていません。
読み手には書き損じに見え、急いで書いた案内だという印象が残ります。

直した文章では「等」を消して、「領収書など」にしました。メールのやわらかい書き方に合わせて「など」を残しています。並べた物は変えていません。

## 設定

重ねた所が1箇所あれば指摘します。`relaxed` にすると、2箇所からです。

```yaml chaff-settings
rules:
  doubled-nado: relaxed
```

見るのは語彙表にある組だけです。「などなど」は話し言葉の強めなので数えません。

```text chaff-explain

```
