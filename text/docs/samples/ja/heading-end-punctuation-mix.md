# 見出しの終わりの記号が揃っていない（`heading-end-punctuation-mix`）

**こんな文書に:** 操作の手引き、手順書、社内の案内。ほかの資料から見出しごと段を写したとき、その見出しだけ「：」や「。」で終わっていることがあります。

## 元の文章

```markdown chaff-before
# 来客受付タブレットの使い方

## 電源を入れる

タブレットの右側にある丸いボタンを、3秒ほど押し続けます。

## お客さまの名前を入れる

画面の「受付」を押し、お客さまに名前と会社名を入れてもらいます。

## 担当者を呼び出す：

一覧から担当者を選ぶと、担当者の席の電話が鳴ります。

## 入館証を渡す

受付の引き出しから入館証を取り出し、お客さまに渡します。
```

## 直し方

この手引きの見出しは、どれも「電源を入れる」のように記号なしで終わっています。3番目の「担当者を呼び出す：」だけが「：」で終わっています。
読み手は、この手順だけ何か特別な扱いなのか、続きの説明が抜けているのかと迷います。目次に並べたときにも、そこだけ浮いて見えます。

ほかの見出しに合わせて、終わりの「：」を外しました。
chaff は、記号を付けるかどうかは決めません。同じ深さの見出しの中で少ないほうを指します。
深さごとに比べるので、一段深い見出しをすべて「任意：」のような札にする書き方は指しません。

## 設定

```yaml chaff-settings
rules:
  heading-end-punctuation-mix: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
同じ深さの見出しが四つ未満の所や、記号で終わる見出しと終わらない見出しが同じくらいある文書は指しません。どのジャンルでも動きます。Markdown の文書だけを見ます。

```text chaff-explain
$ npx chaffjs explain heading-end-punctuation-mix --genre docs/manual

  見出しの終わりの記号が揃っていない   (heading-end-punctuation-mix)

  ほとんどの見出しが「手順」「注意点」のように記号なしで終わるのに、一つだけ「準備：」「確認。」と記号で終わっていたり、その逆だったりすると、読み手はその見出しだけ別の扱いなのかと迷い、目次でも浮いて見えます。直し忘れや、別の文書から貼った見出しによく出る形です。どちらの書き方が正しいかは決めず、同じ深さの見出しのうち少ないほうを指します。深さごとに比べるので、一段深い見出しをすべて「任意：」のような札にする書き方は指しません。

  直しかた: 見出しの終わりを、多いほうの書き方に揃えてください。記号なしの見出しが多ければ「：」や「。」を外します。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax heading-end-punctuation-mix --why "理由"
```
