# 必要な見出しが無い（`required-sections`）

**こんな文書に:** 提案書、稟議書、議事録、障害の報告書。チームで「この節は必ず書く」と決めている文書です。

## 元の文章

```markdown chaff-before
# 受付にタブレットを置く提案

## 目的

来客の受け付けを、紙の名簿からタブレットに切り替えます。
来客の名前と会う相手が、担当者のチャットに届くようになります。

## 費用

タブレット2台と専用の台で、合わせて18万円です。
受け付けの仕組みの利用料は、月に3千円です。

## 進め方

4月に1台を置いて試し、5月から2台にします。
```

```yaml chaff-config
required_sections:
  - 費用
  - リスク
```

## 直した文章

```markdown chaff-after
# 受付にタブレットを置く提案

## 目的

来客の受け付けを、紙の名簿からタブレットに切り替えます。
来客の名前と会う相手が、担当者のチャットに届くようになります。

## 費用

タブレット2台と専用の台で、合わせて18万円です。
受け付けの仕組みの利用料は、月に3千円です。

## リスクと対策

社内の回線が止まると、タブレットでは受け付けられません。
そのときのために、紙の名簿も、すぐに出せる所に残しておきます。

## 進め方

4月に1台を置いて試し、5月から2台にします。
```

## 直し方

この部署では、提案書には費用とリスクの節を必ず書くと決めていました。決裁する人は、いくらかかるかと同じくらい、何が起きたら困るかを知りたいからです。
元の提案書は、目的と費用と進め方がよく書けていますが、リスクの節がありません。回線が止まった日に来客をどう受け付けるのかは、決裁の場で聞かれて初めて考えることになります。

直した文章では「リスクと対策」の節を足し、回線が止まったときのことと、そのときの手立てを書きました。
見出しは「リスク」の一語でなくても、「リスク」を含んでいれば満たします。

## 設定

この規則は、chaff.yaml の `required_sections` に並べた見出しだけを見ます。chaff は必須の見出しを持っていません。
提案書ならこの節、議事録ならこの節、という取り決めを、チームが自分で書きます。

```yaml chaff-settings
required_sections:
  # 決裁の前に必ず読む節
  - 目的
  - 費用
  - リスク
```

並べた語を含む見出しが文書のどこかにあれば満たします（「リスク」は「リスクと対策」でも満たす）。
チームが決めたのに守られていないことを表すので、ふだんは「エラー」として出し、1 つでも足りなければ指摘します。
`relaxed` にすると、2 つ以上足りないときだけ指摘します。

```yaml chaff-settings
rules:
  required-sections: relaxed
```

その節が本当に要らないと思うなら、黙らせるより `required_sections` から外すのが筋です。
どのジャンルでも動きます。`required_sections` が空なら、何も言いません。

```text chaff-explain

```
