# 生成文の特徴がそろっている（`ai-generated-composite`）

**こんな文書に:** ブログ、社内報、体験記。AI に下書きさせた記事を、そのまま出す前に通して読み直すための目印です。

## 元の文章

```markdown chaff-before
# ベランダでミニトマトを育てた夏

今年の五月、ベランダでミニトマトを育て始めました。
きっかけは、近所のホームセンターで苗が一つ二百円で売られていたことです。
正直、うまく育つとは思っていませんでした。

## 育て方

苗は二つ買い、深さ三十センチほどのプランターに一つずつ植えました。
背が伸びてきたところで、支柱を立てて茎をひもで結びました。
わき芽と呼ばれる、葉の付け根から出る小さな芽は、見つけるたびに摘みました。
水やりは朝に一回で、真夏の暑い日だけ夕方にもう一回あげています。

## 収穫

七月の初めに、最初の実が赤くなりました。
八月の終わりまでに採れたのは、二つの苗で合わせて百二十個ほどです。
一番たくさん採れた週は、毎朝の食卓に十個ずつ並びました。

## うまくいかなかったこと

八月の半ばに、実が割れてしまうことが続きました。
調べると、雨のあとに水を吸いすぎると割れやすいと分かり、雨の日の前は水やりを控えるようにしました。

このように、ベランダでも、思った以上にたくさんのミニトマトが採れました。
ぜひ、来年の春に挑戦してみてください。
きっと、毎朝ベランダに出るのが楽しみになるはずです。
```

今年の五月、ベランダでミニトマトを育て始めました。

## 直し方

元の文章には、一つずつなら普通の文章にもある特徴が三つそろっています。
「正直、」の前置き（`honesty-marker`）、同じ長さの文が続くこと（`sentence-rhythm`）、「ぜひ〜してみてください」「きっと〜はずです」の結び（`closing-exhortation`）です。
ブログの記事では、二つそろうと、このルールが読み直す場所として指します。

直した文章では、指摘を一つずつ直すのではなく、記事を通して読み直しました。
書きたかったのは、ベランダでも百二十個採れたことと、実が割れたときに何をしたかです。
前置きを消し、水やりの説明は短い文に分け、割れた実の話は「割れる実はほとんど無くなりました」と結果まで書いています。
結びは、励ましの代わりに、書き手が来年することを一文にしました。

## 設定

次の特徴が、同じ文書に3種そろうと指摘します。ブログ（`blog`）では2種からです。

`ai-tell`、`honesty-marker`、`rule-of-three`、`section-length-uniformity`、`sentence-rhythm`、`padded-intro`、`closing-cliche`、`no-em-dash`、`contrast-framing`、`stock-transition`、`assistant-residue`、`announcing-opener`、`colon-lead-in`、`ai-structure`、`over-general-claim`、`q-fragment-answer`、`closing-exhortation`、`unfilled-placeholder`、`bold-emphasis`

```yaml chaff-settings
rules:
  ai-generated-composite: relaxed
```

`relaxed` にすると、ブログでは3種から（ほかのジャンルは5種から）です。
同じ形を二つのルールが測るとき（節の長さのばらつきは `ai-structure` と `section-length-uniformity` の両方が見ます）は、1種として数えます。
法令・契約（`legal`）、手順書（`docs`）、文学（`literature`）、講演の書き起こし（`speech/transcript`）のジャンルでは、はじめから動きません。
そろっても、AI が書いたとは言いません。読み直す場所の目印です。

文章全体の AI らしさの目安は `npx chaffjs ai-score post.md` で見られます。
