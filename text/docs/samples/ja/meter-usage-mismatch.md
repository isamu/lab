# 指示数の差が使用量と合わない（`meter-usage-mismatch`）

**こんな文書に:** 電気・ガス・水道の検針のお知らせ、テナントに出す光熱費の明細、社宅の使用量の記録。指示数を写し間違えると、使用量と料金のどちらが正しいのか読み手には分かりません。

## 元の文章

```markdown chaff-before
# 電気ご使用量のお知らせ

ハイツみどり 203号室 様

検針日：11月12日

| 区分 | 指示数 |
| --- | --- |
| 今回指示数 | 31,460 |
| 前回指示数 | 31,050 |

ご使用量：390kWh
```

  ✖  指示数の差が使用量と合わない

## 直した文章

```markdown chaff-after
# 電気ご使用量のお知らせ

ハイツみどり 203号室 様

検針日：11月12日

| 区分 | 指示数 |
| --- | --- |
| 今回指示数 | 31,440 |
| 前回指示数 | 31,050 |

ご使用量：390kWh
```

## 直し方

使用量は、今回の指示数から前回の指示数を引いた値です。元の文章では 31,460 − 31,050 で410になり、書いてある使用量の390kWh と合いません。
メーターを読んだ人の控えには「31,440」と書いてありました。お知らせを作るときに、数を一つ打ち間違えていました。
受け取った人が引き算をすると、請求の額まで疑うことになります。テナントや入居者への明細なら、問い合わせへの答えに一件ずつ時間を取られます。

直した文章では、今回の指示数を控えのとおり31,440に直しました。
chaff は、同じ見出しの下に今回指示数・前回指示数・使用量が一つずつあれば、表に書いても「今回指示数：31,440」の行に書いても読み、差と使用量を比べます。乗率が書いてあれば、それも掛けます。
今回が前回より小さいときは、メーターが一巡したと書いてあれば桁の上限を足して比べます。メーターを取り替えたと書いてあれば比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「誤り」として出し、`relaxed` にすると「注意」になります。

```yaml chaff-settings
rules:
  meter-usage-mismatch: relaxed
```

昼と夜の二つのメーターのように、今回・前回・使用量のどれかが一つの見出しの下に二つある所は比べません。kWh と m³ のように単位が食い違う値も比べません。文芸のジャンルでは、はじめから動きません。
