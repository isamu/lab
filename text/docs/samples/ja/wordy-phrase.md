# 回りくどい言い回し（`wordy-phrase`）

**こんな文書に:** 社内の案内、報告書、メール。改まって書こうとすると、「することが可能です」「現時点において」と、一語で言えることに何語もかけます。

## 元の文章

```markdown chaff-before
件名：会議室の予約の仕方が変わります（12月1日から）

社員のみなさま

お疲れさまです。総務課の西です。

12月1日から、会議室の予約は、社内の予約画面で行います。
予約画面からは、空いている会議室を一覧で確認することが可能です。
予約は、使う日の二週間前から取れます。
現時点において、紙の予約表は11月末で終わりにする予定です。

使い方がわからないときは、総務課の西までご連絡ください。

よろしくお願いします。
```

## 直した文章

```markdown chaff-after
件名：会議室の予約の仕方が変わります（12月1日から）

社員のみなさま

お疲れさまです。総務課の西です。

12月1日から、会議室の予約は、社内の予約画面で行います。
予約画面からは、空いている会議室を一覧で確認できます。
予約は、使う日の二週間前から取れます。
現在の予定では、紙の予約表は11月末で終わりにする予定です。

使い方がわからないときは、総務課の西までご連絡ください。

よろしくお願いします。
```

## 直し方

「確認することが可能です」は「確認できます」、「現時点において」は「現在」と同じことです。一つ一つは誤りではありませんが、短い案内のメールに重なると、読み手は語を多く読むだけで、得るものは増えません。

直した文章では、「確認できます」「現在の予定では」と、短い形にしました。言っていることは変わっていません。

## 設定

回りくどい言い回しを含む文の数で見ます。ふだんは 2 文あれば指摘し、`strict` にすると 1 文から、`relaxed` にすると 4 文からです。

```yaml chaff-settings
rules:
  wordy-phrase: strict
```

一つだけなら書き手の癖とは言えないので、ふだんは 2 文からにしています。
人の書いた文章でもふつうの「することができる」は一覧に入れていません。翻訳調（を可能にする）は `translationese-density` が、「〜を行う」は `nominalization` が見ます。
法務、文学、話し言葉のジャンルでは止めています。
