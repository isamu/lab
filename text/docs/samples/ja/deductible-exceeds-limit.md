# 免責金額が支払限度額より大きい（`deductible-exceeds-limit`）

**こんな文書に:** 保険や保証サービスの重要事項の説明、補償の内容のお知らせ、パンフレット。限度額か免責金額の片方だけを直したときや、別の補償の数を写したときに、払われるはずのない補償が書かれます。

## 元の文章

```markdown chaff-before
# スマートフォン保証の内容

お使いのスマートフォンが壊れたときに、修理の費用をお支払いします。

## 画面の割れ

画面が割れたときの修理は、免責金額が1回5,000円、1回あたりの支払限度額が3,000円です。
修理は、全国の提携の修理店で受けられます。

## 水ぬれ

水にぬれて動かなくなったときは、同じ機種の新しい端末と交換します。
```

## 直し方

免責金額は、修理の費用のうち自分で払う額です。限度額は、保証が払う額の上限です。
免責金額が5,000円で限度額が3,000円なら、修理の費用から5,000円を引いた残りは、どんな修理でも3,000円までしか払われません。それどころか、3,000円の修理なら一円も払われません。読む人には、入っても役に立たない保証に見えます。
元の文章の「3,000円」は、30,000円の0を一つ落とした打ち間違えでした。

直した文章では、限度額を30,000円に直しました。
chaff は、一つの文に免責金額（自己負担額）と支払限度額（限度額）の語が一つずつあり、それぞれのすぐ後ろに金額があるときに比べます。「1回」「1事故」「1品」のように、何あたりの額かも読みます。
「1日」と「1回」のように入れ子にならない基準どうしは比べません。免責金額と限度額が同じ額のときも指摘しません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  deductible-exceeds-limit: strict
```

お客さまに出す文書を必ず止めたいなら `strict` にします。
免責金額と限度額を別の文に書いた所や、表の中の金額は比べません。「約5,000円」のような目安の額も比べません。文芸のジャンルでは、はじめから動きません。
