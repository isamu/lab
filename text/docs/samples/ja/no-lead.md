# 題の後の段落が題を言い直しているだけ（`no-lead`）

**こんな文書に:** 社内のお知らせ、報告書、ウェブに載せる記事。題のすぐ下に「この文書では〇〇についてお知らせします」と書き、本当に知らせたいことを後回しにする形がよくあります。

## 元の文章

```markdown chaff-before
# 社員食堂の営業時間の変更

この文書では、社員食堂の営業時間の変更についてお知らせします。

## 変更の中身

12月1日から、昼の営業を午前11時からに早め、午後2時までとします。夕方の営業はやめます。

## 変更の理由

夕方の利用が一日に10人ほどまで減ったためです。
```

## 直した文章

```markdown chaff-after
# 社員食堂の営業時間の変更

12月1日から、社員食堂は昼だけの営業になります。夕方に利用している方は、11月中に別の食事の当てを決めておいてください。

## 変更の中身

12月1日から、昼の営業を午前11時からに早め、午後2時までとします。夕方の営業はやめます。

## 変更の理由

夕方の利用が一日に10人ほどまで減ったためです。
```

## 直し方

このお知らせの最初の段落は、「社員食堂の営業時間の変更についてお知らせします」と、題をそのまま言い直しているだけです。
題の下の一段落は、読む人がこの先を読むかどうかを決める所です。そこに中身が無いと、忙しい人は、自分に関係があるのかも分からないまま閉じてしまいます。

直した文章では、最初の段落に、いつから何が変わるのかと、誰が何をしておけばよいかを書きました。
これで、夕方に食堂を使っている人は、最初の二文だけで自分に関係があると分かります。
最初の段落に書くことが無ければ、段落を消して本文の見出しから始めてもかまいません。

## 設定

この規則は、題を言い直しただけと見る境目が変わります。ふだんは、最初の段落が題に無い内容語を5個より少なくしか足していないときに指摘します。`strict` では6個、`relaxed` では3個です。

```yaml chaff-settings
rules:
  no-lead: relaxed
```

最初の段落が題の文字の並びの半分以上を繰り返していないとき（日付や書き手の名前の行、別の話題で始まる段落）は言いません。
題のすぐ下が箇条書き・表・画像なら、最初の段落が無いものとして見ません。
法令や契約（`legal`）、文学（`literature`）、話し言葉（`speech`）のジャンルでは動きません。
