# 参照に添えた名前が、参照先の見出しと違う（`reference-title-mismatch`）

**こんな文書に:** 社内規程、利用規約、契約書、手順書。章や条を足したり消したりして番号がずれたのに、参照のほうを直し忘れる形がよくあります。

## 元の文章

```markdown chaff-before
# 会議室の利用規程

## 第1章 予約

会議室は、社内の予約画面から、使う日の30日前から予約できます。
予約を取り消すときは、第3章「片付け」を見てください。

## 第2章 使い方

会議室では、飲み物のほかは口にしないでください。
プロジェクターは、使い終わったら電源を切ってください。

## 第3章 取り消し

予約を取り消すときは、前の日の17時までに予約画面から取り消してください。
それより後に取り消すときは、総務課に電話で伝えてください。

## 第4章 片付け

使い終わったら、机と椅子をもとの場所に戻してください。
```

## 直し方

第1章は、取り消しの決まりを「第3章「片付け」」で見るように書いています。けれども第3章の見出しは「取り消し」で、「片付け」は第4章です。
読む人は、番号と名前のどちらを信じればよいか分かりません。第3章を開いた人は名前が違うことに迷い、「片付け」を探した人は取り消しの決まりにたどり着けません。

あとから「取り消し」の章を第3章に差し込み、片付けの章が第4章にずれたと読めます。参照している話は取り消しなので、名前のほうを「取り消し」に直しました。
番号がずれたときは、ほかの参照も同じようにずれていないかを見てください。

## 設定

指摘の重さは「参考」だけです。見たくなければ `off` にします。

```yaml chaff-settings
rules:
  reference-title-mismatch: off
```

参照のすぐ後ろの括弧か引用符の中の名前を、参照先の見出しと比べます。どちらかがどちらかを含めば、合っていると見ます。
参照先が見出しを持たないとき、他の文書の条（民法第709条）、括弧の中が数字を含むか「前述」のような語のときは見ません。
どのジャンルでも動きます。
