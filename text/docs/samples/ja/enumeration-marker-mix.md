# 項目の番号の書き方が揃っていない（`enumeration-marker-mix`）

**こんな文書に:** 社内の手順書、申し込みの案内、規程の条文。前の版や別の文書から項目を貼り付けると、そこだけ番号の書き方が変わります。

## 元の文章

```markdown chaff-before
# 事務所の引っ越しの手順

来月の引っ越しに向けて、各自で次のことを済ませてください。

1. 机の中の私物を持ち帰る
2. 書類を段ボール箱に詰め、箱に名前を書く
3) パソコンの電源を切り、ケーブルを外す
4. 箱を窓際に並べる

わからないことは総務までお問い合わせください。
```

## chaff の指摘

```text chaff-output
$ npx chaffjs --no-guide --genre business/report moving.md

    3) パソコンの電源を切り、ケーブルを外す

  ·  項目の番号の書き方が揃っていない

     番号「3)」の書き方が、同じ並びのほかの番号（「1.」など 3 個）と違います
     「1.」「2.」と数えてきた並びの中に「3)」や「(3)」が一つ混ざると、読み手はそれが同じ並びの続きなのか、一段下の項目なのか迷います。Markdown は「1.」と「1)」が変わる所でリストを二つに分け、「(1)」「①」「一、」「a.」はリストとして読みません。貼り付けや書き換えの途中でよく起きる形です。どの書き方が正しいかは決めず、一つのリストの同じ深さか、続けて番号を振った段落の並びのうち、少ないほうの書き方で、ほかの番号の続きを数えている項目だけを指します。

     → 並びの多くの番号と同じ書き方に揃えてください。一段下の項目のつもりなら、字下げして 1 から数え直してください。

     このルールをゆるめる:  npx chaffjs relax enumeration-marker-mix

              （同じ文章なら何度実行しても同じ結果になります）

  文章は書き換えていません。直すのは書いた人です。
```

## 直した文章

```markdown chaff-after
# 事務所の引っ越しの手順

来月の引っ越しに向けて、各自で次のことを済ませてください。

1. 机の中の私物を持ち帰る
2. 書類を段ボール箱に詰め、箱に名前を書く
3. パソコンの電源を切り、ケーブルを外す
4. 箱を窓際に並べる

わからないことは総務までお問い合わせください。
```

## 直し方

手順の番号は「1.」「2.」「4.」と書かれていますが、三つ目だけが「3)」です。
読み手は、そこから別の並びが始まるのか迷います。Markdown も「1.」と「1)」が変わる所で一覧を二つに分け、間を空けて表示します。

三つ目の番号を、ほかと同じ「3.」にそろえました。
chaff は、どの書き方が正しいかは決めません。一つの並びのうち、少ないほうの書き方で、ほかの番号の続きを数えている項目を指します。

## 設定

```yaml chaff-settings
rules:
  enumeration-marker-mix: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
「1.」の下で「(1)」「(2)」と 1 から数え直す項目は一段下の並びと読み、指しません。Markdown でない文書（.txt）の番号付きの段落も見ます。

```text chaff-explain
$ npx chaffjs explain enumeration-marker-mix --genre business/report

  項目の番号の書き方が揃っていない   (enumeration-marker-mix)

  「1.」「2.」と数えてきた並びの中に「3)」や「(3)」が一つ混ざると、読み手はそれが同じ並びの続きなのか、一段下の項目なのか迷います。Markdown は「1.」と「1)」が変わる所でリストを二つに分け、「(1)」「①」「一、」「a.」はリストとして読みません。貼り付けや書き換えの途中でよく起きる形です。どの書き方が正しいかは決めず、一つのリストの同じ深さか、続けて番号を振った段落の並びのうち、少ないほうの書き方で、ほかの番号の続きを数えている項目だけを指します。

  直しかた: 並びの多くの番号と同じ書き方に揃えてください。一段下の項目のつもりなら、字下げして 1 から数え直してください。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax enumeration-marker-mix --why "理由"
```
