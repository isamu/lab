# 当事者を、定めた呼び名でなく立場の語で書いている（`party-role-name`）

**こんな文書に:** 秘密保持契約、業務委託契約、売買の契約書。ひな形の条文を貼り合わせると、元のひな形の「開示者」「受領者」のような呼び方が、そのまま残ることがあります。

## 元の文章

```markdown chaff-before
# 秘密保持契約書

株式会社さくら設計（以下「甲」という。）と株式会社こだま工業（以下「乙」という。）は、新しい部品の共同開発の検討にあたり、次のとおり契約を結ぶ。

## 第1条（秘密の保持）

乙は、甲から受け取った図面と仕様書を、ほかの者に見せてはならない。

## 第2条（返還）

受領者は、検討を終えたときは、受け取った図面と仕様書を甲に返す。

## 第3条（期間）

この契約は、結んだ日から2年間効力を持つ。
```

## 直した文章

```markdown chaff-after
# 秘密保持契約書

株式会社さくら設計（以下「甲」という。）と株式会社こだま工業（以下「乙」という。）は、新しい部品の共同開発の検討にあたり、次のとおり契約を結ぶ。

## 第1条（秘密の保持）

乙は、甲から受け取った図面と仕様書を、ほかの者に見せてはならない。

## 第2条（返還）

乙は、検討を終えたときは、受け取った図面と仕様書を甲に返す。

## 第3条（期間）

この契約は、結んだ日から2年間効力を持つ。
```

## 直し方

この契約は、前文で二つの会社を「甲」と「乙」と呼ぶと定めています。ところが第2条だけ、「受領者」と書いています。
読み手は、受領者が乙のことなのか、乙から図面を受け取った別の会社まで含むのかを確かめなければなりません。図面を返す義務を負うのはだれか、という大事な所があいまいになります。

第2条の「受領者」を、定めた呼び名の「乙」に書き換えました。
当事者でない人（再委託先など）を指したいときは、その人を前もって定義してから使います。

## 設定

```yaml chaff-settings
rules:
  party-role-name: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
契約などの法務のジャンルで動きます。法令や説明書、論文、文芸、講演のジャンルでは、はじめから動きません。
