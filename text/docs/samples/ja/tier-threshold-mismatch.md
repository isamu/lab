# 会員の値が、書いたランクの基準に当たらない（`tier-threshold-mismatch`）

**こんな文書に:** ポイントの明細、宿泊や航空の会員の案内、取引先の格付けの通知。会員の値を書き換えたのに、ランクを直し忘れたときに起きます。

## 元の文章

```markdown chaff-before
# 2026年度 会員ランクのお知らせ

1年間のお買い物で貯まったポイントから、来年度の会員ランクを決めました。

- 会員ランク：ゴールド
- 年間獲得ポイント：42,400ポイント

| ランク | 年間獲得ポイント |
| --- | --- |
| ブロンズ | 10,000ポイント未満 |
| シルバー | 10,000ポイント以上50,000ポイント未満 |
| ゴールド | 50,000ポイント以上 |

ランクの特典は、4月1日から使えます。
```

## 直した文章

```markdown chaff-after
# 2026年度 会員ランクのお知らせ

1年間のお買い物で貯まったポイントから、来年度の会員ランクを決めました。

- 会員ランク：シルバー
- 年間獲得ポイント：42,400ポイント

| ランク | 年間獲得ポイント |
| --- | --- |
| ブロンズ | 10,000ポイント未満 |
| シルバー | 10,000ポイント以上50,000ポイント未満 |
| ゴールド | 50,000ポイント以上 |

ランクの特典は、4月1日から使えます。
```

## 直し方

この会員の年間獲得ポイントは42,400ポイントで、表ではシルバーの基準に当たります。けれども明細には「ゴールド」と書いてあります。
会員は、ゴールドの特典を使えるつもりで店に来て、使えないと分かって窓口で問い合わせます。

ポイントの記録を確かめると42,400ポイントで合っていたので、ランクをシルバーに直しました。
ポイントのほうが写し間違いなら、そちらを直します。
chaff は、文書のランクの表か箇条書きの基準と、同じ節に書いた会員のランクと値を比べます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  tier-threshold-mismatch: strict
```

ランクの名前が表や箇条書きの名前と同じ字で、基準と会員の値が同じ単位（ポイント、泊、回、円）のときだけ比べます。
下の端だけを書いたランク（20泊以上）は、一つ上のランクが始まる手前までと読みます。残高や、次のランクまでに要る数の行は、会員の値に数えません。
同じ節にその単位の会員の値が二つ以上あるもの、基準の幅が重なるもの、文の中に書いたランクや値は比べません。文芸のジャンルでは、はじめから動きません。
