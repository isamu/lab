# 本文に体言止めが多い（`taigen-dome-in-prose`）

**こんな文書に:** お店や地域の紹介記事、広報誌、ブログ。歯切れよく見せようとして、文を名詞で止め続けがちな文章です。

```markdown chaff-before
駅から歩いて五分、商店街の角にある豆腐店を訪ねました。

店主は、この道四十年の吉川さん。

使う大豆は、隣の県の農家から仕入れる在来種。

最近は、豆乳を使ったドーナツを目当てに、週末になると電車を乗り継いで遠くから来るお客さんも増えていて、昼過ぎには棚が空になる日もあるそうです。
わたしも一つ買って帰りました。
```

## 直した文章


## 直し方

元の記事は、本文の六つの文が名詞で止まっています。
一つなら歯切れよく見えますが、続くと文が途中で切れたように読め、店主がどうしたのか、大豆がどうなのかを、読み手が補うことになります。

直した文章では、述語を足して文を最後まで言い切りました。
「この道四十年の吉川さん」は「四十年豆腐を作ってきました」に、「先代から受け継いだ石臼」は「今も置かれています」になり、記事の中の動きが見えるようになります。

箇条書きの中の体言止めは、普通の書き方なので数えません。「〜か。」で閉じた問いも数えません。

## 設定

本文の体言止めが四つまでなら指摘しません。`strict` にすると二つ、`relaxed` にすると八つまでです。
法務・文学のジャンル、用語集、話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  taigen-dome-in-prose: relaxed
```

見ないことにするなら `taigen-dome-in-prose: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax taigen-dome-in-prose --why "見出しのように短く書く広告の文案のため"
```
