# 中黒の並びが多すぎる（`no-nakaguro-parallel`）

**こんな文書に:** 報告書、お知らせ、企画書。対象や条件を「・」でつないで一文に並べがちな文書です。

## 元の文章

```markdown chaff-before
# 冬の節電の取り組みについて

総務課から、電気代を抑えるために今年の冬に全社で取り組むことをお知らせします。

対象は東京・大阪・名古屋・横浜の四つの事務所と、札幌・仙台・広島・福岡の四つの営業所で、暖房の設定を20度にします。
期間は12月1日から2月末までです。
```

## 直した文章

```markdown chaff-after
# 冬の節電の取り組みについて

総務課から、電気代を抑えるために今年の冬に全社で取り組むことをお知らせします。

暖房の設定を20度にするのは、次の事務所と営業所です。

- 事務所: 東京、大阪、名古屋、横浜
- 営業所: 札幌、仙台、広島、福岡

期間は12月1日から2月末までです。
```

## 直し方

元の文は「東京・大阪・名古屋・横浜」と「札幌・仙台・広島・福岡」の二組を一文に入れていて、中黒が6個あります。
読み手は、どこまでが事務所でどこからが営業所なのかを、「の四つの事務所と」の所まで読んでから区切り直すことになります。
そのあとに「暖房の設定を20度にします」という肝心の中身が来るので、文の頭を忘れがちです。

直した文章では、まず何をするのかを一文で言い、対象の事務所と営業所を箇条書きにしました。
組の切れ目が行で分かれ、自分の事業所が入っているかどうかが一目で探せます。

行の頭の「・」は箇条書きの印なので数えません。

## 設定

一文の中黒が五個までなら指摘しません。`strict` にすると三個、`relaxed` にすると八個までです。
文学のジャンルと話し言葉の書き起こしでは、既定で止めています。

```yaml chaff-settings
rules:
  no-nakaguro-parallel: relaxed
```

見ないことにするなら `no-nakaguro-parallel: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax no-nakaguro-parallel --why "製品の型番を中黒で並べる仕様の一覧のため"
```
