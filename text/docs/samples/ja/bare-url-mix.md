# 言葉のリンクの中に URL がそのまま混ざっている（`bare-url-mix`）

**こんな文書に:** 社内の手引き、利用の案内、ヘルプのページ。ほかのチャットやメールから URL を貼り付けたまま、言葉のリンクに書き直し忘れることがよくあります。

## 元の文章

```markdown chaff-before
# 入社した日にすること

入社おめでとうございます。初日は、次の順に進めてください。

1. [社員番号の確認ページ](https://intra.example.com/id)で、自分の社員番号を確かめます。
2. [パスワードの決め方](https://intra.example.com/password)を読んで、最初のパスワードを変えます。
3. [勤怠の入力画面](https://intra.example.com/timecard)で、出勤を記録します。
4. 経費の精算は https://intra.example.com/expense から申請します。

分からないことがあれば、[情報システム課の窓口](https://intra.example.com/helpdesk)に聞いてください。
```

## 直した文章

```markdown chaff-after
# 入社した日にすること

入社おめでとうございます。初日は、次の順に進めてください。

1. [社員番号の確認ページ](https://intra.example.com/id)で、自分の社員番号を確かめます。
2. [パスワードの決め方](https://intra.example.com/password)を読んで、最初のパスワードを変えます。
3. [勤怠の入力画面](https://intra.example.com/timecard)で、出勤を記録します。
4. 経費の精算は[経費の申請画面](https://intra.example.com/expense)から申請します。

分からないことがあれば、[情報システム課の窓口](https://intra.example.com/helpdesk)に聞いてください。
```

## 直し方

この手引きのリンクは、どれも「勤怠の入力画面」のように行き先の名前で書かれています。
4番目だけが URL のまま本文に出ているので、入ったばかりの人は記号の列を読み、どんな画面が開くのかを URL から推し量ることになります。

URL は変えずに、行き先を「経費の申請画面」という言葉にしてリンクにしました。
ほかの手順と同じ書き方になり、上から順に読むだけで、どこで何をするのかが分かります。
URL そのものを見せたいときは、山括弧で囲んで `<https://…>` と書けば、chaff はわざとそう書いたと読みます。

## 設定

言葉のリンクが一定の数より少ない文書は、どちらが文書の書き方か決まらないので指しません。

```yaml chaff-settings
rules:
  bare-url-mix: strict
```

`strict` にすると、言葉のリンクが少ない文書でも指摘します。`relaxed` にすると、言葉のリンクが多い文書だけで指摘します。見たくなければ `off` にします。
どのジャンルでも動きます。Markdown の文書だけを見ます。

```text chaff-explain
$ npx chaffjs explain bare-url-mix --genre docs/manual

  言葉のリンクの中に URL がそのまま混ざっている   (bare-url-mix)

  文書のリンクがほとんど「[導入の手引き](https://…)」のように言葉で書かれているのに、一部だけ「https://…」がそのまま本文に出ていると、そこだけ読み手は長い記号の列を読まされ、行き先が何かを URL から推し量ることになります。言葉のリンクに揃っていない所は、書き直し忘れのことが多い形です。どちらの書き方が正しいかは決めません。URL をそのまま書く文書（言葉のリンクが少ない文書、URL のほうが多い文書）は指しません。

  直しかた: 行き先の名前を言葉にしてリンクにしてください（[導入の手引き](https://…)）。URL そのものを見せたいときは、山括弧で囲んでリンクにします（<https://…>）。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値:
    strict   言葉のリンクが 2 個以上ある文書で指摘
  → normal   言葉のリンクが 3 個以上ある文書で指摘
    relaxed  言葉のリンクが 5 個以上ある文書で指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax bare-url-mix --why "理由"
```
