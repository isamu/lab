# 一文だけの段落が続く（`one-sentence-paragraph-run`）

**こんな文書に:** 技術記事、ブログ、社内報。画面で読みやすいようにと、一文ごとに空行を入れがちな文章です。

## 元の文章

```markdown chaff-before
# 社内の勉強会を一年続けてわかったこと

去年の春から、チームで週に一度、昼休みに三十分の勉強会を開いています。

最初の三か月は、毎回十人ほどが集まりました。

ところが夏になると、参加する人が半分に減りました。

理由を聞くと、発表の準備が重いという声が一番多くありました。

そこで、発表は五分だけにして、残りの時間は質問と雑談にあてることにしました。

秋からは、参加する人がまた十人ほどに戻っています。

発表の題は、共有の表に誰でも書き込めるようにしてあります。
```

## 直した文章

```markdown chaff-after
# 社内の勉強会を一年続けてわかったこと

去年の春から、チームで週に一度、昼休みに三十分の勉強会を開いています。

最初の三か月は、毎回十人ほどが集まりました。
ところが夏になると、参加する人が半分に減りました。
理由を聞くと、発表の準備が重いという声が一番多くありました。

そこで、発表は五分だけにして、残りの時間は質問と雑談にあてることにしました。
秋からは、参加する人がまた十人ほどに戻っています。
発表の題は、共有の表に誰でも書き込めるようにしてあります。
```

## 直し方

元の記事は、一文ごとに空行を入れていて、一文だけの段落が7つ続いています。
画面では軽く見えますが、どの文とどの文が同じ話なのかが見えません。
参加する人が減った話と、手を打った話と、戻った話の切れ目を、読み手が自分で探すことになります。

直した文章では、同じ話の文を一つの段落にまとめました。
「減ったこととその理由」と「変えたこととその結果」の二つの段落になり、記事の筋が段落の形で見えます。

見出し・箇条書き・表・コードを挟んだ所で数え直します。一文の段落を一つだけ置いて強調するのは、指摘しません。

## 設定

一文だけの段落が四つ続くまでなら指摘しません。`strict` にすると三つ、`relaxed` にすると六つまでです。
法務・文学のジャンルと話し言葉の書き起こしでは、条項や台詞を一文ずつ立てるのが形なので、既定で止めています。

```yaml chaff-settings
rules:
  one-sentence-paragraph-run: relaxed
```

見ないことにするなら `one-sentence-paragraph-run: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax one-sentence-paragraph-run --why "一文ずつ区切って読ませる広報の記事のため"
```
