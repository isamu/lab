# 太字が多すぎる（`bold-density`）

**こんな文書に:** 社内の手引き、報告書、引き継ぎの資料。大事なことを落とされまいとして、太字を足していきがちな文書です。

## 元の文章

```markdown chaff-before
# 新しく入った人への引き継ぎ

総務課の受付の仕事を、来月から担当してもらう人に向けたメモです。

## 受付の一日

受付は**8時45分**に開けます。
まず**来客の予定表**を確かめ、その日に来るお客さまの名前を入館証の箱の横に貼ります。
宅配便は**受付の奥の棚**に置き、宛名の部署へ**昼までに**連絡してください。
会議室の鍵は**総務課の金庫**にあり、借りた人の名前を**貸出簿**に書いてもらいます。
返ってこない鍵があれば、**17時**に借りた人へ連絡します。
お客さまに飲み物を出すときは、**給湯室の右の棚**の紙コップを使ってください。
午後は郵便物の仕分けがあり、届いた封筒を部署ごとの箱に分けて入れていきます。
分からないことがあれば、隣の席の私に遠慮なく聞いてください。
```

## 直し方

元の節は255字に太字が8箇所あり、時刻も場所も帳簿の名前も太字です。
どれも大事なことですが、全部が太いと、目はどこにも止まりません。
引き継ぎを受ける人がいちばん落としてはいけないことが、ほかの太字に埋もれてしまいます。

直した文章では、太字を「昼までに」の一つだけ残しました。宅配便の連絡が遅れると、受け取る部署が困るからです。
ほかの時刻や場所は、普通の文のままでも読めば分かります。
覚えてほしい項目が多いなら、太字を足すより、箇条書きや表にするほうが探しやすくなります。

chaff は節ごとに、1000字あたりの太字の数で見ます。200字より短い節は、1箇所で割合が大きく動くので測りません。
行の頭に置いた短い項目名（**日時：**）も、強調ではないので数えません。

## 設定

ふだんは1000字あたり20箇所までです。`strict` にすると10箇所、`relaxed` にすると40箇所までになります。

```yaml chaff-settings
rules:
  bold-density: relaxed
```

見ないことにするなら `bold-density: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax bold-density --why "画面の操作の名前を太字で書く決まりのため"
```
