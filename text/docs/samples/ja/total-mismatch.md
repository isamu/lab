# 合計が内訳の和と合わない（`total-mismatch`）

**こんな文書に:** 見積書、請求書、予算の表。項目を一行足したのに、下の合計を前のままにしてしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 御見積書

株式会社みなと企画 御中

11月に開く新商品の発表会について、会場の設営を次のとおりお見積りします。

| 項目 | 金額 |
| --- | --- |
| 会場の使用料（1日） | 180,000円 |
| 音響と照明 | 95,000円 |
| 受付の係（2名） | 48,000円 |
| 看板と案内の表示 | 32,000円 |
| 合計 | 323,000円 |

金額には消費税を含みません。
この見積りは、発行の日から30日の間有効です。
```

| 項目 | 金額 |

| 受付の係（2名） | 48,000円 |

## 直し方

四つの項目を足すと355,000円ですが、合計の行は323,000円です。323,000円は、看板と案内の表示を除いた三つの項目の和です。あとから看板の行を足して、合計を直し忘れたのでしょう。
受け取った人が合計だけを見て発注すると、請求の段で32,000円が増えます。気づいた人は、看板が見積りに入っているのかいないのかを問い合わせることになります。

直した文章では、看板の行を残して、合計を355,000円にしました。看板が要らないなら、行を消して合計を323,000円のままにします。どちらにするかは書いた人が決めることで、chaff は数が合わないことだけを示します。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  total-mismatch: relaxed
```

表か箇条書きで「合計」「小計」で始まる行を、同じ列の同じ単位の金額の和と比べます。「設計5,000円、開発6,000円とし、合計11,000円とする」のように一つの文に書いた合計も比べます。小計のあとの総計のように足し方が何通りかあるときは、どの足し方でも合わないときだけ指摘します。
文学のジャンルでは止めています。税の額の計算は `tax-mismatch` が、数量と単価の掛け算は `line-amount-mismatch` が見ます。
