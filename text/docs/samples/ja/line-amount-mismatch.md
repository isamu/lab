# 数量×単価が金額と合わない（`line-amount-mismatch`）

**こんな文書に:** 請求書や見積書や納品書の明細。数量を後から増やしたのに、その行の金額を前のままにする、という形がよくあります。

## 元の文章

```markdown chaff-before
# 請求書

さくら歯科医院 御中

11月にご注文いただいた印刷物について、次のとおりご請求します。

| 品目 | 数量 | 単価 | 金額 |
| --- | --- | --- | --- |
| 名刺（100枚入り） | 3箱 | 2,200円 | 4,400円 |
| 診察券 | 500枚 | 30円 | 15,000円 |
| 予約の案内のはがき | 300枚 | 45円 | 13,500円 |
| 合計 | | | 32,900円 |

金額には消費税を含みます。
```

  ✖  数量×単価が金額と合わない

     金額「4,400円」が、数量×単価（3箱 × 2,200円 = 6,600円）と合いません
     見積書や請求書の明細で、数量と単価を掛けた額がその行の金額と合わないと、読み手はどれが正しいのかを問い合わせることになります。数量か単価だけを直して金額を直し忘れたときに起きます。見出しに数量・単価・金額の列がある表で、行ごとに数量の升の頭の数と単価を掛け、金額の升と比べます。商品カタログの入数・単価・1箱の価格の列がある表では、入数 × 単価を1箱の価格と比べます。項目の升の括弧に書いた掛け算（会費（3,000円×24名））も、名や世帯で数えた数と金額の一つずつなら掛けて、その行のただ一つの金額と比べます。

## 直した文章

```markdown chaff-after
# 請求書

さくら歯科医院 御中

11月にご注文いただいた印刷物について、次のとおりご請求します。

| 品目 | 数量 | 単価 | 金額 |
| --- | --- | --- | --- |
| 名刺（100枚入り） | 3箱 | 2,200円 | 6,600円 |
| 診察券 | 500枚 | 30円 | 15,000円 |
| 予約の案内のはがき | 300枚 | 45円 | 13,500円 |
| 合計 | | | 35,100円 |

金額には消費税を含みます。
```

## 直し方

名刺は3箱で、1箱2,200円なので、金額は6,600円です。表には4,400円と書いてあります。2箱の注文が3箱に増えたとき、数量だけを直したのでしょう。
合計の32,900円は、三つの金額を足した額と合っています。合計の足し算に誤りが無いので、読む人は明細の一行の掛け算までは確かめず、2,200円少ない額が請求されます。

直した文章では、名刺の金額を6,600円にし、合計も35,100円に直しました。数量のほうが誤りなら、数量を「2箱」に戻します。

## 設定

ふだんは「エラー」として出します。`relaxed` にすると「注意」になり、`off` にすると見なくなります。

```yaml chaff-settings
rules:
  line-amount-mismatch: relaxed
```

見出しに数量、単価、金額の三つの列がそろった表だけを、行ごとに比べます。端数は切り捨て、四捨五入、切り上げのどれでも合っていると読みます。「1式」は1と読みます。単価が「10,000円/時」のように何かあたりで、数量が別の単位の行や、値引きや税率のようにほかの列にも数のある行は比べません。
文学のジャンルでは止めています。合計の足し算は `total-mismatch` が見ます。
