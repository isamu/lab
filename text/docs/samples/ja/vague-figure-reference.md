# 図や表、箇条を「上記の図」のように指している（`vague-figure-reference`）

**こんな文書に:** 報告書、企画書、仕様書。図や表に番号を付けているのに、本文では「上の図」「下の表」と置き場所で指す形がよくあります。

## 元の文章

```markdown chaff-before
# 配送センターの残業時間 半期報告

## 残業時間の推移

![月ごとの残業時間のグラフ](zangyo.png)

図1　月ごとの一人あたりの残業時間

![曜日ごとの荷物の数のグラフ](nimotsu.png)

図2　曜日ごとの荷物の数

一人あたりの残業時間は、上の図のとおり、8月に月32時間まで増えました。荷物の多い月曜日に、残業が集まっています。
```

  ⚠  図や表、箇条を「上記の図」のように指している

     「上の図」ではなく、番号で指してください（この文書は図に番号を付けています）
     「上記の図」「下の表」は、どの図のことかを読み手に探させます。図を足したり動かしたりすると、指す先が黙って変わります。印刷やページの区切り、画面の幅で「上」「下」も変わります。JIS Z 8301:2019 の 10.6 は「上記の図」「以下の箇条」のような引用をしないとしています。図や表に番号を付けている文書なら、「図 3」のように番号で指せます。箇条も、条や章に番号を付けている文書なら「箇条 4」のように指せます。番号を一つも付けていない種類は見ません。

     → 指している図や表、箇条の番号を書いてください。「上記の図のとおり」は「図 3 のとおり」に、「以下の箇条による」は「箇条 5 による」に。

     このルールをゆるめる:  npx chaffjs relax vague-figure-reference

## 直した文章

```markdown chaff-after
# 配送センターの残業時間 半期報告

## 残業時間の推移

![月ごとの残業時間のグラフ](zangyo.png)

図1　月ごとの一人あたりの残業時間

![曜日ごとの荷物の数のグラフ](nimotsu.png)

図2　曜日ごとの荷物の数

一人あたりの残業時間は、図1のとおり、8月に月32時間まで増えました。図2のとおり荷物の多い月曜日に、残業が集まっています。
```

## 直し方

この報告書は、図に「図1」「図2」と番号を付けています。ところが本文は「上の図のとおり」と、置き場所で図を指しています。
本文のすぐ上にあるのは、曜日ごとの荷物の数の図2です。残業時間の増え方を見せたいのは図1なので、読む人はどちらの図のことか迷います。
資料を印刷したり、画面の幅を変えたりすると、図の位置はさらに変わります。図を一つ足しただけでも、「上の図」の指す先は黙って変わります。

直した文章では、「図1のとおり」「図2のとおり」と、番号で指すように直しました。
番号で指せば、図がどこに置かれても、読む人は迷いません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  vague-figure-reference: relaxed
```

図や表、条や章に番号を付けている文書で、その種類を「上記の図」「下の表」「以下の箇条」と置き場所で指した所だけを見ます。番号を一つも付けていない種類は、番号で指しようがないので見ません。
「上の図1」のように番号を添えた言い方と、「向上の図」のような長い語の一部は指しません。
文学（`literature`）のジャンルでは動きません。
