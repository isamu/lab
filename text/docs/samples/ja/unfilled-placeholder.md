# 埋め忘れた空欄（`unfilled-placeholder`）

**こんな文書に:** 取引先へのメール、見積書、案内状。雛形や下書きから作ったメールでは、宛名や日付の空欄が埋まらないまま送られることがあります。

## 元の文章

```markdown chaff-before
件名：打ち合わせのお礼

株式会社〇〇
〇〇様

お世話になっております。あおば設計の藤田です。
本日はお忙しいところ、打ち合わせのお時間をいただき、ありがとうございました。

お話しいただいた事務所の改装の件は、【日付】までに図面の案をお送りします。
費用の見積もりも、図面と一緒にお送りします。

引き続き、よろしくお願いいたします。
```

## 直した文章

```markdown chaff-after
件名：打ち合わせのお礼

株式会社さくら物産
総務部 中田様

お世話になっております。あおば設計の藤田です。
本日はお忙しいところ、打ち合わせのお時間をいただき、ありがとうございました。

お話しいただいた事務所の改装の件は、12月5日（金）までに図面の案をお送りします。
費用の見積もりも、図面と一緒にお送りします。

引き続き、よろしくお願いいたします。
```

## 直し方

「株式会社〇〇」「〇〇様」「【日付】」は、雛形の空欄が埋まらないまま残っています。
宛名が空欄のままのお礼のメールは、受け取った人に、使い回しの文だと伝わってしまいます。図面を送る日も分からず、相手は予定を立てられません。

直した文章では、宛名に会社と担当の方の名前を、日付に図面を送る日を書き入れました。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  unfilled-placeholder: strict
```

文の中で例として置いた「○○」（「○○のような場合」）は正しい書き方なので数えません。値が続く見出しの札（【氏名】山田）や、コードのコメントの TODO も指しません。
