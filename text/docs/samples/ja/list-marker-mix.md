# 箇条書きの記号が揃っていない（`list-marker-mix`）

**こんな文書に:** 出張や行事の案内、社内の手順、議事録。メールやチャットから箇条書きを貼り付けると、そこだけ「*」や「・」の記号が残ります。

## 元の文章

```markdown chaff-before
# 工場見学の案内

来週の木曜日に、取引先の工場を見学します。参加する人は、次のことを確かめてください。

## 集合

- 午前8時30分に本社の正面玄関に集まります
- 貸し切りのバスで向かいます

## 持ち物

* 社員証
* 動きやすい靴
* 筆記用具

## 当日の注意

- 工場の中では、写真を撮らないでください
- 案内の人から離れないでください

## 帰り

- 午後4時に工場を出ます
- 本社に着くのは午後5時30分ごろです
```

## 直した文章

```markdown chaff-after
# 工場見学の案内

来週の木曜日に、取引先の工場を見学します。参加する人は、次のことを確かめてください。

## 集合

- 午前8時30分に本社の正面玄関に集まります
- 貸し切りのバスで向かいます

## 持ち物

- 社員証
- 動きやすい靴
- 筆記用具

## 当日の注意

## 帰り
```

## 直し方

この案内の箇条書きは、ほとんどが「-」で始まっています。持ち物の一覧だけが「*」で書かれています。
表示はどちらも同じ点になりますが、元の文章を手直しする人には、ここだけ別の文書から貼ったように見えます。一つの一覧の途中で記号を変えると、Markdown はそこで一覧を二つに分けてしまい、間が空いて表示されます。

持ち物の記号を、ほかと同じ「-」にそろえました。
chaff は、どの記号が正しいかは決めません。同じ深さの一覧のうち、少ないほうを指します。

## 設定

```yaml chaff-settings
rules:
  list-marker-mix: strict
```

ふだんは参考として出します。`strict` にすると注意として出します。見たくなければ `off` にします。
一覧の項目の中で行頭に「・」を打った所も、箇条書きにならず前の行につながるので指します。どのジャンルでも動きます。Markdown の文書だけを見ます。

```text chaff-explain
$ npx chaffjs explain list-marker-mix --genre business/report

  箇条書きの記号が揃っていない   (list-marker-mix)

  箇条書きの記号（「-」「*」「+」「・」）が混ざると、Markdown は書き手の思ったとおりに表示しません。一つのリストの途中で記号を変えると、そこでリストが二つに分かれて間が空きます。リストの項目の中で行頭に「・」を打つと、箇条書きにならず前の項目の行につながります。文書の中で一つのリストだけ記号が違うのは、別の文書から貼ったか、書き換えの途中のことが多い形です。どの記号が正しいかは決めず、同じ深さのリストのうち少ないほうを指します。

  直しかた: 箇条書きの記号を、文書の多くのリストと同じものに揃えてください。「・」で始めた行は、「- 」で始まる項目にします。

  書き直しの深さ: light（語と文を直す。構成と文体は残す）。chaff fix-plan --depth でこれより浅い深さを選ぶと、計画はこのルールを直さず、名前だけを挙げます。

  設定できる値（数える上限は無く、指摘の重さが変わります）:
    strict   注意
  → normal   参考
    relaxed  参考
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax list-marker-mix --why "理由"
```
