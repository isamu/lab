# よくある書き誤り（`known-misspelling`）

**こんな文書に:** 報告書、企画書、社内報。耳で覚えたカタカナ語は、聞こえたとおりの字で書かれがちです。

## 元の文章

```markdown chaff-before
# 新しい受付の流れの試行の報告

総務課で、来客の受付の流れを10月の2週間だけ試しました。その結果を報告します。

試す前に、受付で起きそうなことを書き出して、シュミレーションを三回しました。
本番では、来客を待たせた時間が、一人あたり平均で4分から2分に縮みました。

一方で、受付と各課のコミニュケーションには、まだ手間が残っています。
来客の名前と用件を、内線で一人ずつ伝えているためです。
来月は、名前と用件を画面で各課に送る仕組みを試します。
```

## 直し方

「シュミレーション」「コミニュケーション」は、耳で覚えた形がそのまま残った書き誤りです。正しくは「シミュレーション」「コミュニケーション」です。
報告を読む人が誤りに気づくと、待ち時間の数字のような正しい所まで、疑いながら読むことになります。

直した文章では、二つの語だけを正しい形に直しました。文の言い回しは変えていません。
chaff が指すのは語彙表にある形だけです。「コンピュータ」と「コンピューター」のように、どちらも使われる書き方は誤りとせず、表記のゆれを見るルールに任せます。

## 設定

指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  known-misspelling: strict
```

店や商品の名前として、その字のまま書く語があるなら、chaff.yaml の `names` に足すと、その名前の中は指さなくなります。

```yaml chaff-settings
names:
  - シュミレーション工房
```
