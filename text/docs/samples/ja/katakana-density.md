# カタカナ語が多い（`katakana-density`）

**こんな文書に:** 企画書、提案書、会議の資料、社内のお知らせ。部署の中では普段の言葉でも、ほかの部署や現場の人には通じにくい語が混ざる文書です。

## 元の文章

```markdown chaff-before
# 店舗の受付を予約制にする提案

店舗運営課の西田です。来年の春から、店舗の受付を予約制に切り替えることを提案します。

## いまの課題

週末の午後は、来店したお客さまが受付で平均40分待っています。
アンケートでは、待ち時間へのクレームが一番多く、リピートの率も下がっています。
スタッフも、待っているお客さまへのフォローに追われ、本来のコンサルティングに時間を割けていません。
ピークの時間のオペレーションは、ベテランのスタッフのスキルに頼っているのが実情です。

## 提案

ウェブのフォームから、来店の日時を選べるようにします。
予約したお客さまには、前日にリマインドのメールを送ります。
予約の状況はダッシュボードで見られるようにし、スタッフのシフトもそのデータをベースに組みます。
フォームのデザインは、いまのアプリのテンプレートを流用し、コストを抑えます。

## 進め方

まず駅前店でトライアルを3か月行い、そのフィードバックをもとにオペレーションのマニュアルをアップデートします。
トライアルのKPIは、待ち時間と予約のキャンセル率の二つです。
結果は、6月のミーティングでシェアし、ほかの店舗へのロールアウトをジャッジします。
スケジュールとタスクの詳細は、別のシートにまとめてあります。
```

## 直した文章

```markdown chaff-after
# 店舗の受付を予約制にする提案

店舗運営課の西田です。来年の春から、店舗の受付を予約制に切り替えることを提案します。

## いまの課題

週末の午後は、来店したお客さまが受付で平均40分待っています。
お客さまへの聞き取りでは、待ち時間への苦情が一番多く、もう一度来てくださる方の割合も下がっています。
店員も、待っているお客さまへの声かけに追われ、本来の相談の仕事に時間を割けていません。
混む時間の受付の回し方は、慣れた店員の腕に頼っているのが実情です。

## 提案

店のホームページの申し込み画面から、来店の日時を選べるようにします。
予約したお客さまには、前日に確認のメールを送ります。
予約の状況は一つの画面で見られるようにし、店員の勤務表もその数をもとに組みます。
申し込み画面の見た目は、いまの店のアプリと同じ型を使い、費用を抑えます。

## 進め方

まず駅前店で3か月試し、そこで出た意見をもとに受付の手順書を直します。
試すときに見る数は、待ち時間と、予約を取り消した人の割合の二つです。
結果は、6月の会議で報告し、ほかの店舗にも広げるかを決めます。
日程と、誰が何をするかは、別の表にまとめてあります。
```

## 直し方

この提案は、店で毎日お客さまに接する人たちに読んでもらう文書です。
ところが「スタッフ」「オペレーション」「フォーム」「ロールアウト」「ジャッジ」と、カタカナ語が続き、言いたいことが言葉の後ろに隠れています。chaff は、1000字あたり78語と数えました。
書いた人には普段の言葉なので、多さに気づきにくいところです。

直した文章では、日本語で言える語から言い換えました（スタッフ → 店員、クレーム → 苦情、トライアル → 試す、ロールアウト → 広げる）。
「メール」「アプリ」「ホームページ」のように、読み手が普段から使っている語は、そのままにしています。全部を言い換える必要はありません。

## 設定

1000字あたりのカタカナ語の数で見ます。ふだんは55語までです。短い文書は測りません。

```yaml chaff-settings
rules:
  katakana-density: relaxed
```

`relaxed` にすると1000字あたり65語まで、`strict` にすると45語までです。
コードの中の語と、題名にあるカタカナ語は数えません。
製品名やサービス名のように言い換えられない名前は、chaff.yaml の `names` に並べると数えません。

```yaml chaff-settings
names:
  - ポイントカード
```
