# 累計が当月の値より小さい（`cumulative-below-current`）

**こんな文書に:** 売上の月報、給与明細の年初からの累計、予算の執行表。累計を打ち込むときに、桁を一つ落とす、という形がよくあります。

## 元の文章

```markdown chaff-before
# 店舗別 売上の月報（10月）

単位：千円

| 店舗 | 当月 | 年初からの累計 |
| --- | --- | --- |
| 青葉台店 | 18,420 | 176,310 |
| 緑町店 | 12,860 | 119,540 |
| 駅前店 | 21,750 | 20,480 |
| 合計 | 53,030 | 316,330 |

駅前店は、9月の改装の後、売上が戻りつつあります。
```

## 直した文章

```markdown chaff-after
# 店舗別 売上の月報（10月）

単位：千円

| 店舗 | 当月 | 年初からの累計 |
| --- | --- | --- |
| 青葉台店 | 18,420 | 176,310 |
| 緑町店 | 12,860 | 119,540 |
| 駅前店 | 21,750 | 204,800 |
| 合計 | 53,030 | 500,650 |

駅前店は、9月の改装の後、売上が戻りつつあります。
```

## 直し方

駅前店の当月の売上は21,750千円で、年初からの累計は20,480千円と書いてあります。累計は当月を含んだ合計なので、当月より小さくなることはありません。204,800の最後の「0」を落としたのでしょう。合計の行の累計も、落とした額で足してあります。
月報を読む人は、累計の列で、店ごとの今年の歩みを比べます。この表のとおりなら、駅前店の今年の売上はほかの店の数分の一に見え、改装の後に売上が戻りつつあるという説明とも合いません。

直した文章では、駅前店の累計を204,800千円にし、合計の行の累計も500,650千円に直しました。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  cumulative-below-current: strict
```

どの列が当月でどの列が累計かは、列の見出しの語（当月、今回、当期、累計、年初来）だけで決めます。「前月までの累計」のように前の期間までを言う列は、当月を含まないので累計の列としては読みません。同じ単位で書いた0以上の数だけを比べ、累計と当月が同じ値（最初の月）は言いません。マイナスの升の行や、平均や単価のように足し上げない値の行も比べません。
文学のジャンルでは止めています。合計の行の足し算は `total-mismatch` が見ます。
