# 具体物のない節がある（`concrete-evidence-density`）

**こんな文書に:** 業務改善の報告、半期の振り返り、企画の成果報告。「良くなりました」「好評です」と書くだけで、何がどれだけ良くなったのかを書かない形がよくあります。AI に下書きさせた報告書にも多い形です。

## 元の文章

```markdown chaff-before
# 受付窓口の予約制 導入の報告

## 待ち時間

予約制にしてから、窓口の待ち時間は大きく短くなりました。混み合う時間帯も、以前ほど列ができなくなりました。来られた方を待たせることが少なくなっています。

## お客様の声

お客様からの評判は上々です。電話で予約できて便利だという声を、よくいただきます。予約の取り方が分かりにくいという声も、少しありました。

## 職員の負担

職員の負担も軽くなりました。昼休みを決まった時間に取れるようになりました。窓口の準備も、前の日のうちに済ませられるようになっています。
```

## 直した文章

```markdown chaff-after
# 受付窓口の予約制 導入の報告

## 待ち時間

予約制にしてから、窓口の平均の待ち時間は、25分から8分になりました。最も混む月曜日の午前でも、列が5人を超えた日はありません。来られた方を待たせることが少なくなっています。

## お客様の声

10月に窓口で答えてもらった用紙では、予約制が便利だと答えた方が、120人のうち94人でした。電話で予約できて便利だという声を、よくいただきます。予約の取り方が分かりにくいという声も、11件ありました。

## 職員の負担

職員の残業は、一人あたり月12時間から5時間に減りました。昼休みを決まった時間に取れるようになりました。窓口の準備も、前の日のうちに済ませられるようになっています。
```

## 直し方

この報告書の三つの節は、どれも「大きく短くなりました」「評判は上々です」「負担も軽くなりました」と、良くなったことを言うだけです。
待ち時間が何分から何分になったのか、何人が便利だと答えたのか、残業がどれだけ減ったのか、一つも書いてありません。
報告を受けた人は、予約制を続けるか、ほかの窓口にも広げるかを決めたいのに、その決め手になる数がありません。

直した文章では、それぞれの節に、測った数を一つ以上書きました。
数が無いなら、お客様の声をそのまま引いたり、例を一つ挙げたりするだけでも、読み手が持ち帰るものができます。
どうしても書けることが無い節は、ほかの節にまとめられるかもしれません。

## 設定

この規則は、具体物のない節がいくつあると指摘するかが変わります。ふだんは3個から、`strict` では1個から、`relaxed` では6個から指摘します。

```yaml chaff-settings
rules:
  concrete-evidence-density: strict
```

数字、コード、リンク、固有の名前を具体物として数えます。3文より短い節、項目を並べた節、文の半分以上が問いや指示（〜してください）の節は見ません。
法令や契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、話し言葉（`speech`）、議事録（`business/meeting-notes`）、ブログ（`blog`）のジャンルでは動きません。
