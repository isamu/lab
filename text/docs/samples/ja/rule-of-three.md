# 3 項目の箇条書きばかり（`rule-of-three`）

**こんな文書に:** ブログ、紹介記事、まとめの記事。AI に下書きさせると、言いたいことが二つでも四つでも、箇条書きが三つずつにそろいます。

## 元の文章

```markdown chaff-before
# 在宅勤務の机まわりを整えた

週に三日、家で仕事をするようになって一年がたちました。
最初は食卓で仕事をしていましたが、椅子が低く、画面を見下ろす姿勢が続くので、夕方になると肩と腰が痛くなりました。
この春、机まわりを買い直したので、買ったものと、やめたものを書いておきます。

## 買ってよかったもの

- 高さを変えられる机
- 背もたれの高い椅子
- ノートパソコンを載せる台

机は、座る日と立つ日を半々にしています。
椅子は、近くの家具店で三十分ほど座り比べて決めました。

## 買ったけれど使わなくなったもの

- 足を載せる台
- 手首を載せるクッション
- 机の上に置く小さな加湿器

どれも、置き場所を取るわりに、なくても困りませんでした。

## これから試したいこと

- 午後に一度、外を歩く
- 画面を見る距離を測る
- 照明を暖かい色に変える

肩の痛みは、机と椅子を替えてから二か月ほどで、ほとんど気にならなくなりました。
```

- 高さを変えられる机
- 背もたれの高い椅子

家にいると、一日に千歩も歩かない日があるからです。

## 直し方

元の文章は、三つの箇条書きがどれも三項目です。
「ノートパソコンを載せる台」「机の上に置く小さな加湿器」「画面を見る距離を測る」は、本文で一度も触れられません。
三つにそろえるために足した項目に見え、読み手は、どの項目が書き手にとって本当に大事だったのかを見分けられません。

直した文章では、数を合わせるための項目を消しました。
買ってよかったものは、本文で話している机と椅子の二つです。
使わなくなったものは、箇条書きをやめて、なぜ要らなくなったのか（机と椅子を替えたから）を文で書きました。
これから試すことも、本当に決めている一つだけにしています。

## 設定

箇条書きのうち、3項目のものが70%を超えると指摘します。箇条書きが5つより少ない文書では、全部が3項目のときだけ指摘します。箇条書きが一つしかない文書は見ません。

```yaml chaff-settings
rules:
  rule-of-three: strict
```

`strict` にすると50%まで、`relaxed` なら90%までです。
すぐ下の行が「など」で始まる箇条書き、「家賃：8万円」のように札の後ろに数を書いた内訳、どの項目も3文以上ある箇条書きは、3項目とは数えません。
文の中に並べた三つの語（「速く、安く、確実に」）も数えません。
法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score post.md` で見られます。

```text chaff-explain

```
