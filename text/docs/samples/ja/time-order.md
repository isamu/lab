# 一日の予定の時刻が前後している（`time-order`）

**こんな文書に:** 出張や研修の旅程、式次第、イベントの進行表。予定を一つ入れ替えたときに、時刻だけが前のまま残ります。

## 元の文章

```markdown chaff-before
件名：工場見学の当日の予定

営業部のみなさま

お疲れさまです。総務課の田中です。
11月27日（金）の工場見学の予定が決まりましたので、お知らせします。

- 08:30 本社の正面玄関に集合
- 09:00 バスで出発
- 10:30 工場の見学
- 12:00 社員食堂で昼食
- 11:00 品質管理の担当者との意見交換
- 16:00 本社に到着、解散

昼食の要らない方は、11月20日（金）までに私にお知らせください。

よろしくお願いします。
```

  ⚠  一日の予定の時刻が前後している

     「11:00」が、前後の時刻の並びから外れています（前は「12:00」）
     旅程や式次第のように、頭に時刻を書いた項目を並べた箇条書きや表で、ひとつだけ前の項目より早い時刻があると、書き間違いか順番の入れ替わりかを読み手が確かめることになり、集まる時刻を間違える人も出ます。一日の予定は早い順に並ぶので、その順に逆らう時刻を指します。日付の見出しが変わるところ、行の頭の日付が変わるところで一日を区切ります。23:30 の次の 0:15 のように夜をまたぐ時刻は、翌日の印（翌、+1）があれば翌日の時刻として読みます。開場と開演、受付開始と開始、集合と出発のように、語で前後の決まった二つの時刻も比べます。開場が開演より遅いと、入れない時間に公演が始まってしまいます。

## 直した文章

```markdown chaff-after
件名：工場見学の当日の予定

営業部のみなさま

お疲れさまです。総務課の田中です。
11月27日（金）の工場見学の予定が決まりましたので、お知らせします。

- 08:30 本社の正面玄関に集合
- 09:00 バスで出発
- 10:30 工場の見学
- 12:00 社員食堂で昼食
- 13:00 品質管理の担当者との意見交換
- 16:00 本社に到着、解散

昼食の要らない方は、11月20日（金）までに私にお知らせください。

よろしくお願いします。
```

## 直し方

予定は早い順に並んでいるのに、昼食の12:00の次の意見交換だけが11:00です。
読む人は、意見交換が見学の途中にあるのか、昼食のあとにあるのかを決められません。昼食の前に会議室へ向かう人も、昼食のあとに向かう人も出ます。

工場の担当者に確かめると昼食のあとの13:00だったので、時刻を直しました。
順番のほうが違うなら、項目を並べ替えます。
chaff は、頭に時刻を書いた項目の並びで、早い順に逆らう時刻を指します。開場と開演、集合と出発のように、語で前後の決まった二つの時刻も比べます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  time-order: strict
```

日付の見出しや行の頭の日付が変わるところで、一日を区切ります。23:30 の次の 0:15 のように夜をまたぐ時刻は、翌日の時刻と読みます。
時刻が二つしかない並び、早い順に並ぶ時刻が半分以下の並び、文の中に書いた時刻は比べません。
文芸のジャンルでは、はじめから動きません。
