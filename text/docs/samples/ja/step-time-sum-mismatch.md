# 所要時間が、手順に書いた時間の和と合わない（`step-time-sum-mismatch`）

**こんな文書に:** レシピ、作業の手順書、研修の進行表。手順を一つ足したときに、所要時間を直し忘れる、という形がよくあります。

## 元の文章

```markdown chaff-before
# かぼちゃの煮物

所要時間：30分

1. かぼちゃの種を取り、一口の大きさに切ります（10分）。
2. 鍋にかぼちゃと水、砂糖、しょうゆを入れ、強火にかけます（5分）。
3. 煮立ったら落としぶたをして、弱火で煮ます（15分）。
4. 火を止めて、そのまま冷まし、味をなじませます（10分）。

冷ましている間に、かぼちゃに味がしみこみます。
```

  ⚠  所要時間が、手順に書いた時間の和と合わない

     「30分」が、手順4つに書いた時間の和（40分）と合いません
     「所要時間：60分」と書いたレシピや手順書で、番号を付けた手順の時間（（10分）、40分焼く）を足すと80分になると、読み手は時間の見積もりを誤ります。手順を足したり時間を書き換えたりしたときに、所要時間だけ直し忘れると起きます。手順の外に所要時間の見出し（所要時間、合計時間、合計）のすぐ後ろに書いた時間が一つだけあり、番号付きの手順の並びが一つで、どの手順もその手順にかかる時間をちょうど一つ書いているときに、その和と比べます。所要時間か手順の時間に目安の印（約、程度）があるときは、所要時間の1割（少なくとも5分）までの差を合うとみなします。

## 直した文章

```markdown chaff-after
# かぼちゃの煮物

所要時間：40分

1. かぼちゃの種を取り、一口の大きさに切ります（10分）。
2. 鍋にかぼちゃと水、砂糖、しょうゆを入れ、強火にかけます（5分）。
3. 煮立ったら落としぶたをして、弱火で煮ます（15分）。
4. 火を止めて、そのまま冷まし、味をなじませます（10分）。

冷ましている間に、かぼちゃに味がしみこみます。
```

## 直し方

所要時間は30分と書いてありますが、手順に書いた時間を足すと、10分と5分と15分と10分で40分です。冷まして味をなじませる手順を後から足して、所要時間を直し忘れたのでしょう。
所要時間を見て、夕食の支度に間に合うかを決める人がいます。10分足りない見積もりでは、食卓に出すときにまだ熱く、味もしみていない煮物になります。

直した文章では、所要時間を40分にしました。手順を同時に進めて30分で済むなら、そう書き添えます。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  step-time-sum-mismatch: strict
```

手順の外に所要時間の見出し（所要時間、合計時間、合計）のすぐ後ろに書いた時間が一つだけあり、番号付きの手順の並びが一つで、どの手順もその手順にかかる時間をちょうど一つ書いているときに、その和と比べます。所要時間か手順の時間に「約」や「程度」があるときは、所要時間の1割（少なくとも5分）までの差を合うとみなします。時間を書いていない手順がある並び、「10〜15分」のような幅、「10分後」のようにかかる時間でないものがあると比べません。
