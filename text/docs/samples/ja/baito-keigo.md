# バイト敬語（`baito-keigo`）

**こんな文書に:** お客さまや取引先へのメール、店の案内、電話の受け答えの手引き。接客で耳になじんだ言い方が、書いた文にもそのまま出る所です。

## 直し方

「こちらになります」は、店で品物を出すときによく聞く言い方ですが、「〜になります」は本来、何かが変わるときの言い方です（来月から有料になります）。
「よろしかったでしょうか」も、いまのことを聞いているのに、過去の形になっています。
どちらも敬語の誤りとして挙げられることが多く、取引先には、メールの手入れが足りないように読まれます。

直した文章では、「こちらです」「よろしいでしょうか」と、普通の丁寧な言い方にしました。
丁寧さは下がりません。用紙の確認という本題が、まっすぐ伝わります。

## 設定

一覧にある形が1つあれば指摘します。`relaxed` にすると、2つからです。

```yaml chaff-settings
rules:
  baito-keigo: relaxed
```

見るのは一覧にある形だけです。変化を言う「になります」（来月から有料になります）と、人から預かる「から」（お客様からお預かりした書類）は正しいので指摘しません。
小説の台詞や話し言葉の書き起こしは話したとおりに書くので、文学（`literature`）と話し言葉（`speech`）のジャンルでは動きません。
