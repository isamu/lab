# チームの表記と違う（`preferred-term`）

**こんな文書に:** 使い方の手引き、ヘルプの記事、社内の手順書。何人もで書き足していき、同じものの書き方が人によって揺れる文書です。

## 元の文章

```markdown chaff-before
# パスワードを忘れたとき

1. アプリを開き、ログイン画面の下にある「パスワードを忘れた方」を押します。
2. 登録したメールアドレスを入れて、「送信」を押します。
3. 届いたメールのリンクを開き、新しいパスワードを決めます。
4. 新しいパスワードで、もう一度ログインします。

メールが届かないときは、迷惑メールのフォルダも確かめてください。
それでも届かないときは、お問合せ窓口までご連絡ください。
```

```yaml chaff-config
prefer:
  ログイン: サインイン
  問合せ: 問い合わせ
```

## 直した文章

```markdown chaff-after
# パスワードを忘れたとき

1. アプリを開き、サインイン画面の下にある「パスワードを忘れた方」を押します。
2. 登録したメールアドレスを入れて、「送信」を押します。
3. 届いたメールのリンクを開き、新しいパスワードを決めます。
4. 新しいパスワードで、もう一度サインインします。

メールが届かないときは、迷惑メールのフォルダも確かめてください。
それでも届かないときは、お問い合わせ窓口までご連絡ください。
```

## 直し方

このアプリの画面のボタンには「サインイン」と書いてあります。手引きが「ログイン画面」と書くと、読み手は画面の中に「ログイン」という文字を探して、見つけられません。
「問合せ」と「問い合わせ」も、ほかのページと書き方がそろっていないと、サイトの中を検索したときに片方のページが出てきません。

チームは「サインイン」と「問い合わせ」に寄せると決め、chaff.yaml の `prefer` に書いていました。
直した文章では、指摘された 3 箇所をその書き方に直しました。手引きの言葉と画面の言葉がそろい、読み手は書いてある通りに押せます。

## 設定

この規則は、chaff.yaml の `prefer` に並べた組だけを見ます。左に使わない書き方、右に使う書き方を書きます。
chaff は表記の決まりを持っていません。記者ハンドブックや社内の表記の決まりから、チームで選んだものを並べます。

```yaml chaff-settings
prefer:
  # 画面のボタンの言葉に合わせる
  ログイン: サインイン
  ユーザ: ユーザー
  # 送り仮名
  問合せ: 問い合わせ
  申込み: 申し込み
  # 漢字にしない語
  下さい: ください
```

左が辞書形の動詞なら、活用した形も見つけます（「行う: おこなう」と書けば「行います」「行った」も）。
並べた時点で「使わない」と決めた書き方なので、1 箇所でも指摘します。`relaxed` にすると 3 箇所から指摘します。

```yaml chaff-settings
rules:
  preferred-term: relaxed
```

製品名や引用のように、そこだけは元の書き方を残すべき所は、stet で理由を添えて黙らせます。
どのジャンルでも動きます。`prefer` が空なら、何も言いません。

```text chaff-explain
$ npx chaffjs explain preferred-term --genre docs/manual

  チームの表記と違う   (preferred-term)

  同じものを「サーバー」とも「サーバ」とも書くと、読み手は別のものかと迷い、検索でも片方を取りこぼします。どちらに寄せるかはチームごとに違うので、chaff.yaml の prefer に「使わない書き方」と「使う書き方」の組を自分で並べてください。並べていなければ何も言いません。

  直しかた: 「prefer に並べた使う書き方」に直してください。固有名詞など、そのままにすべき箇所なら stet で理由を添えて黙らせます。

  設定できる値:
    strict   当てはまる語が 1 箇所あれば指摘
  → normal   当てはまる語が 1 箇所あれば指摘
    relaxed  当てはまる語が 3 箇所あれば指摘
    off      見ない

  いまは normal です。

  変える:  npx chaffjs relax preferred-term --why "理由"
```
