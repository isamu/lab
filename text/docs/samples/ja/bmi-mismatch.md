# BMI が身長と体重から出る値と合わない（`bmi-mismatch`）

**こんな文書に:** 健康診断の結果のお知らせ、保健指導の記録、社員の健康管理の報告。去年の結果の表を写して数を書き換えると、BMI だけが去年のまま残ります。

## 元の文章

```markdown chaff-before
# 健康診断の結果のお知らせ

10月14日に受けた定期健康診断の結果をお知らせします。

## 体の計測

| 項目 | 結果 |
| --- | --- |
| 身長 | 172.0 cm |
| 体重 | 68.0 kg |
| BMI | 25.4 |
| 腹囲 | 82.0 cm |

結果について分からないことは、健康管理室の保健師に聞いてください。
```

## 直した文章

```markdown chaff-after
# 健康診断の結果のお知らせ

10月14日に受けた定期健康診断の結果をお知らせします。

## 体の計測

| 項目 | 結果 |
| --- | --- |
| 身長 | 172.0 cm |
| 体重 | 68.0 kg |
| BMI | 23.0 |
| 腹囲 | 82.0 cm |

結果について分からないことは、健康管理室の保健師に聞いてください。
```

## 直し方

BMI は、体重（kg）を身長（m）の二乗で割った値です。68.0 kg ÷（1.72 m × 1.72 m）は、23.0 になります。
元の文章の「25.4」は、去年の結果の表から写したままの値でした。25 を超えると「肥満（1度）」と読まれるので、受け取った人は必要のない心配をし、保健指導の呼び出しにもつながります。

直した文章では、BMI を身長と体重から計算した23.0に直しました。
chaff は、書いた数の最後の桁の半分までの丸めを認めます。「23.0」なら22.95から23.05までを合っていると読みます。
一つの節（見出しから次の見出しまで）を一人の結果として読みます。前の年と並べた表のように、身長や体重が二つある節は比べません。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` にすると「誤り」、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  bmi-mismatch: strict
```

結果を配る前に必ず止めたいなら `strict` にします。文芸のジャンルでは、はじめから動きません。
