# 水増しの導入（`padded-intro`）

**こんな文書に:** 社内の報告書、提案書、ブログの記事。書き出しに困ったとき、とくに AI に下書きさせたときに、「近年、〜が注目を集めています」から始まります。

## 元の文章

```markdown chaff-before
# 問い合わせ窓口に自動応答を試した報告

## はじめに

近年、AI の活用が注目を集めています。
当社でも、10月の一か月間、問い合わせ窓口の一次回答に自動応答を試しました。
この報告では、試した結果と、続けるかどうかの案をまとめます。

## 結果

一か月に届いた問い合わせは、1,240件でした。
そのうち、自動応答だけで解決したのは、配送の状況と返品の手順を尋ねる412件です。
担当者が最初の返事を出すまでの時間は、平均で3時間から40分に縮みました。

## 案

11月からは、配送と返品の二つに限って、自動応答を続けます。
料金や契約の問い合わせは、これまでどおり担当者が答えます。
```

## 直した文章

```markdown chaff-after
# 問い合わせ窓口に自動応答を試した報告

## はじめに

当社は、10月の一か月間、問い合わせ窓口の一次回答に自動応答を試しました。
```

## 直し方

報告の一文目「近年、AI の活用が注目を集めています。」は、どの報告にもそのまま付けられる文です。読み手はこの文から何も知らされず、二文目でようやく、何の報告なのかがわかります。

直した文章では、この一文を消し、「当社は、10月の一か月間、問い合わせ窓口の一次回答に自動応答を試しました。」から始めました。試した期間と、何に使ったかが最初に出るので、読み手はすぐに本題に入れます。
書き出しを別の一般論（「今や AI は欠かせません」）に替えても、同じことです。この報告だけが言えることから始めます。

## 設定

文書の冒頭（最初の 4 文）だけを見ます。ふだんは当てはまる書き出しが 1 箇所あれば指摘し、`relaxed` にすると 2 箇所からになります。

```yaml chaff-settings
rules:
  padded-intro: relaxed
```

報告書・提案書・ブログで動き、プレスリリース、メール、議事録では動きません（冒頭は用件を言う所だからです）。法務、説明書、学術、文学、話し言葉のジャンルでも止めています。
