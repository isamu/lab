# 要旨が長すぎる、または無い（`abstract-length`）

**こんな文書に:** 論文、学会の予稿、研究の報告書。本文を書き上げて満足し、要旨を書き忘れたまま投稿の準備に入る形がよくあります。

## 元の文章

```markdown chaff-before
# 商店街の空き店舗を使った子どもの居場所づくりの効果

## はじめに

地方の商店街では空き店舗が増えている。一方で、放課後に子どもが安心して過ごせる場所は足りていない。本研究では、空き店舗を子どもの居場所に使う取り組みが、商店街の人の流れを変えるかを調べた。

## 方法

ある商店街で、空き店舗の一つを平日の午後に子ども向けに開いた。開く前の3か月と開いた後の3か月で、商店街を通る人の数を数えた。

## 結果

商店街を通る人の数は、平日の午後で1.4倍になった。子どもを迎えに来た保護者が、近くの店で買い物をする姿も見られた。
```

## 直した文章

```markdown chaff-after
# 商店街の空き店舗を使った子どもの居場所づくりの効果

## 要旨

空き店舗を平日の午後に子ども向けに開き、その前後3か月で商店街を通る人の数を比べた。平日の午後の通行量は1.4倍になり、迎えに来た保護者の買い物も増えた。子どもの居場所づくりは、商店街の人の流れを変えうる。

## はじめに

地方の商店街では空き店舗が増えている。一方で、放課後に子どもが安心して過ごせる場所は足りていない。本研究では、空き店舗を子どもの居場所に使う取り組みが、商店街の人の流れを変えるかを調べた。

## 方法

ある商店街で、空き店舗の一つを平日の午後に子ども向けに開いた。開く前の3か月と開いた後の3か月で、商店街を通る人の数を数えた。

## 結果

```

## 直し方

この論文は「はじめに」「方法」「結果」と節を立てていますが、要旨がありません。
論文を探している人は、まず題と要旨だけを読んで、本文を読むかどうかを決めます。
要旨が無いと、何を調べて何が分かったのかを知るために、本文を「結果」まで読み進めなければなりません。

直した文章では、本文の前に「要旨」の節を足し、何をしたか、何が分かったか、何が言えるかを、それぞれ一文で書きました。
要旨が長くなりすぎるときも、この規則が字数の上限を超えた所を示します。

## 設定

この規則は、要旨の字数の上限が変わります。ふだんは1000字まで、`strict` では600字まで、`relaxed` では1400字までです。

```yaml chaff-settings
rules:
  abstract-length: strict
```

要旨と読むのは、「要旨」「抄録」「Abstract」の見出しの下の文、それだけを書いた行の次の段落、段落の頭の「要旨：」「【要旨】」の後ろの文です。和文の論文の英文の Abstract は、英語の語数で測ります。
要旨が無いことは、「はじめに」「方法」「結果」「考察」のような論文の節の見出しが二つ以上ある文書だけで見ます。
論文（`academic/paper`）のジャンルでだけ動きます。
