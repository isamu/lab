# 決まった接ぎで始まる文が多い（`stock-transition`）

**こんな文書に:** お知らせ、プレスリリース、報告書、ブログ。できることを並べて紹介する文章で、AI に下書きさせると文頭に「さらに」「加えて」が続きます。

## 元の文章

```markdown chaff-before
# 図書館の本をスマートフォンで予約できるようになります

市立図書館は4月1日から、本の予約を利用者のスマートフォンで受け付けます。利用者カードの番号があれば、家にいても貸出中の本を予約でき、届いた本は本館と四つの分館のどこでも受け取れます。
これまでは、館内の端末か電話でしか予約を受け付けていませんでした。

## できること

予約した本が届くと、メールで知らせが来ます。さらに、受け取りの期限が近づくと、もう一度知らせが来ます。
加えて、借りている本の返却日も、同じ画面で確かめられます。
延長の手続きも画面から一回押すだけで済み、窓口に並ぶ必要はありません。

## 使い始めるには

図書館の利用者カードの番号と、窓口で決めたパスワードが要ります。
パスワードを決めていない人は、カードと身分証を持って、どの館の窓口でも登録できます。登録は五分ほどで終わります。
カードを無くした人は、再発行の手続きを先に済ませてください。

このように、予約から受け取り、返却日の確認までが手元で済むようになります。
電話での予約も、これまでどおり受け付けます。スマートフォンを持っていない人や、画面での操作が難しい人は、開館時間内にお電話ください。

## 問い合わせ

使い方の説明は、各館の入口に置いたチラシと、図書館のサイトの「よくある質問」に載せています。
分からないことがあれば、本館のカウンターか、電話（平日の午前9時から午後7時まで）でお尋ねください。
```

## 直し方

元の文章は「さらに」「加えて」で機能を足し、「このように」でまとめています。
どれも、前の文と何がどう繋がるのかを言わずに次へ進める語です。
重なると、できることを並べただけに見え、読み手はどれが大事なのかを自分で決めなければなりません。

直した文章では、接ぎの語を消して、繋がりを中身で書きました。
期限の前の知らせは「取り置きが流れる心配はありません」と、なぜうれしいのかまで書いています。
「このように」で始まる一文は、すぐ上の内容を言い直しているだけなので、消しました。

## 設定

決まった接ぎで始まる文が、1000字あたり3個を超えると指摘します。短い文書（500字未満）は測りません。

```yaml chaff-settings
rules:
  stock-transition: relaxed
```

`relaxed` にすると1000字あたり5個まで、`strict` なら2個までです。
話を運ぶ「また」「そのため」「しかし」と、文の途中の接ぎは数えません。
法令・契約（`legal`）、手順書（`docs`）、論文（`academic`）、文学（`literature`）、講演（`speech`）のジャンルでは、はじめから動きません。

このルールは AI らしさの目安にも数えます。文章全体の目安は `npx chaffjs ai-score release.md` で見られます。
