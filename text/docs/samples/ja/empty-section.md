# 中身の無い節（`empty-section`）

**こんな文書に:** 議事録、報告書、手順書。ひな形の見出しを残したまま、書き忘れたり、書くことが無かったりする形がよくあります。

## 直し方

この議事録は「次回までの宿題」という見出しを立てたまま、中身を何も書いていません。
会議のひな形の見出しをそのまま使い、書き込むのを忘れた形です。
読む人は、宿題が無かったのか、書き忘れたのかを区別できません。誰が何をいつまでにするのかが分からないまま、次の会議を迎えることになります。

直した文章では、会議で決めた宿題を、担当と期日を添えて書きました。
本当に宿題が無かったのなら、見出しを消すか、「今回はありません」と一行書いておくと、書き忘れでないことが伝わります。

## 設定

この規則は、指摘の重さだけが変わります。ふだんは「注意」として出し、`strict` で「エラー」、`relaxed` で「参考」になります。

```yaml chaff-settings
rules:
  empty-section: relaxed
```

見出しのすぐ後ろに、同じ深さか浅い見出しが来たときだけ指摘します。すぐ後ろに深い見出しが来る節は、小さな節に分けたものなので指しません。
文書の最後の見出しも、後ろに何も無ければ指摘します。HTML のコメントだけの節は空と数えます。
Markdown の文書でだけ動きます。どのジャンルでも動きます。
