# 節がつながりすぎている（`clause-chain`）

**こんな文書に:** 月次の報告書、議事録、提案書。考えたことを順に書き足して、一文が終わらなくなりがちな文書です。

## 元の文章

```markdown chaff-before
# 9月の問い合わせ対応の報告

カスタマーサポート課の報告です。

9月は新しい料金プランを始めた月で、問い合わせが先月より3割増えましたが、多くは請求の画面の見方についてで、画面に説明を足せば減らせると考えられるので、来月の改修に合わせて説明の文を見直し、そのうえで問い合わせの件数をもう一度数えて、効果を確かめる予定です。

対応の時間は、一件あたり平均12分でした。
```

## 直した文章

```markdown chaff-after
# 9月の問い合わせ対応の報告

カスタマーサポート課の報告です。

9月は新しい料金プランを始めた月で、問い合わせが先月より3割増えました。
ただし、多くは請求の画面の見方についてのもので、画面に説明を足せば減らせると考えています。
そこで、来月の改修に合わせて説明の文を見直します。
改修のあとで問い合わせの件数をもう一度数え、効果を確かめる予定です。

対応の時間は、一件あたり平均12分でした。
```

## 直し方

元の文は「始めた月で」「増えましたが」「見方についてで」「考えられるので」「見直し」「数えて」と六か所でつなぎ、節が七つ続いています。
読み手は、問い合わせが増えた話なのか、画面を直す話なのか、効果を確かめる話なのかを覚えたまま、最後の「予定です」まで待つことになります。

直した文章では、「が」と「ので」の所で文を切り、つながりを「ただし」「そこで」で言い直しました。
増えたこと、増えた理由、直すこと、確かめること、と一文に一つずつ収まり、報告の筋が上から順に読めます。

chaff が数えるのは、「て」「が」「ので」のような文をつなぐ助詞と、読点で止めた動詞（見直し、）です。
「調べている」のような一つの述語の中のつなぎは数えません。

## 設定

報告書（`business/report`）では、一文に節が五つまでなら指摘しません。`strict` にすると四つ、`relaxed` にすると七つまでです。
法務のジャンルでは別の数字を持ち、文学のジャンルでは既定で止めています。

```yaml chaff-settings
rules:
  clause-chain: relaxed
```

見ないことにするなら `clause-chain: off` です。コマンドでも変えられ、理由が chaff.yaml にコメントで残ります。

```bash
npx chaffjs relax clause-chain --why "経緯を一文で書く議事録の形に合わせるため"
```
