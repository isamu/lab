# 移動の時間より短い乗り継ぎ（`connection-time-short`）

**こんな文書に:** 出張や見学や修学旅行の旅程。移動にかかる時間を書き添えたのに、次の予定の時刻をそれより早く組んでしまう、という形がよくあります。

## 元の文章

```markdown chaff-before
# 京都の工場の見学の旅程

12月15日（火）に、営業部の五人で取引先の工場を見学します。

- 08:00 のぞみ203号（東京 08:00発、京都 10:15着）
- 10:25 京都駅の八条口から貸切バスで工場へ（八条口まで歩いて約15分）
- 11:00 工場の見学と質疑
- 13:00 工場の食堂で昼食
- 15:30 のぞみ240号（京都 15:30発、東京 17:45着）

集合は、東京駅の18番線のホームです。
```

## 直した文章

```markdown chaff-after
# 京都の工場の見学の旅程

12月15日（火）に、営業部の五人で取引先の工場を見学します。

- 08:00 のぞみ203号（東京 08:00発、京都 10:15着）
- 10:35 京都駅の八条口から貸切バスで工場へ（八条口まで歩いて約15分）
- 11:10 工場の見学と質疑
- 13:00 工場の食堂で昼食
- 15:30 のぞみ240号（京都 15:30発、東京 17:45着）

集合は、東京駅の18番線のホームです。
```

## 直し方

新幹線は10時15分に京都に着き、バスは10時25分に出ます。間は10分しかありませんが、旅程には、八条口まで歩いて約15分と書いてあります。書いたとおりに歩くと、バスが出てから5分後に乗り場に着きます。
五人のうち誰か一人でも遅れれば、バスはその人を待ち、工場の見学も遅れて始まります。旅程の時刻を信じて動く人ほど、困ることになります。

直した文章では、バスを10:35にし、それに合わせて見学の始まりを11:10にしました。歩く時間のほうが長めに見積もってあるだけなら、時刻はそのままにして「約15分」を直します。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  connection-time-short: strict
```

移動の時間は、文書に書いたものだけを使います。実際にどれだけかかるかを chaff が推し量ることはありません。「徒歩10分以内」のように上限として書いた時間、すぐ前の時刻が着でない所、日付の違う時刻、夜をまたいで時刻が戻る所は言いません。
文学のジャンルでは止めています。
