# 差引額が、総額から控除合計を引いた額と合わない（`net-amount-mismatch`）

**こんな文書に:** 給与明細、賞与の明細、売買代金の精算書。控除の一つを直したあとで、差引額だけを打ち直したときに、数字の並びを取り違える、という形がよくあります。

## 元の文章

```markdown chaff-before
# 給与明細（2026年10月分）

製造部　佐藤様

## 支給

- 基本給：236,000円
- 時間外手当：18,420円
- 通勤手当：12,600円

## 控除

- 健康保険料：13,860円
- 厚生年金保険料：25,620円
- 雇用保険料：1,602円
- 所得税：6,170円
- 住民税：11,300円

## 合計

| 総支給額 | 控除合計 | 差引支給額 |
| --- | --- | --- |
| 267,020円 | 58,552円 | 208,648円 |

差引支給額は、10月25日に指定の口座へ振り込みます。
```

## 直し方

総支給額267,020円から控除合計58,552円を引くと、差引支給額は208,468円です。明細には208,648円と書いてあり、下三桁の「4」と「6」が入れ替わっています。
給与明細を受け取る人は、差引支給額だけを見て、口座に入る額を確かめます。この明細のとおりなら180円多く振り込まれるはずなので、実際に振り込まれた額と食い違い、経理に問い合わせることになります。

直した文章では、差引支給額を208,468円にしました。総支給額と控除合計は、それぞれ上の内訳を足した額と合っています。

## 設定

ふだんは「注意」として出します。`strict` にすると「エラー」に、`relaxed` にすると「参考」になります。

```yaml chaff-settings
rules:
  net-amount-mismatch: strict
```

同じ表か同じ節に、総支給額、控除合計、差引支給額の名前が一つずつあり、それぞれに金額があるときに比べます。この見本のように合計を一つの表にまとめた明細や、一つの節に「総支給額：」「控除合計：」「差引支給額：」の行を並べた明細を読みます。三つの名前が別々の表や節に分かれているときは比べません。文の中の金額や、「振込額」のように語彙表に無い名前も読みません。
文学のジャンルでは止めています。残高の足し引きは `closing-balance-mismatch` が見ます。
